Webディレクターの週2〜3日・副業案件｜探し方と受けるときの注意点

公開 2026-11-04　監修：株式会社エージェントベスト

Webディレクターの週2〜3日・副業の案件は、公開後の運用と改善、事業会社のWeb担当の支援、小さなサイトの制作で見つかりやすくなります。一方で、関係者が多い大きなサイトの作り直しは、毎日の確認の進行が要るため、週5日の稼働が中心です。

短い稼働で受けるときは、担う範囲を絞り、稼働する曜日と稼働日以外の連絡の扱いを先に決めておくことが大切です。この記事では、見つかりやすい案件の型、探し方、信頼を得る進め方、契約・税金・会社の副業規程の注意点を整理します。週3日の働き方全般は週3日の案件の記事で解説しています。

週2〜3日で受けやすい仕事と、受けにくい仕事

Webディレクターの仕事は、決まった周期で回る仕事と、毎日のように判断が要る仕事に分かれます。週2〜3日に向くのは前者です。

向き仕事の例理由
受けやすい月次の更新の段取り、解析の数字の報告、改善の提案周期が決まっていて、稼働日にまとめて進められる
受けやすい事業会社の要望の取りまとめ、制作会社への依頼書づくり週に数回の打ち合わせと資料づくりで回る
条件しだい小さなサイトの制作の進行関係者が少なく、確認の待ち時間を稼働日以外に回せる
受けにくい大きな作り直しの進行、公開日直前の対応確認と指摘が毎日発生し、返答が遅れると全体が止まる

公開日の直前や不具合の対応は、稼働日を選べないことがあります。週2〜3日で受けるなら、時間に追われる局面をだれが受け持つかを最初に確かめておく必要があります。

週2〜3日・副業で見つかりやすい案件の型

運用と改善を受け持つ案件

公開済みのサイトの更新の受付、作業者への依頼、月次の報告と改善の提案を担う案件です。周期が決まっているため、短い稼働と相性がよい型です。解析の数字を読み、改善の案を出せると、選べる案件が広がります。

事業会社のWeb担当を支える案件

社内にWeb担当が少ない会社で、要望の整理や制作会社とのやり取りを支える案件です。週に1〜2回の定例会議と、その間の資料づくりやチャットでの返答が中心になります。社内の承認は担当の社員が行い、ディレクターは判断の材料をそろえる、という分担がよく見られます。

小さなサイトの制作の進行

ページ数の少ないサイトや、キャンペーンのページなど、関係者が少ない制作です。進行の期間が短く、稼働も週の一部で回せる場合があります。ただし、公開日の前後は稼働が増えやすい点に注意が必要です。

コンテンツの制作の進行

記事や事例のページを継続して出す案件で、月の掲載計画、ライターへの依頼、原稿の確認を担います。取材や撮影の立ち会いがある場合は、その日程が稼働日と合うかを確かめましょう。

エージェントベストの見解

Webディレクターの案件をご紹介していると、週2〜3日で長く続く方は、運用や支援の案件で「自分が受け持つ範囲」と「社員の方や他の担当が受け持つ範囲」を最初にはっきりさせている方が多い傾向があります。反対に、制作の進行を週2〜3日で受け、公開日の前後に連絡が集中して、稼働の見込みと実際がずれてしまうケースも見られます。公開日の前後の動き方は、参画前に確かめておくことをおすすめします。

週2〜3日の案件の探し方

1. 担える範囲を先に決める

「運用の段取りと月次の報告まで」「要望の整理と依頼書づくりまで」のように、受け持つ範囲を言葉にしておきます。範囲が決まっていると、案件側も週の稼働で足りるかを判断しやすくなります。

2. 稼働する曜日と、稼働日以外の連絡の扱いを決める

定例会議に出られる曜日と時間帯、稼働日以外のチャットにどこまで返すかを決めておきます。会社員の副業なら、平日の日中に会議に出られるかが大きな分かれ目です。夜や週末だけで回す働き方は週末フリーランスの記事で解説しています。

3. リモートで回せる案件から選ぶ

週2〜3日の案件は、移動の時間を減らせるリモートの案件と相性がよい傾向があります。ただし、取材や撮影、立ち上げの打ち合わせで出社が要る場合もあります。リモートの度合いの見分け方はWebディレクターのリモート案件の記事をご覧ください。

4. 経験の近い案件から選ぶ

短い稼働では、現場に慣れるまでの時間も限られます。これまで担ってきたサイトの種類や工程に近い案件から選ぶと、早く信頼を得られます。

5. 「週2〜3日」の根拠を確かめる

案件票に週2〜3日とあっても、その日数がどう決まったかは案件によって違います。予算から逆算した日数なのか、今の作業量を見積もった日数なのかで、参画後の忙しさは変わります。面談では、今の担当者がどのくらいの時間を使っているか、繁忙の時期はいつかを聞いておくと、稼働の見込みとのずれを防げます。聞き方は業務委託の面談で聞いておくべき逆質問が参考になります。

短い稼働で信頼を得る進め方

週2〜3日の稼働では、いないあいだも仕事が止まらない仕組みをつくることが信頼につながります。

  1. 稼働日を見える形にする：チャットの表示やカレンダーで、いつ返答できるかを共有する
  2. 依頼の窓口をひとつにする：依頼をタスク管理の画面に集め、稼働日にまとめて段取りする
  3. 確認の期限を先に置く：発注元や作業者に、次の稼働日までに何を確かめてほしいかを伝えておく
  4. 週の終わりに短く報告する：進んだこと、止まっていること、次の稼働日にやることを書いて残す
  5. 急ぎの連絡の線を決める：不具合や公開の差し止めなど、稼働日以外でも受ける連絡を取り決めておく

掛け持ちで複数の案件を受ける場合は、稼働日が重ならないように組むことも大切です。考え方は掛け持ちの記事で整理しています。

受けるときの注意点

範囲と稼働日数をそろえる

週2〜3日の契約なのに、受け持つ範囲が週5日の案件と同じ、ということが起きがちです。契約書の業務の範囲が、合意した稼働で回る内容になっているかを確かめましょう。範囲が少しずつ広がるときの扱いは作業範囲が広がったときの契約の扱いをご覧ください。

稼働時間の記録と精算を確かめる

月の稼働時間に幅を決めて精算する契約では、短い時間の作業やチャットの返答も記録に入るかを確かめておきます。精算の仕組みは精算幅の記事で解説しています。

公開日の前後の稼働の増え方を確かめる

公開日や大きな更新の前後に、稼働が増えるかどうか、増えた分をどう扱うかを先に話しておきます。

注意

副業で得た所得は、金額や会社員としての状況によって確定申告が必要になる場合があります。住民税の扱いも含め、判断に迷う場合は税理士や税務署にご相談ください。考え方は副業の20万円ルールの記事で整理しています。

会社員の副業でWebディレクター案件を受けるとき

会社員が副業で業務委託の案件を受けるときは、まず勤め先の就業規則を確かめます。厚生労働省は「副業・兼業の促進に関するガイドライン」を公表しており、2022年7月に改定しています。同省のモデル就業規則でも、副業・兼業に関する規定が設けられています（2026年10月時点）。ただし、実際にどこまで認められるかは、勤め先の規則と手続きによります。

Webディレクターの場合は、次の点も確かめておきましょう。

  • 競業の扱い：勤め先が制作会社なら、同じ業界の会社や、勤め先の取引先から案件を受けてよいか
  • 情報の扱い：勤め先で知った発注元の情報や制作の型を、副業で使わないこと
  • 時間帯：副業の会議や連絡が、本業の勤務時間に食い込まないこと

副業の禁止規定がある場合の考え方は副業禁止の会社で業務委託を受けるときの記事、副業での業務委託の全体像は副業で業務委託を受けるときの記事で解説しています。

エージェントベストの見解

当社では、案件をご案内する前に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをお出ししています。週2〜3日や副業でのご希望の場合は、会議に出られる曜日と時間帯、稼働日以外の連絡にどこまで応じられるかもあわせてお伝えいただくと、案件を照らし合わせやすくなります。案件票に書かれていない公開日の前後の動き方は、ご質問いただければ確認します。

ポイント

  • 週2〜3日のWebディレクター案件は、運用と改善、事業会社の支援、小さなサイトの制作で見つかりやすい
  • 大きな作り直しの進行や公開日直前の対応は、週5日の稼働が中心になりやすい
  • 受け持つ範囲と稼働する曜日、稼働日以外の連絡の扱いを先に決めておく
  • 会社員の副業では、就業規則、競業、情報の扱い、確定申告の要否を確かめる

よくある質問

週2〜3日の案件でも、Webディレクターとしての経験として評価されますか？

評価されます。大切なのは稼働日数より、何を受け持ち、何を決めたかです。スキルシートには稼働日数とあわせて、担った範囲と判断の中身を書きましょう。書き方はWebディレクターのスキルシートの書き方で解説しています。

週2日で始めて、あとから稼働を増やすことはできますか？

案件によっては可能です。ただし、取引先の予算や体制によるため、最初から増やせる前提で受けるのは避けたほうが無難です。増やしたい希望があれば、契約更新の前に相談しましょう。

平日の夜や週末だけでもWebディレクターの案件は受けられますか？

数は限られますが、運用の段取りやコンテンツの原稿の確認など、時間帯を選ばない仕事なら受けられる場合があります。発注元との定例会議が平日の日中にある案件は難しいため、会議の有無と時間帯を最初に確かめましょう。

 副業・複業

週末・夜だけの業務委託案件はある？探し方と会社員が注意すること

週末・夜だけの業務委託案件はありますが、平日日中の稼働を前提にした案件より数は限られます。範囲を区切れる開発や相談・レビューなどで見つかりやすく、勤務先の副業の規定、本業との時間の切り分け、確定申告を確かめておくことが大切です。

 副業・複業

会社員の副業で業務委託案件を受けるときの注意点｜就業規則・契約・税金の確かめ方

会社員が副業で業務委託案件を受けるときは、勤務先の就業規則、本業との競合や秘密の扱い、契約条件、確定申告と住民税の4点を先に確かめます。業務委託は会社員の給与とルールが違うため、受ける前の整理が大切です。

 副業・複業

副業禁止の会社で業務委託を受けるリスク｜就業規則の読み方と許可の求め方

就業規則で副業が禁止・許可制の会社で無断で業務委託を受けると、懲戒などの対象になるおそれがあります。厚生労働省のガイドラインの考え方を踏まえつつ、規則の読み方、許可の求め方、断られたときの選択肢と相談先を整理します。

 副業・複業

副業の確定申告｜所得20万円のルールの正しい理解と、住民税の申告が別に要る理由

副業の所得が20万円以下なら確定申告が不要になるのは、給与を1か所から受け年末調整を受けている人などに限られます。20万円は収入ではなく所得で数え、住民税の申告は別に必要なことがあります。医療費控除などで申告するときは副業分も含めます。

 リモート・稼働日数

複数の案件を掛け持ちするときの注意点｜契約・時間・情報管理の確認

案件の掛け持ちは、契約で他の仕事が制限されていないか、稼働の時間帯が重ならないか、情報を案件ごとに分けて扱えるかを先に確かめれば進めやすくなります。参画前に確認したい点と、掛け持ち中の進め方を整理します。
