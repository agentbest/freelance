ノーコード・ローコード開発者の週2〜3日・副業案件｜探し方と受けるときの注意点

公開 2026-11-04　監修：株式会社エージェントベスト

ノーコード・ローコード開発者の週2〜3日・副業案件は、フリーランスの案件の中では比較的見つかりやすい分野です。ブラウザで作業できるツールが多く、既存のアプリの改修や運用の支援、社内の作り手の伴走など、毎日いなくても回る仕事が多いためです。一方で、新しい業務アプリを短い期間で作り上げる案件や、利用開始の直前の時期は、週5日に近い稼働を求められることがあります。

受けるときは、担える範囲と稼働の曜日を先に決め、依頼の受け付け方と稼働外の連絡の扱いを契約の前にそろえておくことが大切です。この記事では、週2〜3日で見つかりやすい案件の型、探し方、短い稼働で信頼を得る進め方、受けるときの注意点を整理します。週3日案件全般の考え方は週3日のフリーランス案件の記事で解説しています。

週2〜3日の案件が比較的多い理由

ノーコード・ローコードの仕事には、短い稼働と相性のよい性質がいくつかあります。

  • 作業の単位が小さい：項目の追加、一覧の修正、通知の設定など、1件の改修が数時間で終わることが多い
  • 場所を選ばない：発注側の環境にアクセスできれば、ブラウザから作業できるツールが多い
  • 発注側の事情：社内の作り手を支える人や、改修の依頼を受ける人は、毎日いなくても困らない一方、常勤で雇うほどの量はないことが多い

逆に、週2〜3日では回しにくい案件もあります。業務の聞き取りから利用開始までを短い期間で終える案件、利用者が多いアプリの切り替えの時期、社外向けのサービスの公開の直前などです。こうした時期は、打ち合わせと作業の回転が速く、稼働日以外にも判断を求められやすくなります。

週2〜3日・副業で見つかりやすい案件の型

案件の型主な仕事週2〜3日との相性
既存アプリの改修・運用支援改修依頼の対応、問い合わせへの回答、軽い整理よい。依頼をまとめて処理できる
内製化・社内展開の伴走作り手からの相談、勉強会、ルールの見直しよい。定例の日を決めやすい
小規模な業務アプリの構築一つの部署の申請や管理のアプリを作る期間に余裕があればよい
拡張・連携の部分的な開発JavaScript や API での機能の追加よい。作業を切り出しやすい
社外向けWebサービスの改善公開済みのサービスの機能追加や改善公開後ならよい。公開前は稼働が増えやすい

副業として平日の夜や週末に受けられるのは、主に改修・運用支援と、拡張の部分的な開発です。業務の聞き取りや社内の打ち合わせは、発注側の勤務時間に合わせる必要があるため、平日の日中にまったく時間が取れないと担える範囲が限られます。週末だけの働き方の考え方は週末だけのフリーランスの記事をご覧ください。

エージェントベストの見解

ノーコード・ローコードの案件をご紹介していると、週2〜3日の案件で長く続く方は、稼働日以外の連絡の扱いを最初に決めている方が多い印象です。改修の依頼はチャットで随時届きやすく、返事の速さを期待されるうちに、実際の作業時間が契約より増えていくことがあります。「次の稼働日にまとめて対応する」「急ぎの依頼の基準」を参画の前に発注側と合わせておくことをおすすめします。

週2〜3日の案件の探し方

1. 担える範囲を先に決める

改修と運用支援だけか、小さなアプリの構築までか、聞き取りや設計も担うのかを決めます。週2〜3日で全部を担うと、どこかが手薄になります。担える範囲がはっきりしていると、発注側も切り出しやすくなります。

2. 稼働する曜日と時間帯を決める

週2日なら何曜日か、副業なら平日の夜と週末のどちらか、打ち合わせに出られる時間帯はいつかを決めておきます。発注側の定例の会議に毎週出られるかどうかは、案件を選ぶときの大きな条件になります。

3. ツール名と業務の名前の両方で探す

ノーコード・ローコードの案件は、「業務改善」「内製化支援」「社内システムの運用支援」などの名前で募集されることがあります。ツールの名前と、運用・改修・伴走といった業務の名前の両方で探すと見つけやすくなります。

4. 週5日の案件の一部を切り出してもらう

週5日で募集されている案件でも、改修や拡張の部分だけを週2〜3日で担う形にできる場合があります。フリーランスエージェントを使う場合は、稼働日数の希望と、担える範囲を先に伝えておきましょう。

短い稼働で信頼を得る進め方

稼働が短い分、いない日にも仕事が進んでいると発注側に感じてもらう工夫が要ります。

  1. 依頼の窓口を一つにする：チャット、メール、口頭の依頼を混ぜず、一覧で受けて優先順位を発注側に決めてもらう
  2. 稼働日の最初と最後に報告する：その日に対応する依頼と、終わった依頼、次回に回すものを短く伝える
  3. 試験用の環境で確かめてから反映する：本番に直接手を入れず、確かめた結果を見せてから反映する
  4. 変更の記録を残す：何を、なぜ変えたかを、発注側も見られる場所に残す
  5. 社内の人が直せる部分を増やす：簡単な改修は社内の担当者ができるよう、手順を残しておく

5は、稼働を減らす方向に見えますが、発注側にとっては頼りになる進め方です。社内で直せる範囲が広がるほど、自分は設計や拡張など判断の重い部分に時間を使えます。

受けるときの注意点

稼働日数と責任の範囲をそろえる

週2〜3日の契約で、「アプリの不具合にはすぐ対応してほしい」と期待されると、稼働日以外にも拘束されます。障害や急ぎの依頼のときに誰が最初に対応するのか、稼働日以外の対応は契約に含まれるのかを確かめておきましょう。

稼働時間の記録と精算を確かめる

準委任の契約では、月の稼働時間の幅と、超えたときや足りないときの扱いを確かめます。チャットでの短いやり取りを稼働に数えるかどうかも、最初に決めておくと行き違いを防げます。仕組みは精算幅の記事で解説しています。小さなアプリを作って納める請負の形なら、何をもって完成とするか、修正の範囲をどこまでとするかを決めておきます。違いは準委任契約と請負契約の違いをご覧ください。

依頼が少しずつ増えることに備える

ノーコード・ローコードは作るのが速いため、「この画面も少し」「別の部署のアプリも」と依頼が広がりやすい分野です。契約の業務範囲を超える依頼は、引き受ける前に条件の見直しを相談しましょう。考え方は作業範囲が広がったときの契約の扱いで解説しています。

複数の案件を掛け持ちするとき

週2〜3日の案件を二つ組み合わせる場合は、それぞれの発注側の環境やアカウントを混同しないこと、打ち合わせの曜日が重ならないことを確かめます。進め方は複数の案件を掛け持ちするときの記事をご覧ください。

注意

ツールやプラグインの費用、作業に使うアカウントを、自分の名義で用意してしまうと、契約が終わったときに引き継げなくなります。短い稼働の案件ほど、「とりあえず自分のアカウントで」と始めてしまいがちです。費用の負担者と契約の名義が発注側になっているかを、作業を始める前に必ずご確認ください。

会社員の副業で受けるとき

会社員のまま副業で受ける場合は、次の3点を確かめてから始めましょう。

  • 勤務先の副業の規程：副業が認められているか、届け出が必要か、同じ業種の仕事に制限がないか。規程に反するリスクは副業禁止の会社で業務委託を受けるリスクで解説しています
  • 確定申告と住民税：副業の所得の扱いと申告の要否は所得20万円のルールの記事、勤務先に知られるかどうかの仕組みは住民税の記事をご覧ください。個別の判断は税理士・専門家にご相談ください
  • 使える時間の見積もり：本業の繁忙期と、発注側の打ち合わせの時間帯が重ならないか。考え方は副業に使える時間の見積もり方で整理しています

勤務先で使っているツールと同じツールの案件を受けるときは、勤務先で作ったアプリの設計やデータを持ち出さないよう、特に注意が必要です。副業で業務委託を受けるときの全体の注意点は副業で業務委託案件を受けるときの注意点にまとめています。

エージェントベストの見解

当社では、案件をご案内するときに、先に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをお出ししています。週2〜3日の案件では、稼働する曜日や打ち合わせに出られる時間帯で合う・合わないが分かれます。契約では業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししていますので、稼働日以外の対応の扱いなど気になる点は、ご質問いただければ確認します。

ポイント

  • ノーコード・ローコードは、週2〜3日・副業の案件が比較的見つかりやすい分野
  • 見つかりやすいのは、改修・運用支援、内製化の伴走、小規模な構築、拡張の部分的な開発
  • 依頼の窓口を一つにし、稼働日の最初と最後に報告すると、短い稼働でも信頼を得やすい

よくある質問

平日の夜と週末だけでも、ノーコード・ローコードの案件は受けられますか？

改修や拡張の部分的な開発など、打ち合わせの少ない仕事なら受けられることがあります。ただ、業務の聞き取りや発注側との定例の会議は平日の日中に入ることが多いため、担える範囲は限られます。どの時間帯に連絡を返せるかを最初に伝えておきましょう。

週2〜3日の案件でも、設計から任せてもらえますか？

小さな部署の業務アプリなど、期間に余裕のある案件では任されることがあります。聞き取りの打ち合わせを稼働日に固めて入れられるかが分かれ目になります。急ぎの案件では、設計は社内の担当者が担い、構築と拡張を任される形が多くなります。

週3日で始めて、あとから稼働を増やすことはできますか？

発注側の依頼が増え、双方の条件が合えば、稼働日数を見直すことはあります。ただ、最初から増える前提で受けると、本業や他の案件との調整が難しくなります。増やす場合は、契約の更新の時期に合わせて条件を見直すのが現実的です。

リモート・稼働日数

週3日の業務委託案件｜働き方と探し方、収入と稼働の考え方

週3日の業務委託案件は、経験のある職種で、担当範囲がはっきりした業務なら見つけやすい働き方です。報酬は稼働日数に応じて決まることが多く、残りの日の使い方まで含めて考えることが大切です。探し方と確認点を整理します。

 副業・複業

週末・夜だけの業務委託案件はある？探し方と会社員が注意すること

週末・夜だけの業務委託案件はありますが、平日日中の稼働を前提にした案件より数は限られます。範囲を区切れる開発や相談・レビューなどで見つかりやすく、勤務先の副業の規定、本業との時間の切り分け、確定申告を確かめておくことが大切です。

 副業・複業

会社員の副業で業務委託案件を受けるときの注意点｜就業規則・契約・税金の確かめ方

会社員が副業で業務委託案件を受けるときは、勤務先の就業規則、本業との競合や秘密の扱い、契約条件、確定申告と住民税の4点を先に確かめます。業務委託は会社員の給与とルールが違うため、受ける前の整理が大切です。

 副業・複業

副業禁止の会社で業務委託を受けるリスク｜就業規則の読み方と許可の求め方

就業規則で副業が禁止・許可制の会社で無断で業務委託を受けると、懲戒などの対象になるおそれがあります。厚生労働省のガイドラインの考え方を踏まえつつ、規則の読み方、許可の求め方、断られたときの選択肢と相談先を整理します。

 副業・複業

副業の確定申告｜所得20万円のルールの正しい理解と、住民税の申告が別に要る理由

副業の所得が20万円以下なら確定申告が不要になるのは、給与を1か所から受け年末調整を受けている人などに限られます。20万円は収入ではなく所得で数え、住民税の申告は別に必要なことがあります。医療費控除などで申告するときは副業分も含めます。

 副業・複業

副業は会社に知られる？住民税の仕組みと「自分で納付」の選び方

会社員の住民税は給与から天引きされ、税額の通知は会社にも届くため、副業の所得が住民税額に表れることがあります。業務委託の副業なら、確定申告書で副業分を「自分で納付」に選べる場合がありますが、自治体の扱いで変わります。
