フリーランスにPower BIの認定資格（PL-300）は役立つ？評価される場面と準備

公開 2026-10-29　監修：株式会社エージェントベスト

Power BIの認定資格（試験PL-300）は、フリーランスにとってPower BIの案件で、データの準備からモデル化・可視化・管理までを体系的に学んだことの裏付けになります。ただし、資格がなくても、Power BIで作ったレポートが業務で使われた実績があれば参画できる案件は多くあります。

効きやすいのは、Power BIの経験がまだ短い時期や、DAXを使ったモデル設計、ワークスペースや権限の管理まで任される案件です。この記事では、試験の中身、効く場面と効かない場面、実務との組み合わせ方、スキルシートでの書き方を整理します（2026年10月時点のMicrosoft Learnの内容による）。

PL-300で取れる認定と試験の中身

PL-300に合格すると「Microsoft認定: Power BI データ アナリスト アソシエイト」を取得できます。レベルは中級、対象の役割はデータアナリストと位置づけられています。

項目2026年10月時点のMicrosoft Learnの内容
認定の名称Microsoft認定: Power BI データ アナリスト アソシエイト
試験PL-300
試験時間100分。監督付きで、対話型の問題が含まれることがある
言語日本語を含む複数の言語で提供
合格の基準700点以上
更新12か月ごと。Microsoft Learnの無料のオンライン評価に合格して更新する

受験者には、Power Query とDAX（データ分析式）の使用に習熟していることが求められています。2026年4月20日時点の測定されるスキルは、次の4分野です。

  • データの準備（25〜30%）：データソースへの接続、データの品質の確認と整形、ファクトとディメンションのテーブルの作成など
  • データのモデル化（25〜30%）：リレーションシップの設計、共通の日付テーブル、DAXでのメジャーや計算グループ、モデルの性能の改善など
  • データの視覚化と分析（25〜30%）：レポートの作成、ブックマークやドリルスルーなどの操作の設計、Copilotを使ったレポート作成、外れ値の検出など
  • Power BIの管理とセキュリティ保護（15〜20%）：ワークスペースとアプリの管理、更新のスケジュール、ゲートウェイ、行レベルのセキュリティ、機密ラベルなど

試験は定期的に更新され、英語版が先に更新されて、日本語などのローカライズ版は英語版の更新から約8週間後に更新されると案内されています。受験の前に、学習ガイドで最新の範囲を確かめてください。

案件で効く場面と効かない場面

効きやすい場面

  • Power BIの経験がまだ短いとき：Excelでの集計や別のBIツールの経験はあるが、Power BIの実務は短い、という段階で、機能を体系的に学んだことを示せます
  • モデル設計やDAXを任される案件：試験の範囲がデータモデルとDAXに大きく割かれているため、レポートの見た目より計算の正しさや性能が問われる案件と重なります
  • Microsoft 365やAzureを使う会社の案件：Microsoftの製品で業務をそろえている発注先では、ほかのMicrosoft認定と並べて見られることがあります。Azureの認定の考え方はAzureの認定資格の記事をご覧ください

効きにくい場面

  • 分析の結論を求められる案件：どの指標で何を判断するかを任される案件では、ツールの操作より分析の経験が先に見られます
  • データ基盤の構築が中心の案件：Power BIにデータを渡す側のDWHやパイプラインが中心なら、基盤の実績が評価の中心です。詳しくはデータエンジニアのスキルの記事をご覧ください
  • Tableauなど別のBIツールを使う案件：可視化の考え方は通じますが、製品の認定としての効き目は薄れます。Tableauの案件ならTableauの認定資格の記事を参考にしてください

エージェントベストの見解

案件紹介の現場では、Power BIの案件の面談で、レポートの画面よりも「データの更新がどう回っていたか」「誰がどこまで見られる設定にしたか」を聞かれる傾向があります。作成だけでなく運用まで話せる人は、任せられる範囲が広いと受け取られやすくなります。PL-300の管理とセキュリティの分野で学んだことを、実際の設定の経験と結びつけて話せるようにしておくことをおすすめします。

実務経験との組み合わせ方

PL-300の4分野は、Power BIの案件の作業の流れとほぼ重なっています。自分の経験を分野ごとに書き出すと、強みと空白が見えます。

  1. データの準備：どのデータソースにつなぎ、Power Queryでどんな整形をしたか。インポートとDirectQueryなど接続の方式を選んだ理由
  2. モデル化：スタースキーマの形にそろえた経験、DAXで作った指標、性能の改善のために行ったこと
  3. 視覚化と分析：見る人の目的に合わせたページの構成、操作の設計、外れ値や傾向の見せ方
  4. 管理とセキュリティ：ワークスペースとアプリでの配布、更新のスケジュール、ゲートウェイの設定、行レベルのセキュリティの実装

実務で触れてこなかった分野は、試験の学習で補います。たとえば、レポートの作成は経験があっても、行レベルのセキュリティやゲートウェイを設定したことがない人は多いはずです。そうした分野を検証の環境で試しておくと、試験にも面談にも生きます。

スキルシートでの書き方

資格欄には、認定の正式な名称、試験の番号、取得した年月、有効期限を書きます。PL-300で取れる認定は毎年の更新が必要なため、有効期限を書いておくと、読み手が状態を確かめやすくなります。

  • 資格欄の例：「Microsoft認定: Power BI データ アナリスト アソシエイト（PL-300） 20XX年X月 取得／有効期限 20XX年X月」

経歴欄には、レポートの利用者、データの範囲、運用で担ったことを書きます。

  • 「経営会議向けの売上レポートを作成。複数のシステムのデータをPower Queryで統合し、DAXで前年比などの指標を実装」
  • 「部門別の閲覧範囲を行レベルのセキュリティで設定し、ワークスペースとアプリで配布。更新のスケジュールとゲートウェイの設定を担当」

書き方の全体はスキルシートの書き方の記事で紹介しています。

注意

Microsoftのアソシエイトの認定は、更新しないと期限が切れます。更新の評価は、有効期限の前の6か月間に受けられ、無料・オープンブックで、期限が切れる前であれば何度でも受けられると案内されています。期限が切れてから気づくことのないよう、更新の時期を予定に入れておいてください。基礎レベルの認定は期限切れにならないとされており、アソシエイトとは扱いが違う点にもご注意ください。

受験の準備と案件との両立

学習ガイドで範囲を確かめる

Microsoft Learnの学習ガイドには、測定されるスキルの一覧と変更履歴が載っています。2026年4月20日の更新では、データの接続、レポートの強化、ワークスペースの管理の項目に軽微な変更がありました。古い教材だけで学ぶと範囲がずれることがあるため、学習ガイドと照らし合わせてください。

無料の練習と試験の体験を使う

Microsoft Learnでは、練習用の評価や、試験と同じ画面を体験できるサンドボックスが案内されています。初めてMicrosoftの試験を受ける場合は、問題の形式に慣れておくと、当日に操作で迷いにくくなります。

更新を学び直しの機会にする

更新の評価は、元の試験より短く、最新の技術の更新に焦点を当てたものとされています。Power BIは機能の追加が多い製品なので、毎年の更新を、新しい機能を確かめる機会として使うと、案件での説明にも生かせます。

エージェントベストの見解

Power BIの案件は、Microsoft 365の環境の権限や、社内のデータの持ち出しのルールに関わることが多く、参画してから作業できる範囲が決まることもあります。応募の前に、作成・運用・管理のどこまでを任されるのかを確かめることをおすすめします。案件票から役割が読み取りにくいときは、ご質問いただければ確認します。

ポイント

  • PL-300に合格すると、Microsoft認定: Power BI データ アナリスト アソシエイトを取得できる
  • 範囲はデータの準備・モデル化・視覚化と分析・管理とセキュリティの4分野。Power QueryとDAXの習熟が前提
  • 認定は12か月ごとの更新が必要。無料のオンライン評価に合格して更新する
  • スキルシートには正式名称・試験番号・取得年月・有効期限を書き、経歴欄で運用まで示す

よくある質問

PL-300がないと、Power BIの案件には参画できませんか？

参画できる案件は多くあります。多くの案件では、Power BIで作ったレポートが業務でどう使われたかという実績が先に見られます。ただし、案件票の必須条件に認定の名前がある場合は、応募の段階で必要になることがあります。

更新を忘れて期限が切れたらどうなりますか？

更新の評価は、認定の有効期限が切れる前に合格する必要があると案内されています。期限が切れた場合の扱いは、Microsoft Learnの更新に関するよくある質問でご確認ください。スキルシートには、現在の状態を正確に書いてください。

ExcelのスキルだけでPower BIの案件に入れますか？

Excelでの集計の経験は、データの整形や指標の考え方の土台になります。ただし、Power BIの案件では、Power Queryでの整形、データモデルの設計、DAXでの計算、配布と権限の管理まで求められることが多くあります。PL-300の範囲は、Excelから広げるときに学ぶ順番の目安になります。

 データ・AI

データアナリストのフリーランス案件で求められるスキルと経験

データアナリストの案件では、SQLとデータの粒度の理解、指標の設計、施策の結果の読み方、可視化と報告、依頼の進め方の5分野が見られます。抽出を任される段階から分析の窓口を任される段階まで、経験ごとに求められる深さを解説します。

 データ・AI

データアナリストのスキルシートの書き方｜面談で評価される実績の見せ方

データアナリストのスキルシートは、ツールの名前を並べるより、依頼の受付から定例化までのどこを担い、どの指標を扱い、数字が何の判断に使われたかを書くのが基本です。SQLの力の示し方、ツールの書き分け方、架空の記入例を紹介します。

 データ・AI

データエンジニアのフリーランス案件で求められるスキルと経験

データエンジニアのフリーランス案件では、SQLとデータモデリング、失敗しても再実行できるパイプライン、データ品質の検査、権限と個人データの扱いが見られます。分野ごとのスキル、クラウドの認定資格の扱い、経験の示し方を解説します。
