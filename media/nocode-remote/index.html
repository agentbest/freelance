ノーコード・ローコード開発者のフリーランスはリモートで働ける？案件の傾向と探し方

公開 2026-10-29　監修：株式会社エージェントベスト

ノーコード・ローコード開発のフリーランスは、リモートで働ける案件が比較的多い分野です。ブラウザから作業できるツールが多く、発注側の環境に接続できれば場所を選ばずに作れるためです。一方で、業務の聞き取りや、現場の利用者への展開の時期には、出社や訪問を求められることがあります。

リモートで働けるかどうかは、ツールの種類より、どの工程を担うか、発注側の誰と話すか、扱うデータの性質で決まります。この記事では、リモートとの相性を工程ごとに整理し、案件の探し方と契約前の確認点を解説します。

工程ごとのリモートとの相性

工程リモートとの相性理由
アプリの構築・改修進めやすい画面上の設定や拡張の作業は、ツールにアクセスできれば場所を選ばない
拡張・外部連携の開発進めやすいただし、社内のネットワークにある基幹システムとつなぐ場合は接続の方法による
業務の聞き取り案件による画面共有で進める会社もあれば、現場の作業を見てほしいという会社もある
利用者への説明・展開出社を求められやすい現場の担当者がITに慣れていない場合、対面での説明が求められることがある
運用・問い合わせ対応進めやすいチャットやチケットで受け付ける形なら、リモートで続けやすい

すでに業務の整理が終わっていて、構築や改修を担う案件は、フルリモートで募集されることがあります。逆に、業務の聞き取りから始める案件や、紙の業務を置き換える案件では、立ち上がりの時期に現場を見る機会を設けることがあります。

ツールの種類で変わる環境の条件

作業する環境は、ツールの提供の形によって変わります。公式の説明（2026年10月時点）をもとに、リモートで働くときに確かめたい点を整理します。

  • 業務アプリ型：kintone や AppSheet では、発注側が契約している環境の中で作業するのが基本です。AppSheet は Google スプレッドシートや Google ドライブ、Gmail などの Google Workspace のサービスと連携すると説明されており、つなぐ先のデータへの権限も含めて、作り手用のアカウントをどう用意するか、接続元の制限（決まったネットワークからしか入れない設定など）があるかを確かめます。
  • データベース型：Claris FileMaker は、オンプレミスの FileMaker Server とクラウドの FileMaker Cloud のどちらでも共有できると説明されています。社内のサーバーで動かしている場合は、外部から接続する方法（VPN など）と、作業に使う端末の条件が決まっているかが要点になります。
  • Webアプリ型：Bubble はホスティングを含む基盤と説明されており、作業はブラウザで完結しやすい種類です。社外向けのサービスでは、公開前の確認を誰がどこで行うか、本番への反映の手順を確かめます。

エージェントベストの見解

ノーコード・ローコードの案件をご紹介していると、リモートで評価されやすいのは、作ったアプリを画面共有で見せながら、業務部門の人と短い確認を重ねて進める方です。完成してから見せるより、途中の段階で何度も触ってもらうほうが、手戻りが少なく、離れていても信頼を得やすい傾向があります。逆に、作業の進み具合が見えないまま期間が過ぎると、出社を増やしてほしいと言われることがあります。

リモートで進めやすい案件・進めにくい案件

進めやすい案件

  • 既存のアプリの改修や、決まった要件にもとづく構築
  • 外部連携や拡張の開発が中心の案件
  • 導入後の運用支援、問い合わせ対応、社内の作り手の支援
  • 社外向けのWebサービスを、少人数のチームで作る案件

進めにくい案件

  • 工場や店舗、建設現場など、現場の作業をそのままアプリにする案件
  • 紙の帳票を置き換え、利用者の多くがITに不慣れな案件
  • 社内のネットワークの中でしか動かせないデータベースを扱う案件
  • 個人情報や機密性の高いデータを扱い、作業場所を限定している案件

進めにくい案件でも、立ち上がりの数週間だけ出社し、その後はリモートという形もあります。出社の頻度は、時期によって変わることを前提に確かめておきましょう。

出社が求められやすい時期の例

同じ案件でも、時期によって出社の必要は変わります。よくある例を挙げます。

時期出社が求められやすい理由
参画の直後関係者との顔合わせ、現場の業務の見学、作業環境の準備
業務の聞き取り紙の帳票や現場の作業を見ながら確認したい
利用者への展開操作の説明会、利用開始の直後の問い合わせ対応
大きな切り替え旧来の管理表やシステムからの移行の当日

参画前に、こうした時期がいつごろあり、何日程度の出社になりそうかを聞いておくと、生活の予定や他の案件との兼ね合いを立てやすくなります。

リモート案件の探し方

ノーコード・ローコードの案件は、案件名にツールの名前が入っていないこともあります。「業務改善」「社内システムの内製化支援」「DX推進の支援」などの名前で募集され、説明文の中でツールの名前が出てくることも多いため、次のような探し方が役立ちます。

  1. ツールの名前と業務の名前の両方で探す：kintone などのツール名に加え、「業務アプリ」「内製化」「業務改善」でも探す
  2. 工程で絞る：構築・改修や運用支援が中心の案件は、リモートの割合が高い傾向がある
  3. 稼働日数で絞る：運用支援や改修は、週に数日の稼働で募集されることがある。週2〜3日の案件の探し方は週2〜3日・副業案件の記事で扱う
  4. フリーランスエージェントに条件を伝える：リモートの希望と、出社できる頻度の上限を先に伝えておく

リモート案件全般の探し方はフルリモートのフリーランス案件の探し方、エージェントの使い方はフリーランスエージェントの使い方で解説しています。新しく作る案件と運用中の改修の違いは新規開発案件と保守運用案件の違いも参考になります。

離れていても進めやすくする工夫

ノーコード・ローコードの開発は、画面を見せながら決めていく場面が多い仕事です。リモートで進めるときは、次のような工夫で、対面と変わらない確認の密度を保てます。

  • 確認用の環境を分ける：本番とは別に、業務部門の人が自由に触れる試験用のアプリや環境を用意してもらい、そこで意見をもらう
  • 短い動画や画面の画像で伝える：操作の流れを説明するときは、文章だけより、画面の録画を添えると伝わりやすい
  • 決めたことを一か所に残す：項目の意味、権限の考え方、変更の理由を、発注側も見られる場所に記録する
  • 問い合わせの入口を一つにする：チャット、メール、口頭の依頼が混ざると、対応の漏れや優先順位の行き違いが起きやすい

特に、変更の理由を残しておくことは、契約の終了後に社内の担当者が引き継ぐときにも役立ちます。

契約の前に確かめたいこと

リモートで働く前提の案件では、次の点を契約の前に確かめておくと、参画後の行き違いを防げます。

  • 出社の頻度と時期：「原則リモート」の中身（立ち上がりの期間、月に何回か、必要なときだけか）
  • 作業に使う端末：自分の端末でよいか、貸与される端末を使うか
  • アカウントと権限：作り手用のアカウントを誰が用意し、どこまでの権限が与えられるか
  • データの扱い：本番のデータを触るか、試験用のデータで作業するか。データを手元に保存してよいか
  • 連絡の手段と時間帯：チャットの返答を期待される時間帯、定例の打ち合わせの頻度
  • ツールやプラグインの費用：作業に必要な有料の部品を、誰の名義で契約するか

個人情報を含むデータを扱う場合は、契約の中で取り扱いの条件が決められていることがあります。考え方は業務で個人情報を扱うときの契約と注意点で解説しています。

注意

リモートの案件では、作業のために本番のデータを自分の端末に書き出したり、個人のクラウドストレージに置いたりしてしまうことがあります。契約で禁止されている場合、意図せず違反になるおそれがあります。データを手元に持ってよいか、どこに保存してよいかは、作業を始める前に必ずご確認ください。

エージェントベストの見解

当社では、先に稼働日数・リモートの希望・ご希望の金額を伺い、その条件に合う案件だけをご案内しています。ノーコード・ローコードの案件は、「原則リモート」と書かれていても、立ち上がりの時期や利用者への展開の時期に出社がある場合があります。出社の頻度や作業環境について面談の前に知りたい点があれば、ご質問いただければ確認します。

ポイント

  • ノーコード・ローコード開発は、リモートで進めやすい案件が比較的多い
  • 業務の聞き取りや利用者への展開の時期は、出社を求められることがある
  • ツールの提供の形（クラウドか社内のサーバーか）で、作業環境の条件が変わる
  • 出社の頻度、端末、アカウント、データの扱いは、契約の前に確かめる

よくある質問

地方に住んでいても、ノーコード・ローコードの案件に参画できますか？

フルリモートの案件であれば、住んでいる場所を問わない案件もあります。ただ、立ち上がりや展開の時期に出社がある案件もあるため、交通費の扱いと出社の頻度を確かめておきましょう。

業務の聞き取りもリモートでできますか？

画面共有やオンラインの打ち合わせで進める会社も多くあります。業務の流れが分かる資料や、実際に使っている帳票を事前に共有してもらうと、リモートでも聞き取りを進めやすくなります。現場の作業を見る必要がある場合は、その期間だけ訪問する形もあります。

リモートで評価を落とさないために気をつけることはありますか？

作業の進み具合を見える形にすることです。作りかけのアプリを早めに触ってもらう、決めたことを短く記録して共有する、といった進め方が、離れていても信頼につながります。参画初期の進め方は参画初月にやることの記事で扱います。
