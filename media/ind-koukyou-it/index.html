業界別の案件

公共・官公庁業界のフリーランスIT案件｜自治体標準化・ガバメントクラウド・PMO支援の特徴

公共・官公庁のIT案件は、大きく分けると自治体システムの標準化と移行、ガバメントクラウドの利用に関わる設計・構築・運用、府省や自治体のPMO・プロジェクト管理の支援、調達や要件定義の支援、既存システムの運用保守の5つです。どれも、国が定めたルールと年度の予定に沿って進む点が、民間の案件との大きな違いです。

この記事では、案件の種類ごとに中身と特徴を整理します（2026年10月時点の公式情報にもとづきます）。調達や予算年度など業務知識の身につけ方は公共案件の業務知識の記事、経験の書き方はスキルシートの記事、守るべきセキュリティのルールは規制とセキュリティの記事で扱います。

公共・官公庁のIT案件は5つに分かれる

まず全体像です。発注するのは、国の府省、独立行政法人などの公的な機関、都道府県・市区町村などです。フリーランスが参画する場合は、発注者から直接ではなく、受注した事業者やその協力会社を通じた契約になることが多くあります。契約の経路の考え方は商流の記事で解説しています。

種類主な発注者作業の中心
自治体システムの標準化・移行市区町村・都道府県、受注した事業者標準準拠システムへの移行、データ移行、業務の見直し、移行計画の管理
ガバメントクラウド関連府省・自治体、受注した事業者クラウド上の設計・構築、運用設計、移行、費用の管理
PMO・プロジェクト管理の支援府省・自治体、支援事業者計画・進捗・課題の管理、会議の運営、工程レビューへの対応
調達・要件定義の支援府省・自治体、支援事業者要件定義書や調達仕様書の作成支援、事業者からの情報収集の支援

以下、それぞれの中身を見ていきます。

自治体システムの標準化と移行の案件

いま公共分野で規模が大きいのが、地方公共団体の基幹業務システムを国の標準に合わせる取り組みです。根拠は「地方公共団体情報システムの標準化に関する法律」（標準化法）です。

デジタル庁の説明では、標準化の対象は20の事務です。住民基本台帳、戸籍、戸籍の附票、印鑑登録、選挙人名簿管理、固定資産税・個人住民税・法人住民税・軽自動車税の税務、国民健康保険、後期高齢者医療、介護保険、国民年金、障害者福祉、生活保護、健康管理、就学、児童手当、児童扶養手当、子ども・子育て支援が含まれます。

期限は「原則2025年度まで」、ただし移行が続くシステムがある

自治体は、原則として2025年度（令和7年度）までに標準準拠システムへ移行することを目指すとされてきました。一方で、2026年度以降の移行にならざるを得ないと具体化したシステムは「特定移行支援システム」とされ、国は概ね5年以内に移行できるよう支援するとしています。

デジタル庁のページ（2026年9月30日更新）では、2026年3月末時点で、対象の34,366システムのうち10,013システム（29.1％）が特定移行支援システムに該当すると示されています。つまり、2026年10月の時点でも、移行の案件は続いています。移行を終えた自治体では、標準準拠システムの運用や、制度改正に合わせた対応へと仕事の中身が移っていきます。

標準化案件での主な役割

  • 移行計画と進捗の管理：複数の業務システムの移行時期をそろえ、自治体・事業者・関係機関の調整をする
  • データ移行：既存システムのデータを標準の形に合わせて移し、件数や内容を検証する
  • 業務の見直し：標準仕様に合わせて、自治体側の事務の流れや帳票を見直す支援をする
  • テストと切り替え：住民向けの業務を止めないよう、切り替え日の段取りを組む

住民の生活に直結する業務のため、切り替えの日程や、住民への影響の確認が重く扱われます。

ガバメントクラウドに関わる案件

ガバメントクラウドは、デジタル庁が「政府共通のクラウドサービスの利用環境」として整備しているものです。デジタル庁の基本方針（DS-310、2025年5月27日決定）は、政府情報システムでクラウドサービスの採用を第一原則とし、クラウドを使う場合はガバメントクラウドを原則とするとしています。標準化法では、地方公共団体もガバメントクラウドの利用に努めることとされています。

そのため、クラウドの設計・構築・運用の経験が、公共分野でも求められるようになっています。案件では次のような作業が見られます。

  • ガバメントクラウド上の環境の設計と構築、運用の設計
  • オンプレミスや別の環境からの移行の計画と実施
  • 利用料の見込みや実績の管理、構成の見直し
  • 自治体の業務システムを載せるときの、ネットワークや接続の設計

ガバメントクラウドとして使えるクラウドサービスは、デジタル庁が募集・決定して公表しています（直近では2026年3月27日に令和8年度募集分の決定を公表）。どのサービスの経験が合うかは案件ごとに違うため、案件票の必須スキルを確かめてください。読み方は案件票の読み方の記事で解説しています。

エージェントベストの見解

案件紹介の現場で見ていると、公共の案件で評価されやすいのは、クラウドや移行の技術に加えて、「決められたルールと期限の中で、関係者の多い計画を前に進めた経験」を話せる方です。反対につまずきやすいのは、民間の案件と同じ感覚で、意思決定の速さや仕様変更の柔軟さを前提に話してしまうケースです。公共の案件は、承認の段階や文書で残すことが多い前提で、経験を説明する準備をおすすめします。

府省のPMO・プロジェクト管理支援の案件

国の府省では、デジタル庁の「デジタル・ガバメント推進標準ガイドライン」（DS-100）が、政府情報システムを整備・管理するときの共通ルールになっています。このガイドラインでは、府省全体を管理するPMOと、個々のプロジェクトを推進するPJMOという体制が置かれます。

DS-100には、各府省が専門性の高い事業者を調達し、PMO体制に加えることができると書かれています。また、プロジェクトの管理上の作業についてPJMOを支援する事業者（プロジェクト管理支援事業者）という位置づけもあります。フリーランスがPMOとして参画する案件の多くは、こうした支援を受注した事業者のチームに加わる形です。

民間のPMOとの違い

作業の中身は、計画・進捗・課題・リスクの管理、会議体の運営、資料の作成など、民間のPMOと重なります。違いが出るのは、次の点です。

  • ガイドラインに沿った手続きがある：プロジェクト計画書の作成や、PMOによる工程レビューへの対応など、決まった節目で文書を整える
  • 予算と年度に縛られる：計画が会計年度の単位で組まれ、翌年度の予算要求の時期とも連動する
  • 支援する側と作る側が分かれる：プロジェクト管理を支援する事業者は、管理の対象になるシステムの設計・開発の調達に参加できないという決まりがある

最後の点は、案件選びにも関わります。詳しくは業務知識の記事で、調達の流れとあわせて説明します。PMOに求められるスキルそのものはPMOのスキルの記事をご覧ください。

調達・要件定義の支援と、運用保守の案件

調達・要件定義の支援

府省や自治体が新しいシステムを調達する前に、要件定義書や調達仕様書の作成を支援する案件です。業務部門へのヒアリング、現行システムの調査、事業者からの情報収集（RFI）の準備などを行います。発注者の側に立って、仕様が特定の事業者に偏らないよう整える役割を求められます。

運用保守・制度改正対応

稼働中のシステムの運用や、法令・制度の改正に合わせた改修の案件です。改正の施行日が決まっているため、そこから逆算して作業が組まれます。長く続くことが多い一方、契約の区切りは年度や調達の単位で決まります。長期案件の考え方は長期案件と短期案件の記事で整理しています。

民間の案件と比べたときの特徴

観点公共・官公庁の案件で多い傾向
予定の決まり方会計年度、予算、制度の施行日、国が示す期限から逆算して組まれる
文書計画書、議事録、レビュー記録など、残す文書が多い
体制発注者、受注事業者、支援事業者、関係機関と、関係者が多い
作業場所情報の扱いの決まりから、作業場所や端末が指定されることがある
再委託調達の仕様で再委託の制限や承認の手続きが定められることがある

作業場所や端末の決まりは、国や自治体のセキュリティ基準から来ています。中身は規制とセキュリティの記事で扱います。再委託の決まりがあると、フリーランスとして参画できるかどうかや、事前の承認の手続きに影響することがあります。自分で人を使う場合の注意は再委託の記事で解説しています。

注意

公共の案件は、年度末や調達の区切りで体制が変わることがあります。参画前に、契約期間が年度のどこまでか、次の年度の調達がどうなる見込みかを、分かる範囲で確かめておくと、後の予定が立てやすくなります。見込みは発注者側の予算や調達の結果で変わるため、確定した情報として受け取らないことが大切です。

エージェントベストの見解

当社では、案件をご案内するときに、先に稼働日数・リモートの希望・ご希望の金額を伺い、条件に合う案件だけをお出ししています。公共の案件は作業場所の指定がある場合もあるため、出社の可否は早めにご相談ください。契約では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。

ポイント

よくある質問

公共の案件は経験がないと参画できませんか？

公共の経験が必須とされる案件もありますが、クラウド、データ移行、PMOなどの技術や役割が合っていれば、公共分野が初めてでも参画できることはあります。その場合は、ガイドラインや調達の流れを事前に学んでいることを伝えると、受け止められやすくなります。学び方は業務知識の記事をご覧ください。

自治体システムの標準化の案件はもう終わりましたか？

2026年10月時点では終わっていません。デジタル庁の公表では、2026年3月末時点で10,013システムが特定移行支援システムとされ、国は概ね5年以内の移行を支援するとしています。移行を終えた自治体でも、運用や制度改正への対応が続きます。

公共の案件はリモートで働けますか？

案件によって違います。扱う情報やネットワークの決まりから、作業場所や端末が指定される案件がある一方、扱う情報によってはリモートを認める案件もあります。条件は案件票と面談で確かめてください。決まりの背景は規制とセキュリティの記事で説明しています。
