フリーランスエージェントのマージンとは｜報酬の内訳と確かめ方

公開 2026-10-29　監修：株式会社エージェントベスト

目次

  2. その差で何がまかなわれているか

  4. フリーランス法の取引条件の明示との関係

フリーランスエージェントのマージンは、発注元がエージェントに払う金額と、エージェントがフリーランスに払う報酬との差のことです。この差で、案件の開拓、選考の調整、契約・請求の事務、支払の立替えといった仕事がまかなわれています。

マージンの率はサービスや案件によって違い、公的な統計もありません。フリーランスにとって大事なのは、率の大小より、自分の契約に書かれた報酬の額と条件が、提示された内容どおりかを確かめることです。この記事では、内訳の考え方と確かめ方を一般論として整理します。

マージンが生まれる仕組み

エージェント経由の案件では、多くの場合、契約が二つに分かれています。

契約当事者決まること
発注元との契約発注元（エンドや元請）とエージェント発注元がエージェントに払う金額
フリーランスとの契約エージェントとフリーランスエージェントがフリーランスに払う報酬

フリーランスが契約を結ぶのは、エージェントです。発注元とエージェントの間の金額は、フリーランスの契約には書かれていないのが一般的です。この二つの金額の差が、マージンと呼ばれています。

「手数料」と呼ばれることもある

マージンは、「手数料」「仲介料」などと呼ばれることもあります。ただし、フリーランスが請求書から手数料を差し引かれる形ではなく、最初から「フリーランスに払う報酬の額」として契約で決まっていることが多い点に注意が必要です。どちらの形かは、契約書の報酬の書き方を見れば分かります。

商流が深いと、差が重なる

発注元とエージェントの間に、さらに元請や一次請などが入っている場合、それぞれの会社の取り分が重なります。同じ役割の案件でも、どこから来た案件かによって受け取る金額が変わるのはこのためです。構造は商流の記事で解説しています。

その差で何がまかなわれているか

マージンは、エージェントの利益だけではありません。一般的には、次のような仕事の費用が含まれています。

仕事内容
案件の開拓発注元の企業を探し、案件の条件を聞き取る
マッチングと選考の調整条件に合う案件を選び、経歴を提案し、面談を設定する
契約の事務基本契約・個別契約の作成、条件の交渉
請求と支払発注元への請求、フリーランスへの支払
支払の立替え発注元からの入金の前後にかかわらず、契約で決めた期日にフリーランスへ支払う
参画中の対応稼働や業務範囲の相談、更新・終了の調整
回収の負担発注元からの入金が遅れたときの対応

このほか、サービスによっては、福利厚生や保険の案内、税務の相談窓口などを付けている場合もあります。何が含まれるかはサービスごとに違うため、登録時の説明や規約で確かめましょう。

直接契約と比べるときの考え方

エージェントを使わずに発注元と直接契約すれば、マージンの分だけ受け取る金額が増える可能性があります。一方で、上の表にある営業・契約・請求・回収の仕事を自分で行うことになり、案件が途切れたときの次の案件探しも自分の仕事です。比べ方は直接契約とエージェント経由の違いの記事で整理しています。

エージェントベストの見解

案件をご紹介していると、「マージンが何％か」をご質問いただくことがあります。率だけを比べても、同じ案件で比べているとは限らず、商流の深さや精算の条件が違えば受け取る金額も変わります。当社では、ご本人にお支払いする報酬の額と、業務範囲・支払期日・契約期間を個別契約に書いてお渡ししています。比べるときは、契約に書かれた報酬の額と条件をそろえて見ることをおすすめしています。

マージンを確かめる方法

1. 自分の契約の報酬の額を確かめる

まず確かめたいのは、自分とエージェントの契約に書かれた報酬の額です。

  • 月額はいくらか（税込か税別か）
  • 精算幅と、超過・控除の計算方法
  • 交通費や経費が報酬に含まれるか
  • 支払期日と支払方法
  • 振込手数料をどちらが負担するか

この金額が、面談や条件の提示のときに聞いた内容と一致していれば、受け取る金額については約束どおりということです。精算の計算方法は精算幅の記事、税込・税別は報酬は税込か税別かの記事で整理しています。

2. 率や内訳を聞くときは目的を添える

マージンの率を公開しているサービスもあれば、公開していないサービスもあります。気になるときは、担当者に聞いてみて構いません。ただし、発注元との契約金額は、発注元との守秘の約束で答えられない場合もあります。

聞くときは「受け取る金額の根拠を知りたい」「更新時の単価の見直しの参考にしたい」のように目的を添えると、答えられる範囲で説明してもらいやすくなります。

3. 案件をまたいで比べるときは条件をそろえる

複数のサービスから似た案件を紹介された場合は、提示された報酬の額を、次の条件をそろえて比べます。

  1. 稼働日数と精算幅
  2. 交通費・経費の扱い
  3. 支払期日
  4. 契約期間と更新の見込み
  5. 業務の範囲

同じ案件に別々のサービスから重ねて応募するのは避けましょう。注意点は複数登録の記事にまとめています。

フリーランス法の取引条件の明示との関係

2024年11月に施行されたフリーランス法では、発注事業者は業務を委託したら直ちに、給付の内容・報酬の額・支払期日などの取引条件を、書面またはメールなどで明示することとされています（公正取引委員会の案内）。

エージェントがフリーランスと業務委託契約を結んでいる場合、フリーランスに業務を委託しているのはエージェントにあたると考えられます。その場合、フリーランスに明示される報酬の額は、エージェントがフリーランスに払う額です。発注元がエージェントに払う額まで明示されるとは限りません。どちらが委託する側になるかは、契約と取引の実態から総合的に判断されるため（公正取引委員会のQ&A）、気になる場合は契約の当事者を確認しておきましょう。

一方、仲介する事業者が契約を結ばず、請求や支払などの事務を代行しているだけの場合は、発注元が業務委託をする側になります。公正取引委員会のQ&Aでは、仲介する事業者が委託の内容・相手の選定・報酬の額の決定などにどこまで関わっているかを、契約と取引の実態から総合的に見て判断するという考え方が示されています。自分が誰と契約しているのかは、契約書の当事者の欄で確かめられます。

振込手数料の扱い

公正取引委員会の2026年の特設サイトでは、2026年1月1日以降に業務を委託する取引について、振込手数料をフリーランスに負担させて報酬から差し引くことは、報酬の減額にあたるとされています（2025年12月31日以前に委託した取引には経過措置があります）。報酬から差し引かれている項目がある場合は、契約でどう決まっているかを確かめましょう。

注意

「マージンが低い」とうたうサービスでも、受け取る報酬の額が高いとは限りません。発注元から受け取る金額そのものが案件によって違うためです。反対に、率が高めでも、商流の浅い案件や支払条件の良い案件を扱っていれば、受け取る金額が多くなることもあります。率だけで判断せず、契約の報酬の額と条件で比べてください。

マージンをふまえて受け取る金額を増やす考え方

マージンそのものを交渉で下げるのは、現実には難しいことが多いです。受け取る金額を増やしたいときは、次のような考え方が現実的です。

  • 担う役割を広げる：任される範囲が広がると、発注元が払う金額そのものが上がりやすい
  • 更新の時期に相談する：参画中の評価をもとに、発注元との金額の見直しを相談してもらう
  • 商流の浅い案件を選ぶ：間に入る会社が少ないほど、差し引かれる分が減りやすい
  • 条件全体で見る：精算幅や交通費、支払期日の改善も、実質の条件を上げる

交渉の進め方は単価交渉の記事、単価が決まる仕組みは単価の仕組みの記事で整理しています。

エージェントベストの見解

単価の見直しのご相談は、更新の時期にいただくことが多くあります。当社では、参画中に担当する範囲がどう広がったか、現場からどう評価されているかを伺ったうえで、取引先と話を進めます。金額の話だけでなく、精算幅や稼働日数を含めて条件を整理すると、取引先にも説明しやすく、話がまとまりやすい傾向があります。

ポイント

  • マージンは、発注元が払う金額とフリーランスが受け取る報酬の差
  • その差で、案件の開拓、契約・請求の事務、支払の立替え、回収の負担などがまかなわれている
  • 率より、自分の契約に書かれた報酬の額・精算・支払期日を確かめることが大切

よくある質問

マージンの相場はどのくらいですか？

マージンの率をまとめた公的な統計はなく、サービスや案件によって違います。率を公開しているサービスもありますが、何を含めて計算しているかも違うため、数字だけで比べるのは難しいのが実情です。自分の契約の報酬の額と条件で比べることをおすすめします。

発注元がいくら払っているかを教えてもらえますか？

発注元との契約金額は、守秘の約束があり答えられないこともあります。フリーランス法で明示されるのは、自分に業務を委託した事業者が払う報酬の額です。気になるときは、受け取る金額の根拠を知りたいという目的を添えて担当者に聞いてみてください。

マージンが引かれた分、自分で請求書を調整する必要がありますか？

一般的には、エージェントとの契約で決まった報酬の額で請求します。発注元が払う金額から自分で差し引いて請求する形ではありません。請求の方法や締め日は契約によって違うため、参画の前に確認しておきましょう。支払期日の考え方は支払サイトの記事で整理しています。

単価・報酬交渉

フリーランスの単価はどう決まる？報酬の仕組みを整理

フリーランスの単価は、担う役割と経験、案件の需要、稼働日数、商流の深さなどで決まり、案件によって大きく変わります。月額単価・精算幅・受け取り額の関係と、契約で確かめる点を整理します。

 案件の探し方

商流とは｜エンド直・元請・二次請の違いとフリーランスへの影響

商流は、案件を発注した会社（エンド）からフリーランスまで、契約が何社を経てつながっているかを表す言葉です。間に入る会社が多いほど、報酬・情報の伝わり方・指示系統に影響が出やすくなります。構造と確かめ方を整理します。

 案件の探し方

フリーランスエージェントの使い方｜登録から参画までの流れと準備

フリーランスエージェントは、登録・面談で希望を伝え、紹介された案件に応募し、発注側との面談を経て契約・参画する流れで使います。各段階で準備すること、確かめること、うまく使うためのコツを整理します。

 案件の探し方

直接契約とエージェント経由の違い｜それぞれの向き不向き

直接契約は報酬の取り分が増えやすい一方、営業・契約・請求・回収を自分で担います。エージェント経由は案件探しや事務を任せられる一方、差額が生じます。違いを項目ごとに比べ、どんな人に向くかを整理します。

 単価・報酬交渉

単価交渉のタイミングと伝え方｜フリーランスが条件を見直すときの進め方

単価交渉は、参画前の条件のすり合わせと、契約更新の判断が出る前の2つが主なタイミングです。役割の広がりや成果など具体的な材料をそろえ、エージェント経由なら担当者を通して伝えます。準備と伝え方、断られたときの考え方を整理します。

 フリーランス新法・下請法

フリーランス新法の取引条件の明示｜受け取るべき8項目と確認のしかた

フリーランス新法では、発注者は業務委託をしたら直ちに、業務の内容・報酬の額・支払期日など8項目を書面かメール等で明示しなければなりません。口頭だけは不可です。受け取るべき内容と、未定事項や共通事項の扱いを整理します。
