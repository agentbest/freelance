フリーランスにCKA（Kubernetes認定管理者）は役立つ？評価される場面と準備

公開 2026-10-29　監修：株式会社エージェントベスト

CKA（Certified Kubernetes Administrator、Kubernetes認定管理者）は、持っていなくても参画できるKubernetesの案件が多い一方で、選択式ではなくコマンドラインで課題を解く実技の試験のため、「手を動かしてクラスターを扱える」ことの裏付けとして効きます。とくに、障害の切り分けが出題の3割を占める点は、運用を任せる案件で評価につながりやすい部分です。

この記事では、2026年10月時点のLinux Foundationの公式ページをもとに、CKAの範囲・形式・有効期間を確かめ、効く場面と効きにくい場面、実務経験との組み合わせ方を整理します。Kubernetesの案件で求められるスキル全体はKubernetesエンジニアのスキルの記事、職種として取る資格の選び方はKubernetesエンジニアの資格の記事で扱っています。

CKAの試験の範囲と形式

CKAは、Linux FoundationとCloud Native Computing Foundation（CNCF）が作成した認定で、Linux Foundationが提供しています。

項目内容（2026年10月時点のLinux Foundationの案内による）
作成・提供Linux Foundation、Cloud Native Computing Foundation
形式オンラインの監督付きの実技試験。コマンドラインで課題を解く
時間2時間
受験の条件なし
申し込みに含まれるもの12か月の受験資格期間、再受験1回、模擬試験2回
有効期間2年間

出題分野と比率は次のとおりです。

分野比率
トラブルシューティング30%
クラスターのアーキテクチャ、インストール、設定25%
サービスとネットワーク20%
ワークロードとスケジューリング15%
ストレージ10%

試験は特定のバージョンのKubernetesにもとづいて作られていて、対象のバージョンは公式ページに示されています。Kubernetesは更新が早いため、対象のバージョンも変わっていきます。

有効期間の考え方

公式ページでは、認定の有効期間は2年間と案内されています。AWSの3年やAzureの1年ごとの更新と比べると、間隔が違います。更新の方法の詳細は公式ページの案内やよくある質問で確かめ、スキルシートには認定の証明書に書かれた期限を書きます。

CKAがなくても入れる案件が多い理由

Kubernetesの案件の面談では、どの規模のクラスターを、どの体制で運用していたか、障害のときに何を見て原因を切り分けたかが確かめられます。こうした経験を具体的に話せれば、CKAがなくても参画が決まることは珍しくありません。

また、案件で扱うKubernetesの多くは、Amazon EKS、Google Kubernetes Engine、Azure Kubernetes Serviceといったクラウドのマネージドサービスです。マネージドサービスでは、コントロールプレーンの構築や管理をクラウド側が担うため、案件で先に問われるのは、クラウドのネットワークや権限との組み合わせ、デプロイの仕組み、監視の経験です。

CKAが効きやすい場面

実際に手を動かせることを示したいとき

選択式の試験は知識の範囲を示しますが、CKAは制限時間の中でコマンドを使って課題を解く試験です。そのため、「設定ファイルを書き、クラスターの状態を調べ、問題を直せる」ことの裏付けとして読まれます。Kubernetesの実務の期間が短い人が、手を動かせることを書類の段階で示したいときに効きます。

運用や障害対応を任せる案件

出題の3割がトラブルシューティングです。Podが起動しない、サービスにつながらない、ノードが不調といった場面で原因を切り分ける力は、運用の案件でそのまま求められます。SREの案件で基盤の技術を示す材料にもなります。SREの案件での位置づけはSREがフリーランスになるにはの記事で触れています。

自前で構築したクラスターを扱う案件

オンプレミスや、マネージドサービスを使わずに構築したクラスターを扱う案件では、クラスターのインストールや設定、アップグレードの知識が直接問われます。CKAの「クラスターのアーキテクチャ、インストール、設定」の分野と重なる部分が大きい案件です。

CKAだけでは効きにくい場面

  • 基盤全体の設計を任せる案件：クラスターをどう分けるか、どのマネージドサービスを選ぶかといった設計の判断は、クラウドの設計の経験や認定で示します。AWS認定ソリューションアーキテクトの記事もご覧ください
  • アプリの開発者としての案件：Kubernetesの上で動くアプリを作る役割では、管理者向けのCKAより、開発の経験やデプロイの仕組みの経験が先に見られます
  • 信頼性の目標づくりや運用の改善：SLOの設計や、手作業の削減といったSREの取り組みは、CKAの範囲の外にあります。実務の経験で示します

エージェントベストの見解

案件紹介の現場では、CKAをお持ちの方の中でも、実際の運用で起きた障害を一つ取り上げて、何を見て、どう切り分けたかを話せる方は、面談が早く進む傾向があります。反対に、マネージドサービスの画面での操作の説明だけで終わると、CKAで学んだ内容と実務とのつながりが伝わりにくくなります。取得したら、試験のトラブルシューティングの分野と、自分が対応した障害を一度並べて書き出してみることをおすすめします。

実務経験との組み合わせ方

CKAの5つの分野を、自分の経験に当てはめてみます。

分野結びつけやすい実務の経験
トラブルシューティング起動しないPodの原因調査、ノードの不調の切り分け、ログとイベントの確認
クラスターのアーキテクチャ・インストール・設定クラスターのアップグレード、権限（RBAC）の設計、マネージドサービスの設定
サービスとネットワーク外部からの通信の入り口の設計、ネットワークポリシーによる通信の制限
ワークロードとスケジューリングリソースの要求と上限の設定、配置の制御、ローリングアップデート
ストレージ永続ボリュームの設計、データを持つアプリの運用

マネージドサービスの経験しかない場合は、CKAの準備で自分でクラスターを組むと、マネージドサービスの裏側で何が動いているかを説明できるようになります。その経験は、障害の切り分けを話すときの説得力につながります。IaCでクラスターの周りを管理する経験はTerraform Associateの記事、Linuxの基礎の資格はLinuC・LPICの記事で扱っています。

スキルシートでの書き方

資格欄には、正式名称、取得年月、有効期限を書きます。

例：Certified Kubernetes Administrator（CKA）20XX年X月取得、有効期限20XX年X月

経歴欄では、Kubernetesの経験に「マネージドサービス（EKS）での運用」「自前で構築したクラスターの運用」のように、どちらの環境かを添えると、CKAの知識がどこで生きたかが伝わります。期限が切れたものは「取得歴」として分けて書きます。記入例はKubernetesエンジニアのスキルシートの記事やSREのスキルシートの記事で紹介しています。

注意

CKAは実技の試験のため、知識を覚えるだけの準備では時間内に課題を解き終えにくくなります。また、対象のKubernetesのバージョンは更新されていきます。受験の前に、公式ページで対象のバージョンと出題分野、試験の環境の案内を必ずご確認ください。

案件と並行して準備するときの進め方

  1. 出題分野の比率から優先順位を決める：配点の大きいトラブルシューティングと、クラスターの設定から手をつけます
  2. 自分でクラスターを組んで壊して直す：検証環境で設定を変え、わざと動かない状態を作って原因を探す練習をします
  3. 申し込みに含まれる模擬試験を使う：本番に近い形式で時間配分を確かめます。受験資格の期間は12か月のため、案件の繁忙期を避けて日程を決めます

エージェントベストの見解

当社では、経歴は、ご本人の了承を得た案件にだけ、氏名・連絡先を伏せて提案しています。Kubernetesの案件では、マネージドサービスか自前の構築か、何台規模のクラスターをどの体制で運用したかによって、ご案内できる案件が変わります。CKAを経歴に書くときは、こうした環境の情報もあわせて整理しておくことをおすすめします。

ポイント

  • CKAがなくても参画できるKubernetesの案件は多く、運用の体制と障害の切り分けの経験が先に見られる
  • 実技の試験のため、手を動かせることの裏付けになる。出題の3割はトラブルシューティング
  • 有効期間は2年。対象のKubernetesのバージョンは更新されるため、受験前に公式ページで確かめる
  • マネージドサービスか自前の構築かを書き分け、資格と環境をつなげて伝える

よくある質問

マネージドサービスしか使っていなくてもCKAは役立ちますか？

役立ちます。マネージドサービスでも、Podやサービス、権限の扱いはKubernetesと共通です。CKAの準備で自分でクラスターを組むと、障害のときにどこまでが自分の責任範囲かを説明しやすくなります。ただし、案件ではそのマネージドサービスとクラウドの組み合わせの経験もあわせて見られます。

開発者向けの認定とどちらを取るべきですか？

Kubernetesの上で動くアプリを作る役割が中心なら、開発者向けの認定が範囲と重なります。クラスターの運用や障害対応を担う役割を狙うなら、管理者向けのCKAが向いています。狙う案件の案件票に出てくる役割から決めると、学習を実務に結びつけやすくなります。

受験の前にどれくらいの実務経験が必要ですか？

公式ページでは、受験の条件はないとされています。ただ、実技の試験のため、Linuxのコマンド操作と、Kubernetesの設定ファイルを書いた経験がないと、時間内に解き終えるのは難しくなります。実務が短い場合は、検証環境で一通りの操作に慣れてから申し込むと、12か月の受験資格の期間を有効に使えます。
