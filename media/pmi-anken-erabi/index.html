業務・戦略コンサル

M&A・PMIコンサルタントのフリーランス案件の選び方｜契約前に確かめたいこと

公開 2026-11-04　監修：株式会社エージェントベスト

目次

  2. 契約前に確かめたい7つの点
  3. 確かめた内容を書面と照らし合わせる
  4. よくある質問

フリーランスのM&A・PMIコンサルタントの案件を選ぶときは、報酬や稼働日数に加えて、誰の側に立つか、取引の局面と期限、担う領域と決める人、取引が止まったときの扱い、成果物の責任、情報の扱いと売買の制限、稼働の振れ幅の7点を契約前に確かめておくことが大切です。PMIの案件は、肩書きが同じでもこの7点の違いで負担と責任が大きく変わります。

特に見落としやすいのは、取引そのものが延期や中止になったときに、契約がどうなるかです。PMIの案件は取引の進み方に左右されるため、ここを確かめずに受けると、予定していた稼働がなくなることがあります。契約書全般の確認点は業務委託契約書のチェックポイントで解説しているので、この記事ではPMIに固有の点に絞ります。

PMI案件の選び方で差が出る理由

PMIの案件票は、取引の秘密を守るために「製造業の統合支援」「ITデューデリジェンス」のように抽象的に書かれやすく、参画してから想定との違いに気づくことが少なくありません。よくあるずれは次のようなものです。

  • 統合の領域のリードとして入ったのに、実際は課題表の更新と会議の記録が中心だった
  • クロージングが延びて、開始日が何度も後ろにずれた
  • デューデリジェンスの報告書の納品が報酬の条件になっていて、追加の調査が無償で続いた
  • Day1の前後に、夜間や休日の対応が続いた

こうしたずれは、面談と条件の確認の段階で、聞き方を工夫すれば多くを防げます。

契約前に確かめたい7つの点

1. 誰の側に立つのか

最初に確かめたいのは、自分が誰のために動く立場かです。買い手の側か、売り手の側か、統合される対象会社の側か、買い手を支援するコンサルティングの体制の一員か。カーブアウトでは売り手と買い手の双方と話すため、特に大切です。

立場によって、見てよい情報も、話してよい相手も変わります。同じ取引の別の当事者の案件を同時に受けないことも、ここで確かめておきます。

2. 取引の局面と、動かせない期限

案件票に書かれていない「今の局面」を、答えられる範囲で確かめます。

  • 契約の前の調査の段階か、クロージングに向けた準備か、統合後の実行か
  • クロージングやDay1、TSA（移行期間のサービス提供）の終わりなど、動かせない期限はいつごろか
  • 直近で取引の条件や時期が変わったか

局面が分かれば、仕事の中身も稼働の山場も読みやすくなります。局面ごとの仕事の違いはM&A・PMIコンサルタントの仕事内容で整理しています。

3. 担う領域と、決める人

自分が担う領域と、その領域で決める人を確かめます。

  • IT、業務、会計、人事など、どの領域を担うか。領域のリードか、メンバーか
  • 統合の方針を決めるのは誰か。統合委員会などの場はあるか
  • IMO（統合推進の事務局）があるか。ない場合、全体の課題管理も自分が担うか

フリーランスは発注元の社員ではないため、方針や予算の判断は発注元に残るのが一般的です。そのうえで、決める人が明確になっているかが大切です。決める人があいまいな統合では、どれだけ材料をそろえても結論が出ず、期限だけが迫ります。

エージェントベストの見解

M&A・PMIの案件紹介の現場では、参画後に「聞いていた状況と違った」となりやすいのは、取引の局面と、決める人の2点です。取引の秘密に関わるため面談では聞きにくいと感じる方もいますが、担う範囲を判断するために必要な確認として聞けば、答えられる範囲で教えてもらえることが多くあります。案件票だけでは分からない点は、契約の前に確かめることをおすすめします。

4. 取引が延期・中止になったときの扱い

PMIに固有の確認点です。

  • 開始日がクロージングに連動していないか。延びたときはどうなるか
  • 取引が中止になったとき、契約をどう終えるか。それまでの稼働はどう精算されるか
  • 契約期間が局面の区切り（Day1、TSAの終わりなど）と合っているか

フリーランス法では、6か月以上継続して業務を委託している場合に、契約を解除したり更新しなかったりするときは、少なくとも30日前までに予告することが求められています（2026年10月時点、公正取引委員会の案内による）。ただ、取引の中止は急に決まることもあるため、中止のときの扱いを契約の中で確かめておくと安心です。

5. 契約の形と、成果物の責任

PMIの案件は準委任契約が中心ですが、デューデリジェンスでは報告書の納品を約束する形になっていることがあります。

  • 報告書の完成が報酬の条件になっていないか
  • 調査の範囲と、範囲外の追加の依頼の扱いが決まっているか
  • 報告書の内容に対して、どこまでの責任を負う書き方になっているか

開示される資料に限りがある中での調査は、すべてを把握できる前提に立てません。契約の形の違いは準委任契約と請負契約の違い、範囲が広がったときの扱いは作業範囲が広がったときの契約の扱いで解説しています。

6. 情報の扱いと、売買の制限

取引の秘密を扱うため、守るべき約束を契約の前に確かめます。

  • 秘密保持の範囲と期間、契約の終了後の扱い
  • 資料の置き場所、使う端末やアカウントの決まり
  • 閲覧できる人を限った資料（クリーンチームなど）の扱いと、自分がその対象か
  • 株式などの売買を制限する誓約や、取引先の規程に従う定めがあるか

上場会社が関わる取引では、インサイダー取引規制への備えも欠かせません。考え方はM&A・PMIコンサルタントがフリーランスになるには、秘密保持の約束の読み方は秘密保持契約（NDA）の記事をご覧ください。

7. 稼働の振れ幅と精算

PMIの稼働は、取引の山場で大きく振れます。

  • Day1の前後に、夜間や休日の切り替え作業や待機があるか
  • 精算幅を超えたときの扱いと、取引が止まって稼働が少ない月の扱い
  • 出社が必要な時期（Day1の現場対応、従業員への説明など）

「期限だから」と無償で対応し続けると、時間あたりの報酬が下がります。精算の仕組みは精算幅の記事、報酬の決まり方はM&A・PMIコンサルタントの報酬の記事をご覧ください。

注意

PMIの案件では、参画後に役割が広がりやすい傾向があります。別の取引の調査、統合後の事業計画づくり、社内の規程の作成など、契約の業務範囲に入っていない仕事を頼まれたときは、引き受ける前に範囲と条件を確かめましょう。別の取引に関わる場合は、情報の扱いと利益相反の確認もあらためて必要になります。

確かめた内容を書面と照らし合わせる

面談や事前の確認で聞いた内容は、契約の前に書面と照らし合わせます。フリーランス法では、発注する事業者は業務を委託したら直ちに、業務の内容、報酬の額、支払期日などの取引条件を、書面またはメールなどで明示することとされています。支払期日は、給付を受け取った日から60日以内のできる限り短い期間で定めることとされています（2026年10月時点、公正取引委員会の案内による）。明示される事項の中身はフリーランス法で明示される取引条件をご覧ください。

PMIの案件では、特に次の点が書面に反映されているかを確かめます。

  1. 業務の内容に、担う局面と領域が書かれているか
  2. 報告書などの成果物の範囲と、完成が報酬の条件かどうか
  3. 開始日の決まり方と、取引の延期・中止のときの扱い
  4. 稼働の幅と、超えたときの精算方法
  5. 秘密保持と売買の制限の定め

面談で聞いておくとよい質問はM&A・PMIコンサルタントの面談でよく聞かれる質問と答え方の逆質問の項目、一般的な逆質問の考え方は面談で聞いておくべき逆質問で紹介しています。

エージェントベストの見解

当社では、取引先の会社の実態と支払条件を確かめた案件を扱い、契約では業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。PMIの案件で気になりやすい、取引が延びたときの開始日の扱いや、Day1の前後の稼働の扱いなど、書面だけでは読み取りにくい点は、ご質問いただければ確認します。条件に迷う点があれば、契約の前に早めにご相談ください。

ポイント

  • PMIの案件は、立場・局面・取引の確度で負担と責任が大きく変わる
  • 誰の側に立つか、局面と期限、担う領域と決める人を面談で確かめる
  • 取引が延期・中止になったときの扱いと、成果物の責任の書き方を確かめる
  • 情報の扱いと売買の制限、稼働の振れ幅と精算を書面と照らし合わせる

よくある質問

取引の確度が低そうな案件は避けたほうがよいですか？

避ける必要はありません。調査の段階の案件は、取引が見送られることも含めて仕事です。ただし、取引が止まったときに契約をどう終え、それまでの稼働をどう精算するかを、参画前に確かめてから受けることをおすすめします。

面談で取引の局面や期限を聞くのは失礼ですか？

担う範囲と稼働の見込みを判断するための確認として聞けば、失礼にはあたりません。秘密に関わるため答えられないこともあるので、その場合は無理に聞き出さず、「時期の目安だけでも」と範囲を絞って尋ねるとよいでしょう。

報酬の高い案件と、立場や範囲のはっきりした案件で迷ったらどうしますか？

一概には言えませんが、PMIの案件では、範囲があいまいなまま期限だけが迫ると、稼働が増えて時間あたりの報酬が下がることがあります。報酬の額だけでなく、稼働の見込み、決める人の明確さ、取引が止まったときの扱いを合わせて比べるとよいでしょう。

業務委託契約の基礎

業務委託契約書のチェックポイント｜署名前に確かめたい10項目

業務委託契約書は、契約形態・業務範囲・報酬と精算・支払期日・契約期間と解除・知的財産・秘密保持・損害賠償などを署名前に確認します。フリーランス新法で発注者が明示すべき事項と照らし合わせると、抜けに気づきやすくなります。

 業務委託契約の基礎

準委任契約と請負契約の違い｜フリーランスが知っておくべきこと

準委任は「業務を行うこと」、請負は「仕事を完成させること」に報酬が払われる契約です。責任の範囲・報酬の条件・途中でやめるときの扱いが違うため、契約書で何を約束しているかを確かめることが大切です。

 フリーランス新法・下請法

フリーランス新法の取引条件の明示｜受け取るべき8項目と確認のしかた

フリーランス新法では、発注者は業務委託をしたら直ちに、業務の内容・報酬の額・支払期日など8項目を書面かメール等で明示しなければなりません。口頭だけは不可です。受け取るべき内容と、未定事項や共通事項の扱いを整理します。

 業務委託契約の基礎

作業範囲が広がったときの契約の扱い｜追加の報酬と変更の残し方

契約で決めた業務範囲を超える作業は、原則として当初の報酬に含まれません。追加するなら、作業内容・報酬・期限を決め直して書面やメールで合意します。フリーランス新法の不当な給付内容の変更の考え方と、変更を合意する手順を整理します。

 単価・報酬交渉

精算幅（140〜180時間など）とは｜超過・控除の計算方法

精算幅は、月額報酬のままでよい稼働時間の範囲です。上限を超えると超過分が加算され、下限を下回ると控除されます。超過・控除の単価は上下割か中間割かで変わるため、仮の数字を使って計算方法を整理します。

 業務委託契約の基礎

秘密保持契約（NDA）で確認すること｜対象・期間・実績として話せる範囲

NDAで確かめたいのは、秘密情報の範囲と例外、使ってよい目的、守る期間、終了時の返還・廃棄、違反時の責任の5点です。フリーランスは、実績としてどこまで話せるかも署名前に決めておくと安心です。
