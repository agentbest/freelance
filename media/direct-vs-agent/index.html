直接契約とエージェント経由の違い｜それぞれの向き不向き

公開 2026-10-29　監修：株式会社エージェントベスト

直接契約とエージェント経由の違いは、案件探し・契約・請求・回収といった仕事を、自分で担うか、間に入る会社に任せるかです。直接契約は間に入る会社の取り分がない分、受け取る金額が増えやすい一方、営業や事務、トラブル対応はすべて自分の仕事になります。エージェント経由は差額が生じる代わりに、それらを任せられます。

どちらが有利かは人によって違います。この記事では、項目ごとの違いと、それぞれに向く人・注意点を整理します。

二つの形の基本的な違い

項目直接契約エージェント経由
契約の相手発注元（エンドや元請）フリーランスエージェント
案件の探し方自分の人脈・発信・営業担当者が条件に合う案件を紹介
報酬の交渉自分で発注元と行う担当者を通して行う
受け取る金額間に入る会社の取り分がない発注元が払う金額との差が生じる
契約書の作成・確認自分で用意・確認するエージェントが用意し、自分は確認する
請求と回収自分で請求し、入金を確かめるエージェントに請求し、エージェントから受け取る
次の案件自分で探す担当者に相談できる
トラブルの相談自分で対応、必要なら外部の窓口へ担当者に相談できる

「直接契約」という言葉は、ここでは発注元とフリーランスが、間に会社を挟まずに業務委託契約を結ぶ形を指します。

直接契約のよい点と負担

よい点

  • 受け取る金額が増えやすい：間に入る会社の取り分がないため、発注元が払う金額がそのまま報酬になる
  • 発注元と直接話せる：業務内容や評価、更新の意向を直接聞ける
  • 条件を自分で決められる：稼働日数や働き方を、相手と合意できれば柔軟に決められる

負担になること

  • 営業の手間：案件を得るために、人脈を保ち、実績を発信し、提案する時間がかかる
  • 契約の準備：契約書を用意し、業務範囲・報酬・支払期日・損害賠償・秘密保持などを自分で確かめる
  • 請求と回収：毎月の請求書の発行と、入金の確認を自分で行う。入金が遅れたときの催促も自分の仕事
  • 案件が途切れたとき：次の案件を探す期間の収入がない
  • 相手の与信：取引先の経営状態を自分で判断する必要がある

直接契約では、契約書の条項を自分で読み、不利な内容があれば交渉することになります。見るべき点は契約書のチェックポイントで整理しています。

注意

エージェント経由で参画した発注元から、契約の途中や終了後に「直接契約に切り替えないか」と声をかけられることがあります。エージェントとの契約に、一定期間は発注元と直接取引しない旨の条項が入っていることが多いため、応じる前に契約書を確認してください。条項の読み方は直接契約の禁止・競業避止の記事で解説しています。

エージェント経由のよい点と負担

よい点

  • 案件探しを任せられる：希望条件を伝えれば、合う案件を紹介してもらえる
  • 自分では接点のない企業の案件に出会える：人脈だけでは届かない業界や規模の案件に応募できる
  • 契約と請求の事務が軽くなる：契約書の作成や発注元への請求はエージェントが行う
  • 支払の安定：発注元からの入金を待たずに、契約で決めた期日に支払われる形が一般的
  • 間に立って調整してもらえる：業務範囲や稼働の相談、更新・単価の見直しを担当者を通して進められる

負担になること

  • 差額が生じる：発注元が払う金額と、自分が受け取る報酬に差がある。内訳の考え方はエージェントのマージンの記事で整理している
  • 情報が間接的になる：発注元の評価や意向が、担当者を通して伝わる
  • 担当者との相性：担当者の理解度によって、紹介される案件の合い方が変わる

エージェントベストの見解

案件をご紹介する立場から見ると、エージェント経由のよさは「案件を探す」だけでなく、「条件を確かめる」ところにもあると感じます。当社では、取引先の会社の実態と支払条件を確かめた案件を扱い、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。直接契約で自分が担う確認作業のうち、どこまでを任せたいかを考えると、どちらの形が合うかが見えやすくなります。

どちらが向いているか

直接契約が向いている人

  • 前職の取引先や知人など、仕事を頼んでくれる人脈がある
  • 発信や提案が苦にならず、営業の時間をとれる
  • 契約書を読み、条件を交渉することに慣れている
  • 請求・入金管理を、会計ソフトなどで仕組み化できる
  • 案件が途切れても、数か月は生活できる蓄えがある

エージェント経由が向いている人

  • 独立したばかりで、人脈や実績の見せ方がまだ固まっていない
  • 本業の業務に時間を使い、営業や事務は任せたい
  • 自分では接点のない業界や規模の案件を探したい
  • 契約条件の確認や交渉を、間に立って進めてほしい
  • 案件の切れ目をできるだけ短くしたい

組み合わせるという選び方

二つの形のどちらか一つに決める必要はありません。知人から直接受ける小さな案件と、エージェント経由の稼働の大きい案件を組み合わせる人もいます。ただし、掛け持ちでは稼働時間の合計や、それぞれの契約の秘密保持・競業の条項に注意が必要です。考え方は掛け持ちの記事にまとめています。

迷ったときに考えたい3つの問い

向き不向きの一覧に当てはめても決めきれないときは、次の3つを自分に問いかけてみると整理しやすくなります。

1. 営業と事務に、月に何時間を使えるか

直接契約では、案件探し、提案、契約書の確認、請求、入金の確認に時間がかかります。この時間は報酬の対象にならないことが多く、稼働時間とは別に確保する必要があります。本業の稼働で手一杯になりそうなら、その分を任せる価値があります。

2. 案件が途切れたとき、どう次を探すか

直接契約だけで仕事をしている場合、取引先の事情で契約が終わると、次の案件を自分で一から探すことになります。人脈から次の話が来る見込みがあるか、探す期間の生活費をまかなえるかを考えておくと、判断の材料になります。空白期間の備えは案件が途切れたときの記事で整理しています。

3. 契約書を読み、条件を交渉できるか

直接契約では、損害賠償の上限や成果物の権利、中途解約の予告期間などを、自分で読んで判断します。苦手意識がある場合は、最初は条件の確認を任せられる形で経験を積み、慣れてから直接の取引を増やす方法もあります。

直接契約で気をつけたい契約の確認点

直接契約では、自分で条件を確かめる場面が増えます。少なくとも次の点を契約書や発注書で確認しましょう。

  1. 業務の範囲：何をどこまで行うか。追加の依頼の扱い
  2. 報酬の額と精算：月額・精算幅・超過と控除の計算方法
  3. 支払期日：締め日と支払日
  4. 契約期間と解約：更新の方法、中途解約の予告期間
  5. 損害賠償：上限があるか
  6. 成果物の権利：著作権がどちらに帰属するか

2024年11月に施行されたフリーランス法では、発注事業者は業務を委託したら直ちに、給付の内容・報酬の額・支払期日などの取引条件を、書面またはメールなどで明示することとされています。また、報酬の支払期日は、給付を受け取った日から60日以内のできる限り短い期間で定めることとされています（公正取引委員会の案内）。直接契約でも、この明示を受け取り、口頭の約束だけで仕事を始めないようにしましょう。

支払期日の考え方は支払サイトの記事、トラブルにあったときの相談先は取引トラブルの相談先の記事で整理しています。

エージェントベストの見解

直接契約とエージェント経由を組み合わせている方からは、「知人からの案件は条件があいまいなまま始まりやすい」というお話を伺うことがあります。直接契約でも、業務範囲・報酬・支払期日・契約期間を文書に残しておくと、あとで認識がずれたときに確かめる手がかりになります。当社経由の案件では、こうした条件を個別契約に書いてお渡ししています。

ポイント

  • 違いは、案件探し・契約・請求・回収を自分で担うか、任せるか
  • 直接契約は受け取る金額が増えやすいが、営業と事務、回収の負担がある
  • エージェント経由は差額が生じるが、案件探しと条件の確認、事務を任せられる

よくある質問

直接契約に切り替えると、報酬は上がりますか？

上がるとは限りません。発注元が直接契約の場合の予算を別に考えていることもあり、エージェント経由のときに発注元が払っていた金額と同じになるとは限りません。また、エージェントとの契約に直接取引を制限する条項がある場合、切り替え自体ができないこともあります。

直接契約で入金が遅れたら、どうすればよいですか？

まずは契約書や発注書で支払期日を確かめ、相手に確認の連絡を入れます。それでも支払われない場合は、フリーランス法の申出の窓口や、取引上のトラブルを相談できる公的な窓口があります。詳しくは取引トラブルの相談先の記事をご覧ください。

独立直後はどちらから始めるのがよいですか？

人脈から仕事の話がすでにあるなら、直接契約から始める方法もあります。そうでない場合は、エージェント経由で案件の経験と実績を積みながら、直接の取引先を少しずつ増やす人もいます。最初の案件の選び方は最初の案件の記事で整理しています。

案件の探し方

フリーランスエージェントのマージンとは｜報酬の内訳と確かめ方

エージェントのマージンは、発注元が払う金額とフリーランスが受け取る報酬の差です。その差で営業・契約事務・支払の立替などがまかなわれます。率はサービスや案件で違うため、自分の契約の報酬額と条件を確かめるのが要点です。

 案件の探し方

フリーランスエージェントの使い方｜登録から参画までの流れと準備

フリーランスエージェントは、登録・面談で希望を伝え、紹介された案件に応募し、発注側との面談を経て契約・参画する流れで使います。各段階で準備すること、確かめること、うまく使うためのコツを整理します。

 案件の探し方

商流とは｜エンド直・元請・二次請の違いとフリーランスへの影響

商流は、案件を発注した会社（エンド）からフリーランスまで、契約が何社を経てつながっているかを表す言葉です。間に入る会社が多いほど、報酬・情報の伝わり方・指示系統に影響が出やすくなります。構造と確かめ方を整理します。

 案件の探し方

知人の紹介で案件を得るときの注意点｜条件の決め方と関係を守る進め方

知人の紹介の案件は決まりやすい一方、条件をあいまいにしたまま始めやすいのが落とし穴です。業務範囲・報酬・支払期日・契約期間を書面で決め、直接契約の禁止条項や紹介料の扱いも最初に確かめます。

 業務委託契約の基礎

直接契約の禁止・競業避止の条項をどう読むか｜対象・期間・範囲の確認

競業避止は「競合する仕事をしない」、直接契約の禁止は「紹介された取引先と直接契約しない」という約束です。対象・期間・範囲・違反時の扱いを確認します。合理的な範囲を超える一方的な義務は独占禁止法上の問題になり得ます。

 業務委託契約の基礎

業務委託契約書のチェックポイント｜署名前に確かめたい10項目

業務委託契約書は、契約形態・業務範囲・報酬と精算・支払期日・契約期間と解除・知的財産・秘密保持・損害賠償などを署名前に確認します。フリーランス新法で発注者が明示すべき事項と照らし合わせると、抜けに気づきやすくなります。
