インボイス・消費税

フリーランスの消費税の納税｜計算の手順と申告・納付の流れ

消費税の課税事業者になったフリーランスは、1月1日から12月31日までの1年分の消費税を、翌年3月31日までに申告して納めます。令和8年分（2026年分）なら、期限は2027年3月31日（水）です。所得税の確定申告（3月15日）とは別の手続きで、税務署から納付書は届きません。

納める額は、報酬にかかる消費税額から計算します。インボイスの登録で課税事業者になった個人事業者は、令和8年分は「2割特例」、令和9・10年分は「3割特例」を使えるため、まずはその計算で納税額を見積もっておくと資金の準備がしやすくなります（2026年10月時点）。

消費税の申告が必要になるフリーランス

国税庁の案内をもとに整理すると、個人事業者で消費税の申告が必要になるのは主に次の人です。

  • インボイス（適格請求書発行事業者）の登録を受けている人：売上の額にかかわらず申告が必要
  • 基準期間（前々年）の課税売上高が1,000万円を超える人
  • 特定期間（前年1〜6月）の課税売上高が1,000万円を超える人：給与等の支払額で判定することもできる
  • 課税事業者選択届出書を出している人

登録していない免税事業者は、消費税を納める必要はありません。登録するかどうかの考え方はインボイス登録はすべきかの記事、制度の全体像はインボイス制度の基本をご覧ください。

注意

「売上が1,000万円を超えたのは今年だから、今年から課税」ではありません。判定は前々年と前年1〜6月の売上で行います。反対に、売上が1,000万円を超えた年の2年後は、登録の有無にかかわらず課税事業者になり、2割特例・3割特例も使えません。売上が伸びた年は、2年先の納税まで見込んでおきましょう。

納める消費税の計算の手順

消費税の納税額は、どの計算方法を使っても、まず「報酬にかかる消費税額（売上税額）」を出すところから始まります。国税庁の「No.6351」に沿って、一般的な手順を見ていきます。

  1. 1年分の課税売上を集計する：報酬（税込）の合計を、税率ごとに出す。ITの業務委託の報酬は通常10%
  2. 課税標準額を出す：税込の金額に100/110を掛ける
  3. 売上税額（国税分）を出す：課税標準額に7.8%を掛ける
  4. 差し引く額を計算する：一般課税なら仕入・経費の消費税額、簡易課税ならみなし仕入率、2割特例なら売上税額の8割
  5. 地方消費税を加える：国税分の納付税額に22/78を掛けた額を足す

消費税率10%のうち、7.8%が国の消費税、2.2%が地方消費税です。申告書では国税分を先に計算し、地方消費税をその22/78として足します。

どの計算方法を使うか

計算方法差し引く額の考え方詳しい解説
一般課税実際に払った仕入・経費の消費税額―
簡易課税売上税額×みなし仕入率（ITの業務は多くが第5種・50%）簡易課税の記事
2割特例（令和8年分まで）売上税額の8割2割特例の記事
3割特例（令和9・10年分）売上税額の7割2割特例の記事

それぞれの条件や届出の期限は、各記事で解説しています。ここでは、申告と納付の流れに絞って説明します。

2割特例で試算する例

インボイスの登録をきっかけに課税事業者になった個人事業者が、令和8年分に2割特例を使う場合で試算します（仮の数字。端数処理は省略しています）。

  • 1年間の報酬：税込880万円（税抜800万円）、すべて税率10%
手順計算金額
課税標準額880万円×100/110800万円
売上税額（国税分）800万円×7.8%624,000円
2割特例で差し引く額624,000円×80%499,200円
納める消費税（国税分）624,000円−499,200円124,800円
地方消費税124,800円×22/7835,200円
合計160,000円

合計は、報酬にかかる消費税80万円（税抜800万円×10%）の2割と同じになります。同じ報酬で、計算方法ごとの国税分と地方消費税を並べると次のようになります。

計算方法国税分地方消費税（22/78）合計
2割特例（令和8年分）124,800円35,200円160,000円
3割特例（令和9・10年分）187,200円52,800円240,000円
簡易課税（第5種・50%）312,000円88,000円400,000円

報酬が変わらなくても、令和9年分から納税額が増える点を見込んでおきましょう。

エージェントベストの見解

案件をご紹介していると、「報酬が税込か税別か分からないまま参画した」という声を聞くことがあります。税込と税別では、同じ金額でも課税売上の額が変わり、消費税の試算がずれます。当社では、報酬の額と支払期日を個別契約に書いてお渡ししています。登録している方は、契約ごとに税込・税別を確かめ、売上を税率ごとに記録しておくことをおすすめします。

申告と納付の期限

国税庁の「No.6601」によると、個人事業者の消費税の確定申告と納付の期限は、本来の2月末日から3月31日に延長されています。

項目令和8年分（2026年1〜12月）の場合
確定申告の期限2027年3月31日（水）
納付の期限2027年3月31日（水）
所得税の確定申告（参考）2027年3月15日（月）

所得税の申告を3月15日までに済ませると、2週間あまりで消費税の期限が来ます。どちらの申告も、同じ1年分の帳簿をもとに作るため、所得税の決算書を作る段階で消費税の売上の集計も済ませておくと効率的です。

申告書の出し方

申告書は、国税庁の「確定申告書等作成コーナー」で作成し、e-Taxで送信できます。2割特例を使う場合は、申告書に「付表6」を付けます。e-Taxの準備はe-Taxの記事で解説しています。

納付の方法と振替納税

納付は、e-Taxの電子納税、金融機関や税務署の窓口、コンビニ納付などから選べます。口座からの自動引き落としにしたい場合は「振替納税」を使えます。

  • 振替納税を使えるのは、確定申告の所得税と個人事業者の消費税
  • 事前に「預貯金口座振替依頼書」を出す。所得税と消費税は、それぞれ手続きが必要
  • 引き落とし日は国税庁が決める。令和7年分の消費税は2026年4月30日（木）だった

振替納税は、納期限より後の日に引き落とされるため、申告から引き落としまでに資金を準備する時間ができます。ただし、残高が足りずに引き落とせないと、納期限の翌日から延滞税がかかることがあります。

前年の税額が大きいと中間申告がある

国税庁の「No.6609」によると、前年の消費税の年税額（地方消費税を除く）が48万円を超える個人事業者は、年の途中で中間申告と納付をします。

前年の確定消費税額（国税分）中間申告の回数1回に納める額の目安
48万円以下原則不要（任意の中間申告はできる）―
48万円超〜400万円以下年1回前年の税額の6/12
400万円超〜4,800万円以下年3回前年の税額の3/12
4,800万円超年11回前年の税額の1/12

これに地方消費税分（22/78）が加わります。期限は、原則として中間申告の対象期間の末日の翌日から2か月以内です。中間で納めた額は、確定申告の税額から差し引かれます。

2割特例を使っている間は、国税分が48万円を超える人は多くありません。ただ、3割特例や一般課税に移ると税額が増え、中間申告の対象になることがあります。所得税の予定納税とは別の制度で、予定納税の記事では両者の違いも説明しています。

エージェントベストの見解

案件紹介の現場では、インボイスの登録後、初めての消費税の納付で手元の資金が足りなくなった、というご相談を見かけます。所得税・住民税・国民健康保険料の支払いと時期が重なるためです。毎月の報酬が入ったら、売上にかかる消費税額の2〜3割程度を目安に別口座へ移しておくと、3月に慌てずに済みます。計算方法の選び方や個別の税額は、税理士・税務署にご相談ください。

毎月やっておくと申告が楽になること

  1. 請求書ごとに税込・税別と税率を記録する：会計ソフトに入れるときに区分しておく
  2. 交付したインボイスの控えを保存する：登録している以上、特例を使う年も保存が必要
  3. 立替金や交通費の扱いを確かめる：報酬と一緒に受け取る交通費などが課税売上に入るかは、契約の内容で変わる
  4. 納税資金を分けておく：所得税・住民税とは別に、消費税の分を取り分ける

ポイント

  • 課税事業者のフリーランスは、1〜12月分の消費税を翌年3月31日までに申告・納付する
  • 計算は「課税標準額×7.8%」から差し引く額を引き、地方消費税（22/78）を足す
  • 令和8年分は2割特例、令和9・10年分は3割特例で試算できる（条件あり）
  • 前年の国税分が48万円を超えると中間申告がある
  • 振替納税を使うと、納期限より後の日に口座から引き落とされる

よくある質問

消費税の申告は、所得税の確定申告と一緒に出せますか？

別の申告書です。期限も、所得税は3月15日、個人事業者の消費税は3月31日と違います。確定申告書等作成コーナーでは、どちらも作成してe-Taxで送信できるため、同じ時期に続けて作ると手間を減らせます。

売上がなかった年も消費税の申告は必要ですか？

国税庁の「No.6601」では、課税売上がなく納付する税額もない課税期間は、確定申告書の提出は不要とされています。ただし、仕入にかかる消費税額や中間納付額がある場合は、還付を受けるための申告ができます。登録を続けているかどうかも含めて、税務署にご確認ください。

期限までに納められないとどうなりますか？

納期限を過ぎると、延滞税がかかることがあります。申告は期限内に済ませ、納付が難しい場合は早めに税務署に相談してください。振替納税を使っている場合も、引き落とし日に残高が足りないと延滞税の対象になることがあるため、残高を確かめておきましょう。

インボイス制度の基本｜フリーランスへの影響と2026年10月からの変更点

インボイス制度は、取引先が消費税の仕入税額控除を受けるために登録事業者の請求書を求める仕組みです。免税のフリーランスは登録するか否かで納税と取引条件が変わります。2026年10月からの経過措置の変更も整理します。

 インボイス・消費税

2割特例とは｜対象と期限、令和9年分からの3割特例への切り替え

2割特例は、免税事業者から登録して課税事業者になった人が消費税の納税額を売上税額の2割にできる制度です。個人事業者は令和8年分の申告まで使え、令和9・10年分は3割特例に切り替わります。対象と手続きを整理します。

 インボイス・消費税

簡易課税制度の仕組みとみなし仕入率｜ITフリーランスは第5種の50%

簡易課税は、売上の消費税額にみなし仕入率を掛けた額を仕入税額とみなす計算方法です。エンジニアやコンサルの業務は多くが第5種（50%）です。2割特例・3割特例が終わった後の選択肢として、条件と届出の時期を整理します。

インボイス登録はすべき？フリーランスの判断の考え方と試算の手順

登録すべきかは「取引先がインボイスを必要としているか」と「登録後の納税額」で決まります。企業向けの業務が中心なら登録を検討する場面が多く、令和9・10年分は3割特例で負担を抑えられます。判断の手順を整理します。

 インボイス・消費税

免税事業者からの仕入れの経過措置｜控除割合は80%から70%へ、その後の変わり方

免税事業者などからの仕入れについて、発注側が控除できる割合は2026年10月1日に80%から70%に下がりました。2028年10月から50%、2030年10月から30%、2031年10月以降は0%です。フリーランスへの影響を整理します。

 確定申告・所得税

フリーランスの確定申告の流れ｜期限と準備するもの

令和8年分の確定申告は、2027年2月16日から3月15日までに申告し、所得税も同じ日までに納めます。1年分の帳簿と請求書・領収書、控除の証明書をそろえ、決算書を作って申告書を出すのが基本の流れです。
