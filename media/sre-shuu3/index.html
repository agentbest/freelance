SREの週2〜3日・副業案件はある？見つかりやすい案件の型と探し方、受けるときの注意点

公開 2026-11-04　監修：株式会社エージェントベスト

SRE（サイト信頼性エンジニア）の週2〜3日・副業の案件は、ありますが多くはありません。SREは障害のときにすぐ動けることが期待されやすく、オンコールを含む運用の案件では、稼働日の少ない人に任せにくいためです。一方で、SLOや監視の整備、手作業の自動化、障害の振り返りの仕組みづくりなど、成果物で区切れる仕事なら、週2〜3日でも受けられる案件が見つかります。

探すときは、「週3日でSREなら何でも」ではなく、稼働日数に合う仕事の型の案件を選ぶことが大切です。この記事では、週2〜3日・副業のSRE案件の傾向、探し方、受けるときの注意点を整理します。週3日の働き方全般は週3日の業務委託案件の記事で解説しています。

週2〜3日のSRE案件が少ない理由

理由は主に3つあります。

  1. 障害は稼働日を選ばない：本番の環境は毎日動いており、障害の対応に入れる日が限られる人には、運用の責任を持たせにくい
  2. 当番の輪に入りにくい：オンコールの当番は人数で回すため、稼働日が少ない人を入れると当番表が組みにくくなる
  3. 基盤の文脈が深い：構成や過去の障害の経緯を知らないと判断しにくく、短い稼働では立ち上がりに時間がかかる

逆に言えば、障害対応やオンコールを切り離せる仕事なら、稼働日数が少なくても成り立ちます。

週2〜3日・副業で見つかりやすいSRE案件

案件の型中身週2〜3日で成り立つ理由
SLO・監視の整備指標の選定、ダッシュボードとアラートの見直し成果物と期限で区切りやすい
トイルの削減・自動化手作業の洗い出しと、IaCやスクリプトへの置き換え作業を一つずつ切り出して進められる
振り返りの仕組みづくりポストモーテムの型、障害の記録の運用を整える会議と文書が中心で、曜日を決めて進めやすい
技術の相談役社内のSREや開発チームの設計のレビュー、方針の相談定例の場で助言する形にできる
小規模なサービスの基盤の見直しスタートアップなどの監視・バックアップ・リリースの仕組みの点検規模が小さく、全体を短い時間で把握できる

どの型でも、オンコールに入らないこと、障害の一次対応を担わないことが前提になっている案件が中心です。オンコールを含む案件で週2〜3日を求めると、当番の日だけ稼働が大きく増えるなど、条件が合いにくくなります。

週2〜3日のSRE案件の探し方

1. 担える範囲を先に決める

SLOの整備、自動化、振り返りの仕組み、設計のレビューなど、自分が短い稼働でも成果を出せる仕事を先に決めます。「SRE全般」と伝えるより、型を絞って伝えたほうが案件と結びつきやすくなります。

2. オンコールと時間外の連絡の扱いを先に決める

オンコールに入れるか、入れないか。稼働日以外にチャットの連絡をどこまで見るか。障害が起きたときに稼働日外でも呼ばれる可能性があるか。これらを応募の前に決めておくと、面談で条件をすり合わせやすくなります。

3. 週5日の案件の一部を切り出してもらう

週5日で募集されている案件でも、監視の整備や自動化の部分だけなら週2〜3日で担える場合があります。案件票の稼働日数だけで判断せず、切り出せそうな仕事があれば相談してみる価値があります。

4. 経験の近い基盤の案件から選ぶ

稼働日数が少ないほど、立ち上がりの早さが求められます。使ったことのあるクラウドやコンテナ基盤、監視のツールに近い案件を選ぶと、短い稼働でも成果を出しやすくなります。リモートで受けられるかどうかも合わせて確かめておきましょう。SREのリモートの働き方はSREのリモート案件の記事で解説しています。

エージェントベストの見解

SREの案件をご紹介していると、週2〜3日で成果を出している方は、最初に「この期間でこの指標とアラートを整える」「この手作業を置き換える」と、担う範囲と成果物を具体的に決めている傾向があります。反対に、範囲を決めずに参画すると、障害の調査の手伝いなど急ぎの依頼に時間を取られ、本来の改善が進まないことがあります。担える範囲と、オンコールに入るかどうかを最初に伝えておくことをおすすめします。

短い稼働で信頼を得る進め方

  1. 最初の数回で現状を文書にする：構成、監視、過去の障害、手作業の一覧を短くまとめ、発注元と認識をそろえる
  2. 稼働日ごとの成果を残す：その日に何を進め、次の稼働日に何をするかを、共有の場所に書いておく
  3. 小さく出して確かめる：アラートの見直しや自動化は、一度に大きく変えず、一つずつ反映して効果を確かめる
  4. 自分がいない日に困らない形で渡す：手順書やコードの説明を残し、稼働日外に問い合わせが来ない状態をつくる

SREの仕事は、本番の環境に変更を入れるほど、変更の後に何か起きたときの対応が問題になります。稼働日の終わりに大きな変更を入れないのも、短い稼働で信頼を保つための工夫です。

受けるときの注意点

障害対応の責任の範囲を決める

自分が入れた変更で障害が起きたとき、稼働日外でも対応するのか、社内の当番に引き継ぐのかを、契約の前に決めておきます。決めないままでは、責任感から稼働日外に無償で対応し続けることになりかねません。

稼働時間の記録と精算を確かめる

時間外に対応した時間をどう扱うか、精算の条件と合わせて確かめておきます。精算の仕組みは精算幅の記事をご覧ください。参画後に頼まれる仕事が広がった場合の扱いは作業範囲が広がったときの契約の扱いで解説しています。

本番環境の権限と端末の扱いを確かめる

週2〜3日の案件でも、本番の環境に触る権限が与えられることがあります。権限の範囲、作業に使う端末、接続の方法を確かめ、副業の場合は本業の端末と完全に分けましょう。

掛け持ちのときは障害の重なりに備える

複数の案件を掛け持ちする場合、それぞれの案件で同じ時間に障害が起きる可能性があります。どちらの案件でもオンコールに入らない形にしておくと、重なりの問題を避けやすくなります。掛け持ちの注意点は複数の案件を掛け持ちするときの注意点、稼働の割合の考え方は稼働率の記事で解説しています。

注意

会社員の副業でSREの案件を受けるときは、本業の会社の就業規則で副業が認められているかを最初に確かめましょう。SREは本番の環境や障害の情報など、機密に触れやすい立場です。本業で知った構成や障害の情報を副業の案件で使わないよう、意識して切り分ける必要があります。本業でオンコールに入っている場合は、副業の稼働と当番の時間が重ならないかも確かめておきましょう。

会社員の副業でSRE案件を受けるとき

副業の場合、平日の日中に稼働できないことが多く、案件の型はさらに絞られます。設計のレビューや振り返りの仕組みづくりなど、会議を夜や週末に寄せられる仕事や、非同期で進められる自動化の仕事が中心になります。

副業の所得の申告や住民税の扱いは、会社員の副業で業務委託案件を受けるときの注意点と副業の所得が少ないときの確定申告の記事で解説しています。就業規則で副業が禁止されている場合のリスクは副業禁止の会社で業務委託を受けるリスク、平日の日中に動けない場合の探し方は週末・夜だけの業務委託案件の記事をご覧ください。税務の判断に迷う場合は、税理士や勤務先の担当部署にご相談ください。

エージェントベストの見解

当社では、案件をご案内する前に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをお出ししています。週2〜3日や副業でSREの案件を探す場合は、稼働できる曜日と時間帯、オンコールに入れるかどうか、担える仕事の型をあわせてお伝えいただくと、案件を照らし合わせやすくなります。稼働日外の連絡や障害対応の扱いなど、案件票に書かれていない点は、ご質問いただければ確認します。

ポイント

  • SREの週2〜3日・副業の案件は多くないが、成果物で区切れる仕事なら見つかる
  • 見つかりやすいのは、SLO・監視の整備、トイルの削減、振り返りの仕組みづくり、技術の相談役など、オンコールを切り離せる案件
  • 担える範囲とオンコールの扱いを先に決め、稼働日外の障害対応の責任を契約前にそろえる
  • 副業では就業規則、機密の切り分け、本業の当番との重なりを確かめる

よくある質問

週2〜3日の案件でも、SREの経験として評価されますか？

評価されます。稼働日数より、何を整え、何が変わったかが見られます。SLOを導入した、アラートを見直した、手作業をなくしたといった成果を、前と後の変化とあわせてスキルシートに書いておきましょう。書き方はSREのスキルシートの記事で解説しています。

週2〜3日でもオンコールに入れる案件はありますか？

なくはありませんが、当番の日に稼働が大きく増えるなど、条件が複雑になりやすい案件です。入る場合は、当番の頻度、応答までの時間、時間外の対応の精算を、契約の前に書面で確かめておきましょう。

週3日で始めて、あとから週5日に増やすことはできますか？

発注元の状況と、契約の更新の時期によっては可能です。増やしたい場合は、成果を示したうえで、更新の前に相談するのが現実的です。稼働日数を増やすと、オンコールへの参加を求められることもあるため、条件をあわせて確かめておきましょう。

週3日の業務委託案件｜働き方と探し方、収入と稼働の考え方

週3日の業務委託案件は、経験のある職種で、担当範囲がはっきりした業務なら見つけやすい働き方です。報酬は稼働日数に応じて決まることが多く、残りの日の使い方まで含めて考えることが大切です。探し方と確認点を整理します。

 副業・複業

週末・夜だけの業務委託案件はある？探し方と会社員が注意すること

週末・夜だけの業務委託案件はありますが、平日日中の稼働を前提にした案件より数は限られます。範囲を区切れる開発や相談・レビューなどで見つかりやすく、勤務先の副業の規定、本業との時間の切り分け、確定申告を確かめておくことが大切です。

 副業・複業

会社員の副業で業務委託案件を受けるときの注意点｜就業規則・契約・税金の確かめ方

会社員が副業で業務委託案件を受けるときは、勤務先の就業規則、本業との競合や秘密の扱い、契約条件、確定申告と住民税の4点を先に確かめます。業務委託は会社員の給与とルールが違うため、受ける前の整理が大切です。

 副業・複業

副業禁止の会社で業務委託を受けるリスク｜就業規則の読み方と許可の求め方

就業規則で副業が禁止・許可制の会社で無断で業務委託を受けると、懲戒などの対象になるおそれがあります。厚生労働省のガイドラインの考え方を踏まえつつ、規則の読み方、許可の求め方、断られたときの選択肢と相談先を整理します。

 副業・複業

副業の確定申告｜所得20万円のルールの正しい理解と、住民税の申告が別に要る理由

副業の所得が20万円以下なら確定申告が不要になるのは、給与を1か所から受け年末調整を受けている人などに限られます。20万円は収入ではなく所得で数え、住民税の申告は別に必要なことがあります。医療費控除などで申告するときは副業分も含めます。

 リモート・稼働日数

複数の案件を掛け持ちするときの注意点｜契約・時間・情報管理の確認

案件の掛け持ちは、契約で他の仕事が制限されていないか、稼働の時間帯が重ならないか、情報を案件ごとに分けて扱えるかを先に確かめれば進めやすくなります。参画前に確認したい点と、掛け持ち中の進め方を整理します。
