Unityエンジニアの週2〜3日・副業案件｜探し方と受けるときの注意点

Unityエンジニアの週2〜3日・副業の案件は、週5日の案件と比べると少ないのが実情です。ゲームやXRの開発はチームで毎日やり取りしながら進むことが多く、実機での確認や機材の受け渡しもあるため、少ない日数では回しにくい仕事が多いからです。

ただ、仕事の切り出し方しだいで見つかる案件もあります。エディタ拡張などのツールづくり、性能の調査と改善の提案、試作、小さなアプリの改修や保守などです。この記事では、週2〜3日で見つかりやすい案件の型、探し方、短い稼働で信頼を得る進め方、受けるときの注意点を整理します。週3日の案件全般の考え方は週3日の業務委託案件で解説しています。

週2〜3日のUnity案件が少ない理由

Unityの案件で週2〜3日が少ないのは、主に次の理由からです。

  1. やり取りの量が多い：プランナーやデザイナーとの仕様の確認、素材の受け渡し、レビューが毎日のように発生する
  2. 実機での確認がある：端末やヘッドセット、開発機材での確認は、機材のある場所や時間に合わせる必要がある
  3. ビルドと配信の周期に合わせる必要がある：運営中のタイトルでは、配信の前に作業が集中し、週の決まった日だけでは追いつかないことがある
  4. プロジェクトの理解に時間がかかる：既存のコードやアセットの構成を理解するまでの時間は、稼働日数が少なくても大きくは縮まらない

反対に言えば、やり取りが少なく、成果を区切りやすい仕事であれば、週2〜3日でも回せます。

週2〜3日・副業で見つかりやすいUnity案件

案件の型主な仕事週2〜3日と相性がよい理由
ツール・エディタ拡張入力の画面、アセットの検査、ビルドの自動化使う人と仕様が決まれば、まとまった時間で作り進められる
性能の調査と改善の提案Profilerでの計測、原因の特定、直し方の提案調べて報告するまでを区切りやすい
試作・技術検証新しい機能やSDKの試し、企画の見せ方の試作期間と目的がはっきりしている
小さなアプリの改修・保守展示用や業務用のアプリの改修、版上げの対応変更の量が少なく、急ぎの対応が少ない
チームの技術支援コードレビュー、設計の相談、若手の相談役決まった曜日に入る形にしやすい

どの型も、自分が任される範囲と、何をもって終わりとするかを決めやすい点が共通しています。運営中のタイトルの機能開発に週2日で入る形は、チームの進め方次第で成り立つこともありますが、配信前の忙しさに合わせられるかを事前に確かめておきましょう。

エージェントベストの見解

Unityの案件をご紹介していると、週2〜3日で長く続きやすいのは、ツールづくりや性能の調査のように「自分の担当がはっきり区切られている」仕事です。反対に、運営中のタイトルの機能開発に少ない日数で入ると、仕様の確認やレビューの待ちが積み重なり、思ったほど作業が進まない傾向があります。応募の段階で、チームとのやり取りの頻度と、配信前の動き方を聞いておくことをおすすめします。

週2〜3日のUnity案件の探し方

1. 担える仕事を先に決める

まず、週2〜3日で何を担えるかを具体的にします。「Unityの開発全般」より、「エディタ拡張とビルドの自動化」「モバイルの描画負荷の調査」のように、型に当てはめて言えるほうが、案件と照らし合わせやすくなります。

2. 稼働する曜日と、稼働外の連絡の扱いを決める

週のどの曜日に稼働するか、稼働しない日に連絡が来たらどうするかを先に決めておきます。会社員の副業で受ける場合は、本業の時間帯に連絡を受けられないことも、最初に伝えておきましょう。副業に使える時間の見積もり方は副業に使える時間の見積もり方が参考になります。

3. 週5日の案件の一部を切り出してもらう

案件票が週5日になっていても、ツールや性能の調査など、一部を切り出して週2〜3日で受けられる場合があります。何を切り出せば成り立つかを、こちらから具体的に示すと話が進みやすくなります。

4. 機材とライセンスの用意を確かめる

週2〜3日の案件はリモートで受けることが多くなります。端末やヘッドセットを誰が用意するか、Unityのライセンス（シート）を発注元が用意するかを、探す段階で確かめておきましょう。リモートの作業環境の確認点はUnityエンジニアのリモート案件の記事で整理しています。

短い稼働で信頼を得る進め方

週2〜3日の案件では、毎日顔を合わせる人より、進み具合が見えにくくなります。次のような進め方で、見えにくさを補います。

  • 稼働の始めに、その日にやることを書く：チャットで今日の予定を短く共有する
  • 稼働の終わりに、終わったことと残ったことを書く：次の稼働までに相手が判断できるようにする
  • 質問はまとめて早めに出す：稼働しない日に答えをもらえるよう、前の稼働の終わりに出しておく
  • 計測の結果は数字と画面で残す：性能の調査では、計測した条件と結果を、後から誰でも見られる形にする
  • 作ったツールには使い方を添える：自分がいない日でも使えるように、短い説明を残す

特に、稼働しない日に相手を待たせない工夫が、短い稼働で信頼を得る鍵になります。

受けるときの注意点

担う範囲と稼働日数をそろえる

週2〜3日の契約なのに、配信前の不具合対応や、他の人の作業の確認まで求められると、稼働日数と責任が合わなくなります。担う範囲を契約の段階で書面にしておき、範囲が広がるときは条件を見直しましょう。

稼働の数え方と、完成の定義を確かめる

準委任の契約では、月の稼働時間の数え方と、上限・下限を超えたときの扱いを確かめます。ツールの作成や試作を請負で受ける場合は、何をもって完成とするか、検収の手順をはっきりさせておきます。契約の形の違いは準委任と請負の違い、検収の考え方は検収の記事をご覧ください。

忙しい時期の稼働の増え方を確かめる

運営中のタイトルやイベント前の制作では、決まった時期に作業が増えます。その時期に稼働を増やせるか、増やせない場合はどうするかを、事前に話しておきましょう。

注意

複数の案件を掛け持ちする場合、守秘の範囲が重なりやすくなります。未発表のタイトルや機材を扱うゲームやXRの案件では、同じパソコンで別の案件の作業をしてよいか、画面を見られない環境で作業できるかなど、取り決めが厳しいことがあります。掛け持ちの注意点は複数の案件を掛け持ちするときの注意点で解説しています。

会社員の副業でUnity案件を受けるとき

会社員が副業で受ける場合は、次の3点を先に確かめておきます。

  1. 勤め先の副業の規程：副業が認められているか、届け出が必要か、同業や取引先の仕事が制限されていないかを就業規則で確かめる。ゲームや受託開発の会社では、同業の仕事に制限がかかっていることがある
  2. 本業との守秘の線引き：本業で触れているタイトルやツール、社内の仕組みを副業で使わない。作ったものの権利の扱いも契約で確かめる
  3. 税務の手続き：副業の所得がある場合の確定申告や住民税の扱いを確かめる

副業の規程の考え方は副業禁止の会社で業務委託を受けるリスク、副業で業務委託を受けるときの全体の注意点は会社員の副業で業務委託案件を受けるときの注意点、確定申告の考え方は副業の確定申告｜所得20万円のルールの正しい理解で解説しています。個別の税務の判断は、税理士などの専門家にご相談ください。

エージェントベストの見解

当社では、案件をご案内する前に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをお出ししています。週2〜3日や副業でUnityの案件を探す場合は、稼働できる曜日と時間帯、担える仕事の型、端末やヘッドセットを手元に用意できるかをあわせてお伝えいただくと、案件を照らし合わせやすくなります。案件票に書かれていない稼働の柔軟さは、ご質問いただければ確認します。

よくある質問

週2〜3日の案件でも、Unityの経験として評価されますか？

評価されます。期間と稼働日数を正確に書き、その中で何を作り、どんな問題を解いたかを具体的に示せば、次の案件でも経験として受け止められます。短い稼働で担ったツールや性能の調査は、成果がはっきりしているぶん、話の材料にしやすい仕事です。

平日の夜や週末だけでもUnityの案件は受けられますか？

数は限られますが、ツールの作成や小さなアプリの改修、試作など、決まった時間にやり取りしなくてよい仕事では見つかることがあります。探し方は週末・夜だけの業務委託案件はある？で解説しています。

週2日で始めて、あとから日数を増やすことはできますか？

発注元の状況によってはあります。ただ、最初から増やす前提で受けると、増やせなかったときに困ります。今の日数で成り立つ範囲の仕事を受け、増やせる可能性があるかは契約の更新の時期に相談するのが現実的です。

 副業・複業

会社員の副業で業務委託案件を受けるときの注意点｜就業規則・契約・税金の確かめ方

会社員が副業で業務委託案件を受けるときは、勤務先の就業規則、本業との競合や秘密の扱い、契約条件、確定申告と住民税の4点を先に確かめます。業務委託は会社員の給与とルールが違うため、受ける前の整理が大切です。

 副業・複業

副業禁止の会社で業務委託を受けるリスク｜就業規則の読み方と許可の求め方

就業規則で副業が禁止・許可制の会社で無断で業務委託を受けると、懲戒などの対象になるおそれがあります。厚生労働省のガイドラインの考え方を踏まえつつ、規則の読み方、許可の求め方、断られたときの選択肢と相談先を整理します。

 副業・複業

副業の確定申告｜所得20万円のルールの正しい理解と、住民税の申告が別に要る理由

副業の所得が20万円以下なら確定申告が不要になるのは、給与を1か所から受け年末調整を受けている人などに限られます。20万円は収入ではなく所得で数え、住民税の申告は別に必要なことがあります。医療費控除などで申告するときは副業分も含めます。

 副業・複業

副業に使える時間の見積もり方｜業務委託を受ける前の計算と契約への落とし込み

副業に使える時間は、1週間の予定から本業・生活・休息を引き、さらに予備の時間を引いて見積もります。業務委託の作業時間は本業の労働時間と通算されないため、自分で管理する必要があります。計算の手順と、契約に残す条件を整理します。
