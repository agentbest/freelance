Web制作・デザイン

Webデザイナーのフリーランス案件の仕事内容｜案件の種類と1日・1か月の流れ

公開 2026-11-04　監修：株式会社エージェントベスト

フリーランスのWebデザイナーの仕事は、依頼の目的を確かめ、画面の見た目と情報の並びを決め、確認と修正を経て、実装できる形で渡すことの繰り返しです。ただし、制作会社のチームに入るのか、事業会社の社内チームを支えるのか、広告やLPの改善を担うのか、小さなサイトを一人でまとめて作るのかで、1日の時間の使い方も、やり取りする相手も、手元に残る成果物も大きく変わります。

この記事では、フリーランスのWebデザイナーの案件を4つの種類に分け、それぞれの1日と1か月の流れ、関わる相手、成果物を整理します。報酬の決まり方はWebデザイナーの報酬の記事、求められるスキルはWebデザイナーのスキルの記事で扱っているので、ここでは「参画したら実際に何をしているか」に絞ります。

仕事の中身は「入る場所」と「作るもの」で決まる

同じ「Webデザイナー募集」でも、働き方の違いを生むのは主に次の2つです。

  • 入る場所：制作会社のチームか、事業会社の社内か、発注元から直接か
  • 作るもの：新しく作るサイトやLPか、公開後の更新や改善か、広告の素材か

この2つを掛け合わせると、フリーランスのWebデザイナーの案件はおおむね次の4種類に分けられます。

案件の種類主な相手時間を多く使う仕事
制作会社のチームでのサイト制作ディレクター、コーダー、ほかのデザイナー構成案をもとにしたデザイン、修正、実装への受け渡し
事業会社の社内チームの支援事業部門の担当者、マーケティング担当、社内のエンジニア依頼の受付、LPやバナーの制作、サイトの更新
広告とLPの改善広告運用の担当者、マーケティング担当素材の量産、比べるための案づくり、数値を見た作り直し
小規模サイトの一括制作発注元の担当者や経営者聞き取り、構成づくり、デザインと実装、公開の手配

以下では、それぞれの1日と1か月の流れを、典型的な例として紹介します。時間の配分は案件ごとに違うため、目安として読んでください。

制作会社のチームでのサイト制作

1日の流れ（例）

朝は、ディレクターからの依頼と前日の確認の結果を見て、その日に手を入れるページを決めます。午前は構成案やワイヤーフレームを読み、見出しの強弱や写真の置き方を考えながらデザインを進めます。午後はチームの打ち合わせで途中のデザインを見せ、方向性のずれがないかを確かめます。夕方は、修正の指示を反映したり、コーダーからの「この余白はスマートフォンでどうなるか」といった質問に答えたりします。

発注元と直接話す場面は少なく、ディレクターを通して目的と修正を受け取り、形にするのが中心です。

1か月の流れ（例）

  • 月初：新しく始まる案件の構成案と素材を受け取り、トップページなど主要なページの方向性を作る
  • 月の前半：方向性が決まったら、下層ページへ展開する。部品や文字の大きさの決まりをそろえる
  • 月の後半：発注元の確認と修正の山場。並行してコーダーへの受け渡しを進める
  • 月末：実装されたページを見て、デザインどおりに組まれているかを確かめる。次の案件の準備に入る

複数の案件を同時に持つことも多く、ある案件は方向性づくり、別の案件は修正の対応、という重なり方になります。

成果物

ページごとのデザインデータ、画面幅ごとの見え方、部品や色・文字の決まり、書き出した画像、実装の担当者向けの補足（動きや余白の説明）などです。

事業会社の社内チームの支援

1日の流れ（例）

午前は、事業部門やマーケティング担当から届いた依頼を確かめます。「来週のキャンペーンのLP」「新しい料金プランのページ」「SNS用の画像」など、大小の依頼が並びます。目的や締め切りがあいまいな依頼は、担当者に短く聞き返してから着手します。午後は制作を進め、社内の確認者に途中のデザインを見せます。夕方は、社内のエンジニアやサイトの更新担当に、作ったデータを渡します。

制作会社と違い、依頼の交通整理と、社内の決まりに沿った量産に時間を使います。

1か月の流れ（例）

  • 月初：その月のキャンペーンや新機能の予定を確かめ、制作物の一覧と締め切りを担当者とそろえる
  • 毎週：依頼の受付と制作、確認、公開を回す。急ぎの差し込みにも対応する
  • 月の半ば：公開済みのLPやバナーの数値を担当者と見て、直す箇所を話し合う
  • 月末：翌月の予定を聞き、部品やテンプレートの整理など、まとまった時間が要る仕事を進める

成果物

LPや特集ページのデザイン、バナーやSNS用の画像、サイトの更新用のデータ、社内向けのデザインの決まりやテンプレートなどです。社内の決まりに沿って作るため、決まりそのものを整える仕事が任されることもあります。

エージェントベストの見解

Webデザイナーの案件をご紹介していると、制作会社での経験が長い方が事業会社の社内チームに入ったとき、依頼の数の多さと、依頼者ごとに目的の言葉がそろっていないことに戸惑う傾向があります。反対に、社内の運用が長い方は、制作会社のチームで決まった工程と締め切りに合わせて進めることに慣れるまで時間がかかることがあります。応募の段階で、誰から、どのくらいの頻度で依頼が来るかを具体的に聞いておくことをおすすめします。

広告とLPの改善

1日・1か月の流れ（例）

広告用のバナーやLPを作り、出した後の数値を見て作り直す仕事です。1日の中では、広告運用の担当者から「この訴求で3案」「この画像サイズで追加」といった依頼を受け、短い時間で複数の案を作ります。比べる案は、見出しの言葉、写真、ボタンの位置など、一度に変えるところを絞って作るのが基本です。

1か月の単位では、週ごとに素材を入れ替え、月末に担当者と結果を振り返って、次の月に試す案を決めます。数値の読み方は担当者が主導することが多いものの、デザイナーも「なぜこの案の反応がよかったか」を言葉にできると、次の案の質が上がります。

成果物

バナーの各サイズ、LPのデザインと比べるための別案、素材の作り方のメモ、試した案と結果の記録などです。作る数が多いので、データの名前の付け方や置き場所の決まりも成果物の一部と考えたほうがよい仕事です。

小規模サイトの一括制作

1日・1か月の流れ（例）

発注元から直接、企業サイトや店舗のサイトを一式で受ける仕事です。最初の数週間は、発注元の担当者や経営者に、誰に向けたサイトか、何を伝えたいか、どんな写真や文章があるかを聞き取ります。そのうえで、ページの構成を決め、デザインを作り、確認を受けます。実装まで担う場合は、CMSへの組み込みや画面幅ごとの表示の確認、公開の手配まで進めます。

1日の中で、聞き取り、デザイン、実装、連絡のすべてを自分で回すことになり、ディレクターの役割の一部も担うのが他の種類との違いです。WordPressなどのCMSを使う場合の仕事はWordPressエンジニアの仕事内容が参考になります。

成果物

構成案、デザインデータ、実装したサイト、更新の手順書、公開後の修正の記録などです。成果物を納めて報酬を受け取る請負の契約になることが多いため、何を納めたら完了かをはじめに決めておく必要があります。契約の違いは準委任と請負の違いで解説しています。

どの案件にも共通する仕事

種類が違っても、次の仕事はほぼすべてのWebデザインの案件にあります。

  1. 目的の確認：誰に向けて、何をしてもらいたいページかを、作り始める前に言葉にしておく
  2. 途中で見せる：完成させてから見せるのではなく、方向性の段階で一度確認を受ける
  3. 修正の整理：複数の人からの指摘を一つにまとめ、食い違いは決める人に返す
  4. 実装への受け渡し：画面幅ごとの見え方、余白や文字の決まり、動きの意図を残す
  5. データの管理：版と置き場所をそろえ、後から入った人も最新が分かるようにする

フリーランスならではの仕事として、自分の稼働や作業の記録もあります。稼働日数で報酬が決まる契約では、日々の作業時間をつけて報告します。成果物で報酬が決まる契約では、修正の回数や追加の依頼を記録しておくと、条件の見直しを話すときの材料になります。

注意

Webデザインの仕事は「ついでにこれも」と頼まれやすい仕事です。バナーを1点追加、別のページも少し直して、といった依頼が積み重なると、契約で決めた作業の範囲を大きく超えることがあります。引き受ける前に契約の範囲に入るかを確かめ、外れる場合は条件の見直しを相談しましょう。考え方は作業範囲が広がったときの契約の扱いで解説しています。

関わる相手と、その相手に渡すもの

Webデザイナーの1日は、誰に何を渡すかで組み立てられています。相手ごとに整理すると、次のようになります。

相手渡すもの頻度の目安
ディレクター・社内の依頼者途中のデザイン、修正の反映、確認したい点毎日〜週次
発注元の責任者方向性の案、主要なページのデザイン節目ごと
コーダー・エンジニアデザインデータ、画面幅ごとの見え方、動きの説明案件の後半に集中
広告運用・マーケティング担当バナーやLPの案、比べるための別案週次
ほかのデザイナー部品や文字の決まり、データの置き場所随時

ディレクターがいる現場では、目的の聞き取りや修正の取りまとめをディレクターが担い、デザイナーは制作に集中できます。ディレクターがいない現場では、それらも自分で担うため、1日の多くが連絡と整理に使われます。ディレクターの仕事はWebディレクターの仕事内容、画面の使いやすさを設計する仕事はUI/UXデザイナーの仕事内容で解説しています。

働く場所については、データの共有とオンラインの確認で進められる仕事が多い一方、撮影の立ち会いや方向性を決める最初の打ち合わせでは現地を求められることがあります。詳しくはWebデザイナーのリモート案件の記事をご覧ください。

エージェントベストの見解

当社では、案件をご案内する前に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをお出ししています。Webデザイナーの案件では、入る場所と作るものによって毎日の仕事が変わるため、「これまで多く作ってきたもの」と「避けたい働き方」をあわせてお伝えいただくと、案件を照らし合わせやすくなります。依頼の頻度や確認者の数など、案件票に書かれていない働き方の点は、ご質問いただければ確認します。

ポイント

  • Webデザイナーの仕事の中身は、入る場所と作るものの組み合わせで大きく変わる
  • 制作会社のチームは目的を受け取って形にする仕事、社内チームは依頼の整理と量産が中心
  • 広告とLPの改善は案を比べて作り直す仕事、小規模サイトの一括制作は聞き取りから公開まで担う
  • 目的の確認、途中で見せること、修正の整理、実装への受け渡しはどの案件にも共通する

よくある質問

フリーランスのWebデザイナーは、デザインだけをしていればよいのですか？

チームに入る案件では、デザインの作業が中心になります。ただし、修正の整理や実装の担当者への説明など、デザインの前後の仕事も期待されます。小規模サイトを一人で受ける場合は、聞き取りや実装、公開の手配まで担うのが一般的です。

1つの案件だけに集中する働き方と、複数の案件を同時に持つ働き方、どちらが多いですか？

稼働日数で契約するチームへの参画では、1つの現場に集中する形が多くなります。成果物ごとに受ける仕事では、締め切りの違う複数の案件を並行して持つことがよくあります。並行する場合は、確認の山場が重ならないように締め切りを組むことが大切です。

参画して最初の1か月は何をすることが多いですか？

既存のデザインの決まりやデータの置き場所、確認の流れを把握し、小さな依頼から手をつけるのが一般的です。初月の進め方はWebデザイナーの参画初月にやることで詳しく解説します。
