Web制作・デザイン

Webデザイナーのフリーランス案件｜報酬の決まり方と単価を上げる考え方

公開 2026-10-29　監修：株式会社エージェントベスト

フリーランスのWebデザイナーの報酬は、どの工程まで担うか、何の媒体を何の目的で作るか、契約の形（稼働に対して払うか、成果物に対して払うか）、修正の回数と権利の条件、稼働日数、商流で決まります。Webデザイナーの単価について公的な統計はなく、同じ「Webデザイン」の案件でも中身によって大きく変わります。

単価を上げるには、見た目を整えた経験だけでなく、「何のために、何を判断して作り、その後どうなったか」を説明できる実績を増やし、条件をそろえて案件を比べることが近道です。この記事では、報酬が上下する要素と、交渉で使える材料を整理します。

報酬は「担う工程の幅」で大きく変わる

Webデザインの案件は、同じ職種名でも任される範囲に差があります。まず、自分の経験がどの範囲に当てはまるかを確かめておくと、提示された条件を判断しやすくなります。

担う範囲主な作業報酬への影響
制作の一部決まったデザインに沿ったページ追加、バナーの量産、画像の加工応募できる人が多く、条件の差がつきにくい
ページ単位のデザイン構成案をもとにLPや下層ページのデザインを作る媒体の目的を理解しているかで評価が分かれる
サイト全体のデザイントップから下層までの見た目のルールを決め、全体をそろえるデザインの方針を決める経験が問われ、高めに出やすい
実装まで含むデザインに加え、HTML・CSSでの組み込みや確認まで担う一人で完結できるため、小規模な案件で重宝される
運用と改善公開後の数値を見て、LPやバナーを作り直し続ける成果との結びつきを説明できる人が選ばれやすい

ユーザー調査や画面の操作設計が中心の案件は、UI/UXデザイナーの領域です。報酬の決まり方はUI/UXデザイナーの報酬の記事で別に整理しています。

報酬を左右する主な要素

1. 媒体と目的

企業サイト、採用サイト、LP、バナー、サービスサイトでは、求められるものが違います。企業サイトは会社の印象と情報の整理、LPは申し込みや問い合わせへのつながり、バナーは短い時間で目を止めさせる力が問われます。売上や採用に直結する媒体ほど、結果を説明できる人に頼みたいという発注側の意向が強くなり、条件にも反映されやすくなります。

2. 契約の形

Webデザインは、契約の形が報酬の考え方を大きく左右する職種です。

  • 準委任（稼働型）：週の稼働日数や月の稼働時間に対して報酬が決まる。制作会社や事業会社のチームに入る案件で多い
  • 請負（成果物型）：LP1本、サイト一式など、完成した成果物に対して報酬が決まる。小規模な直接の依頼で多い

請負では、修正が増えても報酬は同じというのが基本の考え方なので、見積もりの前提をどこまで書面に残すかが手取りを左右します。違いは準委任と請負の違いで解説しています。準委任で精算幅がある場合の考え方は精算幅の記事をご覧ください。

3. 修正の回数と範囲

デザインの仕事は、確認と修正の往復が多くなりがちです。初稿のあとに何回まで修正を受けるか、方向性そのものを変える場合はどう扱うかで、同じ報酬でも実際の作業量はまったく違ってきます。修正の扱いが決まっていない案件は、見かけの金額が高くても割に合わないことがあります。範囲の外の依頼が来たときの考え方は作業範囲が変わったときの対応で整理しています。

4. 著作権と実績公開の条件

成果物の著作権を発注側に移すのか、自分に残して利用を許すのかは、本来は報酬の前提に関わる話です。権利を移す場合は、その対価が報酬に含まれているかを確かめます。実績として公開できるかどうかも、次の案件を取るときの材料に影響します。考え方は成果物の著作権の記事にまとめています。

5. 稼働日数・場所・期間

週5日のチーム参画か、週2〜3日の部分参画かで、報酬の総額も求められる役割も変わります。リモートか出社かでも応募できる人の数が変わり、条件に影響します。長期の運用案件は月々の額が安定しやすい一方、単発の制作案件は納期と修正の条件次第で手取りが上下します。

6. 商流

発注元と直接つながっているか、間に制作会社や複数の会社が入るかで、手元に届く金額は変わります。Web制作は、発注元から制作会社、さらに個人のデザイナーへと仕事が流れる形がよくあります。仕組みは商流の記事で解説しています。

エージェントベストの見解

Webデザイナーの案件をご紹介していると、面談で評価されやすいのは、作品の見た目の説明よりも「誰に何をしてほしいページで、そのために何を優先したか」を短く話せる方です。反対に、作品を一つずつ見せながら配色や装飾の工夫を話すだけだと、事業の目的を理解して作れる人かどうかが伝わりにくい傾向があります。当社では、先に稼働日数・リモートの希望・ご希望の金額を伺い、その条件に合う案件だけをご案内しています。

同じ「Webデザイン」でも提示額が違う理由

似た募集に見えても、提示額が違うことがあります。比べるときは、次の点をそろえて見ます。

  • 成果物の数と種類：LP1本なのか、LPとバナー数種なのか
  • 素材の用意：写真、イラスト、文章は誰が用意するのか。素材探しや撮影の手配まで含むと作業は大きく増える
  • 実装の有無：デザインデータの納品で終わるのか、組み込みや動作の確認まで含むのか
  • 修正と確認の進め方：修正回数、確認する人の数、最終的に決める人が誰か
  • 支払の条件：支払期日、検収の方法、請負なら着手時の支払の有無

全体の仕組みはフリーランスの単価の決まり方をご覧ください。

単価を上げるための考え方

結果まで話せる実績を一つつくる

報酬の話し合いで最も効くのは、公開後の結果を語れる実績です。LPの申し込みが増えた、問い合わせの質が変わった、といった結果は、数字を出せなくても「改善の前後で何を比べ、何を変えたか」の形で話せます。運用と改善に関わる案件に入ると、こうした材料が増えていきます。

方針を決める側に一段上がる

ページ単位のデザインから、サイト全体の見た目のルールを決める役割へ進むと、任される範囲が広がります。色や文字、余白、部品の使い方をまとめた指針を作った経験は、ほかのデザイナーが作っても品質がそろう仕組みを作れる証拠になります。

実装とアクセシビリティの理解を足す

HTML・CSSで組まれたときにどう見えるかを想定してデザインできる人は、実装担当とのやり取りが少なく済み、チームでの評価が上がります。文字と背景のコントラストや、色だけに頼らない表示などアクセシビリティへの配慮を求める発注も増えています。求められるスキルの全体はWebデザイナーのスキルの記事で整理しています。

更新の前に、増えた役割を事実で示す

担当する媒体が増えたときや、契約更新の前は、条件の見直しを相談しやすい時期です。「最初はバナーだけだったが、LPの構成から任されるようになった」のように、役割の変化を事実で示せるよう準備しておきます。伝え方は単価交渉の記事にまとめています。

注意

請負の案件で「修正は無制限」「ご満足いただけるまで対応」といった条件のまま受けると、確認者が増えるたびに作業が膨らみ、実質の報酬が大きく下がることがあります。修正回数、方向性を変える場合の扱い、検収の時期と方法を、受ける前に書面やメールで残しましょう。

エージェントベストの見解

当社がご案内する案件では、業務の範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。フリーランス法でも、発注側は給付の内容・報酬の額・支払期日などを、業務委託をしたら直ちに書面やメールなどで明示することが求められています。デザインの案件は参画後に作るものが増えやすいので、範囲が広がりそうなときは早めにご相談ください。

ポイント

  • 報酬は、担う工程の幅・媒体と目的・契約の形・修正と権利の条件・稼働条件・商流で決まり、案件ごとに大きく変わる
  • 提示額は、成果物の数、素材の用意、実装の有無、修正の進め方、支払条件をそろえて比べる
  • 単価を上げるには、結果まで話せる実績をつくり、方針を決める側へ役割を広げる

よくある質問

フリーランスのWebデザイナーの単価の相場はいくらですか？

Webデザイナーの単価について公的な統計はなく、担う工程、媒体、契約の形、稼働日数、リモートの可否、商流によって大きく変わります。相場の数字を探すより、ご自身の経験がどの範囲に当てはまるかを整理し、複数の案件で条件をそろえて比べるほうが判断の材料になります。

成果物1本ごとの契約と、稼働日数での契約はどちらがよいですか？

どちらがよいかは、作業量の見通しが立つかで変わります。作るものと修正の範囲がはっきりしているなら成果物ごとの契約でも進めやすく、作るものが途中で増えやすい運用の仕事なら稼働に対して払う契約のほうが無理が出にくくなります。契約前に、修正と範囲外の依頼の扱いを確かめておくことが大切です。

コーディングもできると報酬は上がりますか？

一人でデザインから組み込みまで完結できると、小規模な案件や運用の案件では頼みやすい人として評価されます。ただし、大きなチームでは役割が分かれていることが多く、デザインの判断の質のほうが重く見られる場合もあります。応募する案件の体制に合わせて、どちらを前に出すかを決めるとよいでしょう。
