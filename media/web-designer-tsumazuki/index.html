Web制作・デザイン

Webデザイナーのフリーランスがつまずきやすい点と対策

公開 2026-11-04　監修：株式会社エージェントベスト

目次

  2. 現場でのつまずき
  3. 技術でのつまずき
  4. お金でのつまずき
  5. よくある質問

フリーランスのWebデザイナーがつまずきやすいのは、修正が終わらないこと、素材や確認者の遅れで予定が崩れること、実装との食い違い、作品や素材の権利、成果物ごとの契約での支払いの遅れです。どれも、会社員ならディレクターや営業、法務が受け止めてくれた部分を、外部の立場で自分が抱えることから起きます。

対策の基本は、つまずきの種を契約と参画初期の取り決めで小さくし、現場では記録と早めの共有で守ることです。この記事では、契約・現場・技術・お金の4面に分けて、Webデザイナーならではの場面と対策を整理します。契約前に確かめる項目の一覧はWebデザイナーの案件の選び方で扱っているので、ここでは「実際に起きやすい場面」に絞ります。

契約でのつまずき

修正の回数と範囲が決まっていない

もっとも多いのが、修正が終わらないことです。「少し直して」が続き、気づけば方向性ごと作り直している、ということが起きます。とくに成果物ごとの請負では、修正が増えても報酬は変わらないため、作業時間だけが膨らみます。

対策：契約の段階で、修正が何回まで含まれるか、方向性を変える場合はどう扱うかを決めておきます。修正の段階を「方向性の確認」と「細部の確認」に分け、方向性の確認を終えたら記録に残すと、後からの作り直しを別の依頼として扱いやすくなります。範囲の外の依頼の扱いは業務範囲が変わったときの記事と追加の依頼の断り方をご覧ください。

準委任か請負かを意識せずに受ける

チームに参画して稼働に対して報酬を受ける準委任と、成果物を納めて報酬を受ける請負では、責任の中身も、修正の負担のかかり方も違います。契約書の形を確かめずに受けると、「納品したのに検収されない」「稼働の契約なのに完成責任を求められる」といった食い違いが起きます。

対策：署名の前に、契約の形と、報酬が何に対して払われるのかを確かめます。違いは準委任と請負の違いで解説しています。

作品の公開と権利の扱いがあいまい

成果物の著作権を発注側に移す、著作者人格権を行使しないと約束する、といった条項はよくあります。それ自体は珍しくありませんが、実績として公開してよいかは別の問題です。ここを決めずに進めると、作品をポートフォリオに載せられなかったり、載せたことで指摘を受けたりします。

対策：実績として公開してよいか、公開してよい時期と範囲（社名を出すか、画面の一部だけか）を、契約時にメールなどで残しておきます。考え方は成果物の著作権の記事と著作者人格権の不行使条項の記事をご覧ください。

現場でのつまずき

素材や原稿が届かず、予定が崩れる

写真、文章、ロゴのデータなど、発注側が用意するはずの素材が届かないまま締め切りだけが近づく、という場面はよくあります。遅れの原因が素材でも、表に出るのはデザインの遅れです。

対策：最初に素材の一覧と、それぞれを誰がいつまでに用意するかを書き出し、窓口と確かめます。届かないときは、仮の素材で進める範囲と、差し替えにかかる手間を早めに伝えておきます。

確認する人が多く、意見がまとまらない

企業サイトでは、担当者、上司、他部署、役員と確認者が重なり、それぞれから違う修正が届くことがあります。全部に応えようとすると、デザインの筋が崩れます。

対策：修正の指示を一つの窓口に集めてもらうよう、参画の初期にお願いしておきます。意見が割れたときは、目的に照らして選択肢を並べ、どれを選ぶかを発注側に決めてもらいます。

エージェントベストの見解

案件紹介の現場では、Webデザイナーの方のつまずきとして、デザインの腕前より「確認の進め方」で苦労する例をよく見ます。修正の窓口を一つにしてもらう、方向性の合意を記録に残す、といった進め方を最初に相手と確かめておく方は、確認者の多い案件でも評価を落としにくい傾向があります。

自分の好みとブランドの決まりがぶつかる

発注側には、色やフォント、写真の使い方などの決まりがあることが多くあります。それを知らずに作ると、良い提案でも差し戻されます。

対策：参画の最初に、既存のデザインのルールや過去の制作物を読み、守るべき決まりと、変えてよい部分を確かめます。最初の1か月の進め方はWebデザイナーの参画初月にやることで整理しています。

技術でのつまずき

実装できないデザインを渡してしまう

画面幅ごとの見え方を決めていない、動きの指定があいまい、部品ごとに余白がばらばら、といったデータを渡すと、実装の担当者が迷い、意図と違う画面ができあがります。結果として、手戻りがデザイナーに戻ってきます。

対策：主要な画面幅での見え方、部品の決まり、動きの指定をデータの中にそろえて渡します。実装の担当者と早めに一度話し、組みにくい箇所を先に聞いておくと手戻りを減らせます。求められるスキルはWebデザイナーに求められるスキルをご覧ください。

アクセシビリティや表示の速さを後回しにする

色の差が小さく文字が読みにくい、画像が重く表示が遅い、といった問題は、公開の直前に指摘されると直す時間が足りません。

対策：デザインの段階で、文字と背景の色の差、文字の大きさ、画像の書き出しの条件を決めておきます。発注側に基準があれば、最初に確かめます。

生成AIや素材サービスの使い方が契約に合わない

生成AIで作った画像や、素材サービスの写真を使うとき、発注側の決まりや素材の利用条件に合わないと、差し替えや説明が必要になります。

対策：生成AIを使ってよいか、使う場合に知らせるべきかを、発注側と確かめておきます。素材は商用利用や納品物での使用の条件を読んでから使います。考え方はAIの利用と契約の記事で整理しています。

お金でのつまずき

請負の支払いが検収まで止まる

成果物ごとの請負では、検収が終わるまで報酬が確定しないことがあります。確認者の都合で検収が延びると、支払いも後ろにずれます。

フリーランス法では、発注側は成果物を受け取った日から60日以内のできるだけ短い期間で支払期日を決め、その日までに報酬を払うことになっています（2026年10月時点、公正取引委員会の案内による）。

対策：検収の方法と期間、支払期日を契約時に確かめておきます。期日を過ぎても入金がないときの進め方は支払いが遅れたときの記事をご覧ください。

ツールや素材の費用を見込んでいない

デザインツール、フォント、素材サービスは、会社員時代は会社が払っていたものです。独立後は自分で契約することが多く、案件ごとに必要なものが違うと、費用が積み上がります。

対策：案件で必要なツールを誰が用意するかを、参画前に確かめます。自分で払う費用は、報酬の希望を決めるときに含めて考えます。

一つの取引先に頼りきりになる

運用の案件が長く続くと、気づけば収入のほとんどが一つの取引先から、ということがあります。サイトの刷新や体制の変更で契約が終わると、次の案件まで空白ができます。

対策：契約の更新時期を把握し、終了の可能性がある時期の1〜2か月前には次の案件の相談を始めておきます。

注意

修正や素材の遅れのやりとりを口頭だけで済ませると、後で「言った・言わない」になりやすくなります。方向性の合意、素材の期日、範囲の外の依頼は、チャットやメールで短く残してください。

エージェントベストの見解

当社がご案内する案件では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。取引先の会社の実態と支払条件を確かめた案件を扱っています。修正の扱いや作品の公開など、契約書に書かれていない点が気になるときは、ご質問いただければ確認します。

ポイント

  • 契約では、修正の回数と範囲、契約の形、作品の公開と権利を先に決める
  • 現場では、素材の期日、修正の窓口、ブランドの決まりを参画初期に確かめる
  • 技術とお金では、実装できるデータ、配慮の前倒し、検収と支払期日、ツールの費用を見込む

よくある質問

修正が何度も続いています。どこで線を引けばよいですか？

まず契約で修正が何回まで含まれているかを確かめます。決まっていない場合でも、方向性の確認を終えた時点の記録があれば、それ以降の方向転換は別の依頼として相談しやすくなります。追加の作業として扱うかは、窓口と言葉で確かめてから進めてください。

前の取引先で作った作品を、ポートフォリオに載せたら問題になりますか？

公開してよいかは、契約の定めと取引先との約束によって違います。公開中のサイトでも、関わったことを明かしてよいとは限りません。迷う場合は、載せる前に取引先に確かめるか、作品を見せずに目的と役割を文章で説明する方法をおすすめします。判断に迷う法律の問題は、弁護士などの専門家にご相談ください。

発注側の担当者とデザインの好みが合いません。どうすればよいですか？

好みの違いとして話すと平行線になりやすいため、ページの目的と見る人に立ち返って、選択肢ごとの良い点と気になる点を並べて示すのが基本です。そのうえで、どれを選ぶかは発注側に決めてもらい、決まった内容を記録に残します。

 業務委託契約の基礎

作業範囲が広がったときの契約の扱い｜追加の報酬と変更の残し方

契約で決めた業務範囲を超える作業は、原則として当初の報酬に含まれません。追加するなら、作業内容・報酬・期限を決め直して書面やメールで合意します。フリーランス新法の不当な給付内容の変更の考え方と、変更を合意する手順を整理します。
