フリーランスにJSTQB認定テスト技術者は役立つ？評価される場面と準備

JSTQB認定テスト技術者資格は、フリーランスにとってテストの用語と技法を、発注元と共通の言葉で扱えることの裏付けにはなりますが、合格だけでテストの計画や管理を任されるとは限りません。業務委託の面談で先に見られるのは、テストの計画・設計・実行・報告のどこを担い、何をどこまで確かめれば十分と判断したかという実務の経験です。

効きやすいのは、テストの実行が中心の経歴から設計や管理へ広げたい時期や、発注元がISTQBの用語でテストを進めている現場です。この記事では、区分の選び方、効く場面と効かない場面、更新とシラバス改訂の扱い、スキルシートでの書き方を整理します（2026年10月時点の公式サイトによる）。

JSTQBの資格の仕組み

JSTQBは、ソフトウェアテスト技術者の資格を認定する組織です。国際的な組織であるISTQBと連携しており、ISTQBに加盟する各国の資格と相互に認められる仕組みになっています。シラバス（出題範囲を定めた文書）は、ISTQBのものを日本語にして公開しています。試験は日本語で行われ、選択式です。

区分の大まかな構成

2026年10月時点の公式サイトでは、シラバスが次のように分類されています。

  • Core Foundation：基礎となるFoundation Level
  • Core Advanced：テストマネジメント、テストアナリスト、テクニカルテストアナリスト、テスト自動化エンジニアなど
  • Core Expert：テストマネジメント
  • Testing Specialist：アジャイル、AI、モバイル、性能など、分野や手法ごとの区分

各区分がQAの工程のどこと結びつくかは、QAエンジニアのスキルの記事で整理しています。日本で試験が行われているかどうかは区分ごとに違うため、受けたい区分の実施状況を公式サイトで確かめてください。

受験の条件と更新

Foundation Levelは、2023年10月以降、いつでも受験できる形になっています。Advanced Levelのテストマネジメントは、Foundation Levelの合格者（他国の連携資格の合格者を含む）で、申し込みの時点で3年以上の業務経験があることが条件とされ、業務経歴の申請書の提出も求められます。

FoundationとAdvancedは、いずれも再認定が不要で、更新のための試験や費用はありません。JSTQBは、取得した後も新しい技術を学び続けることを勧めています。

シラバスの改訂に注意する

Advanced Levelは、シラバスの改訂に合わせて試験の範囲が切り替わります。2026年10月時点の案内では、テストマネジメントは新しい版の試験が2025年11月から始まっており、テストアナリストは新しい版の試験が2026年11月中旬に始まる予定とされています。テスト自動化エンジニアも、新しい版の日本語のシラバスが2026年10月に公開されました。

案件で効く場面と効かない場面

効きやすい場面

  • 実行中心から設計へ広げるとき：決められたテストを実行してきた経歴でも、同値分割や境界値分析などの技法を体系的に学んだことを示せます
  • 発注元がISTQBの用語で進めている現場：テスト計画書やテストの報告で使う言葉がそろっていると、参画してすぐに話が通じます
  • 管理の工程を任されたいとき：テストマネジメントの区分は、受験に業務経験の条件があるため、計画や管理の知識に加えて一定の経験があることの材料にもなります

効きにくい場面

  • 自動化の実装が中心の案件：テストコードの設計と保守、CIへの組み込みの経験が中心に見られます。自動化の案件で求められる力はテスト自動化エンジニアのスキルの記事で整理しています
  • 特定の業界の知識が重い案件：決済や医療など、業務の決まりごとを知っていることが先に問われる案件では、資格より業界の経験が重く見られます
  • 品質の改善を組織として進める案件：工程全体の改善や、品質の指標づくりを担った実績が問われます

エージェントベストの見解

案件紹介の現場では、QAの案件の面談で「テスト観点をどうやって洗い出したか」「どこで打ち切りを判断したか」をよく確かめられる傾向があります。JSTQBで学んだ技法の名前は、この説明を短く正確にする助けになります。技法の名前だけを挙げるより、どの対象にどの技法を使い、何が見つかったかを一つ話せるようにしておくと、学んだことが実務につながっていると伝わります。

実務経験との組み合わせ方

区分と、自分の担当範囲をそろえると、資格と経験が一つの流れとして伝わります。

担当している工程組み合わせやすい区分経歴で示すとよいこと
テストの実行と不具合の報告Foundation Level再現手順の書き方、技法を使ったケースの追加
テストの設計Advanced Level テストアナリスト観点の整理、技法の使い分け、レビューの経験
性能やセキュリティなど技術的なテストAdvanced Level テクニカルテストアナリスト非機能のテストの設計と結果の説明
テストの計画と管理Advanced Level テストマネジメントリスクにもとづく優先順位、進み具合と品質の報告
テストの自動化Advanced Level テスト自動化エンジニア自動化の範囲の決め方、保守の工夫

自動化のコードを書く力を補いたい場合は、Python 3 エンジニア認定試験の記事も参考になります。品質の管理を担う役割を目指す場合は、QAマネージャーの資格の記事もあわせてご覧ください。

スキルシートでの書き方

資格欄には、区分まで含めた正式な名称と、合格年月を書きます。シラバスの版で範囲が変わるため、受けた版が分かる場合は添えておくと正確です。

  • 例：「JSTQB認定テスト技術者資格 Foundation Level 20XX年X月合格」
  • 例：「JSTQB認定テスト技術者資格 Advanced Level テストマネジメント 20XX年X月合格」

経歴欄には、資格の技法や考え方を使った作業を書きます。

  • 「決済機能のテスト設計を担当。境界値分析と状態遷移で観点を整理し、ケースの重複を削減」
  • 「リリース前のテストの優先順位をリスクで決め、残リスクを報告書にまとめて判断を支えた」

QAの経歴全体の書き方はQAエンジニアのスキルシートの記事とスキルシートの書き方の記事で紹介しています。

注意

「JSTQB取得」とだけ書くと、Foundation LevelなのかAdvanced Levelなのかが伝わりません。更新が不要な資格でも、合格した時期が古い場合は、その後のシラバスの改訂で用語や範囲が変わっていることがあります。面談の前に、現行のシラバスで変わった点に目を通しておくことをおすすめします。

受験の準備と案件との両立

担いたい工程から区分を決める

狙う案件票で、求められている工程が実行・設計・管理・自動化のどれかを確かめます。区分を工程に合わせて選ぶと、学んだ内容を次の案件ですぐに使えます。案件票の読み方は案件票の読み方の記事で解説しています。

シラバスの版を確かめてから学ぶ

改訂の時期が近い区分は、どの版で受けるかによって学ぶ範囲が変わります。教材を選ぶ前に、受験する時期の試験がどの版に対応しているかを公式サイトで確かめてください。

今の案件の作業を技法の言葉で振り返る

学んだ技法を、今担当しているテストに当てはめて振り返ると、知識が実務の説明に変わります。ただし、取引先の仕様やテスト資料を、学習の教材として外に持ち出すことは避けてください。

エージェントベストの見解

当社では、契約で業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。テストの案件は、実行だけか、設計や報告まで含むかで業務範囲が大きく変わるため、資格で学んだ工程のどこまでを担うのかを、契約の前に確かめておくことをおすすめします。案件票の記載で分かりにくい点は、ご質問いただければ確認します。

ポイント

  • JSTQBはISTQBと連携し、各国の連携資格と相互に認められる。試験は日本語・選択式
  • Foundation Levelはいつでも受験でき、テストマネジメントは業務経験3年以上などの条件がある
  • FoundationとAdvancedは再認定が不要。ただしAdvancedはシラバスの改訂で試験の範囲が切り替わる
  • スキルシートには区分まで含めた名称と合格年月を書き、使った技法を経歴欄で示す

よくある質問

JSTQBのFoundation Levelだけで、テスト設計の案件に参画できますか？

合格だけで参画が決まることは多くありません。テスト設計の案件では、観点を整理してケースを作った経験が先に見られます。Foundation Levelは、技法を共通の言葉で説明できることの裏付けとして、経験に添えて使います。

JSTQBの資格は有効期限が切れることがありますか？

JSTQBの案内では、Foundation LevelとAdvanced Levelは再認定が不要で、更新の試験や費用はありません。ただ、シラバスは改訂が続いているため、取得した後も新しい版の内容を確かめておくと、面談での説明に困りません。

実務経験が浅くてもAdvanced Levelを受けられますか？

区分によって条件が違います。テストマネジメントは、申し込みの時点で3年以上の業務経験などが条件とされています。ほかの区分の条件は、受験の前にJSTQBの公式サイトでご確認ください。
