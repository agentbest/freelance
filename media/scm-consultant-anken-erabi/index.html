業務・戦略コンサル

SCMコンサルタントのフリーランス案件の選び方｜契約前に確かめたいこと

公開 2026-11-04　監修：株式会社エージェントベスト

  2. 契約前に確かめたい8つの点
  3. 確かめた内容を書面と照らし合わせる
  4. よくある質問

SCMコンサルタントの案件を選ぶときは、報酬や稼働日数に加えて、対象の範囲、終わりの定義、決める人、データに触れられる範囲、システムベンダーとの分担、現地の頻度、報酬の形、契約期間とサイクルの区切りの8点を契約前に確かめておくことが大切です。SCMの案件は、募集の名前が同じでもこの8点の違いで負担と成果の出しやすさが大きく変わります。

特に見落としやすいのは、対象の品目や拠点が広がる余地と、計画を最終的に決める人がはっきりしているかです。範囲があいまいで決める人もいない案件では、分析と案づくりを重ねても、決め方が変わらないまま時間が過ぎます。契約書全般の確認点は業務委託契約書のチェックポイントで解説しているので、この記事ではSCMの案件に固有の確認点に絞ります。

SCMの案件選びで差が出る理由

SCMの案件票は、「SCM改革支援」「在庫最適化」「需給計画の高度化」のように、目的は書かれていても範囲と役割が抽象的になりやすい傾向があります。参画してから気づく食い違いには、次のようなものがあります。

  • 在庫の見直しと聞いていたが、実際は月次の在庫報告の集計が中心だった
  • 補充ルールの案をまとめても、営業と工場のどちらが決めるか決まっておらず、話が進まない
  • 実績データに触れる権限が出るまで数週間かかり、分析を始められない
  • 一つの事業部が対象のはずが、別の事業部や海外の販売会社まで頼まれるようになった

こうした食い違いは、面談と条件の確認の段階で、聞き方を工夫すれば多くを防げます。仕事の型ごとの違いはSCMコンサルタントの仕事内容で整理しています。

契約前に確かめたい8つの点

1. 対象の範囲と、広がる見込み

最初に確かめたいのは、対象の領域・品目・拠点・部門の範囲です。

  • 扱う領域は、需要予測・S&OP、在庫、調達、物流のどれか
  • 対象の品目は全品目か、一部の事業や品目群か
  • 対象の拠点は国内だけか、海外の拠点を含むか
  • 範囲が広がる予定があるか。その場合の時期

SCMの改革は、成果が出ると対象を広げたくなる仕事です。広がること自体は悪くありませんが、今の範囲が契約に書かれているかで、広がったときに条件を見直す話のしやすさが変わります。

2. 局面と「終わり」の定義

構想までか、業務とシステムの設計までか、導入と定着までかを確かめます。あわせて、何をもって自分の役割が終わるか、成果物は何かを確かめておきます。

面談では「最初の3か月で、最も期待されている成果は何か」を聞くと、役割の実態が見えやすくなります。答えが「現状の見える化」なら分析寄り、「新しい補充ルールで一部の品目を回し始める」なら決め方の設計と定着まで担う役割です。

3. 計画を決める人と会議体

SCMの仕事は、部門の意見が割れたときに誰が決めるかで進み方が変わります。

  • 需給計画や在庫の方針を最終的に決める会議と、そこに出る人
  • 営業と工場、購買と物流の意見が割れたときに判断する人
  • 自分の報告先と、経営層に説明する場の有無

フリーランスは発注元の社員ではないため、方針を決めるのは発注元に残るのが一般的です。そのうえで、決める人が明確になっているかが大切です。

エージェントベストの見解

SCMの案件をご紹介していると、参画後に「聞いていた状況と違った」となりやすいのは、対象の範囲と、計画を決める人の2点です。面談では聞きにくいと感じる方もいますが、任される役割を判断するための確認として聞けば、多くの発注元は答えてくれます。案件票だけでは分からない点は、契約の前に確かめることをおすすめします。

4. データに触れられる範囲と時期

SCMの分析は、実績データに触れられて初めて始まります。

  • 使える実績データの種類（受注、出荷、在庫、発注、生産など）と期間
  • データに触れるための端末の貸与、アカウントの発行にかかる時間
  • データの持ち出しや、自分の端末での分析が認められるか
  • 契約終了時のデータの返却や消去の扱い

権限の発行に時間がかかる会社では、最初の数週間が聞き取りと資料の読み込みだけになることもあります。その期間を見込んだ計画かどうかを確かめておきましょう。秘密保持の考え方は秘密保持契約の記事、終了時の扱いはデータの返却・消去の記事で解説しています。

5. システムベンダーやほかのコンサルとの分担

計画系やERPの導入と一体の案件では、業務側の自分と、システムの設定を担うベンダー、ほかのコンサルティング会社との役割の分担を確かめます。

  • 業務の要件を決めるのは誰で、自分はその材料づくりか、決める役か
  • マスタの整備やテストの実施を、自分が手を動かして担うか
  • 元請けのコンサルティング会社の一員として入るか、発注元に直接入るか

元請けの一員として入る場合と、発注元に直接入ってベンダーを点検する場合では、立つ側が逆になります。誰の利益のために動く立場なのかを参画前にはっきりさせておくと、板挟みになったときに迷いません。

6. 現地に出る頻度と旅費

工場や倉庫の調査、部門をまたぐ合意の場、本番の切り替えでは、現地での作業が求められやすくなります。出張の頻度と時期、移動時間を稼働に含めるか、旅費の扱いを確かめます。月末や棚卸、切り替えの前後の稼働の増え方と、そのときの精算の扱いも合わせて確かめておきましょう。

7. 報酬の形と、その条件

SCMの案件は、月単位で業務を行う準委任契約が中心です。準委任では、在庫の削減そのものではなく、専門家として通常求められる注意を払って業務を行うことが約束の中身になります。確かめたいのは、契約書や発注の書面の書き方がこの考え方と合っているかです。

  • 「在庫を◯割削減する」のように、結果を約束する書き方になっていないか
  • 削減額に応じた報酬を持ちかけられた場合、指標の定義、計り始めの基準、外部要因の除き方、支払の時期が決まっているか

在庫や物流費は、需要の変化や仕入先の事情など、自分の働きと関係のない要因でも動きます。報酬の形の考え方はSCMコンサルタントの報酬の記事、契約の形の違いは準委任契約と請負契約の違いをご覧ください。準委任の契約なのに、発注元の社員から細かな作業の指示や勤務時間の管理を受ける働き方は、偽装請負の問題につながるおそれがあります。詳しくは偽装請負の記事で解説しています。

8. 契約期間と、計画サイクルや切り替えの区切り

契約の期間と、改革の区切りが合っているかを確かめます。需給計画の仕組みづくりなら、新しい会議の運び方を数か月回して振り返るまで、システム導入なら本番の切り替えと最初の月次の締めを越えるまで、が一つの目安になります。切り替えの直前に契約の更新時期が来ると、更新されなかった場合に最も大事な局面を見届けられません。

フリーランス法では、6か月以上継続して業務を委託している場合に、契約を解除したり更新しなかったりするときは、少なくとも30日前までに予告することが求められています（2026年10月時点、公正取引委員会の案内による）。契約期間と更新の考え方は、改革の見通しと合わせて確かめておきましょう。

注意

SCMの案件では、参画後に役割が少しずつ広がりやすい傾向があります。別の事業部の在庫の相談、物流会社との交渉資料の作成、社内向けの研修など、契約の業務範囲に入っていない仕事を頼まれたときは、引き受ける前に範囲と条件を確かめましょう。考え方は作業範囲が広がったときの契約の扱いで解説しています。

確かめた内容を書面と照らし合わせる

面談や事前の確認で聞いた内容は、契約の前に書面と照らし合わせます。フリーランス法では、発注する事業者は業務を委託したら直ちに、業務の内容、報酬の額、支払期日などの取引条件を、書面またはメールなどで明示することとされています。報酬の支払期日は、給付を受け取った日から60日以内のできる限り短い期間で定めることとされています（いずれも2026年10月時点、公正取引委員会の案内による）。明示される事項の内容はフリーランス法で明示される取引条件をご覧ください。

SCMの案件では、特に次の点が書面に反映されているかを確かめます。

  1. 業務の内容に、対象の領域・品目・拠点の範囲と、担う局面が書かれているか
  2. 結果を約束する書き方や、在庫の削減そのものに責任を負う書き方になっていないか
  3. 稼働の幅と超えたときの精算、出張と旅費の扱い
  4. データの扱いと、契約終了時の返却や消去
  5. 契約期間と更新の時期

面談で聞いておくとよい質問はSCMコンサルタントの面談でよく聞かれる質問と答え方の逆質問の項目でも紹介しています。一般的な逆質問の考え方は面談で聞いておくべき逆質問をご覧ください。

エージェントベストの見解

当社では、取引先の会社の実態と支払条件を確かめた案件を扱い、契約では業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。SCMの案件で気になりやすい対象の範囲や、出張・データの扱いなど、書面だけでは読み取りにくい点は、ご質問いただければ確認します。

ポイント

  • SCMの案件は、募集の名前が同じでも、対象の範囲・局面・決める人・データの扱いで負担が大きく変わる
  • 対象の範囲と広がる見込み、終わりの定義、計画を決める人を面談で確かめる
  • データに触れる時期、ベンダーとの分担、現地の頻度と旅費を確かめる
  • 結果を約束する書き方になっていないか、契約期間が改革の区切りと合っているかを書面と照らし合わせる

よくある質問

「SCM改革支援」とだけ書かれた案件は避けたほうがよいですか？

避ける必要はありません。ただ、対象の領域や範囲、担う局面が決まっていないことがあるため、面談で具体的に確かめてから判断することをおすすめします。答えがあいまいなままなら、最初の契約期間を短めにして、範囲が固まった段階で見直す考え方もあります。

在庫の削減額に応じた報酬は、受けないほうがよいですか？

一概には言えません。在庫は需要の変化や仕入先の事情でも動くため、指標の定義、計り始めの基準、外部要因の除き方、支払の時期が決まっているかが判断の分かれ目になります。内容によって判断が分かれるため、気になる場合は専門家にご相談ください。

報酬の高い案件と、範囲のはっきりした案件で迷ったらどうしますか？

一概には言えませんが、SCMの案件では範囲があいまいなまま対象が広がると、稼働が増えて時間あたりの報酬が下がることがあります。報酬の額だけでなく、対象の範囲、出張の見込み、決める人の明確さを合わせて比べるとよいでしょう。

業務委託契約の基礎

業務委託契約書のチェックポイント｜署名前に確かめたい10項目

業務委託契約書は、契約形態・業務範囲・報酬と精算・支払期日・契約期間と解除・知的財産・秘密保持・損害賠償などを署名前に確認します。フリーランス新法で発注者が明示すべき事項と照らし合わせると、抜けに気づきやすくなります。

 フリーランス新法・下請法

フリーランス新法の取引条件の明示｜受け取るべき8項目と確認のしかた

フリーランス新法では、発注者は業務委託をしたら直ちに、業務の内容・報酬の額・支払期日など8項目を書面かメール等で明示しなければなりません。口頭だけは不可です。受け取るべき内容と、未定事項や共通事項の扱いを整理します。

 業務委託契約の基礎

準委任契約と請負契約の違い｜フリーランスが知っておくべきこと

準委任は「業務を行うこと」、請負は「仕事を完成させること」に報酬が払われる契約です。責任の範囲・報酬の条件・途中でやめるときの扱いが違うため、契約書で何を約束しているかを確かめることが大切です。

 業務委託契約の基礎

作業範囲が広がったときの契約の扱い｜追加の報酬と変更の残し方

契約で決めた業務範囲を超える作業は、原則として当初の報酬に含まれません。追加するなら、作業内容・報酬・期限を決め直して書面やメールで合意します。フリーランス新法の不当な給付内容の変更の考え方と、変更を合意する手順を整理します。

 業務委託契約の基礎

偽装請負とは｜指揮命令の線引きとフリーランスが注意すること

偽装請負は、請負や準委任の契約なのに、実態として発注者が働き手に直接指揮命令している状態です。判断は契約の名前ではなく実態で行われます。フリーランスは「労働者性」の基準と、参画前に確かめたい点を押さえておきましょう。

 業務委託契約の基礎

秘密保持契約（NDA）で確認すること｜対象・期間・実績として話せる範囲

NDAで確かめたいのは、秘密情報の範囲と例外、使ってよい目的、守る期間、終了時の返還・廃棄、違反時の責任の5点です。フリーランスは、実績としてどこまで話せるかも署名前に決めておくと安心です。
