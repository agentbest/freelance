フリーランスにCCSPは役立つ？評価される場面と準備

公開 2026-10-29　監修：株式会社エージェントベスト

CCSPは、フリーランスの案件のうち、複数のクラウドにまたがるセキュリティの設計や、クラウドの利用に関わる規程・統制を考える役割で、特定の製品に依らない知識の裏付けとして役立ちます。一方で、資格がないと入れない案件は多くなく、面談では実際にどのクラウドで何を設計・運用してきたかが先に見られます。

CCSPは、CISSPと同じISC2の資格で、試験に合格するだけでは認定されず、ITとセキュリティの実務経験の要件があります。この記事では、試験の範囲と認定の流れ、効く場面と効かない場面、クラウドごとの認定との使い分け、スキルシートでの書き方を整理します（2026年10月時点のISC2の案内による）。

試験の範囲と認定の流れ

6つのドメイン

CCSPは、国際的な団体であるISC2が認定する、クラウドのセキュリティに絞った資格です。試験は次の6つのドメイン（分野）から出題されます。

ドメイン出題の比率（平均）
1. クラウドの概念・アーキテクチャ・設計17%
2. クラウドのデータセキュリティ20%
3. クラウドのプラットフォームとインフラのセキュリティ17%
4. クラウドのアプリケーションのセキュリティ16%
5. クラウドのセキュリティ運用17%
6. 法律・リスク・コンプライアンス13%

試験は100〜150問・3時間で、1,000点中700点で合格です。日本語でも受験できます。技術の設計や運用だけでなく、法律やリスク、契約・コンプライアンスの領域まで入っているのが特徴です。

認定に必要な実務経験

認定を受けるには、ITの分野で通算5年以上のフルタイムの実務経験が必要です。そのうち3年はサイバーセキュリティの経験で、さらに1年はCCSPの6つのドメインのいずれかに関わる経験であることが求められます。

経験の扱いには、次のような代わりの道があります。

  • CISSPを有効に保っている場合：CCSPの経験要件のすべてを満たせる
  • CSA（Cloud Security Alliance）のCCSKを持っている場合：経験1年分の代わりにできる
  • 経験が足りない場合：試験に合格して「Associate of ISC2」になり、合格から6年以内に経験を積む

エンドースメントと維持の条件

試験に合格したあとは、9か月以内にエンドースメント（推薦）の手続きを終えます。申請は、資格を有効に保っているISC2の会員が内容を確かめて推薦する形です。

認定のあとは、3年ごとのサイクルで継続教育（CPE）を積みます。CCSPでは3年間で90単位が必要で、そのうち60単位はドメインに直接関わる活動であることが求められます。あわせて年会費（AMF）の支払いも必要で、期限から90日の猶予を過ぎても満たされないと、資格は停止の状態になります。

フリーランスの案件で効く場面

複数のクラウドにまたがる設計や統制

複数のクラウドを使い分けている会社で、共通のセキュリティの方針や設計の基準を作る案件では、特定の製品に依らない知識が求められます。CCSPのドメインはクラウドの考え方からデータ、運用まで横断しているため、こうした案件の裏付けになります。案件で求められる経験はクラウドセキュリティエンジニアのスキルの記事で解説しています。

クラウドの利用に関わる規程や契約の確認

クラウドの利用の規程づくり、クラウド事業者の評価、データの所在や契約の確認など、技術と法務・リスクの間に立つ役割では、「法律・リスク・コンプライアンス」のドメインを学んでいることが生きます。

CISSPを持つ人がクラウドに軸を寄せるとき

CISSPを有効に保っている人は、CCSPの経験要件を満たせます。全体を見渡す立場の経験を、クラウドの案件に寄せていきたい場合に、組み合わせとして分かりやすい資格です。CISSPの仕組みはCISSPの記事で扱っています。

効きにくい場面

  • 特定のクラウドの構築や設定が中心の案件：そのクラウドでの実務の経験や、クラウドごとの認定が直接見られる
  • クラウドの実務の経験がほとんどない状態での応募：設定や運用を任せられるかの判断材料が足りない
  • 診断やインシデント対応の実施が中心の案件：調査や確認の作業の経験が問われる
観点CCSPクラウドごとの認定
範囲製品に依らないクラウドのセキュリティ全体。法律・リスクも含むそのクラウドのサービスと設定
効きやすい案件複数のクラウドの方針・設計、規程や統制そのクラウドでの構築・設定の見直し
認定の条件実務経験の要件とエンドースメント試験の合格

AWSに絞った資格はAWS認定セキュリティの記事、AWSの経験の見せ方はAWSエンジニアのスキルの記事をご覧ください。

エージェントベストの見解

案件紹介の現場では、クラウドのセキュリティの案件で、資格の名前よりも「どのクラウドで、どの範囲の設定や方針を自分で決めたか」を聞かれる傾向があります。CCSPのように製品に依らない資格を持っている方は、それに加えて、実際に使ってきたクラウドの名前と、担った範囲（権限の設計、ログの集約、データの暗号化など）を具体的に話せると、任せる範囲が伝わりやすくなります。応募の前に、経験をクラウドごとに整理しておくことをおすすめします。

実務経験との組み合わせ方

CCSPは、製品ごとの経験を、製品に依らない言葉で説明し直すときに力を発揮します。

  1. 経験をドメインに当てはめる：たとえば、権限の設計は「プラットフォームとインフラ」、データの暗号化や保管場所の管理は「データセキュリティ」に分ける
  2. 製品ごとの認定と並べる：使ってきたクラウドの認定で実務の深さを、CCSPで横断の知識を示す
  3. 規程や契約の側へ役割を広げる：技術の設定から、利用の方針や事業者の評価へ、役割を一段広げる材料にする

フリーランスとしての経験も要件の対象になるかを判断するため、契約の期間と担当した業務を後から説明できるように記録しておくと、申請のときに整理しやすくなります。独立までの進め方はクラウドセキュリティエンジニアがフリーランスになるにはで解説しています。

スキルシートでの書き方

資格欄には、正式名称・認定の年月・認定団体を書きます。

  • 認定済みの場合：「CCSP（Certified Cloud Security Professional、ISC2、20XX年X月認定）」
  • 試験に合格し、経験を積んでいる途中の場合：「Associate of ISC2（CCSP試験合格、20XX年X月）」

経歴欄では、クラウドの名前と担った範囲を、プロジェクトごとに書きます。資格欄に並べるだけより、製品に依らない知識と、製品での実務の両方が伝わります。書き方の例はクラウドセキュリティエンジニアのスキルシートの記事で紹介しています。

注意

試験に合格しても、エンドースメントを終えて認定されるまでは、CCSPの認定者として書くことはできません。また、CPEや年会費が満たされず停止の状態のときに、有効な資格として書くと、確認されたときに信頼を損ないます。CISSPとCCSPの両方を持つ場合は、それぞれのCPEの条件とサイクルの期限を分けて管理してください。

準備の進め方

  1. 狙う案件を決める：複数のクラウドの方針・設計か、特定のクラウドの構築かを見極める
  2. 経験の要件を確かめる：IT5年・セキュリティ3年・ドメイン1年を満たすか、CISSPやCCSKで代えられるかを見る
  3. 推薦の手続きを見込む：合格から9か月以内に手続きを終える必要がある
  4. CPEを積む手段を決める：研修や勉強会など、案件と並行できる方法を選ぶ

クラウドのセキュリティの分野で評価される資格の全体像はクラウドセキュリティエンジニアの資格の記事、資格全般の考え方は資格はフリーランスの案件獲得に役立つかの記事で整理しています。

エージェントベストの見解

クラウドのセキュリティの案件は、設計の段階だけ関わるものから、運用まで続けて関わるものまで、期間や稼働の形がさまざまです。資格をきっかけに新しい種類の案件を探すときは、業務の内容とあわせて、稼働日数やリモートの可否を先に考えておくことをおすすめします。案件票の資格の条件が必須か歓迎かが分かりにくいときは、ご質問いただければ確認します。

ポイント

  • 資格がなくても参画できる案件は多く、面談では使ってきたクラウドと担った範囲が先に見られる
  • 効きやすいのは、複数のクラウドの方針・設計、クラウドの規程や契約の確認、CISSPからクラウドへ軸を寄せるとき
  • 認定にはIT5年（うちセキュリティ3年、ドメイン1年）の経験とエンドースメントが必要。CISSPで経験要件を満たせる
  • 維持には3年で90単位のCPEと年会費が必要

よくある質問

CCSPとクラウドごとの認定は、どちらを先に取るべきですか？

特定のクラウドの構築や設定の案件を狙うなら、そのクラウドの認定が直接評価されやすく、複数のクラウドの方針や統制の案件を狙うならCCSPが合います。狙う案件票に出てくる名前から選びます。

CISSPを持っていれば、CCSPの経験要件は不要ですか？

ISC2の案内では、CISSPを有効に保っている場合、CCSPの経験要件のすべてを満たせるとされています。試験の合格とエンドースメントの手続きは別に必要です。

クラウドの実務経験が短くても、受験できますか？

受験はできます。経験が要件に足りない場合は、合格後に「Associate of ISC2」となり、合格から6年以内に経験を積めば認定を受けられます。スキルシートには、認定済みのCCSPと区別して書きます。
