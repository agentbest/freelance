フリーランスエージェントの使い方｜登録から参画までの流れと準備

公開 2026-10-29　監修：株式会社エージェントベスト

フリーランスエージェント（案件紹介サービス）は、登録→担当者との面談→案件の紹介→応募と書類選考→発注側との面談→条件の合意と契約→参画という流れで使います。うまく使うコツは、最初の面談で稼働日数・リモート・希望金額・避けたい条件をはっきり伝え、紹介された案件ごとに「誰と契約し、何を任されるか」を確かめることです。

この記事では、各段階でやること・準備すること・確かめることを順番に整理します。

登録から参画までの全体の流れ

サービスによって細かな手順は違いますが、おおむね次の順に進みます。

段階やること目安となる準備
1. 登録Webで基本情報・希望条件を入力するスキルシート（なければ経歴の箇条書き）
2. 担当者との面談経歴と希望を伝え、紹介の方向性を決める希望条件の優先順位
3. 案件の紹介条件に合う案件の説明を受ける気になる点の質問
4. 応募・書類選考了承した案件に経歴を提案してもらう案件に合わせたスキルシートの調整
5. 発注側との面談現場の担当者と話し、相性と経験を確かめ合う実績の説明・逆質問
6. 条件の合意・契約金額・精算幅・期間・業務範囲を決め、契約書を交わす契約書の確認
7. 参画業務を始める。月ごとに稼働報告・請求稼働時間の記録

登録から参画まで、早ければ数週間、条件が合う案件を待つと数か月かかることもあります。今の仕事の終わりが決まっている場合は、余裕を持って動き始めると選べる案件が増えます。

1. 登録の前に用意しておくもの

登録自体は数分で終わることが多いですが、そのあとの面談と紹介の質は、手元の準備で変わります。

スキルシート

最初から完成していなくても構いませんが、プロジェクトごとに「期間・役割・担当工程・使った技術・規模・成果」が分かる形にしておくと、担当者が紹介できる案件を判断しやすくなります。書き方の型はスキルシートの書き方の記事で紹介しています。

希望条件と優先順位

次の項目を、譲れない条件と相談できる条件に分けておきます。

  • 稼働日数（週5日・週3〜4日など）
  • 働き方（フルリモート・一部出社・常駐）
  • 希望金額（最低ラインと目標）
  • 開始可能な時期
  • やりたい役割・工程、避けたい業務
  • 契約期間の希望（長期・短期）

すべてを満たす案件は多くありません。優先順位が決まっていると、紹介された案件のどこを妥協してよいかを判断しやすくなります。

2. 担当者との面談で伝えること

登録後、担当者とオンラインなどで面談します。ここで話した内容をもとに案件が選ばれるため、遠慮せずに具体的に伝えることが大切です。

  1. 直近の経歴：直近2〜3件のプロジェクトで、どの立場で何をしたか
  2. 得意な領域：技術・業界・工程のうち、強みとして出したいもの
  3. 希望条件：上で整理した優先順位
  4. 他の応募状況：他のサービスや直接の話で、すでに応募している案件があるか

4つ目は伝えにくいかもしれませんが、同じ案件に別の経路から重ねて応募すると、発注側で混乱が生じ、選考に影響することがあります。複数のサービスに登録するときの注意点は複数登録の記事で整理しています。

エージェントベストの見解

案件をご紹介する立場から見ると、最初の面談で希望金額と稼働条件をはっきり伝えていただける方ほど、ご紹介が早く進みます。当社では、先に稼働日数・リモートの可否・希望金額を伺い、条件に合う案件だけをご案内しています。「相場が分からないので金額は任せたい」という場合も、最低限ここを下回ると困るという線だけは教えていただけると、条件の合わない案件に時間を使わずに済みます。

3. 案件を紹介されたときに確かめること

紹介された案件は、案件情報だけでは分からない点があります。応募を決める前に、次のことを担当者に聞いておきます。

確かめること理由
業務内容と役割実装担当か、設計・調整まで任されるかで負担と評価が変わる
契約の相手自分が誰と業務委託契約を結ぶのか
エンドの業界・規模社名が明かせなくても、業界や規模は聞けることが多い
稼働条件稼働日数、出社の頻度、精算幅
期間と更新の見込み短期か、長期を見込むか
チームの体制誰から依頼を受け、誰に報告するか

契約の相手から上に何社が入っているか（商流）によって、報酬や情報の伝わり方が変わることがあります。仕組みは商流の記事で解説しています。

応募は了承した案件だけにする

経歴を発注側に提案するのは、ご本人が了承した案件だけ、という形が基本です。どの案件に経歴が出ているかを把握していないと、同じ案件に別の経路から重複して応募してしまうおそれがあります。応募した案件は、サービス名・案件の概要・日付を手元に記録しておくと安心です。

合わない案件は理由を添えて断る

紹介された案件が合わないときは、「出社が週3日だと難しい」「保守運用より新規開発に入りたい」のように、理由を具体的に伝えて断ります。理由が分かると、担当者は次に紹介する案件を絞り込みやすくなります。反対に、理由を伝えずに断り続けると、条件のずれが解消されないまま時間が過ぎてしまいます。

4. 書類選考と発注側との面談

書類選考

担当者が、スキルシートを案件に合わせて発注側に提案します。案件によっては、求められる経験に近いプロジェクトを上に並べ替える、要約を書き直すといった調整を相談されることがあります。事実と違うことを書くのは避け、表現の順序や強調の仕方を調整するのが基本です。

発注側との面談

業務委託の面談は、採用面接というより「この役割を任せられるか」「一緒に進めやすいか」を確かめる場です。多くの場合、担当者も同席します。

  • 直近のプロジェクトで、自分が判断したこと・工夫したことを具体的に話す
  • 案件の業務内容と、自分の経験が重なる部分を先に示す
  • 最後に、体制・役割・稼働の実態について逆質問をする

よく聞かれる質問は面談でよく聞かれる質問の記事、面談の前に確かめる項目は面談前のチェックリストにまとめています。

注意

面談の場で、金額や精算幅などの条件を発注側と直接交渉するのは避けた方が無難です。契約の相手が担当者の会社である場合、条件の調整はその会社を通して行うのが一般的です。気になる点は、面談のあとに担当者へ伝えましょう。

5. 条件の合意と契約

面談を通過すると、金額・精算幅・開始日・契約期間などの条件が示されます。合意したら、契約書（基本契約と個別契約、または発注書）を交わします。

2024年11月に施行されたフリーランス法では、発注事業者は業務を委託したら直ちに、給付の内容・報酬の額・支払期日などの取引条件を、書面またはメールなどで明示することとされています。また、報酬の支払期日は、給付を受け取った日から60日以内のできる限り短い期間で定めることとされています（公正取引委員会の案内）。

契約書では、少なくとも次の点が口頭で聞いた内容と一致しているかを確認します。

  1. 業務の内容と範囲
  2. 報酬の額、精算幅、超過・控除の計算方法
  3. 支払期日と支払方法
  4. 契約期間と更新・解約の条件
  5. 秘密保持や再委託の扱い

精算の計算方法は精算幅の記事、契約書全体の見方は契約書のチェックポイントで整理しています。エージェントを経由する場合の報酬の内訳の考え方はエージェントのマージンの記事をご覧ください。

6. 参画してからの付き合い方

参画したあとも、担当者とのやりとりは続きます。

  • 月ごとの稼働報告と請求：締め日までに稼働時間を報告し、請求書を出す流れを確認する
  • 困りごとの相談：業務範囲が契約と違ってきた、稼働が精算幅を大きく超えそう、といったときは早めに相談する
  • 更新の確認：契約期間の終わりが近づくと、更新するかどうかの意向を聞かれる。単価の見直しを相談するのもこの時期が多い

更新の仕組みは契約更新の記事、単価の見直しの伝え方は単価交渉の記事で解説しています。

エージェントベストの見解

参画後のご相談で多いのは、業務の範囲が少しずつ広がっていく、稼働時間が想定より増える、といった内容です。当社では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししているため、そのときは契約に書かれた範囲と照らし合わせて、早めにご相談ください。早めに声をかけていただくほど、選べる対応が増えます。

ポイント

  • 流れは「登録→担当者面談→紹介→応募→発注側面談→契約→参画」
  • 最初の面談で、稼働日数・リモート・希望金額・避けたい条件を具体的に伝える
  • 応募は了承した案件だけにし、契約書で業務範囲・報酬・支払期日を確かめる

よくある質問

登録したらすぐに案件を紹介してもらえますか？

希望条件に合う案件があれば早く紹介されますが、時期や条件によっては待つこともあります。稼働日数やリモートの条件を少し広げると、紹介できる案件が増えることがあります。参画したい時期の1〜2か月前から動き始めると、比べながら選びやすくなります。

会社員のうちに登録してもよいですか？

登録や情報収集は在職中でもできます。ただし、参画の開始日は退職日が決まってから調整するのが現実的です。会社の副業の規則や、退職前の準備については会社員からフリーランスになる手順の記事で整理しています。

エージェントを使うと、フリーランス側に費用はかかりますか？

多くの案件紹介サービスでは、フリーランスが登録料や紹介料を直接払う形ではなく、発注側から受け取る金額と、フリーランスに支払う報酬との差がサービスの収入になっています。ただし、仕組みはサービスによって違うため、登録の前に利用規約や契約書で確かめてください。内訳の考え方はエージェントのマージンの記事で整理しています。

案件の探し方

フリーランスエージェントのマージンとは｜報酬の内訳と確かめ方

エージェントのマージンは、発注元が払う金額とフリーランスが受け取る報酬の差です。その差で営業・契約事務・支払の立替などがまかなわれます。率はサービスや案件で違うため、自分の契約の報酬額と条件を確かめるのが要点です。

 案件の探し方

直接契約とエージェント経由の違い｜それぞれの向き不向き

直接契約は報酬の取り分が増えやすい一方、営業・契約・請求・回収を自分で担います。エージェント経由は案件探しや事務を任せられる一方、差額が生じます。違いを項目ごとに比べ、どんな人に向くかを整理します。

 案件の探し方

フリーランスエージェントは複数登録してよい？重複応募を防ぐ管理の仕方

フリーランスエージェントに複数登録すること自体は、登録先の規約で制限されていなければ問題ありません。注意したいのは、同じ案件に別の経路から重ねて応募する重複応募です。応募の管理表と担当者への伝え方を整理します。

 スキルシート・面談

フリーランスのスキルシートの書き方｜基本の構成とプロジェクト欄の例

スキルシートは「基本情報・得意分野の要約・スキル一覧・プロジェクト経歴」の順で、1件ごとに役割と担当工程、成果を具体的に書くのが基本です。構成とプロジェクト欄の書き方の型を、架空の例で紹介します。

 案件の探し方

案件の面談前に確認しておくべき項目チェックリスト｜条件・契約・段取り

業務委託の面談の前には、案件の条件、契約の相手と形態、面談の段取り、自分の準備の4つを確認しておきます。面談で聞くべきことと事前に担当者へ確かめることを分けると、面談の時間を業務の話に使えます。項目を一覧で整理します。

 スキルシート・面談

業務委託の面談でよく聞かれる質問と答え方｜回答の組み立て方

業務委託の面談では、経歴の説明、直近案件での役割、技術や業務の深さ、稼働条件の4つがよく聞かれます。「結論→背景→自分の行動→結果」の順で短く答えると伝わりやすくなります。質問ごとの答え方を架空の例で紹介します。
