データ・AI

データサイエンティストのフリーランス案件｜報酬の決まり方と単価を上げる考え方

データサイエンティストのフリーランス案件の報酬は、使える分析手法の種類よりも、問いの設計から関わるか、報告の相手が誰か、業界の知識、データがどこまで整っているか、稼働の形（常駐型か伴走型か）、商流で決まります。データサイエンティストの単価について公的な統計はなく、案件ごとに大きく変わります。

単価を上げるには、「頼まれた集計や分析をこなす人」から「何を分析すべきかを決め、その結果で判断を動かす人」へ役割を移し、その経験を判断の中身で示すことが近道です。この記事では、報酬が上下する理由と、契約や交渉で押さえる点を整理します。

報酬の差は「誰の、どの判断に関わるか」で生まれる

データサイエンティストの案件は、手法が同じでも、分析の結果を誰が何に使うかで期待される責任が変わります。報酬の差も、主にそこから生まれます。

関わり方期待されること報酬への影響
依頼された集計・レポート作成指定された切り口で正確に数字を出す担える人が多く、条件で差がつきにくい
仮説を立てた分析原因や打ち手の候補を示す業務の理解と問いの立て方で差がつく
効果検証の設計施策の前に比べ方を決め、続けるかの判断材料を出す設計を誤ると判断を誤るため、任せられる人が限られる
分析の企画・方針づくりどのテーマから分析するか、指標をどう定義するかを決める経営層や事業責任者と話せる人が少なく、高めに出やすい

案件の型ごとの仕事内容はデータサイエンティストがフリーランスになるにはで、求められるスキルはデータサイエンティストのスキルの記事で整理しています。この記事では、それが報酬にどう表れるかに絞って説明します。

報酬を左右する主な要素

1. 問いの設計から入るかどうか

もっとも差がつくのは、「何を明らかにすれば判断できるか」を自分で決める立場かどうかです。問いが決まった状態で渡される案件は、作業の範囲がはっきりしている分、応募できる人が多くなります。問いを一緒に作る段階から入る案件は、相談相手としての役割も期待されるため、条件が上がりやすくなります。

2. 報告の相手の階層

分析の結果を、現場の担当者に渡すのか、事業部長や経営層に説明するのかでも期待は変わります。経営層への報告では、統計の正しさに加えて、結論を短く言い切る力と、言えないことを言えないと伝える力が求められます。

3. 業界とデータの知識

マーケティング、金融、小売、製造、医療などでは、データの意味や扱いの決まりが違います。たとえば会員データ、購買履歴、センサーデータでは、欠損や偏りの出方が異なります。業界のデータを読み慣れている人は、立ち上がりが早いと見られ、評価されやすくなります。

4. データの準備状態

見落とされやすいのが、データがどこまで整っているかです。分析用のテーブルが用意されている案件と、複数のシステムからデータを集めて定義をそろえるところから始まる案件では、同じ「分析」でも作業の中身が違います。後者は工数が読みにくいため、データの準備まで担う前提で条件を決めるのか、別の担当者がいるのかを確かめておくことが大切です。データの基盤づくりが中心になる場合は、データエンジニアの報酬の記事の考え方に近くなります。

5. 稼働の形

データサイエンティストの案件には、週5日でチームに入る常駐型のほかに、週1〜3日で分析チームの相談役や指標の見直しを担う伴走型もあります。伴走型は月額を稼働日数の割合で決めるとは限らず、時間単価や月額固定で決めることもあります。稼働の読み方は稼働率の記事、時間単価との換算は月額単価の換算の記事をご覧ください。

エージェントベストの見解

データ分析の案件をご紹介していると、同じ経験年数でも、ご案内できる案件の幅に差が出ることがあります。差が出やすいのは、「分析した」だけでなく「その分析で何が決まり、何が変わったか」を一件ずつ話せるかどうかです。当社では、先に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをご案内しています。伴走型で週の稼働を抑えたい場合も、最初にお伝えいただくことをおすすめします。

単価が上がりやすい経験・下がりやすい経験

上がりやすい経験

  • 効果検証を設計から担った：施策の前に比較の方法を決め、偏りへの対応まで説明できる
  • 指標の定義を決めた：「アクティブな顧客」などの言葉を社内でそろえ、継続して見られる形にした
  • 分析の結果が予算や施策の判断に使われた：判断の場に同席し、質問に答えた
  • 社内の分析メンバーを育てた：レビューの基準や進め方を作り、チームの質を上げた

下がりやすい状況

  • 定型のレポート作成が中心になった：BIツールで自動化できる作業は、外部に任せる理由が薄くなる
  • 作業の範囲が「依頼された集計」で止まっている：問いを決める側に回る機会がないと、説明できる経験が増えない
  • 分析の結果が使われずに終わる：判断につながらない分析が続くと、継続の判断で不利になりやすい

ダッシュボードが整い、定型の作業が減ること自体は成果です。そのあとに「次に何を分析すべきか」を提案できるかで、契約の続き方が変わります。

成果に連動した報酬の提案を受けたときの注意

分析の案件では、「売上が上がった分の一部を報酬にする」「施策の効果が出たら追加で支払う」といった、成果に連動した報酬を提案されることがあります。考える前に、次の点を確かめておきましょう。

  1. 成果を左右するのは自分か：分析の結果を施策にするのは発注元です。施策の実行や予算の判断は自分では動かせません
  2. 成果の測り方が決まっているか：比べる期間、比べる対象、季節や広告の影響をどう除くかが決まっていないと、成果の有無で意見が分かれます
  3. 基本の報酬があるか：成果に連動する部分は上乗せにとどめ、作業そのものへの報酬は準委任の形で確保するのが無難です

分析は、やってみるまで結果が分かりません。「結論」ではなく「作業と報告」を約束する考え方は、準委任契約と請負契約の違いでも解説しています。

注意

データが予定どおりに届かず、分析を始められない期間が出ることがあります。精算幅のある月額契約では、稼働時間が下限を下回ると報酬が控除されることがあります。データの受け渡しが遅れたときの扱い（待機の時間をどう数えるか、開始日をずらすか）を、参画前に確かめておきましょう。精算の仕組みは精算幅の記事で解説しています。

同じ分析案件でも提示額が違う理由

  • データの準備を含むかどうか：分析の前の取り出しや定義の整理まで担うかで、作業の量が変わる
  • 報告の相手が違う：現場向けの資料か、経営層向けの説明か
  • 期間と稼働の形が違う：短期の分析プロジェクトか、継続の伴走か
  • 契約までの経路が違う：事業会社と直接か、コンサルティング会社や開発会社を経由するか。詳しくは商流の記事を参照

月額だけでなく、精算幅、稼働日数、契約期間、支払期日までそろえて比べましょう。全体像はフリーランスの単価の決まり方でまとめています。

交渉で示せる材料

更新の前に条件の見直しを相談するときは、発注側が社内で説明しやすい材料をそろえます。

材料例
判断への貢献分析をもとに、施策の継続・中止や予算の配分が決まった
作業の削減毎月のレポート作成を仕組みにし、担当者の手作業を減らした
役割の広がり分析の依頼の窓口や、テーマの優先順位づけを任されるようになった
組織への貢献分析の進め方の標準化や、社内メンバーのレビューを担った

成果は数字で示せると伝わりやすくなりますが、発注元の売上などの数字を外に出してよいかは、秘密保持の約束に注意が必要です。伝え方とタイミングは単価交渉の記事、面談での見せ方はデータサイエンティストのスキルシートの記事をご覧ください。

エージェントベストの見解

分析の案件は、扱うデータや報告の形が参画後に変わることがあります。当社がご案内する案件では、業務の範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。フリーランス法でも、発注側は業務の内容・報酬の額・支払期日などを書面やメールで明示することとされています。データの準備まで任されそうなときなど、範囲が広がりそうな場合は早めにご相談ください。

ポイント

  • データサイエンティストの報酬は、問いの設計への関わり、報告の相手、業界知識、データの準備状態、稼働の形、商流で決まり、案件ごとに大きく変わる
  • 定型のレポート作成は条件が上がりにくく、効果検証の設計や指標づくりは評価されやすい
  • 成果連動の報酬は、成果の測り方と基本の報酬を先に決めてから考える

よくある質問

データサイエンティストの単価の相場はいくらですか？

データサイエンティストの単価について公的な統計はなく、関わり方、報告の相手、業界、稼働の形、商流によって大きく変わります。相場の数字より、ご自身の経験が「集計」「仮説を立てた分析」「効果検証の設計」「分析の企画」のどこに当てはまるかを整理し、複数の案件で条件をそろえて比べるほうが判断の材料になります。

機械学習のモデルを作れると報酬は上がりますか？

モデルを作れることは強みですが、それだけで条件が決まるわけではありません。データサイエンティストの案件では、モデルの結果を業務の判断にどう使ったかが見られます。モデルを本番のシステムで動かし続ける役割まで担う場合は、機械学習エンジニアの報酬の記事の考え方に近くなります。

週2〜3日の伴走型の案件は不利ですか？

稼働日数が少ない分、月額は小さくなりやすい一方で、複数の案件を組み合わせられる利点があります。少ない稼働で成果を出すには、相談への答え方や判断の早さが求められるため、経験を積んだ方に向いた形です。稼働時間の上限と、急ぎの依頼への対応の扱いを、契約前に確かめておきましょう。
