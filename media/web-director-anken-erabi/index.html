Web制作・デザイン

Webディレクターのフリーランス案件の選び方｜契約前に確かめたいこと

公開 2026-11-04　監修：株式会社エージェントベスト

  4. よくある質問

Webディレクターの案件選びで差が出るのは、報酬の額より、自分が決めてよい範囲と、サイトの今の段階、そして体制です。同じ「Webディレクター」の募集でも、要件の整理から任される案件と、決まった仕様の進行だけを担う案件では、毎日の仕事も負う責任もまったく違います。

契約前には、役割の実態、承認の流れ、今の段階と公開日、体制、契約の形と成果物、稼働の振れ幅、契約期間の7点を確かめ、最後に書面と照らし合わせます。この記事では、それぞれを面談や事前のやり取りでどう確かめるかを整理します。契約全般の確認点は業務委託契約で確認すべきポイントで解説しています。

Webディレクター案件の選び方で差が出る理由

Webディレクターの仕事は、発注元、制作会社、デザイナー、エンジニア、ライターなど、多くの人の間に立ちます。そのため、案件票の数行からは見えない条件が、参画後の働きやすさを左右します。

  • 決める人がだれか：要望の取捨を自分が決めるのか、毎回発注元の承認が要るのかで、進み方の速さが変わる
  • サイトの段階：作り直しの立ち上げ、実装の最中、公開の直前、運用中のどこに入るかで、最初の数週間の忙しさが変わる
  • 作る人がいるか：デザイナーやエンジニアがそろっているか、自分が手を動かす前提かで、稼働の中身が変わる

案件の種類ごとの働き方はWebディレクターの案件の仕事内容で整理しています。ここでは、そうした違いを契約前に見分ける方法に絞ります。

契約前に確かめたい7つの点

1. 役割の実態は、ディレクターか、進行管理か、制作か

募集名が「Webディレクター」でも、実態は進行表の管理が中心の案件や、ページの更新作業が中心の案件もあります。反対に、事業会社の側で要件を決め、制作会社を選ぶところまで求められる案件もあります。

確かめ方は、1週間の仕事を具体的に聞くことです。どの会議に出て、何の資料をつくり、どの作業を自分で手を動かすのかを聞くと、役割の実態が見えてきます。

2. 決めてよい範囲と、承認の流れ

要望をどこまで自分の判断で絞れるか、公開の可否をだれが決めるか、追加の依頼の受け入れをだれが判断するかを確かめます。承認の段階が多い組織では、確認が戻るまでの日数が長くなり、スケジュールの組み方が変わります。

面談では「仕様の変更はどなたの承認で決まりますか」「公開前の確認には、どの部署が関わりますか」と聞くと、答えから流れが分かります。

3. サイトの今の段階と、公開日の決まり方

要件の整理中か、デザイン中か、実装中か、運用中かを確かめます。あわせて、公開日が事業の都合で動かせない日なのか、調整できる日なのかを聞きます。動かせない公開日が近い案件は、参画直後から稼働が増えやすくなります。

前任のディレクターがいた場合は、交代の経緯も答えられる範囲で聞いておくと、案件の状態をつかむ手がかりになります。

エージェントベストの見解

Webディレクターの案件をご紹介していると、参画後に「聞いていた段階と違った」と感じやすいのは、作り直しの案件で、要件が決まったと聞いていたのに実際には社内の合意が取れていなかった、というケースです。面談では「決まっていること」と「これから決めること」を分けて聞いておくことをおすすめします。案件票に書かれていない段階の詳細は、ご質問いただければ確認します。

4. 体制と、自分の位置

デザイナー、エンジニア、ライターがチームにいるか、外部の会社に頼むのか、自分が手配するのかを確かめます。自分で外注先を手配する前提の案件では、外注先との契約や支払いも自分の仕事になり、発注者としての義務も負います。考え方はWebディレクターがフリーランスになるにはで解説しています。

あわせて、自分の報告先がだれか、制作会社の側に入る場合は発注元とどこまで直接やり取りするかも確かめます。指揮命令の関係が曖昧なまま常駐に近い働き方になる場合は、契約の形との整合も見ておきましょう。

5. 契約の形と、成果物・検収・権利

準委任（作業や役割を担う契約）か、請負（サイトなどの完成を約束する契約）かで、負う責任が変わります。請負の場合は、何をもって完成とするか、検収の期間と方法、不具合が見つかったときの扱いを確かめます。違いは準委任と請負の違いの記事、検収は検収の記事で整理しています。

ワイヤーフレームや構成案、原稿などの成果物の権利をだれが持つか、制作実績として公表してよいかも、この段階で確かめておきたい点です。考え方は成果物の著作権の記事をご覧ください。

6. 稼働の振れ幅と精算

公開日の前後や大きな更新の時期に、稼働が増えるかを確かめます。月の稼働時間に幅を決めて精算する契約なら、上限を超えたときの扱いも聞いておきます。精算の仕組みは精算幅の記事で解説しています。

夜間や休日の公開作業がある案件では、その時間をどう扱うかも先に決めておきたい点です。

7. 契約期間と、段階の区切り

最初の契約期間と、更新の判断がどの時点で行われるかを確かめます。作り直しの案件では、公開を区切りに契約が終わるのか、公開後の運用まで続くのかで、先の見通しが変わります。段階ごとに契約を分ける場合は、次の段階に進む条件も聞いておきましょう。

運用の案件では、期間の区切りが曖昧なまま長く続くことがあります。更新のたびに、受け持つ範囲と稼働が最初の約束から変わっていないかを見直すと、条件の相談もしやすくなります。更新の前に何を確かめるかは契約更新の記事で解説しています。

注意

Webディレクターの案件では、契約の業務範囲に「Webサイトの制作進行」とだけ書かれ、公開後の不具合対応や他のサイトの更新が含まれるかが曖昧なことがあります。範囲が曖昧なまま参画すると、頼まれごとが少しずつ増え、稼働と報酬が合わなくなります。業務範囲は具体的な言葉で書かれているかを確かめ、広がるときの扱いは作業範囲が広がったときの契約の扱いを参考にしてください。

確かめた内容を書面と照らし合わせる

面談や事前のやり取りで聞いた内容は、契約の書面と照らし合わせます。口頭で聞いた話と書面が違う場合、後で頼りになるのは書面です。

フリーランス法では、発注事業者は業務を委託したら直ちに、給付の内容、報酬の額と支払期日などの取引条件を、書面やメールなどで明示することとされています。公正取引委員会の特設サイトでは、明示すべき項目として、当事者の名称、委託をした日、給付の内容、納品や作業の期日、納品や作業の場所、検査をする場合の完了期日、報酬の額と支払期日、金銭以外で支払う場合の支払方法が挙げられています（2026年10月時点）。項目ごとの見方は取引条件の明示の記事で整理しています。

照らし合わせるときは、次の点を見ておくとずれに気づきやすくなります。

面談で聞いたこと書面で確かめる箇所
役割と受け持つ範囲業務の内容、給付の内容
稼働日数とリモートの度合い作業の場所、稼働時間の定め
公開日と段階の区切り作業の期日、契約期間
稼働の振れ幅精算の幅、超過したときの扱い
成果物と権利著作権、実績の公表に関する条項

書面の内容に迷う点がある場合は、署名の前に確かめましょう。法的な判断が要る場合は、弁護士などの専門家にご相談ください。

よくある質問

公開日が近い案件は避けたほうがよいですか？

避ける必要はありません。ただ、参画直後から稼働が増えやすく、現場に慣れる時間も短くなります。公開日が動かせるか、残っている作業の量、夜間や休日の作業の扱いを確かめてから判断しましょう。

制作会社の側と事業会社の側の案件で迷ったらどうしますか？

これまで時間を多く使ってきた仕事に近いほうから選ぶと、早く力を出せます。複数の案件を速く回す経験が多いなら制作会社の側、社内の調整と運用の改善が多いなら事業会社の側が合いやすい傾向があります。働き方の違いはWebディレクターの案件の仕事内容をご覧ください。

報酬の高い案件と、範囲のはっきりした案件で迷ったらどうしますか？

範囲が曖昧な案件は、参画後に仕事が広がり、時間あたりで見ると報酬が下がることがあります。報酬の額だけでなく、受け持つ範囲と稼働の振れ幅を並べて比べることをおすすめします。報酬の決まり方はWebディレクターの報酬の記事で解説しています。

業務委託契約の基礎

業務委託契約書のチェックポイント｜署名前に確かめたい10項目

業務委託契約書は、契約形態・業務範囲・報酬と精算・支払期日・契約期間と解除・知的財産・秘密保持・損害賠償などを署名前に確認します。フリーランス新法で発注者が明示すべき事項と照らし合わせると、抜けに気づきやすくなります。

 業務委託契約の基礎

準委任契約と請負契約の違い｜フリーランスが知っておくべきこと

準委任は「業務を行うこと」、請負は「仕事を完成させること」に報酬が払われる契約です。責任の範囲・報酬の条件・途中でやめるときの扱いが違うため、契約書で何を約束しているかを確かめることが大切です。

 業務委託契約の基礎

作業範囲が広がったときの契約の扱い｜追加の報酬と変更の残し方

契約で決めた業務範囲を超える作業は、原則として当初の報酬に含まれません。追加するなら、作業内容・報酬・期限を決め直して書面やメールで合意します。フリーランス新法の不当な給付内容の変更の考え方と、変更を合意する手順を整理します。

 業務委託契約の基礎

成果物の著作権は誰のもの？業務委託の知的財産の扱い

業務委託で作ったプログラムや資料の著作権は、契約で決めなければ原則として作ったフリーランスに残ります。発注者に移す場合は、譲渡の範囲・時期・対価と、以前から持っているコードの扱いを契約で確かめます。

 業務委託契約の基礎

検収とは｜請負で報酬が確定するタイミングと、契約書で確かめる検査の条件

検収は、発注者が納品物を検査して契約どおりと認め、受け入れることです。請負では検収完了を報酬の支払条件にする契約が多いため、検査期間・合格基準・期間内に連絡がないときの扱いを確かめます。フリーランス新法の支払期日との関係も解説します。

 スキルシート・面談

業務委託の面談で聞いておくべき逆質問｜参画後のずれを防ぐ確認項目

業務委託の面談の逆質問は、印象づくりより「参画後のずれを防ぐ確認」に使うのが基本です。業務の範囲、体制と指示の流れ、稼働の実態、期間の見込みの4つを確かめておくと、契約後の「話が違う」を減らせます。
