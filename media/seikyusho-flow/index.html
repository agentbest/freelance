単価・報酬交渉

業務委託の請求書の出し方｜締めから入金までの流れと毎月の手順

業務委託の報酬は、締め日に稼働を確定 → 精算額を決める → 請求書を出す（または発注側の支払通知書を確かめる） → 支払期日に入金を確認する、という流れで受け取ります。毎月同じ手順の繰り返しなので、最初の1〜2か月で自分の段取りを決めてしまうと、あとは迷わずに回せます。

この記事では、月額の準委任案件を例に、締めから入金までの各段階でやることと、つまずきやすい点を整理します（2026年10月時点）。

締めから入金までの全体の流れ

月末締めの案件を例にすると、1か月の流れは次のようになります。

段階時期の目安やること
1. 締め締め日その月の稼働を締め、稼働報告をまとめる
2. 報告・確定締め日の後、数営業日現場の確認を受けて報告を出し、精算額が確定する
3. 請求確定の後、決められた期限まで請求書を作って送る。または発注側から届く支払通知書を確かめる
4. 入金支払期日指定口座への入金を確認する
5. 照合・記帳入金の後請求額と入金額を突き合わせ、帳簿に記録し、書類を保存する

稼働報告の書き方は稼働報告書の記事、締め日と支払日の関係は支払サイトの記事で解説しています。この記事は、3〜5の「請求して受け取るまで」に重点を置きます。

請求書は誰が作るのか：2つの方式

業務委託の請求には、大きく2つの方式があります。参画前に、どちらの方式かを確かめておきます。

方式流れフリーランスがやること
請求書方式フリーランスが請求書を作って送る金額を計算し、書式を整えて期限までに送る
支払通知書方式発注側（エージェントを含む）が、確定した金額をもとに支払通知書（支払明細書）を作る届いた金額と内訳を確かめ、誤りがあれば連絡する

支払通知書方式では、自分で請求書を作らなくてよい代わりに、届いた内容を確かめることが大切になります。稼働時間、超過・控除の金額、消費税の扱い、源泉徴収の有無などが、自分の計算と合っているかを見ておきます。

インボイス発行事業者として登録している場合、発注側が支払明細書を作る取引での扱いは、適格請求書の書き方の記事で整理しています。

請求書を自分で作るときの手順

1. 金額を計算する

月額報酬に、精算による超過・控除、立て替えた経費などを加減して、請求する金額を出します。税込か税別かは契約の取り決めに合わせます。迷ったら税込・税別の記事で確認できます。

2. 書く項目をそろえる

インボイス発行事業者（適格請求書発行事業者）として登録している場合は、国税庁が示す次の事項を書きます。

  1. 請求書を作る人の氏名または名称と登録番号
  2. 取引年月日
  3. 取引の内容
  4. 税率ごとに分けて合計した対価の額と適用税率
  5. 税率ごとに分けた消費税額等
  6. 請求書を受け取る事業者の氏名または名称

このほか、実務では請求書番号、発行日、支払期日、振込先口座、稼働報告との対応（対象月）を書いておくと、相手の経理で処理しやすくなります。登録していない場合でも、取引の内容と金額、対象月、振込先は同じように書きます。源泉徴収の対象になる報酬がある場合は、源泉徴収の記事も参考にしてください。

3. 送り方を確かめて送る

送り方は、PDFをメールで送る、発注側のシステムにアップロードする、郵送するなど、取引先ごとに決まっています。宛先（経理部門か、現場の担当者か）、件名の付け方、ファイル名のルールがある場合もあります。最初の請求のときに確認し、次回からは同じ形で送ります。

エージェントベストの見解

当社は、取引先の会社の実態と支払条件を確かめた案件を扱っており、報酬と支払期日は個別契約に書いてお渡ししています。最初の請求の前に、個別契約に書かれた支払期日をカレンダーに入れ、報告の期限・請求の期限・入金日の3つを並べておくことをおすすめします。請求の方法で分からないことがあれば、ご質問いただければ確認します。

請求が遅れても、支払期日は動かないのが原則

請求書を出し忘れたり、期限に遅れたりしたら、支払も遅れるのでしょうか。公正取引委員会のQ&Aと特設サイトでは、請求書が出ていないことを理由に支払期日を過ぎることは認められないとしています。支払期日の上限（給付を受領した日から60日以内、月単位の締めなら条件付きで締めの期間の末日から60日以内）は、従業員を使う発注者に課されたルールです。詳しくは60日ルールの記事で整理しています。

とはいえ、発注側の経理では請求書や報告をもとに支払の準備をしているため、期限に遅れると手続が慌ただしくなります。ルールに頼らず、期限を守って出すのが基本です。

入金を確認し、請求額と照合する

支払期日になったら、口座の入金を確かめ、請求額と照合します。

金額が合わないときに確かめること

差の原因確かめること
源泉徴収源泉徴収の対象になる報酬で、所得税等が差し引かれていないか
振込手数料振込手数料が差し引かれていないか
精算の違い超過・控除の計算が、自分の報告と違っていないか
消費税税込・税別の扱いや端数の処理が、請求と違っていないか
経費立て替えた経費が、報酬と別の日に支払われる取り決めになっていないか

振込手数料については、公正取引委員会の特設サイトで、2026年（令和8年）1月1日以降に業務委託した取引では、振込手数料をフリーランスに負担させて報酬から差し引くことは、事前に合意していても報酬の減額にあたるとされています（1か月以上の業務委託が対象）。2025年12月31日以前に業務委託した取引では、事前に書面やメールなどで合意していれば、実費の範囲で差し引くことは減額にあたらないとされていました。差し引かれていたら、委託を受けた時期と契約の内容を確かめて、発注側に問い合わせます。

入金がないとき

支払期日を過ぎても入金がない場合は、まず請求書の送付先や口座情報に誤りがないかを確かめ、記録が残る形で問い合わせます。その後の対処は報酬が支払われないときの記事で順を追って説明しています。

注意

口座を変えたのに、請求書の振込先だけ直して、発注側の登録情報を変える手続をしていない、というケースがあります。発注側の支払システムには、登録済みの口座が使われることが多いため、口座を変えるときは請求書とは別に、変更の手続を早めに依頼しましょう。誤った口座を伝えていたために受け取れなかった場合は、支払が遅れても発注側の違反にならないことがあります。

帳簿への記録と書類の保存

入金を確かめたら、売上として帳簿に記録します。発生主義で記帳している場合は、請求した時点（役務の提供が終わった月）に売上を計上し、入金時に売掛金を消し込む形が一般的です。記帳の方法は、使っている会計ソフトや税理士の指示に合わせてください。

あわせて、次の書類を保存します。

  • 送った請求書、または届いた支払通知書
  • 稼働報告書の控え
  • 入金の記録（通帳や明細）

メールで送受信したPDFや、クラウドでやり取りした請求書のデータは、電子帳簿保存法の「電子取引」にあたります。同法では、注文書・契約書・領収書・見積書などに通常書かれる取引情報を電子的にやり取りした場合、そのデータを保存することが求められています。保存の方法は電子帳簿保存法の記事で整理しています。

エージェントベストの見解

案件紹介の現場では、独立して最初の数か月に、請求書の宛先の誤りや、締め日と対象月の書き違いで差し戻しが起きる傾向があります。いずれも最初の月に一度手順を固めてしまえば防ぎやすいものです。請求書の雛形に「対象月」「稼働報告との対応」「支払期日」の欄をあらかじめ作っておくことをおすすめします。

毎月の手順をチェックリストにする

請求の作業は毎月同じです。次のようなチェックリストを作っておくと、抜け漏れを防げます。

  1. 締め日：稼働の合計を出し、報告の書式に転記した
  2. 報告：現場の確認を受け、期限までに提出した
  3. 請求：金額・対象月・登録番号・振込先を確かめ、決められた方法で送った（支払通知書方式なら、内容を確かめた）
  4. 入金：支払期日に入金を確認し、請求額と一致した
  5. 記録：帳簿に記録し、請求書・報告書・入金記録を保存した

複数の案件を掛け持ちしている場合は、案件ごとに締め日と支払日が違うことがあります。案件ごとに行を分けた一覧表を作っておくと、入金の予定と実績を見比べやすくなります。

ポイント

  • 流れは「締め → 報告・確定 → 請求 → 入金 → 照合・記録」
  • 請求書を自分で作るか、発注側の支払通知書を確かめるかを参画前に確認する
  • 請求書には、インボイスの記載事項に加え、対象月・支払期日・振込先を書く
  • 2026年1月1日以降の委託では、振込手数料の差し引きは合意があっても減額にあたる（1か月以上の委託）
  • 電子でやり取りした請求書はデータのまま保存する

よくある質問

請求書はいつ出せばよいですか？

取引先が決めた期限に合わせます。月末締めの案件では、稼働報告が確定したあと、翌月の初めの数営業日以内とされることが多くあります。期限が分からない場合は、最初の請求の前に、発注側やエージェントに確かめておきましょう。

エージェント経由の案件では、請求書は誰に出しますか？

契約の相手はエージェントなので、請求書もエージェントに出すのが一般的です。エージェントが支払通知書を作る方式の場合は、届いた内容を確かめて、誤りがあれば連絡します。どちらの方式かは、参画前の案内や契約書で確認できます。

請求書の金額を間違えて送ってしまいました。どうすればよいですか？

気づいた時点で、取引先に連絡し、正しい請求書を出し直すのが基本です。インボイス発行事業者として登録している場合は、修正した適格請求書を交付する必要があります。直し方は適格請求書の書き方の記事で解説しています。

単価・報酬交渉

稼働報告書（作業報告書）の書き方と提出の注意点｜時間の数え方と期限

稼働報告書は、月額報酬の精算額を決める根拠になる書類です。日ごとの稼働時間と作業内容を、契約で決めた時間の数え方に沿って書き、期限までに現場の確認を受けて出すのが基本です。書く項目、時間の数え方、提出の流れと注意点を整理します。

 業務委託契約の基礎

支払サイトとは｜締め日・支払日の確認ポイントとフリーランス新法

支払サイトは、報酬の締め日から実際に支払われる日までの期間です。フリーランス新法では、従業員を使う発注者は受領日から60日以内に支払期日を定める必要があります。締め日・支払日・請求書の期限・振込手数料の確認ポイントを整理します。

 インボイス・消費税

適格請求書（インボイス）の書き方と記載事項｜フリーランスの請求書の例

適格請求書には、登録番号を含む6つの事項を書きます。様式は自由で、手書きやPDFでもかまいません。消費税額の端数処理は1枚につき税率ごとに1回です。フリーランスの月額報酬の請求書を例に、書き方と注意点を整理します。

 確定申告・所得税

報酬から引かれる源泉徴収｜対象になる仕事と確定申告での精算

源泉徴収は、原稿料・講演料・デザイン料・経営コンサルタント等の報酬から支払者が10.21%を差し引いて納める仕組みです。システム開発の報酬は対象の一覧にありません。引かれた分は確定申告で精算し、多ければ還付されます。

 単価・報酬交渉

報酬は税込か税別か｜見積・契約・請求で確認することと計算例

業務委託の報酬が税込か税別かは、当事者の取り決めで決まります。見積・契約書・請求書のすべてで表記をそろえ、インボイス登録の有無や源泉徴収の有無で金額が変わるかを確かめることが大切です。仮の数字で差を整理します（2026年10月時点）。

 単価・報酬交渉

報酬が支払われないときの対処｜確認・督促・相談・法的手続の順番

報酬が支払期日に入金されないときは、自分側の請求や口座の誤りを確かめ、記録が残る形で問い合わせ、書面で督促し、解決しなければ相談窓口や支払督促・少額訴訟を検討します。段階ごとにやることと、そろえておく証拠を整理します。
