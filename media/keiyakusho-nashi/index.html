業務委託契約の基礎

契約書がないまま作業を始めるリスク｜口頭の合意で困ることと着手前に残すもの

公開 2026-10-29　監修：株式会社エージェントベスト

契約書がなくても、口頭の合意だけで契約は成立します。困るのは、何を・いくらで・いつまでに・いつ払うのかを、後から証明しにくくなることです。作業範囲が広がったとき、入金が遅れたとき、途中で打ち切られたときに、自分の主張を支える材料がなくなります。

一方、フリーランス新法では、発注者は業務委託をしたら直ちに、条件を書面かメールなどで示す義務を負っています。着手前に条件を文字で受け取り、届かないときは自分から確認のメールを送っておく。これが、契約書のないまま始めるときの最低限の備えです（2026年10月時点の情報です）。

契約書がなくても契約は成立する

民法第522条は、契約は申込みに対して相手が承諾したときに成立し、法令に特別の定めがある場合を除いて、書面の作成などの方式は要らないとしています。公正取引委員会のフリーランス法Q&A（Q37）でも、業務委託の合意は契約書による必要はなく、口頭でもかまわないとしつつ、トラブルを防ぐために記録に残る方法が望ましいとしています。

つまり、「契約書がないから契約もない」とは限りません。電話やオンライン会議で「来週からお願いします」「承知しました」とやり取りしていれば、その時点で契約が成立していると見られることがあります。反対に、条件が固まっていない段階の打診では、まだ成立していないと見られることもあります。

問題は成立するかどうかより、成立した契約の中身を誰がどう証明するかです。

契約書がないと困る6つの場面

場面契約書（または条件を書いたメール）がないと起きること
作業範囲が広がったどこまでが当初の範囲か示せず、追加の報酬を求めにくい
報酬の額でもめた月額か時間単価か、精算の有無、税込か税別かの認識がずれる
入金が遅れた支払期日が分からず、督促や相談の根拠が弱くなる
途中で打ち切られた契約期間や予告期間の定めがなく、どこまで払われるかが曖昧になる
成果物の権利でもめた著作権を譲るのか、どこまで使ってよいのかが決まっていない
損害賠償を求められた責任の範囲や上限の定めがなく、交渉の土台がない

契約で決めていない事柄は、民法などの一般的なルールで判断されます。

たとえば報酬の支払時期です。準委任に準用される民法第648条第2項では、報酬は委任事務を履行した後でなければ請求できず、期間によって報酬を定めたときは、その期間が過ぎた後に請求できるとされています。支払日を決めていないと「月末に締めて翌月すぐに払われる」と思っていたのに、相手は「請求書を受け取ってから社内の支払サイクルで払う」つもりだった、という食い違いが起きます。後払いの原則と支払サイトの読み方は支払サイトの記事で整理しています。

ただ、一般的なルールは個別の事情を前提にしていないため、自分の想定と違う結論になることもあります。成果物の権利は著作権の記事、責任の上限は損害賠償の条項の記事で考え方を整理しています。

注意

「契約書は後で回すので、先に入ってください」と言われ、そのまま数か月が過ぎるケースがあります。後から届いた契約書に、口頭で聞いていた条件と違う内容（精算の方法、損害賠償の範囲、直接契約の禁止など）が書かれていても、すでに働いた後では断りにくくなります。条件の確認は、作業を始める前が最も交渉しやすい時期です。

発注者には条件を明示する義務がある

フリーランス新法第3条は、発注者がフリーランスに業務委託をしたときは、直ちに、業務の内容・報酬の額・支払期日などを、書面または電磁的方法（メール、チャットなど）で明示しなければならないとしています。この義務は、従業員のいない個人の発注者にもかかります。

口頭で伝えるだけでは、この義務を果たしたことになりません。明示すべき項目と方法の詳細は取引条件の明示の記事にまとめています。ここで押さえたいのは、次の2点です。

  • 契約書という形でなくても、発注書やメール、チャットで条件が届いていれば明示にあたり得る
  • 条件が文字で届かないまま作業を始めるのは、発注者側が義務を果たしていない状態でもある

「契約書を作ってほしい」と頼みにくくても、「明示の内容をメールでいただけますか」と頼むのは、法律に沿った自然な依頼です。

着手前に残しておくもの

発注者から受け取るもの

理想は署名した契約書ですが、時間がないときでも、次の内容が書かれたメールや発注書を受け取っておきます。

  1. 発注者と自分の名称
  2. 業務の内容（担当する工程、作業範囲、成果物があればその内容）
  3. 作業の期間、または納期
  4. 作業場所（リモートか出社か）
  5. 報酬の額（月額・時間単価・固定額など）と精算の方法
  6. 支払期日（「◯月末締め翌月◯日払い」のように特定できる形）

届かないときは、自分から確認のメールを送る

条件が文字で届かないときは、自分の理解をまとめて送り、返事をもらいます。

先ほどのお打ち合わせの内容を、次のとおり理解しております。相違があればご指摘ください。業務内容：◯◯システムの詳細設計とテスト。期間：◯月◯日〜◯月◯日。報酬：月額◯円（税別）、精算幅◯〜◯時間。支払期日：毎月末締め、翌月◯日払い。作業場所：原則リモート。

相手から「この内容で問題ありません」と返事があれば、それ自体が合意の記録になります。返事がない場合でも、送った記録は残ります。

エージェントベストの見解

当社は、フリーランスの方と業務委託契約を結び、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。参画の日程が近いと、書面の確認が後回しになりがちです。個別契約が届く前に作業の開始を求められた場合や、届いた内容がご案内のときと違うと感じた場合は、作業を始める前に早めにご相談ください。

すでに契約書なしで始めてしまったとき

すでに作業を始めている場合でも、今から記録を整えることはできます。

  1. 今の条件を文字にする：上の確認メールを、今からでも送る。過去の分と、これからの分を分けて書く
  2. これまでの記録を集める：打ち合わせのメモ、チャットの履歴、作業の記録、見積書、送った請求書と入金の記録
  3. 契約書の作成を依頼する：明示の義務にふれながら、契約書か発注書の発行を依頼する
  4. 届いた契約書を、これまでのやり取りと照らす：条件が変わっていないか、さかのぼって不利な条項が入っていないかを確かめる

入金の遅れなど、すでにトラブルが起きている場合の進め方は報酬が支払われないときの記事をご覧ください。

契約書が届いたら、署名前に読む

後から届いた契約書は、それまでの作業も含めて適用される書き方になっていることがあります。契約期間の始まりの日、報酬の計算、知的財産の扱い、損害賠償の範囲を、これまでのやり取りと見比べます。署名前の確認項目は契約書のチェックポイントの記事で整理しています。修正を求めるときの考え方は契約書の修正の記事にあります。

知人からの仕事や小さな仕事こそ文字で残す

契約書がないまま始まりやすいのは、知人からの紹介、短期のスポットの仕事、以前の取引先からの追加の依頼などです。関係が近いほど条件を細かく決めにくくなりますが、条件をメールで確かめ合うことは、関係を壊すものではありません。紹介案件の進め方は知人の紹介で案件を得るときの記事にまとめています。

基本契約を結んでいる取引先からの追加の依頼なら、個別契約や注文書で何を決めればよいかは基本契約と個別契約の記事をご覧ください。電子契約で手早く結ぶ方法もあります（電子契約の記事）。

エージェントベストの見解

案件紹介の現場では、参画を急ぐあまり、報酬の額だけを確認して支払期日や精算の方法を確かめずに始めてしまう方が、あとで条件の食い違いにつまずきやすい傾向があります。確認に必要なのは、長い契約書ではなく、条件をまとめたメール1通のこともあります。どの案件でも、着手の前に条件を文字で受け取っておくことをおすすめします。

ポイント

  • 契約は口頭でも成立する。困るのは条件を後から証明できないこと
  • 発注者には、業務の内容・報酬の額・支払期日などを書面かメール等で明示する義務がある
  • 条件が届かなければ、自分の理解をメールで送り、返事をもらって記録にする
  • 後から届いた契約書は、それまでのやり取りと照らしてから署名する

個別の契約が成立しているか、どの条件で合意したと言えるかは、やり取りの中身で判断されます。判断に迷うときは、弁護士や取引トラブルの相談先にご相談ください。

よくある質問

チャットで条件を送ってもらいました。これで契約書の代わりになりますか？

チャットやメールで、業務の内容・報酬の額・支払期日などが示されていれば、フリーランス新法の明示にあたり得ますし、合意の記録にもなります。ただし、損害賠償や知的財産の扱いなどは書かれていないことが多いため、必要に応じて契約書も求めましょう。チャットは見られなくなることがあるので、スクリーンショットやPDFで保存しておきます。

契約書を求めたら、相手に嫌がられないか心配です。

条件を文字で示すことは、発注者の法律上の義務です。「確認のため、条件をメールでいただけますか」と頼むのは自然な依頼です。それでも条件を文字にすることを強く拒まれる場合は、その相手との取引に慎重になる理由の一つになります。

口頭で聞いた報酬と、後から届いた契約書の金額が違いました。

署名する前に、口頭で聞いた金額との違いを指摘し、理由を尋ねます。違いの理由が分からないまま署名すると、契約書の金額で合意したと見られやすくなります。話し合いの経緯はメールで残しておきましょう。

基本契約と個別契約の関係｜何がどちらに書かれるか

基本契約には取引全体に共通するルール（秘密保持・知的財産・損害賠償・解除など）を、個別契約には案件ごとの条件（業務内容・期間・報酬・支払期日など）を書くのが一般的です。食い違ったときにどちらが優先されるかも確認します。

電子契約で業務委託契約を結ぶときの注意点｜署名前の確認と締結後の保存

業務委託契約は電子契約でも有効に結べます。署名前に条件と添付書類を見比べ、署名の方式と相手を確かめ、締結後は契約書のデータを保存するのが基本です。電子署名法の推定、印紙税、電子帳簿保存法、フリーランス法の明示との関係を整理します。

 単価・報酬交渉

報酬が支払われないときの対処｜確認・督促・相談・法的手続の順番

報酬が支払期日に入金されないときは、自分側の請求や口座の誤りを確かめ、記録が残る形で問い合わせ、書面で督促し、解決しなければ相談窓口や支払督促・少額訴訟を検討します。段階ごとにやることと、そろえておく証拠を整理します。

成果物の著作権は誰のもの？業務委託の知的財産の扱い

業務委託で作ったプログラムや資料の著作権は、契約で決めなければ原則として作ったフリーランスに残ります。発注者に移す場合は、譲渡の範囲・時期・対価と、以前から持っているコードの扱いを契約で確かめます。
