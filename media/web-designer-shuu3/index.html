Web制作・デザイン

Webデザイナーの週2〜3日・副業案件｜見つかりやすい案件の型と探し方、注意点

公開 2026-11-04　監修：株式会社エージェントベスト

週2〜3日や副業で受けられるWebデザイナーの案件は、エンジニアやPMの案件と比べると見つかりやすい部類です。デザインの作業は稼働日にまとめて進めやすく、確認もデータとコメントのやり取りで回せるためです。見つかりやすいのは、バナーやLPの継続的な制作、既存サイトの更新、デザインの決まりやテンプレートの整備、成果物の単位で区切れる小さなサイト制作などです。

ただし、どの案件でも短い稼働で回るわけではありません。探すときは、稼働日数に合う作り方の案件を選ぶことが大切です。この記事では、週2〜3日・副業のWebデザイナー案件の傾向、探し方、受けるときの注意点を整理します。週3日の働き方全般は週3日の業務委託案件の記事で解説しています。

Webデザインで週2〜3日の案件が成り立ちやすい理由

週2〜3日の案件が比較的多いのは、仕事の性質によるものです。

  • 作業を稼働日にまとめられる：構成案と素材がそろっていれば、デザインの作成はまとまった時間で進められる
  • 確認を待つ時間がある：途中のデザインを見せてから返事が来るまでに日があくため、毎日いなくても進む
  • 依頼の量が波打つ：キャンペーンや新しいサービスの公開に合わせて仕事が増減し、発注元も週5日の人を抱えるより短い稼働で頼みたい場面がある

一方で、週2〜3日では回りにくい仕事もあります。サイト全体の作り直しの方向性を決める時期、毎日のように差し込みの依頼が来る運用、公開直前の修正が集中する時期などです。こうした仕事は、週5日や、週2〜3日でも稼働日以外の連絡に応じることを前提に募集されることがあります。

週2〜3日・副業で見つかりやすいWebデザイン案件

案件の種類主な仕事週2〜3日で成り立つ理由
バナー・LPの継続制作広告や販促のバナー、キャンペーンのLPを定期的に作る依頼が週や月の単位でまとまり、締め切りが読みやすい
既存サイトの更新決まったデザインに沿った下層ページの追加、画像の差し替え決まりが整っていて、判断に迷う場面が少ない
デザインの決まりの整備部品、色、文字の決まりの整理、テンプレートづくり毎日の即応より、まとまった作業時間が求められる
小さなサイトの制作（成果物単位）小規模な企業サイトや店舗サイトのデザイン納期と成果物で区切れ、作業する日を自分で決めやすい
制作会社の繁忙期の応援混み合う時期だけ、下層ページの展開や修正を担う期間と範囲を区切って頼まれる

バナー・LPの継続制作は、事業会社のマーケティング部門が外部のデザイナーに定期的に頼む形で出てくる案件です。社内に依頼をまとめる担当者がいれば、デザイナーは決まった曜日に依頼を受けて作り、次の稼働日までに確認を受ける、という周期で回せます。

デザインの決まりの整備は、更新を続けてきたサイトで、部品や文字の大きさがばらついてきたときに出てくる仕事です。毎日の対応は求められにくい一方、既存の画面を読み解いて、使われる決まりにまとめる力が問われます。

エージェントベストの見解

Webデザイナーの案件をご紹介していると、週2〜3日の希望で決まりやすいのは、「この稼働日数なら、月にこのくらいの量と種類を担える」と自分から示せる方です。反対に、稼働日数だけを伝えて担える範囲を示さないと、発注元が不在の日の依頼をどう扱うかを決められず、見送られやすい傾向があります。稼働日数と担える範囲、確認への返事の速さをセットで伝えることをおすすめします。

週2〜3日のWebデザイン案件の探し方

1. 担える量と種類を先に決める

週2〜3日で受けるなら、どの種類の制作物を、月にどのくらい担えるかを先に考えておきます。たとえば「LP1本とバナー数点の制作と修正」「既存サイトの下層ページの追加を月に数ページ」のように言葉にしておくと、案件との照らし合わせが早くなります。

2. 稼働する曜日と、稼働日以外の連絡の扱いを決める

稼働する曜日を固定できるか、稼働日以外に確認の返事や小さな修正にどこまで応じられるかを決めておきましょう。確認の返事が数日あくと、発注元の公開の予定に響くことがあります。返事ができる時間帯をはっきりさせておくと、短い稼働でも任せやすくなります。

3. 経験のある媒体と、決まりの整った現場から選ぶ

稼働日数が少ないほど、立ち上がりの早さが求められます。作ったことのある媒体、使い慣れたデザインツール、デザインの決まりが整っている現場を選ぶと、短い稼働でも成果を出しやすくなります。リモートで受けられるかも合わせて確かめておきましょう。Webデザイナーのリモートの働き方はWebデザイナーのリモート案件の記事で解説しています。

4. 成果物で区切る形も検討する

稼働日数で報酬が決まる準委任の形だけでなく、成果物ごとに報酬が決まる形も選択肢になります。成果物で区切れば作業する日を自分で決めやすい一方、修正の回数や範囲を決めておかないと、作業が延びても報酬が変わりません。どちらの形が合うかは、本業や生活の時間の組み方で考えます。

短い稼働で信頼を得る進め方

週2〜3日のWebデザイナーは、不在の日があることを前提に、仕事の進め方を組み立てる必要があります。

  • 依頼の締め切りを稼働日に合わせる：依頼を受けたら、どの稼働日に途中の案を出し、いつ仕上げるかを最初に伝える
  • 途中の段階で早めに見せる：方向性の段階で見せておけば、不在の日に確認が進み、次の稼働日に修正から始められる
  • 意図を文章で添える：なぜこの形にしたかを短く書いて渡すと、不在の日に確認する人が迷わない
  • データの版と置き場所をそろえる：最新のデータがどこにあるかを決めておき、自分がいない日もほかの人が触れるようにする
  • 稼働日の終わりに短く報告する：進んだこと、確認を待っていること、次の稼働日の予定を残す

こうした進め方を面談で具体的に話せると、短い稼働でも任せられるかを発注元が判断しやすくなります。

受けるときの注意点

量と稼働日数をそろえる

週2〜3日の案件で起きやすいのは、稼働日数は減ったのに、依頼の量は週5日と同じという状態です。急ぎの依頼が続き、稼働日以外に作業が増えていきます。参画前に、月にどのくらいの量を想定しているか、急ぎの依頼をどう扱うかを確かめておきましょう。

修正の回数と、稼働時間の扱いを確かめる

成果物で報酬が決まる場合は修正の回数と範囲、稼働日数で報酬が決まる場合は稼働日以外に対応した時間の扱いを確かめます。精算の仕組みは精算幅の記事、参画後に依頼が広がった場合の扱いは作業範囲が広がったときの契約の扱いをご覧ください。

著作権と実績公開の条件を確かめる

短い案件でも、作った制作物の著作権がどちらに残るか、自分の実績として公開してよいかは確かめておきます。副業で作った作品を、次の案件のためにポートフォリオに載せたい場合は特に大切です。考え方は業務委託の著作権の記事で解説しています。

注意

複数の案件を掛け持ちする場合、公開の時期が重なると、確認の返事と修正が一度に集中します。キャンペーンの時期は業界ごとに似ることもあり、重なりやすい点に注意が必要です。案件ごとにデータの置き場所や素材を分け、取り違えを防ぐことも大切です。掛け持ちの注意点は複数の案件を掛け持ちするときの注意点で解説しています。

会社員の副業でWebデザインの案件を受けるとき

会社員が副業でWebデザインの案件を受ける場合は、上の注意点に加えて、次の点を確かめます。

  • 勤務先の就業規則：副業が禁止か、許可制か、届出制か。業務委託が対象に含まれるか
  • 本業との競合：本業がデザインや制作の会社の場合、同じ業界の顧客や、本業の取引先に関わる案件は、競業や秘密の扱いで問題になりやすい
  • 時間帯：打ち合わせや確認の返事が平日の日中に求められることがあり、本業の時間と重ならないか
  • 道具と素材：本業で使うパソコンやソフトのライセンス、素材サイトの契約を副業に使ってよいか

デザインの仕事では、本業で使っている素材やフォントのライセンスを、そのまま副業に使えないことがあります。副業用に自分で契約するか、発注元が用意するかを確かめておきましょう。

所得が出れば、確定申告が必要になる場合があります。副業の所得と申告の関係は副業の所得と確定申告の記事、就業規則の読み方や確定申告の全体は会社員の副業で業務委託案件を受けるときの注意点と副業禁止の会社で業務委託を受けるリスク、平日の日中に動けない場合の探し方は週末・夜だけの業務委託案件の記事で解説しています。判断に迷う場合は、勤務先の担当部署や税理士などの専門家にご相談ください。

エージェントベストの見解

当社では、案件をご案内する前に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをお出ししています。週2〜3日のWebデザイン案件では、稼働できる曜日、稼働日以外の確認への対応、担える制作物の量と種類をあわせてお伝えいただくと、条件を照らし合わせやすくなります。契約では業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。

ポイント

  • Webデザイナーは作業を稼働日にまとめやすく、週2〜3日・副業の案件が比較的見つかりやすい
  • 見つかりやすいのは、バナー・LPの継続制作、既存サイトの更新、決まりの整備、成果物単位の小さなサイト、繁忙期の応援
  • 担える量と種類、稼働する曜日と返事ができる時間帯を先に決め、依頼の量と稼働日数をそろえる
  • 会社員の副業では、就業規則、本業との競合、時間帯、素材やソフトのライセンスを確かめる

よくある質問

週2〜3日の案件でも、スキルシートの経験として評価されますか？

担った範囲と制作物の中身を具体的に書けば、経験として評価されます。稼働日数と担った種類・量を正確に書き、全体のデザインの責任者と誤解されない書き方にしておきましょう。書き方はWebデザイナーのスキルシートの記事で解説しています。

週3日で始めて、あとから稼働を増やすことはできますか？

依頼の量が増えたり、決まりの整備など新しい仕事が出てきたりして、稼働を増やせることがあります。ただし、案件ごとに予算や体制の事情が違うため、増やせる前提で受けるのは避けたほうが無難です。将来の希望がある場合は、参画前に伝えておくと話がしやすくなります。

平日の夜や週末だけでもWebデザインの案件は受けられますか？

成果物で区切れる制作なら、夜や週末の作業で進められる案件もあります。ただし、打ち合わせや確認の返事を平日の日中に求められることがあるため、連絡の取り方と返事ができる時間帯を、参画前に発注元とそろえておく必要があります。

 副業・複業

週末・夜だけの業務委託案件はある？探し方と会社員が注意すること

週末・夜だけの業務委託案件はありますが、平日日中の稼働を前提にした案件より数は限られます。範囲を区切れる開発や相談・レビューなどで見つかりやすく、勤務先の副業の規定、本業との時間の切り分け、確定申告を確かめておくことが大切です。

 副業・複業

会社員の副業で業務委託案件を受けるときの注意点｜就業規則・契約・税金の確かめ方

会社員が副業で業務委託案件を受けるときは、勤務先の就業規則、本業との競合や秘密の扱い、契約条件、確定申告と住民税の4点を先に確かめます。業務委託は会社員の給与とルールが違うため、受ける前の整理が大切です。

 副業・複業

副業禁止の会社で業務委託を受けるリスク｜就業規則の読み方と許可の求め方

就業規則で副業が禁止・許可制の会社で無断で業務委託を受けると、懲戒などの対象になるおそれがあります。厚生労働省のガイドラインの考え方を踏まえつつ、規則の読み方、許可の求め方、断られたときの選択肢と相談先を整理します。

 副業・複業

副業の確定申告｜所得20万円のルールの正しい理解と、住民税の申告が別に要る理由

副業の所得が20万円以下なら確定申告が不要になるのは、給与を1か所から受け年末調整を受けている人などに限られます。20万円は収入ではなく所得で数え、住民税の申告は別に必要なことがあります。医療費控除などで申告するときは副業分も含めます。

 リモート・稼働日数

複数の案件を掛け持ちするときの注意点｜契約・時間・情報管理の確認

案件の掛け持ちは、契約で他の仕事が制限されていないか、稼働の時間帯が重ならないか、情報を案件ごとに分けて扱えるかを先に確かめれば進めやすくなります。参画前に確認したい点と、掛け持ち中の進め方を整理します。
