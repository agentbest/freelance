案件の探し方

SNSや交流会で案件を得るときの注意点｜発信・声かけ・条件の残し方

SNSや交流会で仕事を得るときは、発信の段階で参画中の案件の秘密を守ること、声をかけられたら相手の会社と契約の相手を確かめること、条件をメールやメッセージで残すことの3つが要になります。SNSや交流会は、知らない相手と出会える一方で、相手の素性や条件が見えにくいまま話が進みやすい場です。仕事の話になった時点で、知人の紹介や案件紹介サービスを通すときと同じ確認に切り替えます。

すでに知っている人からの紹介については知人の紹介の記事で解説しています。この記事では、まだ関係の浅い相手から仕事の話が来るときの注意点を扱います。

SNS・交流会から仕事になるまでの流れ

SNSや交流会から仕事になるときは、おおむね次の順で進みます。段階ごとに、気をつけることが違います。

段階よくあること気をつけること
発信・参加技術の話題や仕事の様子を発信する、交流会で名刺を交換する参画中の案件の秘密に触れない
声かけメッセージや交流会の場で「相談したい」と言われる相手が誰か、何の仕事かを確かめる
相談オンラインで話を聞く、資料を見せてもらう無償でどこまで応じるかを決めておく
条件のすり合わせ金額・期間・作業内容を話す契約の相手と支払条件を確かめる
契約・着手発注の連絡を受けて始める条件を文面で受け取ってから着手する

発信で守ること

SNSでの発信は、自分の技術や仕事ぶりを知ってもらう手段になります。一方で、参画中の案件や過去の案件の情報を出してしまうと、契約上の問題になることがあります。

参画中の案件の情報を出さない

業務委託契約には秘密保持の条項が入っていることがよくあり、業務で知った情報を外に出さないことが求められます。社名を書かなくても、次のような発信から取引先や案件が特定されることがあります。

  • 作業中の画面やチャットの画像（背景に映り込んだ情報も含む）
  • 「今の現場は〇〇業界の大きなシステム刷新で」のような具体的な説明
  • 障害やトラブルの様子を、時刻や状況とともに書く投稿
  • 現場の人とのやりとりや、評価に関する話題

技術の学びを発信したいときは、案件から切り離した一般的な話題として書くか、自分で試した内容に置き換えます。契約の秘密保持の範囲は秘密保持契約の記事で解説しています。

稼働の状況の伝え方

「案件を探しています」「来月から空きがあります」と発信すると、声をかけてもらえるきっかけになります。ただし、参画中の取引先の人も発信を見ている可能性があります。参画中の案件の終了を自分から公表する前に、取引先との間で終了の時期が確定しているかを確かめます。

声をかけられたら、相手を確かめる

SNSのメッセージや交流会で仕事の話を持ちかけられたら、話を進める前に、次の点を確かめます。

  1. 相手は個人か会社か：会社なら正式な名称と所在地、相手の役割
  2. 契約の相手は誰になるか：声をかけてきた人の会社か、その先の会社か。仲介している場合は、どこと契約するのか
  3. 仕事の中身：何を、いつまでに、どこで行うのか
  4. 連絡の手段：SNSのメッセージだけでなく、会社のメールアドレスなどで連絡が取れるか

相手の会社が実在するか、名称と所在地が合っているかは、公的な情報で確かめられます。方法は取引先の会社を調べる方法の記事にまとめています。

注意

仕事の話の中で、次のような要求があったときは、立ち止まって確かめてください。

  • 仕事を始める前に、登録料・教材費・機材の購入などで先にお金を払うよう求められる
  • 契約の前の段階で、本人確認書類や口座の情報を求められる
  • 業務の内容が説明されず、「簡単な作業」「すぐ稼げる」とだけ言われる
  • 会社名や所在地を聞いても答えてもらえない

判断に迷うときは、話を進めずに、フリーランス・トラブル110番などの相談窓口にご相談ください。

無償の相談と有償の仕事の線引き

SNSや交流会で知り合った相手から、「ちょっと相談に乗ってほしい」「少しだけ見てほしい」と頼まれることがあります。最初の相談に応じることは、関係づくりとして意味があります。ただし、線引きをしないまま応じ続けると、本来は報酬が発生する作業を無償で行うことになります。

線を引くときは、次のように考えると決めやすくなります。

  • 話を聞いて、方向性を伝えるまでは無償の相談として応じる
  • 資料やコードを読んで具体的な指摘をする、設計を書く、作業をするのは有償の仕事として見積もる
  • 無償の相談は、時間（たとえば初回の1回だけ）を先に決めて伝えておく

「ここから先はお見積もりのうえで進めます」と早めに伝えておくと、相手も依頼の仕方を判断しやすくなります。面談の段階で課題を求められたときの線引きは無償作業の線引きの記事で解説しています。

エージェントベストの見解

SNSや交流会での出会いは、相手の人柄や考え方が先に分かる一方で、会社としての支払の流れは見えにくいものです。人柄への信頼と、支払条件の確認は分けて考える必要があります。当社では、取引先の会社の実態と支払条件を確かめた案件を扱っています。SNSや交流会からの仕事でも、着手の前に相手の会社と支払期日を確かめておくことをおすすめします。

条件はメッセージでも残る形で受け取る

仕事の条件がまとまったら、着手の前に文面で受け取ります。2026年10月時点のフリーランス法では、フリーランスに業務を委託した事業者は、業務の内容、報酬の額、支払期日などを直ちに明示することが求められています。発注者が従業員を使わない個人の場合も、この明示の義務は負います。

公正取引委員会の特設サイトによると、明示の方法は書面のほか、メールやSNSのメッセージなどの電磁的方法でもよいとされています。ただし、SNSについては、送信者が受信者を特定して送るものに限られ、誰でも見られる投稿やブログへの書き込みは認められません。電話や打ち合わせで口頭で伝えるだけでは、明示したことになりません。

SNSや交流会からの仕事で実務上注意したいのは、次の点です。

  • 交流会の場で口頭で決めたことは、後日メールやメッセージでまとめて送り、相手の確認をもらう
  • SNSのメッセージで条件を受け取った場合は、画面を保存するなど、あとで見返せるようにしておく（アカウントの削除などでやりとりが消えることがある）
  • 条件の一部が決まっていない場合は、いつ決まるのかも文面で確かめる

明示される項目と確かめ方は取引条件の明示の記事で解説しています。

参画中の契約とぶつからないか

交流会で、参画中の現場の関係者や、その取引先の人と知り合うことがあります。参画中の契約に、取引先と直接取引することを制限する条項があると、そこから生まれた仕事を受けられない場合があります。新しい仕事を受ける前に、参画中の契約の条項を確かめます。条項の読み方は直接契約の禁止・競業避止の記事をご覧ください。

関係を仕事につなげるために

SNSや交流会は、すぐに仕事を得る場というより、時間をかけて信頼を積み上げる場として使うと、無理のない形で仕事につながります。

  • 発信は、自分が得意なことが伝わる話題にしぼる
  • 交流会で知り合った人には、後日あいさつの連絡を入れ、自分ができることを短く伝える
  • 名刺やプロフィールには、問い合わせ先と、受けられる仕事の種類を書いておく

関係の育て方は人脈づくりの記事、名刺やWebサイトの考え方は名刺やWebサイトの記事で解説しています。直接の取引と案件紹介サービスの使い分けは直接契約とエージェント経由の記事をご覧ください。

エージェントベストの見解

SNSや交流会で仕事を探す方法と、案件紹介サービスを使う方法は、組み合わせることができます。当社では、ご案内の前に稼働日数・リモートの可否・希望金額を伺い、合う案件だけをご案内しています。経歴は、ご本人の了承を得た案件にだけ、氏名・連絡先を伏せて提案しています。SNSで実名や稼働の状況を発信している場合も、どの取引先に経歴を出すかはご本人が選べます。

ポイント

  • 発信では、画面・業界・時期の組み合わせから参画中の案件が特定されないようにする
  • 声をかけられたら、相手の会社、契約の相手、仕事の中身を確かめてから話を進める
  • 無償の相談の範囲を先に決め、具体的な作業は見積もってから受ける
  • 条件はメールや相手を特定したメッセージで受け取り、口頭の合意は文面にまとめ直す

よくある質問

SNSのダイレクトメッセージで受けた依頼も、フリーランス法の取引条件の明示の対象になりますか？

フリーランスに業務を委託する事業者であれば、依頼の経路にかかわらず、取引条件を明示する義務があります。明示の方法として、相手を特定して送るSNSのメッセージも認められています。条件の文面は、あとで見返せるように保存しておきます。

交流会で知り合った人から、名前を出さずに仕事を手伝ってほしいと言われました。

自分の名前が表に出ない形でも、業務委託として仕事を受けることはできます。その場合も、契約の相手が誰か、報酬は誰から支払われるのかを確かめてください。相手がさらに別の会社から仕事を受けている場合は、相手の契約で再委託が認められているかも確かめておくと安心です。

SNSで過去の案件の実績を紹介してもよいですか？

案件の契約の秘密保持の範囲によります。社名や具体的なシステムの内容を出すことは、契約で認められていないことがあるため、取引先が特定されない書き方にします。判断に迷う場合は、取引先に確かめてから公開してください。

案件の探し方

知人の紹介で案件を得るときの注意点｜条件の決め方と関係を守る進め方

知人の紹介の案件は決まりやすい一方、条件をあいまいにしたまま始めやすいのが落とし穴です。業務範囲・報酬・支払期日・契約期間を書面で決め、直接契約の禁止条項や紹介料の扱いも最初に確かめます。

 年代別のキャリア

フリーランスの人脈づくり｜案件につながる関係の育て方と守ること

フリーランスの人脈で案件につながりやすいのは、一緒に働いた人との関係です。数を増やすより、仕事ぶりを知る人に、得意な領域と稼働の条件が伝わっている状態を作ることが大切です。関係の育て方と、守秘・契約の注意点を整理します。

 独立・開業の準備

フリーランスに名刺やWebサイトは必要？｜要る場面・載せる項目・後回しでよいケース

業務委託のエンジニアやコンサルは、案件紹介を通じて仕事を探すなら名刺もWebサイトもなくて困らないことが多く、直接の営業や紹介で仕事を得るなら用意する意味があります。必要になる場面、載せる項目、注意点を整理します。

 業務委託契約の基礎

秘密保持契約（NDA）で確認すること｜対象・期間・実績として話せる範囲

NDAで確かめたいのは、秘密情報の範囲と例外、使ってよい目的、守る期間、終了時の返還・廃棄、違反時の責任の5点です。フリーランスは、実績としてどこまで話せるかも署名前に決めておくと安心です。

 案件の探し方

取引先の会社を調べる方法｜参画前に法人番号・登記・インボイスで確かめること

取引先の会社は、法人番号公表サイトで名称と所在地を、登記事項証明書で登記の内容を、インボイス公表サイトで登録の状況を確かめます。公的な情報で分かるのは実在と基本情報までなので、支払条件や契約の窓口は相手に直接確かめます。

 フリーランス新法・下請法

フリーランス新法の取引条件の明示｜受け取るべき8項目と確認のしかた

フリーランス新法では、発注者は業務委託をしたら直ちに、業務の内容・報酬の額・支払期日など8項目を書面かメール等で明示しなければなりません。口頭だけは不可です。受け取るべき内容と、未定事項や共通事項の扱いを整理します。
