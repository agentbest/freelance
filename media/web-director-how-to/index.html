Web制作・デザイン

Webディレクターがフリーランスになるには｜必要な経験と独立までの進め方

公開 2026-10-29　監修：株式会社エージェントベスト

フリーランスのWebディレクターになるには、サイトの制作や運用を、要望の聞き取りから公開まで自分が中心になって進めた経験が必要です。案件側が知りたいのは「ディレクターの肩書きがあったか」より、「関係者の要望をどうまとめ、何を決めて公開まで運んだか」です。

独立の準備は、担当した案件の棚卸し、受けたい案件の型の見極め、スキルシートと面談の準備、お金と手続きの順に進めると無理がありません。デザイナーやエンジニアに外注して仕事を受けるつもりなら、自分が発注者として負う義務も先に押さえておきます。

独立前に確かめたい3つの経験

Webディレクターの経験は、所属していた会社の体制によって中身が大きく違います。独立を考えたら、次の3つを自分がどこまで担ってきたかを確かめましょう。

1. 要望を整理して、作るものを決めた経験

発注元や社内の要望を聞き取り、目的、ページ構成、必要な機能、優先度をまとめた経験です。「言われたものを作った」のではなく、要望が多すぎるときに何を残し、何を次の段階に回すかを決めた経験があると、外部から参画しても任されやすくなります。

2. 制作を公開まで運んだ経験

スケジュールを引き、素材をそろえ、デザインと実装の確認を回し、公開前の確認を経て世に出すまでの流れです。遅れや仕様の変更が起きたときに、誰と何を調整して公開日を守ったか（または動かしたか）を説明できるようにしておきます。

3. 社外の人を取りまとめた経験

制作会社、フリーランスのデザイナー、システム会社、ライターなど、指揮命令の関係にない相手に依頼し、成果物を受け取った経験です。依頼の内容をどう伝え、受け取ったものをどう確認したかは、独立後にそのまま問われます。

経験が「進行の管理」に偏っている場合は、会社にいるうちに要件の整理や公開後の改善の工程に手を挙げておくと、独立後に選べる案件が広がります。案件で見られるスキルの詳細はWebディレクターの案件で求められるスキルで整理しています。

フリーランスのWebディレクターの主な働き方

働き方中身向いている経験
制作会社のチームに入る制作会社のディレクターとして、発注元の案件を進める制作会社でのディレクション経験
事業会社のWeb担当を支える事業会社の側に立ち、制作会社や外注先をまとめる発注側での経験、社内調整の経験
運用を受け持つ公開後の更新、計測、改善を継続して回す運用と改善の経験
一式を受けてチームを組む自分で受注し、デザイナーやエンジニアに外注して制作する見積もりと外注先の管理の経験

最初の案件は、チームに入る形（準委任）のほうが、外注費の立て替えや検収のリスクを負わずに始められます。一式を受ける形は、取引先と外注先の両方との契約を自分で管理する必要があります。契約の種類の違いは準委任と請負の違いの記事をご覧ください。

エージェントベストの見解

Webディレクターの案件をご紹介していると、面談でつまずきやすいのは、会社員時代の担当範囲がはっきりしないケースです。社内では上司が見積もりや発注元との交渉をしていて、ご本人は進行だけを担っていた、ということも少なくありません。独立前に「自分が決めたこと」と「上司や営業が決めたこと」を分けて書き出しておくことをおすすめします。経歴は、ご本人の了承を得た案件にだけ、氏名・連絡先を伏せて提案しています。

独立までの進め方

1. 担当した案件を棚卸しする

案件ごとに、サイトの種類と目的、規模、関わった人と会社、自分が担った工程、決めたこと、公開後の結果を書き出します。守秘義務がある案件は、業種と目的だけで説明できる形にしておきます。書き方はWebディレクターのスキルシートの書き方で解説しています。

2. 受けたい案件の型と条件を決める

上の表のどの働き方から始めるか、週何日稼働するか、リモートをどこまで希望するかを決めます。条件を先に決めておくと、案件の比較がしやすくなります。報酬の決まり方はWebディレクターの報酬の記事で整理しています。

3. 退職と開業の手続きを進める

退職の進め方は会社を辞めてフリーランスになる手順にまとめています。開業届は、国税庁のタックスアンサー（No.2090）で、事業を始めた年分の確定申告期限までに提出することとされています（2026年10月時点）。手続きの詳細は開業届の記事をご覧ください。

4. 外注を使うなら、その前提を整える

一式を受けて外注する働き方を考えている場合は、次の節の義務を押さえ、外注先と交わす発注書の型を用意してから始めます。

外注するときは自分が「発注者」になる

Webディレクターは、デザイナー、コーダー、ライター、カメラマンなどに仕事を出す立場になりやすい職種です。外注先に仕事を出すと、法律上は自分が発注者として義務を負います。2026年10月時点の公正取引委員会の資料をもとに整理します。

取引条件の明示は、従業員がいなくてもかかる

フリーランス法（特定受託事業者に係る取引の適正化等に関する法律）では、フリーランスに業務を委託する事業者は、委託したら直ちに、業務の内容、報酬の額、支払期日などを書面やメール・チャットなどで明示することとされています（第3条）。公正取引委員会のQ&Aでは、従業員を使っていないフリーランスが別のフリーランスに委託する場合も、この明示の義務がかかると説明されています。口頭だけの依頼は認められません。明示する項目は取引条件の明示の記事で整理しています。

従業員を雇うと、義務が増える

従業員を使う発注者（特定業務委託事業者）には、明示に加えて、給付を受け取った日から60日以内のできる限り短い期間で支払期日を定める義務や、1か月以上の委託での受領拒否・減額などの禁止、6か月以上の委託での中途解除の30日前予告などがかかります。ここでいう従業員は、週の所定労働時間が20時間以上で、31日以上続けて雇う見込みの人です。人を雇うと自分がフリーランス法で守られる立場から外れることもあるため、詳しくは再委託の記事をご覧ください。

法人化すると取適法の対象になることがある

2026年1月1日に下請法は取適法に改められました。Webサイトのデザインや制作の委託は、公正取引委員会のリーフレットでいう「情報成果物作成委託」にあたり、取適法の対象かどうかは、発注側と受注側の資本金・従業員数の基準で決まります。法人化して規模が大きくなると、外注先に対して取適法の義務を負う場合があります。自分が対象になるかは、下請法（取適法）とフリーランス新法の違いと公正取引委員会の資料で確かめてください。

取引先との契約で再委託が許されているか

そもそも、受けた仕事を外注してよいかは、取引先との契約で決まります。準委任では、民法上、発注者の許諾かやむを得ない事由がなければ他の人に任せられません。請負でも、契約書に再委託の禁止や承諾の条項があればそれに従います。外注先が作ったデザインや文章の著作権を取引先に渡せる形にしておくことも大切です（成果物の著作権の記事）。

注意

外注先への支払期日を、取引先からの入金日より前に設定すると、資金を立て替える期間ができます。一方で、取引先の入金が遅れたことを理由に外注先への支払いを遅らせると、トラブルのもとになります。外注先への支払期日は、自分の入金の予定と照らして無理のない日にし、明示した日に払いましょう。法的な判断に迷う場合は、弁護士や公正取引委員会の窓口にご相談ください。

エージェントベストの見解

当社がご紹介する案件は、ご本人のスキルと経歴をもとに取引先に提案し、ご本人が稼働することを前提に契約しています。参画後に、制作の一部を知り合いのデザイナーに任せたいと考えたときは、まず契約の再委託の条項を確かめることをおすすめします。契約の業務範囲・報酬・支払期日・契約期間は個別契約に書いてお渡ししていますので、気になる点はご質問いただければ確認します。

よくある質問

制作会社のアシスタントディレクターの経験でも独立できますか？

進行の補助が中心だった場合、外部から単独で任される案件は限られます。小さなサイトでも、要望の整理から公開までを自分が中心になって担った経験があると、応募できる案件が増えます。会社にいるうちに、そうした案件を担当させてもらえないか相談してみるのも一つの方法です。

デザインやコーディングの経験がなくても大丈夫ですか？

自分で手を動かせなくても、Webディレクターとして参画できる案件はあります。ただ、デザインの意図や実装の手間を理解していないと、見積もりや確認の精度が落ちます。制作の流れと用語を説明できる程度の理解は持っておきましょう。

知り合いのデザイナーに外注するときも書面が必要ですか？

相手がフリーランスであれば、フリーランス法の取引条件の明示の義務がかかります。知り合いであっても、業務の内容、報酬の額、支払期日などを、メールやチャットを含む記録の残る形で示しましょう。義務の全体はフリーランス新法の要点で解説しています。
