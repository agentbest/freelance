サーバーエンジニアの週2〜3日・副業案件｜探し方と受けるときの注意点

公開 2026-11-04　監修：株式会社エージェントベスト

週2〜3日や副業で受けられるサーバーエンジニアの案件は、数は限られますが、あります。サーバーの案件は、本番環境の作業や障害への備えがあるため、週5日の稼働を前提にしたものが中心です。そのなかで、週2〜3日でも成り立ちやすいのは、設計書や手順書の作成、移行前の現行調査、構成管理のコード化などの自動化、小規模な環境の保守、レビューや助言の役割などです。

探すときは、「週3日で何でも」ではなく、稼働日数で区切れる仕事の案件を選ぶことが大切です。この記事では、週2〜3日・副業のサーバー案件の傾向、探し方、受けるときの注意点を整理します。週3日の働き方全般は週3日の業務委託案件の記事で解説しています。

週2〜3日のサーバー案件が少ない理由

サーバーの案件で週5日が多いのは、仕事の性質によるものです。

  • 本番作業の時間が決まっている：計画停止や切り替えは業務の都合で日時が決まり、稼働日に合わせて動かせないことが多い
  • 障害はいつ起きるか分からない：運用の案件では、通知を受けてすぐに動ける人がいることが求められる
  • 作業の権限と手続きが重い：本番環境に入るための申請、踏み台、作業の承認があり、人を増やすと管理の手間も増える

そのため、運用の当番や構築の主担当を週2〜3日で募集することは多くありません。週2〜3日の案件は、期限はあっても毎日の即応は求められない仕事として切り出されることがほとんどです。

週2〜3日・副業で見つかりやすいサーバー案件

案件の種類主な仕事週2〜3日で成り立つ理由
設計書・手順書の作成パラメータシートや構築手順書、運用手順書の作成と見直し成果物で区切れ、作業を稼働日にまとめやすい
移行前の現行調査既存サーバーの設定や依存関係の洗い出し調査の期間と範囲を決めやすい
自動化・構成管理定型作業のスクリプト化、構成管理のコード化コードの作成と検証が中心で、本番の即応が少ない
小規模な環境の保守少数のサーバーのパッチ適用、バックアップの確認作業の量が少なく、曜日を決めて対応しやすい
レビュー・助言設計や手順のレビュー、構成の見直しの助言定期的な確認が中心で、日々の運用は担わない

設計書や手順書の作成は、社内のサーバー担当が手を回しきれず、文書の整備だけを外部に頼みたいときに出てくる案件です。既存の環境を読み、抜けている手順や古くなった設定値を直していく仕事で、リモートで進められることもあります。

自動化や構成管理の案件も、週2〜3日で見つかりやすい領域です。ただし、作ったコードを運用チームが使える形で渡すまでが仕事に含まれるため、使い方の説明や引き継ぎの時間も稼働に見込んでおきましょう。

エージェントベストの見解

サーバーの案件をご紹介していると、週2〜3日の希望で決まりやすいのは、「この稼働日数なら、この成果物まで担える」と範囲を自分から示せる方です。反対に、運用の当番や障害対応を週3日で引き受けようとすると、発注元が不在の日の対応に不安を持ち、見送られやすい傾向があります。稼働日数と担える範囲をセットで伝えることをおすすめします。

週2〜3日のサーバー案件の探し方

1. 担える範囲を成果物で決める

週2〜3日で受けるなら、どの成果物を担い、どの作業は担わないかを先に決めておきます。たとえば「手順書の作成と検証環境での確認は担うが、本番作業と障害の一次対応は社内の担当者にお願いする」のように言葉にしておくと、案件との照らし合わせが早くなります。

2. 作業の場所と時間帯を確かめる

サーバーの案件では、どこから作業できるかで、週2〜3日が成り立つかが変わります。踏み台を通してリモートで作業できるか、本番環境に触れる作業は現地に限られるか、作業の時間帯は日中か夜間かを確かめましょう。リモートの働き方の傾向はサーバーエンジニアのリモート案件の記事で解説しています。

3. 週5日の案件の一部を切り出してもらう

週5日で募集されている案件でも、文書の整備だけ、現行調査の期間だけ、といった形で切り出せる場合があります。ただし、本番作業や当番の体制によっては難しいこともあるため、条件を押しつけず、切り出せる範囲を相談する姿勢が大切です。

4. 経験の近い環境から選ぶ

稼働日数が少ないほど、立ち上がりの早さが求められます。扱うOSの系列、仮想化基盤の種類、構成管理の道具が自分の経験に近い案件を選ぶと、短い稼働でも成果を出しやすくなります。

短い稼働で信頼を得る進め方

週2〜3日のサーバーエンジニアは、不在の日があることを前提に、仕事の進め方を組み立てる必要があります。

  • 作業の区切りを稼働日に合わせる：変更や検証を途中で止めたまま不在の日を迎えないよう、稼働日の中で区切れる単位に分ける
  • 不在の日の連絡先を決める：自分が作った手順や設定で問題が出たときに、誰が一次対応をするかを先に合意しておく
  • 作業の記録を残す：何を変え、どこまで進み、何が残っているかを、不在の間も関係者が読めるように書く
  • 週の始めと終わりに短く報告する：稼働日の最初に予定、最後に結果と気になる点を文章で残す

こうした進め方を面談で具体的に話せると、短い稼働でも任せられるかを発注元が判断しやすくなります。

受けるときの注意点

責任の範囲と稼働日数をそろえる

週2〜3日の案件で起きやすいのは、稼働日数は減ったのに、障害の対応は週5日の担当と同じように求められる状態です。不在の日にも連絡が来て、結果として稼働日以外の作業が増えていきます。参画前に、障害時に自分が呼ばれる範囲と、その時間の扱いを確かめておきましょう。

夜間作業と待機の扱いを確かめる

切り替えや計画停止が夜間に入る場合、それが稼働日に数えられるのか、別に精算されるのかを確かめます。待機を求められる場合の報酬の考え方は待機の報酬の記事、稼働時間の精算は精算幅の記事をご覧ください。参画後に作業が広がった場合の扱いは作業範囲が広がったときの契約の扱いで解説しています。

作業の環境と情報の扱いを確かめる

サーバーの作業では、本番環境への接続の方法や、作業に使う端末の条件が決められていることがあります。貸与の端末が必要か、自分の端末から接続してよいかを確かめましょう。

注意

複数の案件を掛け持ちする場合、サーバーの作業は本番の作業日時が動かしにくく、夜間の切り替えや障害の連絡が重なると対応しきれなくなることがあります。接続の情報や設定の資料も、案件ごとに分けて管理する必要があります。掛け持ちの注意点は複数の案件を掛け持ちするときの注意点で解説しています。

会社員の副業でサーバー案件を受けるとき

会社員が副業でサーバーの案件を受ける場合は、上の注意点に加えて、次の点を確かめます。

  • 勤務先の就業規則：副業が禁止か、許可制か、届出制か。業務委託が対象に含まれるか
  • 本業との競合：本業の取引先や同じ業界の顧客の基盤に関わる案件は、競業や秘密の扱いで問題になりやすい
  • 時間帯：計画停止や障害の連絡が、本業の勤務時間と重ならないか

厚生労働省は、副業・兼業について企業と働く人が留意すべき事項をガイドラインにまとめ、モデル就業規則でも副業・兼業の規定を設けています（2026年10月時点、厚生労働省の案内による）。ただし、実際に認められるかは勤務先の規程によります。サーバーエンジニアは基盤の構成や接続の情報など、機密に触れやすい立場です。本業で知った情報を副業の案件で使わないよう、意識して切り分ける必要があります。

就業規則の読み方や確定申告などは会社員の副業で業務委託案件を受けるときの注意点、副業禁止の会社で業務委託を受けるリスク、副業の所得と確定申告の考え方で解説しています。平日の日中に動けない場合の探し方は週末・夜だけの業務委託案件の記事をご覧ください。判断に迷う場合は、勤務先の担当部署や税理士などの専門家にご相談ください。

よくある質問

週2〜3日の案件でも、サーバーエンジニアの経験として評価されますか？

担った成果物と作業の範囲を具体的に書けば、経験として評価されます。週2〜3日の案件は範囲が絞られていることが多いため、スキルシートには稼働日数と担った工程を正確に書き、本番の主担当と誤解されない書き方にしておきましょう。

運用の当番を週3日で受けることはできますか？

シフトが組まれた運用の現場では、決まった曜日の当番として受けられる場合があります。ただ、当番の日以外の連絡や、障害が長引いたときの扱いを先に決めておかないと、稼働が読めなくなります。参画前に確かめておくことをおすすめします。

平日の夜や週末だけでもサーバーの案件は受けられますか？

計画停止の作業や手順書の作成など、時間帯や成果物で区切れる仕事なら成り立つことがあります。一方、日中の打ち合わせや承認が必要な案件は難しくなります。作業の時間帯と連絡の取り方を、応募の段階で確かめておきましょう。

週3日の業務委託案件は、経験のある職種で、担当範囲がはっきりした業務なら見つけやすい働き方です。報酬は稼働日数に応じて決まることが多く、残りの日の使い方まで含めて考えることが大切です。探し方と確認点を整理します。

 副業・複業

週末・夜だけの業務委託案件はある？探し方と会社員が注意すること

週末・夜だけの業務委託案件はありますが、平日日中の稼働を前提にした案件より数は限られます。範囲を区切れる開発や相談・レビューなどで見つかりやすく、勤務先の副業の規定、本業との時間の切り分け、確定申告を確かめておくことが大切です。

 副業・複業

会社員の副業で業務委託案件を受けるときの注意点｜就業規則・契約・税金の確かめ方

会社員が副業で業務委託案件を受けるときは、勤務先の就業規則、本業との競合や秘密の扱い、契約条件、確定申告と住民税の4点を先に確かめます。業務委託は会社員の給与とルールが違うため、受ける前の整理が大切です。

 副業・複業

副業禁止の会社で業務委託を受けるリスク｜就業規則の読み方と許可の求め方

就業規則で副業が禁止・許可制の会社で無断で業務委託を受けると、懲戒などの対象になるおそれがあります。厚生労働省のガイドラインの考え方を踏まえつつ、規則の読み方、許可の求め方、断られたときの選択肢と相談先を整理します。

 副業・複業

副業の確定申告｜所得20万円のルールの正しい理解と、住民税の申告が別に要る理由

副業の所得が20万円以下なら確定申告が不要になるのは、給与を1か所から受け年末調整を受けている人などに限られます。20万円は収入ではなく所得で数え、住民税の申告は別に必要なことがあります。医療費控除などで申告するときは副業分も含めます。

 リモート・稼働日数

複数の案件を掛け持ちするときの注意点｜契約・時間・情報管理の確認

案件の掛け持ちは、契約で他の仕事が制限されていないか、稼働の時間帯が重ならないか、情報を案件ごとに分けて扱えるかを先に確かめれば進めやすくなります。参画前に確認したい点と、掛け持ち中の進め方を整理します。
