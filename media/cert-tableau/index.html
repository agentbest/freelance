フリーランスにTableauの認定資格は役立つ？評価される場面と準備

公開 2026-10-29　監修：株式会社エージェントベスト

Tableauの認定資格は、フリーランスにとってTableauを使う可視化・BIの案件で、製品の知識を体系的に持っていることの裏付けになります。ただし、資格がなくても、ダッシュボードを作って業務で使われた実績があれば参画できる案件は多くあります。

効きやすいのは、Tableauの経験年数がまだ短い時期や、作成だけでなくデータの準備や公開・権限の設計まで任される案件です。この記事では、主な認定であるSalesforce Certified Tableau Data Analystの中身、効く場面と効かない場面、実務との組み合わせ方、スキルシートでの書き方を整理します（2026年10月時点の公式の学習モジュールによる）。

Tableau Data Analyst認定の中身

Tableauの認定資格は、Salesforceの認定資格の仕組みの中で提供されています。データ分析の実務者向けの認定が「Salesforce Certified Tableau Data Analyst」で、入門の位置づけとしてTableau Desktop Foundationsの認定もあります。Salesforceの学習サイトTrailheadの試験準備モジュールでは、Data Analystの試験について次のように案内されています。

項目2026年10月時点の公式モジュールの内容
資格の名称Salesforce Certified Tableau Data Analyst
受験の前提条件なし
推奨される経験Tableau Prep、Tableau Desktop、Tableau ServerまたはTableau Cloudを含む、Tableau製品での6か月以上の経験。Desktop Foundationsの範囲のスキルを持っていること
出題の形択一式・複数選択式の60問（ほかに採点されない問題が5問）
合格の基準65%
受験方法監督付き。試験会場またはオンラインの監督環境で受験。資料の参照は不可
有効期間1年。年1回、Trailheadでメンテナンスのモジュールを完了する必要がある

出題の分野と比率は、次のとおりです。

  • データへの接続と変換：24%
  • データの探索と分析：41%
  • コンテンツの作成：26%
  • Tableau Server・Tableau Cloudでのコンテンツの公開と管理：9%

期限までにメンテナンスを終えないと認定は失効します。取ったあとも年に1回の手続きが続く点は、受験を考える段階で知っておくとよいでしょう。

案件で効く場面と効かない場面

効きやすい場面

  • Tableauの経験がまだ短いとき：ExcelやほかのBIツールの経験はあるが、Tableauでの実務は短い、という段階で、製品の機能を体系的に学んだことを示せます
  • データの準備から公開まで任される案件：出題範囲がTableau Prepでのデータの整形やServer・Cloudでの公開まで含むため、作成だけでなく運用に近い作業を任される案件と範囲が重なります
  • 案件票に資格の名前があるとき：Tableauの導入や活用の定着を支援する案件では、歓迎条件に認定の名前が書かれていることがあります

効きにくい場面

  • 分析の中身が問われる案件：どの指標を見て、何を結論にするかを任される案件では、ツールの操作より分析の経験と考え方が先に見られます。求められる力はデータサイエンティストのスキルの記事で整理しています
  • データ基盤の構築が中心の案件：Tableauにデータを渡す側の、DWHやデータパイプラインの設計が中心なら、基盤の実績が評価の中心です。詳しくはデータエンジニアのスキルの記事をご覧ください
  • 別のBIツールを使う案件：可視化の考え方は通じますが、製品の認定としての効き目は薄れます。Power BIを使う案件ならPower BIの認定資格の記事を参考にしてください

エージェントベストの見解

案件紹介の現場では、BIの案件の面談で、作ったダッシュボードの画面より「誰が、何を決めるために使っていたか」を聞かれる傾向があります。Tableauの認定を持っていても、利用者と使われ方が説明できないと、作成の作業だけを任される見込みで受け取られやすくなります。認定は操作の裏付けとして添え、経歴では使われ方まで書いておくことをおすすめします。

実務経験との組み合わせ方

Tableauの案件で評価されるのは、画面を作れることに加えて、使われ続ける仕組みを作れることです。認定の範囲と実務を、次のように対応させて整理すると伝わりやすくなります。

  1. データへの接続と変換：どのデータソースにつなぎ、Tableau Prepなどでどんな整形をしたか。抽出と接続の使い分けを判断した経験
  2. 探索と分析：計算フィールドや表計算、詳細レベルの式を使って、どんな問いに答えたか
  3. コンテンツの作成：ダッシュボードの構成、フィルターや操作の設計、見る人に合わせた見せ方の工夫
  4. 公開と管理：Server・Cloudへの公開、更新の設定、閲覧権限の設計。比率は小さい分野ですが、案件では運用の相談を受ける入口になります

作った画面は、取引先の情報を含むためそのまま見せられないことが多いはずです。公開されているデータで同じ考え方のダッシュボードを作っておくと、面談で具体的に説明する材料になります。

スキルシートでの書き方

資格欄には、正式な名称と取得した年月、有効期間がある認定であることを踏まえて、有効な状態かどうかを書きます。

  • 資格欄の例：「Salesforce Certified Tableau Data Analyst 20XX年X月 取得（有効）」

経歴欄には、ダッシュボードの利用者と目的、データの範囲を書きます。

  • 「営業部門の週次会議向けダッシュボードを作成。複数のデータソースをTableau Prepで統合し、Tableau Cloudで部門別に閲覧権限を設定」
  • 「既存の帳票をTableauに移行。利用者への聞き取りで指標を絞り込み、更新作業を手作業から自動更新に変更」

技術欄には、使ったTableauの製品（Desktop、Prep、Server、Cloud）を分けて書くと、どこまで触れたかが読み手に伝わります。書き方の全体はスキルシートの書き方の記事で紹介しています。

注意

Tableauの認定は、年1回のメンテナンスを期限までに終えないと失効します。スキルシートに書いたまま期限が切れていると、確認されたときに信頼を損ないます。案件に応募する前に、Trailheadの自分の認定の状態を確かめてください。また、認定の名称は提供の仕組みの変化にあわせて変わることがあるため、取得したときの正式な名称で書くのが基本です。

受験の準備と案件との両立

推奨される経験を先に積む

公式モジュールは、Tableau製品での6か月以上の経験を推奨しています。前提条件はありませんが、出題の4割ほどが探索と分析の分野で、実際に操作した経験がないと判断しにくい問題が多いと考えられます。業務で触れる機会がない場合は、試用できる環境で、接続から公開までを一通り試しておくとよいでしょう。

出題の比率に合わせて時間を配る

探索と分析が41%、コンテンツの作成が26%、接続と変換が24%、公開と管理が9%です。比率の大きい分野から学び、自分の実務で触れてこなかった分野（たとえばPrepや公開の設定）を重点的に補うと、学習が実務の幅にもつながります。

メンテナンスの時期を予定に入れる

取得したら、メンテナンスの期限を予定表に入れておきます。案件の繁忙期と重なると後回しになりやすいため、早めに済ませる習慣をつけておくと安心です。Salesforceの認定全般の考え方はSalesforce認定資格の記事もあわせてご覧ください。

エージェントベストの見解

BIの案件は、「ダッシュボードを作る」「既存の帳票を移行する」「社内に定着させる」など、同じツールでも役割の幅が大きい案件です。応募の前に、作成と運用のどこまでを求められているかを確かめることをおすすめします。案件票から役割が読み取りにくいときは、ご質問いただければ確認します。

ポイント

  • Tableauの認定はSalesforceの認定資格の仕組みの中で提供されている。実務者向けはSalesforce Certified Tableau Data Analyst
  • Data Analystは前提条件なし。6か月以上の製品経験が推奨され、出題は4分野
  • 有効期間は1年で、年1回のメンテナンスを期限までに終えないと失効する
  • スキルシートには正式名称・取得年月・有効な状態を書き、経歴欄で利用者と使われ方を示す

よくある質問

Tableauの認定がないと、Tableauの案件には参画できませんか？

参画できる案件は多くあります。多くの案件では、Tableauで作ったものが業務でどう使われたかという実績が先に見られます。ただし、案件票の必須条件に認定の名前がある場合は、応募の段階で必要になることがあります。

Desktop FoundationsとData Analystは、どちらを受けるべきですか？

Tableauの操作に慣れていない段階ではDesktop Foundationsの範囲が入口になり、公式モジュールもData Analystの前提として同等のスキルを挙げています。実務での経験があり、データの準備から公開まで担うなら、Data Analystが案件の内容に近い認定です。

TableauとPower BIの両方の資格を持つ意味はありますか？

案件によって使うツールが決まっているため、両方の経験があると選べる案件が広がることはあります。ただし、資格を増やすより、どちらかで業務に使われ続けた実績を作るほうが、面談では伝わりやすくなります。
