Web制作・デザイン

Webデザイナーのフリーランス案件の選び方｜契約前に確かめたい7つの点

公開 2026-11-04　監修：株式会社エージェントベスト

  4. よくある質問

フリーランスのWebデザイナーの案件を選ぶときは、報酬や稼働日数に加えて、担う工程の範囲、決める人と確認の流れ、修正の回数、素材とツールの用意、既存のデザインの決まり、契約の形と完了の決め方、著作権と実績公開の条件の7点を契約前に確かめておくことが大切です。Webデザインの案件は、案件票の書き方が似ていても、この7点の違いで負担が大きく変わります。

特に見落としやすいのは、修正の回数と、何をもって完了とするかです。ここがあいまいなまま始めると、確認者が増えるたびに作業が延び、報酬に見合わない状態が続きます。この記事では、Webデザイナーの案件に固有の確認点を整理します。契約書全般の確認点は業務委託契約書のチェックポイントで解説しています。

Webデザイナーの案件選びで差が出る理由

Webデザインの案件票は、「LPのデザイン」「コーポレートサイトのリニューアル」「バナー制作」のように、作るものの名前で書かれることが多くあります。作るものが同じでも、次のような違いが参画後に表に出てきます。

  • デザインだけのつもりが、構成案づくりや文章の手直し、実装まで頼まれた
  • 確認する人が想定より多く、指摘が食い違うたびに作り直しになった
  • 写真や素材がそろわず、自分で探したり撮影の手配をしたりすることになった
  • 作った制作物を自分の実績として見せられないことを、終わってから知った

こうしたずれは、面談と条件の確認の段階で、聞き方を工夫すれば多くを防げます。

契約前に確かめたい7つの点

1. 担う工程の範囲

最初に確かめたいのは、自分が担う工程の範囲です。Webの制作は、目的の聞き取り、構成づくり、デザイン、画像の加工、実装、公開後の更新と、いくつもの工程に分かれます。

  • 構成案やワイヤーフレームは誰が作るか。自分が作る場合、その分は報酬に含まれているか
  • 文章や見出しの言葉は誰が用意するか
  • 実装はするか。する場合、どの範囲まで（HTML・CSSのみか、CMSへの組み込みまでか）
  • 公開後の修正や更新は、契約に含まれるか

案件の種類ごとの仕事の中身はWebデザイナーの仕事内容で整理しています。

2. 決める人と、確認の流れ

デザインを最終的に決めるのは誰かを確かめます。

  • 途中の確認と、最終の承認をする人はそれぞれ誰か
  • 確認する人は何人か。指摘はまとめて届くか、一人ずつ届くか
  • 制作会社を通す案件の場合、発注元と直接やり取りすることはあるか

確認者が多い現場で、指摘を取りまとめる人がいないと、食い違う指示の調整までデザイナーが担うことになります。指摘を一つにまとめてくれる窓口がいるかは、作業の負担を大きく左右します。

3. 修正の回数と範囲

成果物ごとに報酬が決まる契約では、特に大切な点です。

  • 修正は何回まで、またはどの段階まで報酬に含まれるか
  • 方向性が決まった後に、方向性そのものを変える依頼が来たときの扱い
  • 追加のページや画面幅、バナーのサイズ違いが増えたときの扱い

稼働日数で報酬が決まる契約でも、修正が続くと他の依頼が後ろにずれます。修正の扱いをはっきりさせておくと、優先順位の相談もしやすくなります。

エージェントベストの見解

Webデザイナーの案件をご紹介していると、参画後に「聞いていた状況と違った」となりやすいのは、確認する人の数と、修正の扱いの2点です。面談では聞きにくいと感じる方もいますが、作業の段取りを組むために必要な確認として聞けば、多くの発注元は答えてくれます。案件票だけでは分からない点は、契約の前に確かめることをおすすめします。

4. 素材とツールの用意

デザインに使う素材と道具を、誰が用意するかを確かめます。

  • 写真やイラストは発注元が用意するか。足りない場合、誰が手配し、費用は誰が持つか
  • 撮影が必要な場合、立ち会いは求められるか
  • 使うフォントや素材のライセンスは、誰の名義で契約するか
  • デザインツールは自分で用意するか、発注元のアカウントを使うか

素材やフォントのライセンスには、使える範囲や名義の決まりがあります。自分の契約で買った素材を納品物に使ってよいか、発注元に引き渡した後も使い続けられるかは、素材の利用条件によって変わります。迷う場合は、発注元に用意してもらう形にすると、権利の整理がしやすくなります。

5. 既存のデザインの決まりとデータの状態

既存のサイトの改修や運用の案件では、今のデータがどうなっているかを確かめます。

  • 部品や色、文字の決まりがまとまっているか
  • 元のデザインデータが残っているか。どのツールで作られているか
  • 前任のデザイナーがいた場合、引き継ぎの資料はあるか

元のデータがない、決まりがばらばらといった状態では、最初の数週間を現状の整理に使うことになります。それ自体は問題ではありませんが、整理の時間が見込まれているかを確かめておくと、参画直後に成果を急かされずに済みます。

6. 契約の形と、何をもって完了とするか

フリーランスのWebデザイナーの契約は、稼働日数に対して報酬が決まる準委任と、成果物の完成に対して報酬が決まる請負に大きく分かれます。

  • 準委任の場合、稼働の幅と、超えたときや足りないときの精算方法
  • 請負の場合、納める成果物の範囲と、検収の方法と期間
  • 検収で不具合が見つかったときの直し方と、その期間

請負では、成果物を納めて検収に通ることが報酬の条件になります。何を納めたら完了かが書面で決まっていないと、修正の終わりが見えなくなります。契約の形の違いは準委任と請負の違い、精算の仕組みは精算幅の記事で解説しています。

7. 著作権と実績公開の条件

Webデザイナーにとって、次の案件につながる大切な点です。

  • 制作物の著作権は、納品後に発注元に移るか、自分に残るか
  • 著作者人格権を行使しない旨の定めがあるか
  • 制作物を自分の実績として公開してよいか。公開できる時期と、見せ方の条件
  • 生成AIを制作に使ってよいか。使う場合の範囲

著作権を発注元に移す定めがあっても、実績としての公開が認められることはあります。逆に、公開を認めない現場もあります。考え方は業務委託の著作権の記事と著作者人格権の記事、生成AIの扱いは生成AIの利用と業務委託契約で整理しています。

注意

Webデザインの案件では、参画後に依頼が少しずつ広がりやすい傾向があります。別のキャンペーンのバナー、SNS用の画像、資料のデザインなど、契約の業務範囲に入っていない仕事を頼まれたときは、引き受ける前に範囲と条件を確かめましょう。考え方は作業範囲が広がったときの契約の扱いで解説しています。

確かめた内容を書面と照らし合わせる

面談や事前の確認で聞いた内容は、契約の前に書面と照らし合わせます。フリーランス法では、発注する事業者はフリーランスに業務を委託したら、直ちに書面または電子メールなどの方法で取引条件を明示することとされています。明示する事項には、給付の内容、報酬の額、支払期日などが含まれます（2026年10月時点、公正取引委員会の案内による）。明示される事項の詳細はフリーランス法で明示される取引条件をご覧ください。

報酬の支払期日は、成果物などを受け取った日から60日以内で、できる限り短い期間に定めることとされています（2026年10月時点、同）。請負で受ける場合は、納品の日と支払期日の関係も確かめておきましょう。詳しくはフリーランス法の60日ルールの記事で解説しています。

Webデザインの案件では、特に次の点が書面に反映されているかを確かめます。

  1. 業務の内容に、担う工程（構成、デザイン、実装、更新など）が書かれているか
  2. 修正の回数や範囲、追加の依頼の扱い
  3. 請負の場合は成果物の範囲と検収の方法、準委任の場合は稼働の幅と精算方法
  4. 著作権の帰属と、実績公開の条件
  5. 契約期間と更新の時期、支払期日

面談で聞いておくとよい質問はWebデザイナーの面談でよく聞かれる質問と答え方の逆質問の項目でも紹介しています。一般的な逆質問の考え方は面談で聞いておくべき逆質問をご覧ください。

エージェントベストの見解

当社では、取引先の会社の実態と支払条件を確かめた案件を扱い、契約では業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。Webデザインの案件で気になりやすい確認の流れや、実績公開の条件など、書面だけでは読み取りにくい点は、ご質問いただければ確認します。条件に迷う点があれば、契約の前に早めにご相談ください。

ポイント

  • Webデザインの案件は、作るものが同じでも工程の範囲、確認の流れ、修正の扱いで負担が大きく変わる
  • 担う工程、決める人、修正の回数、素材とツール、既存の決まりの状態を面談で確かめる
  • 請負なら完了の決め方と検収、準委任なら稼働の幅と精算を確かめる
  • 著作権と実績公開の条件、支払期日を、書面と照らし合わせる

よくある質問

修正の回数が決まっていない案件は避けたほうがよいですか？

稼働日数で報酬が決まる契約では、修正の回数を決めないことも珍しくありません。その場合は、修正が続いたときに優先順位をどう決めるかを確かめておけば足ります。成果物で報酬が決まる契約で回数が決まっていない場合は、契約の前に範囲を決めておくことをおすすめします。

実績として公開できない案件は、受けないほうがよいですか？

公開できない案件にも、報酬や経験の面で受ける価値はあります。ただ、ポートフォリオの作品が増えないため、公開できる案件とのバランスを考えて選ぶとよいでしょう。公開できない作品は、スキルシートで媒体の種類と担当範囲を言葉で伝えれば、経験として示せます。

報酬の高い案件と、条件のはっきりした案件で迷ったらどうしますか？

一概には言えませんが、修正の扱いや確認の流れがあいまいな案件では、作業が延びて時間あたりの報酬が下がることがあります。報酬の額だけでなく、作業の見込みと条件の明確さを合わせて比べるとよいでしょう。報酬の決まり方はWebデザイナーの報酬の記事で解説しています。

業務委託契約の基礎

業務委託契約書のチェックポイント｜署名前に確かめたい10項目

業務委託契約書は、契約形態・業務範囲・報酬と精算・支払期日・契約期間と解除・知的財産・秘密保持・損害賠償などを署名前に確認します。フリーランス新法で発注者が明示すべき事項と照らし合わせると、抜けに気づきやすくなります。

 業務委託契約の基礎

準委任契約と請負契約の違い｜フリーランスが知っておくべきこと

準委任は「業務を行うこと」、請負は「仕事を完成させること」に報酬が払われる契約です。責任の範囲・報酬の条件・途中でやめるときの扱いが違うため、契約書で何を約束しているかを確かめることが大切です。

 業務委託契約の基礎

作業範囲が広がったときの契約の扱い｜追加の報酬と変更の残し方

契約で決めた業務範囲を超える作業は、原則として当初の報酬に含まれません。追加するなら、作業内容・報酬・期限を決め直して書面やメールで合意します。フリーランス新法の不当な給付内容の変更の考え方と、変更を合意する手順を整理します。

 業務委託契約の基礎

成果物の著作権は誰のもの？業務委託の知的財産の扱い

業務委託で作ったプログラムや資料の著作権は、契約で決めなければ原則として作ったフリーランスに残ります。発注者に移す場合は、譲渡の範囲・時期・対価と、以前から持っているコードの扱いを契約で確かめます。

 業務委託契約の基礎

著作者人格権の不行使条項とは｜意味と署名前に確かめたい範囲

著作者人格権は譲渡できないため、発注者が成果物を改変・公表できるよう「行使しない」と約束する条項が置かれます。確かめたいのは、誰に対して、どの成果物の、どんな利用について行使しないのかの3点です。

 業務委託契約の基礎

業務での生成AIの利用に関する契約条項｜禁止・承認制・条件付き許可の読み方

生成AIの利用に関する条項は、禁止・事前承認・条件付き許可の3つの型に分かれます。確かめたいのは、使ってよいサービス、入力してよい情報、出力の権利と保証、利用の報告の4点です。定めがない場合は使う前に書面で確かめます。
