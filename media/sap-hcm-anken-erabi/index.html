SAP HCM・SuccessFactorsコンサルのフリーランス案件の選び方｜契約前に確かめたいこと

公開 2026-11-04　監修：株式会社エージェントベスト

  2. 契約前に確かめたい8つの点
  3. 確かめた内容を書面と照らし合わせる
  4. よくある質問

SAP HCM・SuccessFactorsコンサルの案件を選ぶときは、報酬や稼働日数に加えて、担当する製品・機能・工程、給与を担うかと並行稼働の予定、立つ側と決める人、基盤側の設定の分担、プロジェクトの状態と切替の時期、個人情報の扱いと作業の場所、稼働の振れ幅と精算、契約期間と契約の形の8点を契約前に確かめておくことが大切です。

人事・給与の案件は、同じ「HCMコンサル募集」でもこの8点の違いで負担と責任が大きく変わります。特に見落としやすいのは、給与の暦と契約の区切りが合っているかです。この記事では、この職種に固有の確認点を整理します。契約書全般の確認点は業務委託契約書のチェックポイントで解説しています。

HCM・SuccessFactors案件の選び方で差が出る理由

人事・給与の案件票は、「SuccessFactors導入」「人事システム刷新」のように抽象的になりやすく、参画してから想定との違いに気づくことが少なくありません。よくあるずれは次のようなものです。

  • Employee Centralの担当で入ったのに、給与との連携の検証まで任された
  • 移行の案件なのに、旧環境の資料がほとんど残っておらず、読み解きに想定以上の時間がかかった
  • 切替の時期が年末調整と重なり、締めの前後の稼働が続いた
  • 個人情報の扱いの決まりで、聞いていたより出社の日が多かった

こうしたずれは、面談と条件の確認の段階で、聞き方を工夫すれば多くを防げます。

契約前に確かめたい8つの点

1. 担当する製品・機能・工程

最初に確かめたいのは、自分が担う範囲です。オンプレミスのHCMかSuccessFactorsか、S/4HANA上の人事か。機能は人事マスタか、勤怠か、給与か、タレント管理か。工程は要件定義からか、設定とテストからか。機能ごとに専門が分かれやすい分野のため、自分で設定する機能と、つなぎ目だけ話し合う機能を分けて確かめます。

面談では、「着任後の最初の1か月で、最も期待されている成果は何か」を聞くと、役割の実態が見えやすくなります。

2. 給与を担うか、並行稼働の予定はどうか

給与の範囲は、負担を最も左右する点です。

  • 給与の計算の設定と検証を自分が担うか、別の担当がいるか
  • 並行稼働を何回行う予定か、差異を許容するかどうかを誰が決めるか
  • 社会保険料や税の控除、年末調整など、制度に沿った計算のどこまでが範囲か

給与を担う場合は、計算の結果が従業員と経理に直接影響します。差異の判断を誰が行うかが曖昧なまま受けると、コンサルの責任だけが問われやすくなります。

3. 立つ側と、決める人

導入パートナーの一員として参画するのか、発注元の人事・情報システム部門に直接参画するのかを確かめます。立つ側によって、誰の利益のために動くか、誰に報告するかが変わります。

あわせて、制度や運用を変えるかどうかを決める人が誰かを確かめます。標準機能に寄せる提案をしても、人事部門の側で決める人が明確でないと、論点が積み上がるだけで進みません。

エージェントベストの見解

人事・給与の案件をご紹介していると、参画後に「聞いていた状況と違った」となりやすいのは、給与の範囲と、制度を決める人の2点です。面談では聞きにくいと感じる方もいますが、担当範囲を判断するために必要な確認として聞けば、多くの発注元は答えてくれます。案件票だけでは分からない点は、契約の前に確かめることをおすすめします。

4. 基盤側の設定と、他の担当との分担

SuccessFactorsの案件では、基盤側の設定を誰が担うかを確かめます。SAP Learningの認定ページでは、基盤側の設定（プロビジョニング）の権限が与えられるのは登録された導入パートナーのコンサルタントで、個人のコンサルタントには与えられないと案内されています（2026年10月時点）。フリーランスが担えるのは画面から行える設定や設計が中心になるため、パートナー側の誰と作業を分けるかを参画前に確かめておくと、作業が止まる場面を減らせます。

あわせて、勤怠・会計・他システムの担当との分担と、連携の仕様を誰が決めるかも確かめます。

5. プロジェクトの今の状態と、切替の時期

案件票に書かれていない「今の状態」と日程を確かめます。

  • 計画に対して予定どおりか、遅れているか
  • 移行の案件なら、旧環境の設定やアドオンの資料が残っているか、保守担当に話を聞けるか
  • 本番の切替の時期が、給与の締め、賞与、年末調整、春の異動の時期とどう重なるか

遅れのある案件を避ける必要はありません。ただ、状態を知ったうえで受けることが大切です。

6. 個人情報の扱いと、作業の場所・端末

人事・給与の仕組みは、従業員の住所、家族、給与の額、評価、マイナンバーなどを扱います。

  • 本番のデータや移行のデータに触れるか、テストのデータは加工されているか
  • 作業の場所と端末の指定、持ち出しの決まり
  • 秘密保持や個人情報の扱いについて、契約でどんな義務を負うか

この点は、リモートで働けるかどうかにも直結します。契約の考え方は業務で個人情報を扱うときの契約と注意点、作業の場所の傾向はリモート案件の記事で解説しています。

7. 稼働の振れ幅と精算

人事・給与の案件の稼働は、給与の暦と切替の時期で大きく振れます。

  • 締めの前後、年末調整、切替の週末に、夜間や休日の対応があるか
  • 給与の不具合が起きたときの連絡と対応の体制に、自分が入るか
  • 精算幅を超えたときの扱いと、稼働が少ない月の扱い

超過した時間の扱いを確かめておかないと、給与の支給日を守るために無償で対応し続けることになりかねません。精算の仕組みは精算幅の記事をご覧ください。

8. 契約期間と工程の区切り、契約の形

契約の期間と、工程の区切りが合っているかを確かめます。たとえば、並行稼働の途中や切替の直前に契約の更新時期が来ると、更新されなかった場合に最も大事な局面を見届けられません。

フリーランス法では、6か月以上継続して業務を委託している場合に、契約を解除したり更新しなかったりするときは、原則として少なくとも30日前までに予告することが求められています（2026年10月時点、公正取引委員会の案内による）。予告の考え方は契約解除・不更新の予告の記事、契約期間の決め方は契約期間の記事で解説しています。

契約の形も確かめます。フリーランスのコンサルは多くの場合、準委任契約で参画します。「給与の計算を誤りなく完了させる」のように完成を約束する書き方や、計算の誤りそのものに対する損害賠償の定めがないかを確かめましょう。契約の形の違いは準委任契約と請負契約の違い、準委任なのに細かな作業の指示や勤務時間の管理を受ける働き方の問題は偽装請負の記事で解説しています。

注意

人事・給与の案件では、参画後に頼まれごとが広がりやすい傾向があります。帳票の追加、操作の研修、別の会社への展開の相談などです。また、届出の書類の作成や提出の代行のように、社会保険労務士の業務にあたるおそれのある作業は、資格のない人が報酬を得て行えない場合があります。契約の業務範囲に入っていない作業を頼まれたときは、引き受ける前に範囲と条件を確かめましょう。考え方は作業範囲が広がったときの契約の扱いで解説しています。

確かめた内容を書面と照らし合わせる

面談や事前の確認で聞いた内容は、契約の前に書面と照らし合わせます。フリーランス法では、発注する事業者は業務を委託したら直ちに、業務の内容、報酬の額、支払期日などを、書面またはメールなどで明示することとされています（2026年10月時点、公正取引委員会の案内による）。明示される事項の内容はフリーランス法で明示される取引条件をご覧ください。

この職種の案件では、特に次の点が書面に反映されているかを確かめます。

  1. 業務の内容に、担当する製品・機能・工程と、給与を担うかどうかが書かれているか
  2. 完成を約束する書き方や、計算の誤りそのものの責任を負う書き方になっていないか
  3. 個人情報の扱い、作業の場所と端末の決まり
  4. 稼働の幅と、超えたときの精算方法
  5. 契約期間と更新の時期が、並行稼働や切替の時期とどう重なるか

面談で聞いておくとよい質問はSAP HCM・SuccessFactorsの面談でよく聞かれる質問と答え方の逆質問の項目でも紹介しています。一般的な逆質問の考え方は面談で聞いておくべき逆質問をご覧ください。

エージェントベストの見解

当社では、取引先の会社の実態と支払条件を確かめた案件を扱い、契約では業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。人事・給与の案件で気になりやすい給与の範囲や、締めの前後の稼働の扱い、作業の場所の条件など、書面だけでは読み取りにくい点は、ご質問いただければ確認します。

ポイント

  • 人事・給与の案件は、同じ募集でも製品・機能・給与の範囲・立つ側で負担が大きく変わる
  • 給与を担うか、並行稼働の差異を誰が決めるか、基盤側の設定を誰が担うかを面談で確かめる
  • 切替の時期と給与の暦、個人情報の扱いと作業の場所を、稼働の見込みと合わせて確かめる
  • 準委任なのに完成や計算の誤りの責任を負う書き方になっていないかを、書面と照らし合わせる

よくある質問

給与を担う案件と担わない案件、どちらを選ぶべきですか？

今の経験と広げたい方向によります。給与を担える人は限られるため評価につながりやすい一方、締めの前後の稼働や差異の説明の負担が大きくなります。給与の経験が浅い場合は、人事マスタや連携の担当として入り、給与の担当と近い位置で経験を積む進め方もあります。報酬への影響は報酬の記事で解説しています。

切替が年末調整の時期と重なる案件は避けたほうがよいですか？

避ける必要はありませんが、その時期の稼働の見込みと精算の扱い、体制の厚さを確かめてから受けることをおすすめします。切替の直後に契約の更新が来ないかもあわせて確かめておくと安心です。

面談で旧環境の資料の有無や、前任の交代理由を聞くのは失礼ですか？

担当範囲を判断するための確認として聞けば、失礼にはあたりません。「着任後に最初に取り組むべきことを把握したい」という目的を添えると、相手も答えやすくなります。答えられない場合は無理に聞き出さず、ほかの確認点で判断しましょう。仕事の流れの全体は仕事内容の記事をご覧ください。

業務委託契約の基礎

業務委託契約書のチェックポイント｜署名前に確かめたい10項目

業務委託契約書は、契約形態・業務範囲・報酬と精算・支払期日・契約期間と解除・知的財産・秘密保持・損害賠償などを署名前に確認します。フリーランス新法で発注者が明示すべき事項と照らし合わせると、抜けに気づきやすくなります。

 業務委託契約の基礎

準委任契約と請負契約の違い｜フリーランスが知っておくべきこと

準委任は「業務を行うこと」、請負は「仕事を完成させること」に報酬が払われる契約です。責任の範囲・報酬の条件・途中でやめるときの扱いが違うため、契約書で何を約束しているかを確かめることが大切です。

 業務委託契約の基礎

偽装請負とは｜指揮命令の線引きとフリーランスが注意すること

偽装請負は、請負や準委任の契約なのに、実態として発注者が働き手に直接指揮命令している状態です。判断は契約の名前ではなく実態で行われます。フリーランスは「労働者性」の基準と、参画前に確かめたい点を押さえておきましょう。

 業務委託契約の基礎

作業範囲が広がったときの契約の扱い｜追加の報酬と変更の残し方

契約で決めた業務範囲を超える作業は、原則として当初の報酬に含まれません。追加するなら、作業内容・報酬・期限を決め直して書面やメールで合意します。フリーランス新法の不当な給付内容の変更の考え方と、変更を合意する手順を整理します。

 フリーランス新法・下請法

フリーランス新法の取引条件の明示｜受け取るべき8項目と確認のしかた

フリーランス新法では、発注者は業務委託をしたら直ちに、業務の内容・報酬の額・支払期日など8項目を書面かメール等で明示しなければなりません。口頭だけは不可です。受け取るべき内容と、未定事項や共通事項の扱いを整理します。

 フリーランス新法・下請法

中途解除の30日前予告｜フリーランス新法のルールと例外

6か月以上の業務委託を発注者が中途解除・不更新にするときは、原則として30日前までの予告が必要です。予告の方法、予告が不要になる5つの例外、理由開示の請求の仕方を、公正取引委員会・厚生労働省の資料をもとに整理します。
