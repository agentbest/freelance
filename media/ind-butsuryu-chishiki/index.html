業界別の案件

物流業界の案件で求められる業務知識と身につけ方｜倉庫の作業・輸配送・荷主との関係

公開 2026-10-29　監修：株式会社エージェントベスト

目次

  2. 案件の領域ごとに、どこを厚く知るか
  3. 参画前にできる身につけ方
  4. 参画後に知識を深めるやり方

物流の案件で求められる業務知識は、倉庫の作業の流れと在庫の単位、輸配送と配車の制約、荷主と物流会社の関係とお金の流れ、会社の間の情報の受け渡しの4つです。全部を深く知る必要はなく、担当する領域によって厚く知るべきところが変わります。

身につけ方の基本は、参画前に入荷から配送までの流れを一通り押さえ、参画後に倉庫や営業所の現場で、モノと情報がどう動いているかを自分の目で確かめることです。案件の種類そのものは物流業界のIT案件の記事で整理しています。

物流の案件で問われる4つの知識

業界知識一般の考え方は業界知識を強みにする方法で解説しています。ここでは物流に固有の中身に絞ります。

1. 倉庫の作業の流れと在庫の単位

倉庫の業務は、入荷、検品、格納、保管、ピッキング、流通加工・梱包、出荷検品、出荷の流れで動きます。WMSの要件は、この流れのどこで、何を、どの単位で記録するかの積み重ねです。

押さえておきたいのは次の点です。

  • ロケーション：棚の番地。品目ごとに置き場を決める方式と、空いている場所に置く方式があり、ピッキングの効率や在庫の探しやすさが変わります
  • 在庫の単位：同じ品目でも、パレット、ケース、ピース（バラ）で数えることがあります。入数（1ケースに何個入るか）の変換を誤ると、在庫が合わなくなります
  • ロットと期限：食品や医薬品などでは、ロット番号や賞味期限・使用期限で在庫を分け、古いものから出す（先入れ先出し）や、期限の近いものから出すといったルールがあります
  • ピッキングの方式：注文ごとに集める方式と、複数の注文分をまとめて集めてから仕分ける方式があり、倉庫の広さや注文の形によって向き不向きがあります
  • 棚卸：帳簿上の在庫と実際の在庫を照らし合わせる作業。止めて数えるか、動かしながら少しずつ数えるかで、システムの作りが変わります

2. 輸配送と配車の制約

運ぶ業務では、どの車両で、どの順に、どこへ届けるかが中心です。配車の計画は、次のような制約の中で立てられます。

  • 車両の大きさと積める量、荷物の大きさや重さ
  • 届け先の受け取り可能な時間、入れる車両の大きさ
  • 温度の管理が必要な荷物かどうか
  • 自社の車両で運ぶか、協力会社に依頼するか
  • ドライバーの拘束時間や休息の取り方

積載率（どれだけ荷台を使えているか）、荷待ち時間（到着から荷役の開始までの待ち時間）、荷役の時間といった指標の意味も知っておきます。国土交通省は、改正物流効率化法の解説で、荷待ち時間を「ドライバーが到着した時間から荷役等の開始時間までの待ち時間」と説明しています。こうした指標を記録する機能は、制度の動きとも関係します。制度の中身は物流業界の規制の記事で扱います。

3. 荷主と物流会社の関係とお金の流れ

物流には、荷物を出す荷主、倉庫や運送を請け負う物流会社、さらにその先の協力会社がいます。荷主の物流をまとめて請け負う形（3PLと呼ばれることがあります）では、1つの倉庫で複数の荷主の荷物を扱います。

お金の流れも押さえておきます。

押さえたい点中身
保管の料金置いている量や期間に応じた料金の考え方
荷役の料金入荷・出荷の件数や作業の内容に応じた料金の考え方
運賃距離・重さ・車両・時間などによる計算と、付帯する作業の料金
協力会社への支払依頼した運送の実績にもとづく支払と照合

物流会社のシステムでは、作業の実績から荷主への請求をつくる仕組みが重要になります。荷主ごとに料金の決め方が違うことが多く、料金の計算ルールの整理が要件定義の大きな部分を占めることもあります。

4. 会社の間の情報の受け渡し

物流では、荷主からの出荷の指示、仕入先からの入荷の予定、運送会社への依頼、届け先への到着の連絡など、会社をまたいだ情報の受け渡しが毎日発生します。事前に届く出荷の情報（事前出荷情報）があると、受け取る側は検品や人の手配を前もって準備できます。

伝票やラベルに何が書かれ、どの時点で誰に渡るのかを知っておくと、データ連携の案件で「この項目はいつ確定するのか」を正しく聞けるようになります。

「概要」は用語と全体の流れが分かる程度、「深く」は例外の扱いまで現場の担当者と議論できる程度を指します。参画前に全部を学ぶより、担当する領域の「深く」に時間をかけるほうが効率的です。

エージェントベストの見解

案件紹介の現場で見ていると、物流の案件の面談で評価されやすいのは、「在庫が合わなかったとき」「出荷の直前に注文が変わったとき」「車両が足りなかったとき」に、現場とシステムでどう対応したかを話せる方です。つまずきやすいのは、用語は知っていても、それが前後のどの作業とつながるかを説明できない場合です。知識は単語ではなく、モノの流れに沿って整理しておくことをおすすめします。

参画前にできる身につけ方

モノと情報の流れを2本の線で描く

まずは、仕入先から倉庫、倉庫から届け先までの流れを1枚の図に描きます。モノの動きの線と、情報の動きの線を分けて描くのがコツです。情報が先に届くのか、モノと一緒に届くのか、後から届くのかが見えると、システムに求められることが分かります。

検定の試験範囲を点検表に使う

体系的に学ぶ手段として、中央職業能力開発協会（JAVADA）のビジネス・キャリア検定の「ロジスティクス」分野があります。2026年10月時点の公式ページでは、2・3級が「ロジスティクス管理」と「ロジスティクス・オペレーション」の2つの区分に分かれ、BASIC級と1級もあります。

ロジスティクス管理は、ロジスティクス企画、需給管理、業務管理に従事している人が対象で、試験範囲には在庫管理、物流システム管理、物流コスト管理、物流情報システムなどが挙げられています。ロジスティクス・オペレーションは、主に物流センターなどで荷役・保管、流通加工・包装、輸配送管理に従事している人が対象で、包装・荷役・保管、輸配送システム、国際輸送、物流センターの計画と管理・運営などが範囲です。受験するかどうかにかかわらず、自分が説明できるかの点検表として使えます。資格の位置づけの考え方は資格の記事で整理しています。

自分の経験を物流の言葉に置き換える

物流業界以外の経験でも、置き換えられるものはあります。小売や卸の受発注の経験は出荷の指示や入荷の予定に、製造業の資材の在庫管理はロケーションやロットの考え方に近い部分があります。経験の洗い出し方はキャリアの棚卸しの記事、業界未経験での参画の考え方は未経験の記事を参考にしてください。

参画後に知識を深めるやり方

倉庫と営業所で作業を見る

見学の機会があれば、入荷から出荷までを順に見せてもらいます。作業者がどこでハンディ端末を使い、どこで紙を見て、どこで手が止まるかは、資料では分かりません。配車の担当者が計画を立てる様子を見ると、システムで表しにくい判断がどこにあるかが分かります。

実績のデータとマスタから読み解く

既存のシステムの刷新では、品目・ロケーション・荷主・届け先・車両などのマスタと、作業の実績のデータが、業務を知る手がかりになります。項目の意味が分からないときは、どの場面で使うかを現場の担当者に聞きます。

荷主ごとの違いを一覧にする

物流会社の案件では、荷主ごとに出荷のルール、帳票、料金の決め方が違います。違いを自分用の一覧にまとめておくと、要件の漏れを防げます。ただし、取引先の資料をそのまま写したり持ち出したりせず、自分の言葉で書いた一般的な理解にとどめます。

参画の初月の進め方全般は初めての案件の記事もご覧ください。

注意

業務を覚える目的で、届け先の名前や住所が入った出荷のデータ、荷主の取引の情報を個人のPCやクラウドに保存するのは避けてください。物流のデータには個人情報や取引先の秘密が多く含まれます。扱いのルールは物流業界の規制の記事で整理しています。

エージェントベストの見解

当社では、取引先の会社の実態と支払条件を確かめた案件を扱っています。物流の案件で、どの程度の業務知識が求められるかは案件によって違うため、気になる場合は早めにご相談ください。今の経験をどの領域の案件に生かせるかについても、ご質問いただければ確認します。

よくある質問

物流の業務知識は、どこから学び始めればよいですか？

担当する領域に近いところから始めるのが効率的です。WMSの案件なら入荷から出荷までの倉庫の作業と在庫の単位、配車の案件なら車両や時間の制約から押さえます。全体の流れを1枚の図に描き、描けない部分を調べていく方法がおすすめです。

荷主側の経験しかありませんが、物流会社の案件で生かせますか？

生かせる部分はあります。荷主側で出荷の指示や在庫を扱った経験は、物流会社が受け取る情報の意味を理解するのに役立ちます。物流会社では複数の荷主を扱い、作業の実績から請求をつくる点が加わるため、その部分を補うと理解が早くなります。

ロジスティクスの検定に合格すると、案件で評価されますか？

検定の合格だけで参画が決まるとは限りません。案件では、実際にどの業務の、どの判断に関わったかが見られます。ただし、試験範囲は物流の業務を体系的に押さえる助けになり、業界未経験から入るときの学習の地図として役立ちます。
