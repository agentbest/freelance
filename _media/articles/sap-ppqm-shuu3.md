SAP PP/QMコンサルの案件は**週5日の稼働が中心で、週2〜3日や副業で受けられる案件は多くありません**。工場の業務と直結し、切替や稼働直後には工場からの問い合わせにすぐ答えることが求められるためです。それでも、運用保守の問い合わせの切り分け、工場ごとの作り込みの棚卸し、検査計画やマスタの見直し、要件定義の助言役など、範囲を区切りやすい仕事では週2〜3日の案件が見つかることがあります。

この記事では、週2〜3日のPP/QM案件が少ない理由、見つかりやすい案件の型、探し方、短い稼働で信頼を得る進め方、受けるときの注意点を整理します。週3日の働き方全般は[週3日のフリーランス案件の記事](/media/week3/)で解説しています。

## 週2〜3日のPP/QM案件が少ない理由

PP/QMの仕事が週5日に寄りやすいのには、このモジュールならではの理由があります。

- **工場は毎日動いている**：計画は日々回り、指図や検査ロットも毎日作られる。問題が起きると、その日のうちに判断を求められる
- **交代勤務の担当者と話す**：製造や検査の担当者は勤務の時間帯が決まっており、稼働する曜日が限られると打ち合わせの機会が減る
- **他モジュールとのつなぎ目が多い**：購買、在庫、原価、MESとの確認が日常的にあり、チームの会議に毎日出ることが前提になりやすい
- **切替の時期に負荷が集まる**：生産を止められる時間が限られ、その前後は稼働が延びやすい

このため、導入や移行のプロジェクトでPP/QMの主担当を週2〜3日で担うのは、発注側にとっても本人にとっても負担が大きくなりがちです。

## 週2〜3日・副業で見つかりやすいPP/QM案件

| 案件の型 | 主な仕事 | 週2〜3日にしやすい理由 |
|---|---|---|
| 運用保守の切り分け | 計画結果・指図・検査ロットの問い合わせの調査、小さな改修 | 一次対応を社内の担当が持ち、難しいものだけ回ってくる形にしやすい |
| 作り込みの棚卸し | 移行の前に、工場ごとの独自の画面・帳票・処理を一覧にする | 調査の範囲と期限を区切りやすい |
| マスタ・検査計画の見直し | 品目の計画の項目、部品表、作業手順、検査計画の整備の方針づくり | 成果物がはっきりしており、作業を曜日で区切りやすい |
| 要件定義・設計の助言役 | 社内の担当やベンダーの設計を確かめ、論点を指摘する | 会議とレビューが中心で、手を動かす時間が少ない |
| 展開先の工場の支援 | 共通の型に合わせた工場ごとの違いの確認 | 工場ごとに区切って関われる |

いずれも、**主担当として毎日の判断を背負うのではなく、範囲を決めて関わる**形です。保守の案件はリモートで進めやすいことも多く、現地作業との分かれ方は[PP/QMのリモートの記事](/media/sap-ppqm-remote/)で整理しています。

:::view
PP/QMの案件をご紹介していると、週2〜3日のご希望で見つかりやすいのは、運用保守や移行前の調査のように、範囲と期限を区切れる仕事です。導入の主担当を週3日で担う形は、工場の打ち合わせや他モジュールとの確認に追われ、稼働が延びやすい傾向があります。当社では、先に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをご案内しています。
:::

## 週2〜3日のPP/QM案件の探し方

### 1. 担える範囲と担わない範囲を先に決める

「保守の問い合わせの切り分けと小さな改修まで」「QMの検査計画の見直しだけ」のように、担う範囲を言葉にしておきます。切替の当日の立ち会いや、工場への出張を受けるかどうかも決めておくと、案件との合い方を判断しやすくなります。

### 2. 稼働する曜日と、稼働外の連絡の扱いを決める

工場の問い合わせは曜日を選びません。稼働しない日に連絡が来たときに、翌稼働日の対応でよいのか、緊急時だけ受けるのかを、参画前に取り決めておきます。考え方は[稼働時間外の連絡の扱いの記事](/media/renraku-jikan/)にまとめています。

### 3. 保守・運用の案件を視野に入れる

稼働後の問い合わせ対応や、新しい品目群の追加などの改修は、週の稼働を決めて受けやすい仕事です。導入の経験が中心の方も、原因を追う力を生かせます。

### 4. 週5日の案件の一部を切り出してもらう

週5日の募集でも、作り込みの棚卸しや検査計画の整備など、一部の仕事を切り出せる場合があります。切り出す範囲を具体的に示すと、発注側も判断しやすくなります。

### 5. 業態と生産方式が近い案件から選ぶ

稼働が短いほど、前提の説明に使える時間は限られます。組立型かプロセス型か、見込み生産か受注生産かが近い案件を選ぶと、少ない稼働でも成果を出しやすくなります。

## 短い稼働で信頼を得る進め方

- **稼働日の最初に状況をそろえる**：前回からの問い合わせ、工場の予定（計画停止、棚卸し、月末の締め）を確かめてから作業に入る
- **調べた手順を残す**：原因の切り分けで確かめたマスタや設定を記録し、稼働しない日にも社内の担当が追えるようにする
- **工場側の窓口を決めてもらう**：生産管理・製造・品質保証の問い合わせ先を一人ずつ置いてもらうと、限られた時間で確認が進む
- **次回までの宿題を明確にする**：工場に確かめてほしい点を、だれが、いつまでにを添えて渡す

## 受けるときの注意点

### 責任の範囲と稼働日数をそろえる

週2〜3日で「PP/QM全体の担当」とされていると、問い合わせや会議が稼働日数を超えて集まります。担う範囲と稼働日数が見合っているかを、契約の前に確かめましょう。範囲が広がったときの考え方は[作業範囲が広がったときの契約の扱い](/media/scope-change/)で解説しています。

### 稼働時間の記録と精算を確かめる

月の稼働時間に幅を決めて精算する契約では、短い稼働でも幅の考え方が効きます。問い合わせの対応で稼働日以外に作業した時間をどう扱うかも確かめておきます。仕組みは[精算幅の記事](/media/seisan-haba/)をご覧ください。

### 繁忙期の稼働の増え方を確かめる

月末の締め、棚卸し、切替の前後は、問い合わせが増えやすい時期です。その時期に稼働を増やす前提になっていないかを確かめましょう。

:::caution
ほかの案件や本業と掛け持ちする場合、切替や稼働直後の対応が重なると、どちらの工場にも十分に時間を割けなくなることがあります。切替の予定時期と、そのときに求められる稼働を、参画前に聞いておきましょう。掛け持ちの考え方は[案件の掛け持ちの記事](/media/kakemochi/)で解説しています。
:::

## 会社員の副業でPP/QM案件を受けるとき

会社員がPP/QMの案件を副業で受ける場合は、次の点を確かめておきます。

1. **勤め先の副業の規程**：副業が認められているか、届け出が必要か、競合する仕事を禁じていないか。考え方は[副業が禁止されている会社での注意点](/media/fukugyo-kinshi/)にまとめています
2. **本業の取引先との関係**：本業の会社の顧客や取引先の工場の案件は、利益が相反するおそれがあります。[本業の取引先の案件を受けるときの記事](/media/hongyo-torihikisaki/)をご覧ください
3. **稼働できる時間帯**：平日の日中に工場と打ち合わせが必要な案件は、会社員の副業では難しいことが多くあります。時間の考え方は[副業の稼働時間の記事](/media/fukugyo-jikan/)が参考になります
4. **税金の手続き**：副業の所得によっては確定申告が必要になります。基準は[副業の確定申告の記事](/media/fukugyo-20man/)で解説しています。個別の判断は税理士などの専門家にご相談ください

業務委託で副業を受けるときの契約の基本は[副業を業務委託で受けるときの記事](/media/fukugyo-gyomu-itaku/)で整理しています。

:::view
当社がご紹介する案件は、取引先の会社の実態と支払条件を確かめたもので、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。週2〜3日の案件では、稼働しない日の連絡の扱いや、切替の時期の稼働の増え方が案件ごとに違うため、気になる点はご質問いただければ確認します。
:::

:::point
- PP/QMは工場の毎日の動きと直結し、週5日の案件が中心になりやすい
- 週2〜3日で見つかりやすいのは、保守の切り分け、作り込みの棚卸し、マスタ・検査計画の見直し、助言役、展開先の支援
- 担う範囲、稼働外の連絡、繁忙期の稼働の増え方を参画前に取り決める
- 会社員の副業では、勤め先の規程、本業の取引先との関係、稼働できる時間帯、税金の手続きを確かめる
:::

## よくある質問

### 週2〜3日の案件でも、PP/QMの経験として評価されますか？

評価されます。期間や稼働日数より、どの範囲を担い、何を設定や成果物に落としたかが見られます。スキルシートには稼働日数を書いたうえで、担った範囲と成果物を具体的に書いておくと、次の案件でも説明しやすくなります。

### 週3日で始めて、あとから週5日に増やすことはできますか？

案件によってはあります。保守や調査で信頼を得た後に、移行や展開の本体に関わるよう声がかかることもあります。増やす可能性があるなら、最初の面談でその希望を伝えておくと、発注側も体制を考えやすくなります。

### 平日の夜や週末だけでもPP/QMの案件は受けられますか？

多くはありません。工場の担当者や他モジュールの担当と平日の日中に話す場面が多いためです。調査の資料づくりや設計書のレビューなど、打ち合わせの少ない仕事に限られることが多いと考えておきましょう。週末の働き方は[週末だけのフリーランスの記事](/media/weekend-freelance/)で解説しています。
