小規模企業共済は、個人事業主や小さな会社の役員が毎月掛金を積み立て、**事業をやめたときや役員を退いたときに共済金を受け取る**、国の機関（独立行政法人中小企業基盤整備機構）が運営する共済です。いわば「経営者の退職金」を自分で用意する仕組みです。

掛金は**月1,000円から70,000円**まで500円単位で選べ、**払った掛金は全額が所得控除**になります。ただし、掛金を納めた期間が12か月未満で解約すると掛け捨て、20年未満で任意解約すると元本割れするため、長く続けられる額で始めることが大切です（2026年10月時点）。

## 制度の要点を一覧で見る

| 項目 | 内容 |
|---|---|
| 運営 | 独立行政法人中小企業基盤整備機構（中小機構） |
| 加入できる人 | 個人事業主、その共同経営者（2人まで）、小規模な会社等の役員など |
| 掛金 | 月1,000円〜70,000円（500円単位）。加入後に増額・減額できる |
| 掛金の税金 | 全額が小規模企業共済等掛金控除の対象 |
| 受け取るとき | 廃業・退任・老齢給付など。満期や満額の定めはない |
| 受け取り方 | 一括、分割、一括と分割の併用 |
| 受け取りの税金 | 一括は退職所得、分割は公的年金等の雑所得として扱う |
| 貸付 | 掛金の範囲内で事業資金を借りられる |

## フリーランスは加入できるか

中小機構の加入資格では、個人事業主は次の条件をすべて満たす必要があります。

- 税務署に開業の届出をし、事業所得として確定申告をしている
- 雇用契約で雇われて働いているのではない
- 給与のような固定の収入を受けていない（完全歩合制は可）
- 事務所を持つ、常に事業に従事しているなど、事業者として認められる

業務委託契約で案件を受けているフリーランスは、事業所得で確定申告をしていれば、個人事業主として加入できる場合があります。従業員を雇う場合は、業種ごとに常時使用する従業員の数に上限があり、サービス業（宿泊業・娯楽業を除く）などは5人以下です。

### 加入できない主な人

- 会社員として雇われながら副業をしている人
- 雇用契約で働いている人
- 主な仕事が小規模企業の経営でない人

会社員の副業として業務委託を受けている間は、加入できない点に注意が必要です。独立して開業届を出してからが加入の目安になります。開業届は[開業届の記事](/media/kaigyo-todoke/)で解説しています。

## 掛金は全額が所得控除になる

国税庁の案内では、小規模企業共済の掛金は**小規模企業共済等掛金控除**の対象で、控除できるのはその年に払った掛金の全額です。iDeCo（個人型確定拠出年金）の掛金も同じ控除の対象です。

所得控除が増えると、所得税と住民税の計算のもとになる課税所得が下がります。たとえば月30,000円を1年間納めると、年360,000円が所得から差し引かれます。どれだけ税金が下がるかは、その人の所得税率などで変わります。

確定申告では、確定申告書の「小規模企業共済等掛金控除」の欄に書き、中小機構から届く掛金の証明書を添付するか提示します。令和8年分以後の確定申告書を令和9年1月1日以後に出す場合は、証明書の代わりに一定の事項を書いた明細書を添付する方法もあります。

:::caution
所得控除は、払った年の税金を下げる効果です。将来受け取るときには、退職所得や雑所得として税金の計算に入ります。「払った分がそのまま得になる」わけではなく、税金がかかる時期と扱いが変わる仕組みだと考えておきましょう。具体的な税額の比較は税理士にご相談ください。
:::

## 受け取れる共済金の種類

共済金は、やめ方によって種類が分かれ、受け取れる額も変わります。個人事業主の場合の主な区分は次のとおりです。

| 種類 | 主な請求事由（個人事業主） |
|---|---|
| 共済金A | 個人事業の廃業（複数の事業ならすべてやめた場合）、契約者の死亡 |
| 共済金B | 老齢給付（65歳以上で、掛金を180か月以上納めた場合） |
| 準共済金 | 法人成りして個人事業主としての加入資格を失った場合など |
| 解約手当金 | 任意解約、掛金を12か月以上滞納したことによる機構解約など |

共済金AとBは、掛金を納めた月数が6か月未満だと受け取れません。準共済金と解約手当金は、12か月未満だと受け取れません。

### 元本割れする条件

任意で解約した場合の解約手当金は、次のように扱われます。

- **掛金を納めた月数が12か月未満**：解約手当金は受け取れず、掛け捨てになる
- **20年（240か月）未満**：解約手当金は、納めた掛金の合計を下回る
- 解約手当金は、納めた掛金の80%から120%相当で、100%以上になるのは240か月以上納めた場合

廃業などで共済金Aを受け取る場合とは扱いが違います。途中で掛金を払えなくなって解約すると、所得控除の効果があっても、受け取る額が払った額を下回ることがあります。掛金は増額・減額できるため、払うのが苦しくなったときは解約より先に減額を検討する方法もあります。

:::view
案件紹介の現場では、フリーランスの報酬は月ごとに入金されても、案件の切れ目で数か月入金が止まることがあります。小規模企業共済の掛金を高めに設定すると、そうした時期に負担が重くなりがちです。当社では、案件の契約期間と報酬の支払期日を個別契約に書いてお渡ししていますので、次の更新までの見通しを確かめたうえで掛金を決めると、途中で解約する事態を避けやすくなります。
:::

## 法人化したときの扱い

フリーランスが法人化（法人成り）すると、個人事業主としての立場はなくなります。このとき、小規模企業共済の扱いは次の2通りに分かれます。

- **共済金を受け取る**：法人成りで個人事業主としての加入資格を失った場合は、原則として準共済金の対象になる
- **契約を続ける（掛金納付月数の通算）**：請求事由が生じてから1年以内に、新しく作った会社の役員になるなどして加入資格を満たす場合、共済金を請求せずに新しく契約を結び、前の契約の掛金納付月数を通算できる

通算する場合は、会社の役員として加入資格を満たしていることが前提です。通算した後に資格がなかったと分かると通算は取り消され、所得控除を受けていた場合は修正申告が必要になることがあります。法人化を考えている人は、どちらを選ぶかを手続きの前に確かめておきましょう。法人化の考え方は[法人化のタイミングの記事](/media/incorporation-timing/)で解説しています。

## 掛金の範囲内で借りられる貸付制度

契約者は、納めた掛金の範囲内で事業資金を借りられます。中小機構の案内では、一般貸付けのほか、緊急経営安定貸付け、傷病災害時貸付け、創業転業時・新規事業展開等貸付け、廃業準備貸付けなどの種類があります。

案件が途切れて一時的に資金が足りないときなど、解約せずに資金を用意する方法として知っておくとよいでしょう。金利や借りられる額は、中小機構の案内でご確認ください。

## 掛金を決めるときの手順

掛金は加入後に増額・減額できますが、途中で解約すると不利になりやすい制度です。次の順で考えると、続けやすい額を決めやすくなります。

1. **毎月の固定の支出を出す**：生活費、国民健康保険料、国民年金保険料、住民税の月割りを足す
2. **案件が途切れた月を想定する**：入金がない月が数か月続いても、掛金を払える額かを確かめる
3. **iDeCoなどとの配分を決める**：老後の年金として使うiDeCoと、廃業・退任時に受け取る小規模企業共済で、目的に合わせて配分する
4. **所得控除の効果を確かめる**：確定申告の結果を見ながら、翌年に掛金を見直す

最初は少なめの額で始め、収入が安定してから増額する方法もあります。国民年金保険料や国民健康保険料の負担は、[国民年金の記事](/media/kokumin-nenkin/)と[国民健康保険の記事](/media/kokuho/)で確かめられます。

## ほかの制度との違い

| 制度 | 目的 | 掛金の控除 | 途中で引き出せるか |
|---|---|---|---|
| 小規模企業共済 | 廃業・退任時の退職金 | 小規模企業共済等掛金控除（全額） | 解約はできるが、20年未満は元本割れ |
| iDeCo | 老後の年金 | 小規模企業共済等掛金控除（全額） | 原則60歳まで引き出せない |
| 国民年金基金 | 国民年金への上乗せの年金 | 社会保険料控除（全額） | 年金として受け取る |

小規模企業共済とiDeCoは、それぞれの上限の範囲で併用できます。受け取るきっかけが「事業をやめたとき」か「年齢」かで性格が違うため、両方を組み合わせる人もいます。iDeCoは[iDeCoの記事](/media/ideco/)、国民年金基金は[国民年金基金の記事](/media/nenkin-kikin/)で解説しています。

:::view
独立して数年たった方から、「節税のために掛金を最大にしたほうがよいか」というご相談を受けることがあります。案件紹介の立場から見ると、報酬が高い時期が続くとは限らず、参画先のプロジェクトの終了で次の案件まで間が空くこともあります。所得控除の大きさだけで掛金を決めず、手元に数か月分の生活費と保険料・税金を残したうえで、続けられる額にしておくことをおすすめしています。個別の判断は税理士にご相談ください。
:::

:::point
- 個人事業主や小規模な会社の役員が、廃業・退任時に受け取る退職金を積み立てる制度
- 掛金は月1,000〜70,000円で、全額が所得控除になる
- 12か月未満の解約は掛け捨て、20年未満の任意解約は元本割れ
- 法人成りしても、1年以内に役員として加入資格を満たせば掛金納付月数を通算できる

## よくある質問

### 会社員のまま副業でフリーランスの仕事をしていても加入できますか？

中小機構の加入資格では、会社員として雇われながら副業をしている人は加入できないとされています。独立して開業届を出し、事業所得として確定申告をするようになってから、加入資格を確かめるとよいでしょう。

### 掛金が払えなくなったらどうすればよいですか？

掛金は加入後に減額できます。12か月以上滞納すると機構による解約となり、20年未満の解約では受け取れる額が払った掛金を下回るため、払うのが難しくなったら早めに減額を検討しましょう。手続きは中小機構の契約者向けの案内でご確認ください。

### 前納した掛金は、払った年の控除にできますか？

国税庁の案内では、控除できるのは「その年に支払った掛金の全額」とされています。前納した場合の扱いには細かな決まりがあるため、中小機構から届く証明書の内容を確かめ、判断に迷う場合は税務署や税理士にご相談ください。
