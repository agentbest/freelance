SAPの認定資格は、フリーランスの案件で**扱ったことの少ないモジュールや新しい製品に広げるときの裏付けにはなりますが、なくても参画できる案件が多い資格です**。SAPの案件では、どのモジュールを、どの工程で、どの規模の導入で担ったかが先に見られます。

もう一つ知っておきたいのは、SAPの認定は**取得から12か月ごとに維持の手続きが必要**な仕組みになっている点です。この記事では、認定が効く場面と効きにくい場面、2026年10月時点の試験の形式と維持の仕組み、実務との組み合わせ方を整理します。

## 実務が先に見られるSAPの案件

SAPの案件で発注側が知りたいのは、「導入のどの工程を、自分の手で進められるか」です。たとえば、FI/COで会社コードや支払プログラムを設定した、SD/MMで受注から出荷・請求までの流れを設計した、Basisでシステムのコピーやアップグレードを担当した、といった経験です。

こうした経験は、案件の規模、業種、ECCかS/4HANAか、といった条件と組み合わせて読まれます。認定を持っていても、実務で担った工程が案件と合わなければ参画にはつながりにくく、反対に、認定がなくても同じ工程の経験があれば参画できます。モジュールごとに求められる経験は、[SAP FI/COのスキルの記事](/media/sap-fico-skills/)や[S/4HANA移行のスキルの記事](/media/s4hana-skills/)で解説しています。

## 認定が効く場面と効きにくい場面

| 場面 | 認定の見られ方 |
|---|---|
| 経験の浅いモジュールに広げたい（例：FIの経験者がCOへ） | 体系的に学んでいることの裏付けになる |
| ECCの経験者がS/4HANAの案件に入りたい | 新しい仕組みを学んでいることを示す材料になる |
| 案件票の歓迎条件に認定の名前がある | 書類の段階で目に留まりやすい |
| 同じモジュールの導入を何度も経験している | 実務の実績が先に見られ、認定は補足になる |
| 保守・運用で特定の顧客の環境に長く関わってきた | 環境に慣れていることが重視され、認定の影響は小さい |

効きやすいのは、**実務の経験がまだ追いついていない領域に広げる場面**です。SAPは製品の更新が続いており、同じモジュールでもS/4HANAやクラウドの製品では仕組みが変わっています。新しい領域の知識を学んでいることを、認定で示せるのは強みです。

一方で、経験の長い領域では、認定がなくても実務の説明で十分に伝わります。認定は「経験の代わり」ではなく、「経験の広がりを裏付けるもの」として使うと考えると、優先順位をつけやすくなります。

## 2026年10月時点の試験の形式

SAP Learningの案内では、SAPの認定試験は2つの形式が並行して実施されています。

- **監督付きの選択式の試験**：従来からの形式で、一部の認定で引き続き使われている
- **実践型・オープンブックの試験**：2025年11月に導入された形式で、実際のSAPの環境での操作や、シナリオに沿った課題で評価する

2つの形式は2026年を通じて並行して実施されると案内されています。受験の枠は、SAP Learning Hubの購読に4回分の受験が含まれるほか、単独で購入する場合は2回分の受験が含まれる形が案内されています。

たとえば、FIの認定「SAP Certified - SAP S/4HANA Cloud Private Edition, Financial Accounting」（試験コード C_TS4FI）のページでは、2026年10月時点で、試験はシステムを使う評価1つ、試験時間3時間、合格の基準60%、言語は英語と表示されています。出題の範囲や配分は認定ごとに違い、見直されることもあるため、受験する認定のページで最新の内容を必ずご確認ください。

実践型の試験は、設定の画面を実際に操作する力が問われるため、**実務で設定に触れてきた人ほど準備の負担が軽くなる**形式です。反対に、設定に触れた経験が少ない領域で受験する場合は、検証環境で手を動かす時間を確保しておく必要があります。

## 12か月ごとの維持と、失効したとき

SAP Learningの案内では、認定の維持の仕組みは次のとおりです（2026年10月時点）。

1. **有効期間**：最初の試験から12か月の有効期間があり、少なくとも年に1回、知識が最新であることを示す必要がある
2. **維持の方法**：期限前の90日の更新期間に、Stay Certifiedの評価を受ける。AIを使ったロールプレイ形式の評価が推奨され、選択式の評価も選べる。評価は監督なしの短い形式で、何度でも受けられる
3. **必要なもの**：準備の教材と評価の受験には、SAP Learning Hubの購読が必要
4. **延長**：評価に合格すると、合格した日から12か月先まで期限が延びる
5. **期限を過ぎた場合**：状態が「Expired」になり、認定は有効でなくなる。その認定の最新のリリースの試験に合格して取り直すことが案内されている

認定の状態は、SAP Learningの「My Learning」の画面で、Valid（有効）、Stay certified due（期限が近い）、Expired（失効）のように確かめられます。

:::caution
SAPの認定は、取得した時期によって維持の扱いが違う場合があります。スキルシートに「有効」と書く前に、My Learningで状態と期限を確かめてください。維持にはSAP Learning Hubの購読が必要なため、フリーランスとして自分で費用を負担して続けるかどうかを、受験の前に考えておくことをおすすめします。
:::

## 実務経験との組み合わせ方

認定を評価につなげるには、**認定で学んだ領域を、実務の経験とどう重ねるか**を示すことが大切です。よくある組み合わせは次のとおりです。

- **FIの導入経験 × COの認定**：管理会計の領域へ広げたいことを示し、原価センタや収益性分析の設定を学んでいると伝える
- **ECCの経験 × S/4HANAの認定**：新しい会計や物流の仕組みを学び、移行の論点を説明できることを示す
- **業務側の経験 × モジュールの認定**：経理や購買の実務の経験がある人が、SAPの設定の知識を補う
- **Basisの経験 × クラウド関連の認定**：オンプレミスの運用の経験に、クラウドの製品の知識を加える

面談では、「認定の学習で何を理解したか」と「実務で何をしたか」を分けて話すと、任せられる範囲が伝わりやすくなります。会計の業務知識を補いたい場合は、[日商簿記の記事](/media/cert-boki/)も参考になります。

:::view
案件紹介の現場では、SAPの案件ほど「どのモジュールの、どの工程まで担えるか」を細かく確かめられる傾向があります。認定を持っていても、その領域の実務が経歴に出てこないと、面談では実務の深さの確認に時間がかかります。認定の領域と経験の領域が違う場合は、そのことを経歴の中で正直に分けて書いておくことをおすすめします。
:::

## スキルシートでの書き方

### 資格欄

資格欄には、認定の正式名称、試験コード、取得年月を書きます。維持が必要な認定は、現在の状態も確かめておきます。認定の名称は製品の名前の変更にあわせて変わることがあるため、取得時の正式名称で書き、必要に応じて対応するモジュールを括弧で添えると読みやすくなります。

- 書き方の例：SAP Certified - SAP S/4HANA Cloud Private Edition, Financial Accounting（C_TS4FI／FI）2026年◯月 取得

### 経歴欄

経歴欄では、モジュール、工程、担った設定や作業を具体的に書きます。認定の領域で実務の経験がある場合は、その案件の行に設定の内容を書くことで、資格と実務のつながりが伝わります。書き方の全体は[SAP FI/COのスキルシートの記事](/media/sap-fico-skillsheet/)が参考になります。

### 失効した認定

失効した認定は、有効な認定と並べて書かないようにします。学習した事実を伝えたい場合は、「過去に取得（現在は失効）」と分かる形で書きます。

## 取得の前に考えたいこと

SAPの認定は、受験の枠と維持の両方にSAP Learning Hubが関わるため、取得と維持を続けられるかを先に考えておくと判断しやすくなります。

1. **狙う領域**：今の経験を深めるのか、隣のモジュールや新しい製品に広げるのか
2. **試験の形式**：受ける認定が選択式か実践型か。実践型なら検証環境で手を動かす時間が要る
3. **維持の負担**：12か月ごとの評価を、稼働と並行して続けられるか
4. **言語**：受験する認定の試験がどの言語で提供されているか

学習の時間の作り方は[学習時間の作り方の記事](/media/benkyo-jikan/)をご覧ください。

:::view
新しいモジュールやS/4HANAの案件に広げたい場合は、どの領域の経験を積みたいかを、稼働日数・リモートの希望・ご希望の金額とあわせてお知らせいただくことをおすすめします。案件票の認定の条件が必須か歓迎か分かりにくいときは、ご質問いただければ確認します。
:::

## よくある質問

### SAPの認定がないと、SAPの案件には入れませんか？

入れる案件は多くあります。SAPの案件では、どのモジュールをどの工程で担ったかが先に見られます。ただし、案件票の条件に認定の名前がある場合や、経験の浅い領域に入りたい場合には、認定が判断の材料になることがあります。

### 維持をやめると、取得した事実もなくなりますか？

SAP Learningの案内では、期限までに評価を受けないと状態が「Expired」になり、認定は有効でなくなります。スキルシートに書く場合は、失効していることが分かる形で書き、有効な認定と区別してください。取り直す場合は、その認定の最新のリリースの試験に合格することが案内されています。

### 日本語で受験できますか？

認定ごとに提供される言語が違います。たとえばC_TS4FIのページでは、2026年10月時点で言語は英語と表示されています。受験を考えている認定のページで、言語と形式を確かめてください。
