広告・メディアの案件で求められる業務知識の中心は、**広告の取引の流れ、成果を測る指標、メディアの収益モデル**の3つです。この骨格を知っていると、仕様書に出てくる言葉や、営業・広告運用の担当者の説明が早く頭に入ります。

そのうえで、関わる領域の分だけ深さが必要になります。アドテクの案件なら入札と配信の仕組みまで、計測の案件ならタグと成果の数え方まで、というように、案件の範囲に合わせて深掘りしていくのが現実的です。この記事では、それぞれの押さえどころと身につけ方を整理します。業界知識を強みにする全体の考え方は[業界知識の記事](/media/gyoukai-chishiki/)で扱っているので、ここでは広告・メディアに固有の中身に絞ります。

## 広告の取引の流れ：誰が誰にお金を払うか

広告の取引は、広告を出したい広告主と、広告を載せる場所を持つメディア（媒体）の間で行われます。その間に、広告会社や運用の代行会社、広告の売買を自動で行う仕組みの事業者が入ります。

### 予約型と運用型

広告の売り方は、大きく2つに分けて考えると分かりやすくなります。

| 売り方 | 決め方 | 案件で関わる仕組みの例 |
|---|---|---|
| 予約型 | 掲載する場所・期間・量を、事前に決めて契約する | 広告枠の在庫管理、掲載の予約と入稿、掲載の実績報告 |
| 運用型 | 表示の機会ごとに、入札などで出す広告を決める | 入札の管理、配信先や対象者の設定、成果に応じた調整 |

予約型は、新聞や雑誌、Webメディアの特集面などで使われる売り方です。運用型は、検索結果やSNS、多くのWebサイトやアプリの広告枠で使われています。

### 運用型の中心にあるオークション

運用型の広告では、広告枠が表示されるたびに、どの広告を出すかを入札で決める仕組みが広く使われています。デジタルプラットフォームの透明化法の対象を定める政令でも、デジタル広告の事業区分の要件として、広告を表示する事業者を「主として競りにより決定する」ことが挙げられています。

アドテクの案件では、買う側の入札を行う仕組み、売る側で広告枠を出品して最も条件のよい入札を選ぶ仕組み、両者をつなぐ取引所のような仕組みが出てきます。業界ではそれぞれに略語の呼び名があり、仕様書でも略語のまま使われます。名前を覚えるより、**どの立場の事業者が、何を基準に入札し、誰が手数料を受け取るか**という流れで理解しておくと、略語が変わっても迷いにくくなります。

### お金と数字は別の経路で動く

広告の配信は秒単位で行われますが、お金の精算は月単位などでまとめて行われることが一般的です。配信の記録、各社の集計、請求の金額が、それぞれ別の仕組みで作られるため、数字がずれることがあります。どの数字を正とするか、ずれたときにどう突き合わせるかは、案件ごと・取引先ごとに決まっています。参画したら最初に確かめておきたい点です。

## 成果を測る指標：何を数え、何で割るか

広告の案件では、指標の名前が説明なしに使われることが多くあります。代表的なものを、何を数えて何で割るか、という形で押さえておきます。

| 指標 | 意味 | 押さえたい点 |
|---|---|---|
| インプレッション | 広告が表示された回数 | 「表示」をどの時点で数えるかの定義が仕組みによって違う |
| クリック率（CTR） | 表示のうちクリックされた割合 | 分母が表示回数であること |
| CPM | 表示1,000回あたりの費用 | 予約型・運用型のどちらでも使われる |
| CPC | クリック1回あたりの費用 | 成果ではなくクリックに対する費用 |
| コンバージョン（CV） | 購入や申込みなど、広告主が決めた成果 | 何を成果とするかは広告主ごとに違う |
| CPA | 成果1件あたりの費用 | 成果の数え方が変わると数字が大きく変わる |
| ROAS | 広告費に対する売上の割合 | 売上をどの範囲で広告の成果とみなすかで変わる |

指標の計算そのものは単純ですが、案件で問題になるのは**数え方の定義**です。同じ「成果」でも、広告をクリックしてから何日以内の購入までを数えるのか、複数の広告に触れた場合にどの広告の成果とするのか、といった決まりによって数字が変わります。仕様を読むときは、計算式よりも、分子と分母が何を指すかを先に確かめると、テストの観点を漏らしにくくなります。

### 計測の仕組みとプライバシー

成果の計測には、サイトやアプリに入れたタグやSDK、Cookieなどの識別子が使われてきました。総務省の外部送信規律のFAQは、規律の対象となる情報の送信について、タグやSDKのような情報収集モジュール、Cookieに保存されたIDを通じたものを例に挙げ、Cookieを使わない送信も対象になりうると説明しています。計測の案件では、技術の仕組みと、利用者の情報の扱いのルールをセットで理解しておく必要があります。ルールの中身は[規制の記事](/media/ind-koukoku-kisei/)で扱います。

:::view
広告・メディアの案件をご紹介していると、面談で評価されやすいのは、指標の名前を知っていることより、「この指標の数え方が変わったときに、どこを直す必要があるか」を説明できる方です。反対に、指標をレポートの見出しとしてしか扱ってこなかった方は、計測の案件で立ち上がりに時間がかかりやすい傾向があります。関わった指標の定義を、自分の言葉で説明できるようにしておくことをおすすめします。
:::

## メディアの収益モデル：広告だけではない

メディアの側の案件では、そのメディアがどうやって収益を得ているかを知っておくと、仕様の優先順位が読みやすくなります。主な収益の柱は次のとおりです。

| 収益の柱 | 中身 | 関わるシステムの例 |
|---|---|---|
| 広告収入 | 広告枠を販売する | 広告サーバー、広告枠の管理、記事内の広告の出し分け |
| 購読・有料会員 | 記事や動画の閲覧に料金を受け取る | 会員登録、課金、閲覧制限、解約の手続き |
| コンテンツの外部提供 | 記事や映像を他社のサービスに提供する | 配信用のデータ連携、利用の記録 |
| 物販・イベント | 関連商品の販売や催し | EC、チケット販売、申込みの管理 |

どの柱を重視しているかで、システムの判断も変わります。広告収入が中心のメディアでは、表示速度と広告の見え方の両立が課題になり、有料会員が中心のメディアでは、登録までの導線や解約の扱いが重視されます。編集部と営業部門の意見が分かれる場面もあり、背景にある収益の考え方を知っていると、要件の整理がしやすくなります。

## 案件ごとに必要な知識の深さ

すべてを深く知っている必要はありません。案件の領域ごとに、優先して身につけたい知識の目安を示します。

| 案件の領域 | 優先して身につけたい知識 |
|---|---|
| アドテクの開発 | 入札の流れ、広告枠と在庫の考え方、手数料の発生する場所 |
| 配信・計測 | 指標の定義、タグと識別子の仕組み、成果の数え方の決まり |
| CMS・Webメディア | 編集の作業の流れ、記事と広告の配置、収益モデル |
| 動画配信 | 配信と再生の仕組み、動画の中の広告の差し込み、同時視聴の負荷 |
| データ基盤 | 配信記録と精算の数字の関係、集計の締めのタイミング |

## 身につけ方：参画前と参画中

### 参画前にやること

1. **取引の流れを図に描く**：広告主からメディアまで、お金と広告がどう流れるかを自分で描いてみる。立場ごとの役割が整理できる
2. **指標の定義を書き出す**：上の表の指標を、分子と分母の言葉で説明できるようにする
3. **公的な資料で枠組みを知る**：デジタル広告の取引の透明性に関する法律や、外部送信規律の解説は、業界の構造やデータの流れを知る入口にもなる

業務知識と資格の関係は[資格の記事](/media/shikaku/)で扱っています。広告の領域では、資格よりも、関わった仕組みと指標を説明できるかが問われる場面が多くあります。

### 参画中にやること

- 用語集がなければ、自分用に作る。略語は会社ごとに意味がずれることがあるため、現場での意味を書いておく
- 営業や広告運用の担当者が見ているレポートを一度見せてもらい、どの数字で判断しているかを知る
- 数字のずれの問い合わせに一度対応してみると、配信から精算までの流れが一気につながる

要件の整理の進め方は[上流工程の記事](/media/upper-process/)が参考になります。マーケティング寄りの知識は[マーケティングコンサルタントのスキルの記事](/media/marketing-consultant-skills/)でも扱っています。

:::view
当社では、案件をご案内するときに、先に稼働日数・リモートの希望・ご希望の金額を伺い、条件に合う案件だけをお出ししています。広告・メディアの案件は、同じ技術でも買う側か売る側かで求められる業務知識が違います。ご自身がどちらの立場の知識を持っているかを整理してお伝えいただくことをおすすめします。案件ごとに必要な知識の範囲は、ご質問いただければ確認します。
:::

:::point
- 業務知識の骨格は、取引の流れ、指標、メディアの収益モデルの3つ
- 運用型広告の中心にはオークションがあり、立場ごとの役割で理解すると略語に振り回されにくい
- 指標は計算式より、分子と分母が何を指すか、成果の数え方の決まりを先に確かめる
- 知識の深さは案件の領域に合わせ、参画中は用語集とレポートで現場の意味を押さえる
:::

## よくある質問

### 広告の略語が多くて覚えきれません。どうすればよいですか？

略語を一覧で覚えるより、取引の流れの図の中に置いて覚えるほうが定着しやすくなります。買う側・売る側・つなぐ側のどこにある仕組みか、何を数える指標かを書き添えた用語集を、参画中に自分で作っていくのが現実的です。

### エンジニアでも広告運用の知識は必要ですか？

案件によります。配信・計測やアドテクの案件では、広告運用の担当者が何を見て判断しているかを知っていると、要件の意図をくみ取りやすくなります。CMSや動画配信の案件では、運用の細かい知識より、収益モデルと編集の流れの理解が役に立つことが多くあります。

### メディアの業務知識はどこで学べますか？

まずは参画先の編集・営業の担当者の説明と、社内の資料が一番の情報源です。業界の構造については、デジタル広告の取引に関する法律や総務省の外部送信規律の解説など、公的な資料も入口になります。業界知識の広げ方は[業界知識の記事](/media/gyoukai-chishiki/)をご覧ください。
