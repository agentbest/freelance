ネットワークエンジニアのフリーランス案件の報酬は、**設計・構築・運用のどの工程を担うか、現地作業や夜間の切り替え作業があるか、その時間をどう扱うか、止めることが許されない網かどうか、扱う機器の分野、クラウド接続や自動化の経験**で決まります。ネットワークエンジニアの単価について公的な統計はなく、案件ごとに大きく変わります。

ネットワークの案件は、作業の時間帯と場所が報酬の中身を大きく左右するのが特徴です。同じ月額でも、夜間作業や移動の扱いによって、1時間あたりの報酬は大きく変わります。単価を上げるには、設計書や切り替え計画を自分で書く側に回ることと、夜間・現地の作業の条件を契約で明確にすることの両方が大切です。

## 工程で変わる報酬の考え方

| 工程 | 主な仕事 | 報酬への影響 |
|---|---|---|
| 要件定義・設計 | 構成の決定、冗長化の方式、IPアドレスや経路の設計 | 構成を決める責任があり、高めに出やすい |
| 構築・切り替え | 設定の作成と投入、試験、旧環境からの切り替え | 切り替えの計画を立てられるかで差がつく |
| 運用・保守 | 設定変更、機器の交換、障害の切り分け | 手順化されている範囲が広いほど候補者が多い |
| 監視 | アラートの一次対応、定型の報告 | 交代勤務を含むことがあり、時間帯の条件が重い |

運用や監視から構築、設計へと進むほど、任される判断が増え、報酬の説明材料も増えます。各工程で求められるスキルは[ネットワークエンジニアの案件で求められるスキル](/media/network-skills/)にまとめています。

## 報酬を左右する主な要素

### 1. 止められない網かどうか

金融機関、通信事業者、工場、病院など、止まると業務や社会への影響が大きい網の案件では、作業の手順や承認が厳しく、経験のある人が求められます。責任の重さが報酬に表れやすい一方、作業の準備や報告に多くの時間がかかることも理解しておきましょう。

### 2. 現地作業の有無と範囲

データセンターや拠点での機器の設置、配線の確認、切り替えの立ち会いは、現地に行かなければできません。拠点が多い案件では、移動の時間と交通費が負担になります。交通費が報酬に含まれるのか、別に精算されるのかで手取りが変わるため、考え方は[交通費の記事](/media/transportation-fee/)で確かめておきましょう。

### 3. 夜間・休日の作業の扱い

業務への影響を避けるため、切り替えや機器の交換は夜間や休日に行うことがよくあります。その頻度と、時間の数え方が報酬の実質を決めます。この扱いは次の章で詳しく説明します。

### 4. 機器とセキュリティの分野

ルーターやスイッチ、ファイアウォール、無線、ロードバランサーなど、扱う分野によって応募できる人の数が変わります。特定のメーカーの機器に深い経験があると、その機器を使う現場で重宝されますが、案件の幅は狭まることがあります。

### 5. クラウド接続と自動化

オンプレミスとクラウドを専用線やVPNでつなぐ設計、Ansibleなどを使った設定の自動化は、従来のネットワークの経験に足すことで、参画できる案件を広げる要素です。

:::view
ネットワークの案件をご紹介していると、面談で評価されやすいのは、扱った機器の名前を並べる方より、「切り替えのときに何を確かめ、問題が出たらどの時点で元に戻すと決めていたか」を話せる方です。戻す判断の基準まで説明できると、本番の作業を任せられる人として受け止められやすくなります。一方で、夜間作業の頻度や現地作業の範囲を面談で確かめずに参画し、あとから負担の大きさに気づく例も見られます。
:::

## 夜間作業の報酬は契約で決まる

会社員であれば、午後10時から午前5時までの深夜に働いた時間には、通常の賃金の2割5分以上の割増賃金を払うことが労働基準法第37条で定められています。ただし、この決まりは、使用者に使用されて賃金を受け取る「労働者」についてのものです（同法第9条）。業務委託で働くフリーランスには当然には当てはまらないため、**夜間作業をどう報酬に反映するかは、契約で決めておく必要があります**。

夜間作業の扱いには、次のような決め方があります。

| 決め方 | 内容 | 確かめておきたいこと |
|---|---|---|
| 月額に含める | 夜間作業があっても月額は変わらない | 想定される回数と、超えたときの扱い |
| 稼働時間に入れて精算する | 夜間の作業時間も精算幅の計算に含める | 精算幅の上限を超えやすくならないか |
| 日中の稼働と振り替える | 夜間に働いた分、日中の稼働を減らす | 振り替えの申請方法と期限 |
| 作業ごとに別に決める | 夜間作業1回ごとの報酬を別に取り決める | 中止や延期になったときの扱い |

どれが正しいということはなく、案件の性質に合っているかが大切です。たとえば仮の数字で考えると、精算幅の上限が180時間の案件で、日中に170時間働き、夜間作業が月に3回・各4時間あった場合、夜間の時間を稼働に含めるなら合計は182時間になり、上限を超えます。超えた分が精算されるのか、月額に吸収されるのかで、実質の報酬は変わります。精算の計算方法は[精算幅の記事](/media/seisan-haba/)で解説しています。

なお、業務委託であっても、発注元から作業の進め方や時間を細かく指示され、勤務の管理を受けている場合は、契約の形と働き方が合っていない可能性があります。気になる場合は[偽装請負の記事](/media/gisou-ukeoi/)で確かめ、個別の判断は専門家にご相談ください。

:::caution
夜間の切り替え作業のあと、翌日も通常どおり日中に稼働する前提になっている案件があります。休む時間が取れないまま作業が続くと、ミスの原因にもなります。夜間作業の翌日の稼働の扱いや、作業が延びた場合の連絡の方法を、参画前に確かめておきましょう。
:::

## 提示額を比べるときにそろえる項目

ネットワークの案件は、月額が近くても、時間帯と場所の条件で中身が大きく違います。複数の案件を比べるときは、次の項目を並べて見ると差が分かりやすくなります。

1. 月額と精算幅（上限・下限の時間）
2. 夜間・休日作業の想定回数と、その時間の扱い
3. 夜間作業の翌日の稼働の扱い
4. 現地作業の頻度と、移動時間を稼働に含めるか
5. 交通費・宿泊費を報酬に含むか、別に精算するか
6. 出社の頻度と、リモートでできる作業の範囲
7. 支払期日と契約期間

月額だけを見て選ぶと、夜間や移動の負担が大きい案件を、条件のよい案件と取り違えることがあります。全体の考え方は[フリーランスの単価の決まり方](/media/rate-mechanism/)でまとめています。

## 報酬が上がりにくいパターン

- **監視と一次対応だけが続いている**：判断は別の人が行い、手順どおりの対応が中心
- **他の人が書いた手順で設定を投入しているだけ**：設計や計画に関わった経験が残らない
- **一つのメーカー・一つの分野に限られている**：選べる案件が少なくなる
- **夜間・現地作業の条件をあいまいにしている**：月額が同じでも、実質の報酬が下がっている

## 単価を上げるための考え方

### 設計書と切り替え計画を自分で書く

構築の経験がある人は、次の案件で設計書や切り替えの計画書を書く役割を引き受けると、説明できる経験が大きく変わります。作業者から計画を立てる側へ回ることが、報酬を上げる一番の近道です。

### 運用の中で改善を提案する

運用や監視が中心の人は、繰り返し起きる障害の原因を調べて対策を提案したり、手作業の確認を自動化したりすると、構築や設計の案件に進む材料になります。

### クラウドとの接続を経験に足す

オンプレミスのネットワークの経験に、クラウドとの接続の設計を足すと、移行やハイブリッド構成の案件にも応募しやすくなります。

### 条件の見直しを更新の前に相談する

担当が設計に広がったときや、夜間作業の回数が想定より増えているときは、条件の見直しを相談する材料になります。夜間作業の実績は、日付と時間を記録しておくと説明しやすくなります。伝え方は[単価交渉の記事](/media/rate-negotiation/)にまとめています。

:::view
夜間作業や現地作業を含む案件では、作業の時間帯と場所を、報酬と同じ重さで条件として決めておくことをおすすめします。当社がご案内する案件では、業務の範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。フリーランス法でも、発注側は業務の内容・報酬の額・支払期日などを書面やメールで明示することが求められています。参画後に夜間作業の回数が大きく変わりそうなときは、早めにご相談ください。
:::

:::point
- ネットワークの報酬は、工程・止められない網かどうか・現地作業・夜間作業の扱い・機器の分野・クラウドや自動化の経験で決まり、案件ごとに大きく変わる
- 業務委託では、深夜の割増賃金の決まりが当然には当てはまらないため、夜間作業の扱いは契約で決める
- 単価を上げるには、設計書と切り替え計画を自分で書く側に回る
:::

## よくある質問

### ネットワークエンジニアの単価の相場はいくらですか？

ネットワークエンジニアの単価について公的な統計はなく、担当工程、扱う網の重要度、夜間・現地作業の有無、機器の分野、稼働日数、商流によって大きく変わります。相場の数字より、夜間作業や移動の扱いまで含めて条件をそろえ、1時間あたりの実質で比べるほうが判断の材料になります。

### 夜間作業をすると報酬は割増になりますか？

業務委託では、会社員のような深夜の割増賃金の決まりが当然には当てはまらないため、割増になるかどうかは契約しだいです。月額に含めるのか、稼働時間に入れて精算するのか、別に報酬を決めるのかを、参画の前に確かめておきましょう。

### 夜間作業や現地作業がない案件だけを選べますか？

設計や、クラウドとの接続、リモートで進められる運用の案件など、夜間や現地の作業が少ない案件もあります。ただ、構築や切り替えの工程では避けにくいため、選べる案件の幅は狭くなります。働き方の考え方は[ネットワークエンジニアがフリーランスになるには](/media/network-how-to/)をご覧ください。
