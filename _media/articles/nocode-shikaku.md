ノーコード・ローコード開発者に、**資格は必須ではありません**。案件の多くは、どんな業務をどのツールでアプリにし、どの工程まで担い、そのアプリが今も使われているかで参画が決まります。

一方で、資格が効く場面はあります。まだ実務の浅いツールに広げたいとき、書類で候補者が並んだとき、コードによる拡張や運用環境の管理など、経験の幅を短く伝えたいときです。この記事では、ツールの提供元による認定を中心に、評価されやすい資格と効きにくい資格を分け、実務とどう組み合わせると効くかを整理します。資格全般の考え方は[資格はフリーランスの案件獲得に役立つ？](/media/shikaku/)で解説しています。Power Platform と RPA の資格は、[Power Platform の資格の記事](/media/power-platform-shikaku/)と[RPA の資格の記事](/media/rpa-shikaku/)をご覧ください。

## 資格がなくても案件に入れる理由

ノーコード・ローコードの仕事は、業務を聞き取り、アプリとデータの形に落とし込み、使われる状態まで運ぶことです。発注側が気にしているのは、作ったものが現場で使われ続けるか、契約が終わったあと社内で直せる状態になるかです。この点は、試験の点数より、これまでの取り組みのその後を聞けば分かると考える面談官が多くいます。

そのため、案件票の必須条件に資格の名前が入ることは多くありません。入っていても「歓迎」の扱いであることがほとんどです。資格がないことを理由に応募をあきらめる必要はなく、まずは[スキルシート](/media/nocode-skillsheet/)で担った工程と判断を伝わる形にすることが先です。

## 資格が効く4つの場面

| 場面 | 資格が効く理由 |
|---|---|
| 実務の浅いツールや工程に広げるとき | 体系的に学んだことの裏付けになり、書類で門前払いされにくくなる |
| 書類で候補者が並んだとき | 同じような経歴の中で、知識の範囲を短く示せる |
| 拡張や運用環境の管理を含む案件 | コードによる拡張、サーバーやクラウドでの管理など、操作以外の知識を示せる |
| 提供元の認定を重視する発注側 | 社内の作り手の育成や、パートナー企業の体制の説明に使われる |

どの場面でも、資格は「任せられそうだ」という判断の後押しにはなりますが、それだけで決まることはありません。資格が効くのは、**実務の経験と並べたときに、経験の説明を補う役割を果たす場合**です。

:::view
ノーコード・ローコードの案件をご紹介していると、提供元の認定を持っている方でも、面談で評価が分かれるのは資格の有無より、作ったアプリのその後を話せるかどうかです。一方で、業務アプリ型の経験がある方がデータベース型やWebアプリ型に広げるときなど、実務の浅い分野では、認定が「基礎を体系的に押さえている」ことの裏付けになり、書類の段階で目に留まりやすくなる傾向があります。
:::

## 評価されやすい資格：ツールの提供元による認定

ノーコード・ローコードの分野では、汎用の資格より、扱うツールの提供元による認定のほうが案件と結びつきやすい傾向があります。以下はいずれも2026年10月時点の公式ページの内容です。受験料や試験の内容は改定されることがあるため、受験前に公式サイトで最新の情報をご確認ください。

### kintone認定資格（サイボウズ）

専門分野とスキルのレベルによって3段階5種類に分かれ、アソシエイトから順に上位の資格を取得していく仕組みです。テストセンターでの受験と、オンラインでの受験が案内されています。

| 資格 | 証明する内容（公式の説明の要約） | 受験の前提 | 受験料（税込・一般） |
|---|---|---|---|
| アソシエイト | kintone の機能と設定、アプリやスペースの作成などの基本の知識 | なし | 16,500円 |
| アプリデザインスペシャリスト | アプリの設計・構築・展開による業務改善のスキル | アソシエイトに合格 | 22,000円 |
| カスタマイズスペシャリスト | kintone API などの基本の知識と、プログラミングを用いた開発のスキル | アソシエイトに合格 | 22,000円 |
| カイゼンマネジメントエキスパート | チームの継続的な業務改善を推進するスキル（小論文と実績登録で判定） | アプリデザインスペシャリストに合格 | 公式ページでご確認ください |
| システムデザインエキスパート | kintone を使った業務改善プロジェクトを推進するスキル（小論文と実績登録で判定） | カスタマイズスペシャリストに合格 | 1次試験 33,000円 |

アソシエイトは60分・50問の多肢選択式です。カスタマイズスペシャリストは2026年10月5日に試験問題が改定され、アソシエイトは2027年1月上旬ごろの改定が予定されています。

案件との結びつきで言えば、アプリデザインスペシャリストは業務の整理と設計、カスタマイズスペシャリストは JavaScript や API による拡張の裏付けになります。エキスパートの2つは、小論文と実績の登録で判定されるため、**実務の経験そのものを第三者の基準で整理した証拠**として話しやすい資格です。

### Claris FileMaker 技術者試験（Claris）

データベース型の Claris FileMaker の技術者試験は、2026年版として4つの区分があります。

| 区分 | 公式の説明の要約 | 受験料（税込） |
|---|---|---|
| Basic Developer | 構成と基礎を理解し、業務の課題を解決するカスタム App を作れる | 6,600円 |
| Advanced Developer | 共有利用を前提に、データを守りながら業務を効率化するカスタム App を作れる | 12,100円 |
| Expert Developer | 利用場面や課題に応じた多様なカスタム App を開発できる | 17,600円 |
| System Admin | FileMaker Server や FileMaker Cloud を導入し、App を管理できる | 12,100円 |

Basic Developer と Expert Developer は2026年10月1日に配信が始まり、Advanced Developer は2026年12月、System Admin は2027年2月に配信予定とされています。2024年版の試験は2027年2月末に終了する予定です。公式の案内では試験の合格は失効しないとされていますが、新しい試験が出ると古い版の合格になるため、スキルシートには版も書いておくと親切です。

System Admin は、社内のサーバーやクラウドでの運用を任される案件で、構築以外の経験を示す材料になります。

### Bubble Developer Certification（Bubble）

Webアプリ型の Bubble には、提供元による開発者向けの認定があります。公式ページでは「初心者向けの試験ではない」と明記され、オンラインで監視付き、90問、正答率80%以上で合格とされています。資料を参照してよい形式で、受験料は個人で45米ドル（2回まで受験可）、2025年4月1日以降に取得した認定の有効期間は発行から2年で、期間が過ぎると再認定が必要です。

社外向けのサービスを一通り作る案件では、画面からデータ、権限、外部連携まで幅広い知識を問われる認定として、経験の幅を示す材料になります。

## 効きにくい資格と、補助として効く資格

次のような資格は、持っていて損はないものの、ノーコード・ローコードの案件の評価にはつながりにくい傾向があります。

- **案件で使わないツールの認定**：別のツールの認定は、学ぶ姿勢は伝わるものの、その案件の判断の材料にはなりにくい
- **有効期限の切れた認定**：更新が必要な認定は、期限が切れていると、かえって確認の手間を増やす
- **操作の知識だけを問う民間の検定**：提供元の認定より知名度が低いと、読み手が中身を判断しにくい

一方、ITの基礎を示す国家試験は補助として効く場面があります。業務部門からこの分野に移った方が、[ITパスポート](/media/cert-itpassport/)や[基本情報技術者](/media/cert-ipa-fe/)でITの基礎の裏付けを添える形です。IPAの情報処理技術者試験は、現行の制度が2026年度の実施で終わり、2027年度から新しい制度に移る予定です（2026年10月時点、IPAの案内による）。詳細は各試験の記事をご覧ください。業務改革の構想から関わる案件では、[中小企業診断士](/media/cert-shindanshi/)のような経営や業務の知識を示す資格が話の材料になることもあります。

:::caution
受験料や試験の内容、受験の前提条件は、改定で変わることがあります。この記事の金額は2026年10月時点の公式ページの記載で、受験の時点では変わっている可能性があります。また、受験のための費用を案件の発注側が負担するかどうかは案件ごとに違うため、勝手に経費や請求の前提にせず、受ける前に確かめましょう。
:::

## 実務経験との組み合わせ方

資格は、実務のどこを補うかを決めてから選ぶと効果が出ます。今の経験と、広げたい方向で考えると整理しやすくなります。

| 今の経験 | 広げたい方向 | 組み合わせやすい資格 |
|---|---|---|
| 構築を中心に担ってきた | 業務の聞き取りと設計 | アプリデザインスペシャリスト |
| 標準の機能で組んできた | コードによる拡張・連携 | カスタマイズスペシャリスト |
| 設計から定着まで担ってきた | 全体の推進・社内展開 | システムデザインエキスパート、カイゼンマネジメントエキスパート |
| FileMaker の App を作ってきた | 運用環境の管理 | System Admin |
| 業務アプリ型が中心 | 社外向けのWebサービス | Bubble Developer Certification |

組み合わせのポイントは、資格と**同じ方向の実務の場面**を1つでも持っておくことです。カスタマイズスペシャリストを取ったなら、小さくても実際の業務で拡張した場面を話せるようにします。アプリデザインスペシャリストを取ったなら、学んだ考え方で聞き取りや設計を変えた経験をつくっておきます。

## スキルシートと面談での伝え方

1. **資格欄**：正式な名称と取得年月。版や有効期限がある資格は、それも書く
2. **経歴欄**：資格で学んだ考え方を使った場面があれば、判断の中身として書く
3. **面談**：資格について聞かれたら、取った理由と、実務で生かした場面を1つ話す

学習中の資格は、受験予定の時期とあわせて書いておくと、学ぶ姿勢が伝わります。取得していない資格を取得済みのように読める書き方は避けてください。

## よくある質問

### kintone認定資格は、どれから取るのがよいですか？

上位の資格はアソシエイトの合格が前提になっているため、まずアソシエイトからになります。その先は、業務の整理と設計に広げたいならアプリデザインスペシャリスト、コードによる拡張に広げたいならカスタマイズスペシャリストと、狙う案件の方向で選ぶのが現実的です。

### 資格を取れば、実務経験がなくても案件に入れますか？

資格だけで実務の経験を補うのは難しいのが実情です。業務委託の案件では、実際の業務をアプリにした経験が問われることが多くあります。社内の業務や小さな案件で、聞き取りから利用の開始までを一通り経験し、その結果を資格と並べて話せるようにしておくことをおすすめします。

### 複数のツールの認定を取ったほうが有利ですか？

数を増やすより、軸にするツールで設計や拡張など一段上の認定を取るほうが、案件と結びつきやすい傾向があります。別の種類のツールに広げるときは、そのツールの基礎の認定を取り、実務の場面を一つ添えると伝わりやすくなります。
