契約で決めた業務の範囲を超える作業は、原則として当初の報酬に含まれていません。範囲の外の作業を引き受けるなら、**作業内容・報酬・期限を決め直し、書面やメールで合意してから**始めるのが基本です。

フリーランス新法では、従業員を使う発注者が1か月以上の業務委託をする場合、フリーランスに責任がないのに給付の内容を変更させ、その費用を負担しないことは「不当な給付内容の変更」として禁止されています。範囲が広がったときの判断の基準と、変更を合意する手順を順に説明します（2026年10月時点）。

## 「範囲が広がった」かどうかは契約の書き方で決まる

追加の作業かどうかを判断する基準は、契約書や個別契約に書かれた業務の範囲です。契約の型によって、範囲の決まり方が違います。

### 準委任：業務の内容と稼働時間で決まる

月額で稼働する準委任の案件では、「◯◯システムの詳細設計・実装」「PMO業務（進捗管理・課題管理）」のように、業務の内容と稼働時間で範囲が決まります。精算幅のある契約なら、同じ役割の中で作業が増えても、まずは稼働時間の精算で調整される形です。精算の仕組みは[精算幅の記事](/media/seisan-haba/)をご覧ください。

一方、役割そのものが変わる依頼は、時間の精算だけでは片づきません。たとえば、PMOとして参画したのにテストの実施を任される、設計担当なのに運用の夜間対応を求められる、といった場合です。

### 請負：仕様で決まる

請負では、完成させる成果物の仕様が範囲です。仕様にない機能や画面の追加は、変更にあたります。民法では、請負人が仕事を完成しない間は、注文者はいつでも損害を賠償して契約を解除できるとされています（第641条）が、仕様の追加について報酬をどうするかは、民法ではなく当事者の合意で決まります。

## よくある「広がり方」

参画後に範囲が広がるのは、大きな依頼よりも、小さな依頼の積み重ねのことが多くあります。

- 「ついでにこれも見ておいて」という担当外の確認や資料作り
- 他のメンバーの欠員を埋めるための、別の工程の作業
- 定例会議や報告資料の追加で、稼働時間が上限に近づく
- 成果物の種類や数が増える（設計書の追加、別環境への展開など）
- 夜間・休日の障害対応への参加
- 検収の場で出てくる、仕様にない要望（[検収の記事](/media/kenshu/)）

どれも一つずつは小さくても、続くと稼働時間や責任の範囲が当初の契約から離れていきます。

## フリーランス新法で押さえておきたいルール

### 給付の内容は明示されている

フリーランス新法第3条により、発注者は業務委託をしたら直ちに、給付の内容（業務の内容）を書面やメールなどで明示しなければなりません。まず、手元にある明示の内容が、範囲を判断する出発点になります。

公正取引委員会のQ&Aでは、取引の途中で委託内容がより詳しく決まった場合でも、当初の明示で委託内容が十分に明らかであれば、改めて明示し直すことは必ずしも必要ないとしています。ただし、後で決まった内容もフリーランスに伝え、委託内容を明確にするよう努めることが望ましいとしています。取引条件の明示全体は[取引条件の明示の記事](/media/freelance-act-terms/)にまとめています。

### 費用を負担しない給付内容の変更は禁止

従業員を使う発注者（特定業務委託事業者）が1か月以上の業務委託をする場合、フリーランスの責めに帰すべき事由がないのに、給付の内容を変更させたり、受領後にやり直しをさせたりして、フリーランスの利益を不当に害することは禁止されています（第5条第2項第2号）。

公正取引委員会・厚生労働省の「考え方」では、次のように整理されています。

- 「給付の内容を変更させる」とは、受領前に、明示した給付の内容と異なる作業を行わせること。業務委託の取消しも含まれる
- 変更によって、それまでの作業が無駄になったり、当初の委託内容にない追加の作業が必要になったりしたのに、発注者が**その費用や損失を負担しない**ことが、利益を不当に害することにあたる
- 発注者が費用を負担するなど、利益を不当に害しないと認められる場合は問題にならない

さらに、考え方は、費用を全額負担しないまま変更ややり直しを求めることが認められない場合として、次のような例を挙げています。

1. フリーランスが内容を明確にするよう求めたのに、発注者が正当な理由なく明確にせず作業を続けさせ、後から委託内容と合わないとする場合
2. フリーランスの提案を発注者が了承し、その内容で作業したのに、後から委託内容と合わないとする場合
3. 業務委託後に検査基準を恣意的に厳しくする場合
4. 相当の期間、予定を確保させておきながら、実施の直前に業務委託を取り消し、別の仕事を受けられなくさせた場合

禁止行為の全体は[7つの禁止行為の記事](/media/freelance-act-kinshi/)をご覧ください。

### 変更を理由に報酬を下げることにも注意

Q&Aでは、すでに行っている業務委託について、算定方法を変えて報酬を引き下げて支払うことは「報酬の減額」として問題になるとしています。範囲の変更の話し合いの中で、追加の報酬ではなく単価の引き下げを提案された場合は、どの業務委託についての話なのかを確かめましょう。

:::view
案件紹介の現場では、参画後に「最初に聞いていた範囲より広がった」という声が出るのは、業務範囲が「◯◯に関する業務一式」のように大づかみに書かれた契約で多い傾向があります。当社がご案内する案件では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。範囲の外と思われる依頼を受けたときは、作業を始める前に早めにご相談ください。
:::

## 変更を合意するときの手順

情報処理推進機構（IPA）の「情報システム・モデル取引・契約書（第二版）」では、契約内容の変更は、事前に協議したうえで書面で変更契約を結ぶことによってのみ行えるとしています。仕様書の変更については、変更の内容と理由を書いた「変更提案書」を出し、受け取った側が次のような事項を書いた「変更管理書」を交付して、変更の可否を協議する手順が示されています。

- 変更の名称、提案の責任者、年月日
- 変更の理由
- 変更の詳細（仕様を含む）
- 費用がかかる場合はその額
- 検討期間を含めた変更作業のスケジュール
- 作業期間・納期・委託料など、契約の条件への影響

フリーランスの規模の取引でも、この項目はそのままメールの骨組みに使えます。進め方は次のとおりです。

1. **依頼を文字で受け取る**：口頭やチャットの雑談で頼まれたら、内容をメールやチャットで書いて確認する
2. **範囲の内か外かを判断する**：契約書・個別契約・明示された業務の内容と照らす
3. **影響を見積もる**：必要な時間、今の作業の遅れ、追加の報酬、期限の延長
4. **条件を提示して合意する**：「この作業は契約の範囲外のため、◯時間程度、追加で◯◯の条件でお受けできます」のように伝える
5. **合意を書面に残す**：個別契約の変更、覚書、発注書の再発行、またはメールでの合意

基本契約と個別契約に分かれている場合、変更は多くの場合、個別契約の差し替えや追加で行います。関係は[基本契約と個別契約の記事](/media/basic-and-individual-contract/)をご覧ください。

:::caution
範囲の外の作業を何も言わずに続けると、発注者からは「範囲内の作業として引き受けた」と受け取られることがあります。後から追加の報酬を求めても、合意の記録がなければ話し合いは難しくなります。小さな依頼でも、範囲の外だと思ったら、その場で一言確認しておきましょう。
:::

## 断るとき・条件をつけるときの伝え方

範囲の外の依頼を、すべて断る必要はありません。プロジェクトの事情に応じて、引き受け方を選べます。

| 対応 | 伝え方の例 |
|---|---|
| 条件をつけて受ける | 「範囲外の作業になるため、追加の稼働と報酬について先に合意させてください」 |
| 優先順位を入れ替える | 「今月はこの作業を優先し、◯◯の作業は翌月に回してよいか確認させてください」 |
| 一部だけ受ける | 「調査までは対応し、実装は別途お見積りします」 |
| 断る | 「契約の範囲と稼働の上限を超えるため、今回は対応が難しいです」 |

なお、準委任の契約で、発注者が直接細かく作業を指示し、時間や場所を管理する形が強まると、契約の形と実態がずれていきます。範囲の話とあわせて[偽装請負の記事](/media/gisou-ukeoi/)も確認しておくと安心です。報酬の上げ方の相談は[単価交渉の記事](/media/rate-negotiation/)で扱っています。

:::view
当社は、案件をご案内するときに、稼働日数・リモートの可否・希望金額を先に伺い、合う案件だけをご紹介しています。範囲の変更で稼働が増える場合は、その変更が当初のご希望と合っているかも判断の材料になります。エージェントを通じて参画している場合は、取引先の担当者と直接条件を変えず、契約の窓口を通して個別契約を改めることをおすすめします。
:::

:::point
- 範囲の外の作業は、原則として当初の報酬に含まれない。判断の基準は契約書・個別契約・明示された業務の内容
- 従業員を使う発注者が1か月以上の業務委託で、費用を負担せずに給付内容を変更させるのは禁止
- 変更は、内容・理由・費用・スケジュール・契約条件への影響を書いて合意し、書面に残す
- 範囲の外だと思ったら、作業を始める前に確認する
:::

## よくある質問

### 精算幅の範囲内なら、追加の作業は報酬なしで受けるべきですか？

同じ役割の中で作業量が増えた場合は、精算幅の中で調整されるのが一般的です。ただし、役割や工程そのものが変わる依頼は、時間の精算だけでは足りないことがあります。契約で決めた業務の内容に含まれるかどうかを、まず確かめましょう。上限を超えそうなときは、早めに発注者と稼働の見通しを共有しておくと話がしやすくなります。

### 請負の案件で、仕様の追加を無償で求められました。

仕様にない機能の追加は、原則として契約の変更にあたります。追加の報酬と納期を提示し、合意してから着手しましょう。従業員を使う発注者が1か月以上の業務委託で、費用を負担しないまま給付の内容を変更させることは、フリーランス新法で禁止されています。事情に争いがある場合は、専門家にご相談ください。

### 範囲の外の作業をすでにしてしまいました。今からでも請求できますか？

依頼のメールやチャット、作業の記録が残っていれば、それをもとに追加の報酬を相談する余地はあります。ただし、事前の合意がないと、報酬の額で話がまとまりにくくなります。まずは記録を整理し、次からは作業前に合意する流れに切り替えましょう。話し合いがまとまらない場合の相談先は[相談先の記事](/media/freelance-trouble-consult/)にまとめています。
