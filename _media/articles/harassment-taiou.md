業務委託先でハラスメントを受けたときは、**身の安全と心身の状態を守ること**を最優先にします。そのうえで、①その日のうちに記録を残す、②契約の相手の相談窓口に書面で伝える、③改善しない・言いにくいときは都道府県労働局やフリーランス・トラブル110番に相談する、の順で進めるのが基本です。

フリーランス法は、従業員を使う発注者に、フリーランスへのハラスメントを防ぐ相談体制の整備などを義務づけています。義務の中身や、何がパワハラにあたるかの例は[ハラスメント対策の記事](/media/freelance-act-harassment/)にまとめています。この記事では、実際に被害を受けたときの動き方を、2026年10月時点の法律と厚生労働省の指針をもとに整理します。

## 最初に、身の安全と心身を守る

暴力や脅し、身体への接触などがあった場合は、その場を離れることを優先します。危険を感じるときは、警察への相談もためらわないでください。

すぐに危険はなくても、強い言葉を浴び続けたり、無視が続いたりすると、眠れない・食欲がない・仕事のことを考えると動悸がするといった不調が出ることがあります。不調が続くときは、医療機関の受診を考えましょう。厚生労働省のポータルサイト「こころの耳」には、フリーランス向けのメンタルヘルスケアのページがあり、電話・SNS・メールで相談できる「働く人の『こころの耳相談』」は個人事業者等からの相談も受け付けています。疲労の度合いを確かめるチェックリストも公開されています。

体調を崩して稼働を続けるのが難しいときは、無理に作業量を保とうとせず、契約の相手に稼働の調整を相談します。体調管理の考え方は[働きすぎを防ぐ記事](/media/taichou-kanri/)で解説しています。

## その日のうちに記録を残す

ハラスメントの相談では、「何があったか」を後から説明できるかどうかが大切です。発注者は相談を受けると事実関係を確認しますが、言った・言わないの争いになると、確認が進みにくくなります。記憶が新しいうちに、次の項目を書き残します。

| 項目 | 書くこと |
|---|---|
| 日時 | 年月日と時刻。続いている場合は回数と期間 |
| 場所・場面 | 会議室、オンライン会議、チャット、懇親会など |
| 相手 | 名前、所属（発注者の社員か、客先の社員か、ほかの事業者か） |
| 言われたこと・されたこと | できるだけ相手の言葉のまま |
| その場にいた人 | 見聞きしていた人の名前 |
| 自分の対応と影響 | どう返したか、その後の体調や作業への影響 |

チャットやメールは、相手に削除される前に画面を保存しておきます。オンライン会議での発言は、議事録や会議のメモに残っていることもあります。報酬の減額やいわれのないやり直しの要求をともなう場合は、発注のメールや納品の記録も一緒にまとめておきます。

記録は、事実と自分の受け止めを分けて書くと伝わりやすくなります。「人格を否定された」と書くより、「『こんなこともできないのか、向いていない』と、他のメンバーの前で言われた」と書くほうが、確認する側が状況をつかみやすくなります。

:::view
当社経由で参画している場合、フリーランスの方の契約の相手は当社です。客先の方からの言動で困ったとき、現場で直接言い出すのは負担が大きいものです。記録がまだ少ない段階でもかまいませんので、早めにご相談ください。
:::

## 相談窓口への伝え方

### 窓口がどこかを確かめる

指針では、発注者が相談窓口をあらかじめ定め、契約書やメールなどでフリーランスに知らせることが求められています。まず、契約書や発注のメールに窓口が書かれていないか確かめます。見当たらない場合は、契約の担当者に「業務委託の方向けのハラスメントの相談窓口を教えてほしい」と問い合わせます。

仲介会社を通じて客先で働いている場合、契約の相手は仲介会社です。客先の社員の言動であっても、まず契約の相手に伝えるのが基本です。三者の関係は[エージェント経由の契約の記事](/media/sansha-kankei/)で整理しています。

### 書面で伝える

相談は、口頭だけでなく、メールやフォームなど記録が残る方法で伝えておくと、いつ何を相談したかが明確になります。書くときは、次の4点に絞ると要点が伝わります。

1. いつ、どこで、誰から、どのような言動があったか（記録の要約）
2. 業務や体調にどのような影響が出ているか
3. 何をしてほしいか（事実の確認、相手への注意、担当の変更、作業場所の変更など）
4. 相談したことを相手に伝えてよいかどうか、伝える範囲

### 相談のあとに何が行われるか

指針は、相談を受けた発注者に、事実関係を迅速かつ正確に確認することを求めています。例として、相談者と行為者の双方から事情を聞き、主張が食い違う場合は第三者からも話を聞くこと、確認の状況を共有することが適切な場合は伝えられる範囲で相談者に共有することが挙げられています。ハラスメントが確認できた場合は、被害者への配慮（行為者と離す、謝罪、取引条件上の不利益の回復など）と、行為者への措置、再発防止策を講じることとされています。

相談者や行為者のプライバシーを守ることも求められています。どこまで話が伝わるのかが不安な場合は、相談の時点で確かめておきましょう。

## 相手が発注者の社員でない場合

ハラスメントの相手は、発注者の社員とは限りません。客先の社員、同じ現場で働くほかの事業者やフリーランス、取引先の顧客ということもあります。

指針は、ほかの事業者等からのパワハラや、顧客等からの著しい迷惑行為（暴行、脅迫、ひどい暴言、著しく不当な要求など）について、発注者が相談に応じる体制を整えたり、被害者に配慮したりすることが**望ましい**としています。配慮の例として、メンタルヘルス不調への相談対応、著しい迷惑行為をする人に一人で対応させないこと、客先の社員によるハラスメントについて客先に事実確認や防止の申入れを行うこと、同じような条件の別の業務委託に切り替えることが挙げられています。

義務ではなく望ましい取組とされている部分もありますが、相談すること自体に問題はありません。相手が誰であっても、まず契約の相手に事実を伝え、どう対応できるかを話し合いましょう。

:::caution
相談したことや、事実確認に協力して事実を述べたことを理由に、発注者が契約を解除するなどの不利益な扱いをすることは、法律で禁止されています（フリーランス法第14条第2項）。一方で、怒りにまかせて相手に直接抗議したり、SNSに書き込んだりすると、別のトラブルを招くおそれがあります。対応は、記録と相談の窓口を通して進めましょう。
:::

## 改善しないとき・窓口に言いにくいとき

相談しても状況が変わらない場合や、発注者の窓口に言いにくい場合は、外部の相談先を使います。

- **都道府県労働局 雇用環境・均等部（室）**：フリーランス法の就業環境の整備（ハラスメント対策を含む）についての相談先です。発注者が体制を整えていないなど法律違反と思われる場合は、厚生労働大臣への申出もできます。申出の準備と流れは[申出の記事](/media/freelance-act-moushide/)で解説しています
- **フリーランス・トラブル110番**：弁護士に無料で相談できる窓口で、匿名でも相談できます。相談の項目に「ハラスメントについて」があり、話し合いでの解決を目指す和解あっせんも利用できます

相談先ごとにできること・できないことは[相談先の記事](/media/freelance-trouble-consult/)で比べています。慰謝料など損害の賠償を求めたい場合は、弁護士への依頼を検討することになります。

## 契約を続けるか、終えるかを考える

状況によっては、その案件から離れることが自分を守る選択になる場合もあります。判断の前に、次の点を確かめておきます。

- **契約期間と解約の条項**：自分から途中で解約する場合の予告期間や手続き（[中途解約の記事](/media/termination/)）
- **報酬の扱い**：作業した分の報酬の請求、途中の成果物の扱い
- **引き継ぎ**：誰に、何を、いつまでに引き継ぐか

発注者の側から契約を打ち切られた場合、6か月以上の継続的な業務委託であれば、原則として30日前までの予告と、求めに応じた理由の開示が必要です（[中途解除の30日前予告の記事](/media/freelance-act-termination-notice/)）。相談の直後に契約を切られたときは、経緯を時系列で残し、外部の相談先に伝えましょう。

:::view
案件のご案内では、先に稼働日数・リモートのご希望・希望金額を伺い、合う案件だけをお出ししています。つらい経験のあとで次の案件を探すときは、稼働日数や出社の頻度の希望を見直してから探すのも一つの方法です。参画前の面談では、困ったときの相談窓口や連絡の流れについて質問しておくことをおすすめします。
:::

:::point
- まず身の安全と心身を守る。不調が続くときは受診や「こころの耳」の相談も
- 日時・場所・相手・言動・その場にいた人を、その日のうちに記録する
- 契約の相手の相談窓口に、記録が残る方法で伝える。何をしてほしいかも書く
- 相手が客先や他社の人でも、まず契約の相手に伝える
- 改善しないときは都道府県労働局やフリーランス・トラブル110番へ
:::

## よくある質問

### 一度きりの強い叱責でも、相談してよいですか？

相談してかまいません。ハラスメントにあたるかどうかは、言動の内容や状況から判断されます。指針は、業務上必要かつ相当な範囲の注意はパワハラにあたらない例としていますが、それを自分だけで判断する必要はありません。記録を残し、繰り返されるようなら早めに相談しましょう。

### 相手がほかのフリーランスの場合、誰に相談すればよいですか？

まず、自分の契約の相手である発注者や仲介会社に伝えます。指針は、ほかの事業者等からのパワハラについても、発注者が相談に応じる体制を整えることなどを望ましい取組として挙げています。発注者を通じて対応が進まない場合は、フリーランス・トラブル110番などの外部の相談先を使えます。

### 発注者が従業員のいない個人の場合も、相談できる窓口はありますか？

従業員を使っていない個人の発注者には、フリーランス法第14条の体制整備の義務はかかりません。ただし、それはハラスメントが許されるという意味ではありません。取引上のトラブルとして、フリーランス・トラブル110番で弁護士に相談できます。暴力や脅しがある場合は、警察への相談も考えてください。
