ヘルプデスク・社内ITサポートのフリーランスの将来性は、**問い合わせを受ける量や手作業の速さではなく、OSの更新や端末の入れ替えを段取りし、自動で設定する仕組みを運用できるか**で変わります。2026年10月時点のMicrosoftの公式情報を見ると、Windowsは毎年のように更新の期限が来て、端末の準備も手作業から仕組みへ移る流れが示されています。

社内の利用者を支える仕事がなくなるわけではありません。ただ、定型の受付と手作業のキッティングは減らしやすく、更新の計画と仕組みの運用、窓口の改善を担える人が求められやすくなります。この記事では、公式の動向から読み取れる変化と、経験の段階に応じた広げ方を整理します。

## 公式の動向から読み取れる変化

### Windows 10のサポート終了後も、移行の仕事は残っている

Microsoftのライフサイクル情報によると、Windows 10は2025年10月14日にサポートが終了しました。Home・Pro・Enterpriseなどのエディションで、それ以降は技術サポート、機能の更新、セキュリティを含む品質の更新が提供されなくなっています。

一方で、有料の「拡張セキュリティ更新（ESU）」プログラムがあり、組織に属するPCは、登録すればサポート終了から最大3年間、セキュリティの更新を受け取れるとされています。ESUは年単位で購入し、Windows 10のバージョン22H2であることが前提です。新しい機能やテクニカルサポートは含まれません（2026年10月時点、Microsoft Learnの案内による）。

つまり、**移行が終わっていない端末を抱えたまま、期限つきで運用している会社もある**ということです。残った端末の洗い出し、ESUの対象になっているかの確認、入れ替えの順番の調整は、ヘルプデスクの現場に近い仕事です。

### Windows 11は、バージョンごとに期限が来る

Windows 11は、毎年のように新しいバージョンが出て、それぞれにサービスの終了日が決まっています。2026年10月時点の公式の掲載では、次のように示されています。

| エディション | バージョン | サービス終了 |
|---|---|---|
| Home・Pro | 24H2 | 2026年10月 |
| Home・Pro | 25H2 | 2027年10月 |
| Enterprise・Education | 23H2 | 2026年11月 |
| Enterprise・Education | 24H2 | 2027年10月 |

掲載されている開始日と終了日を見ると、Home・Proは約2年、Enterprise・Educationは約3年で各バージョンのサービスが終わります。端末の多い会社では、**どの端末がどのバージョンかを把握し、期限の前に更新を配り、更新後の問い合わせに備える**仕事が毎年発生します。期限は変わることがあるため、実際の作業では最新の公式情報をご確認ください。

サーバーやオフィスソフトを含めた期限の一覧と、IT計画の立場からの見方は[情シス支援の将来性の記事](/media/jousys-future/)で解説しています。

### 端末の準備は、手作業から仕組みへ

MicrosoftのWindows Autopilotは、端末にあらかじめ入っているWindowsを、設定やアプリの適用で業務用の状態に変える仕組みで、端末のモデルごとにイメージを作り直す必要がなくなると説明されています。利用者に求められる操作は、ネットワークに接続して資格情報を確かめることだけで、それ以外は自動で行われるとされています（2026年10月時点、Microsoft Learnの案内による）。

展開した後の端末は、Microsoft IntuneやConfiguration Managerなどの管理ツールで管理できるとされています。こうした仕組みが入ると、1台ずつ設定する作業は減ります。その代わり、**設定の内容を決め、配布がうまくいかなかった端末を調べ、利用者に案内する**仕事が中心になります。

:::view
ヘルプデスクの案件をご紹介していると、端末の入れ替えやOSの更新の時期に合わせた案件で、面談で問われるのは「何台をどの順番で、どんな段取りで進めたか」です。評価されやすいのは、作業の速さより、更新後の問い合わせを見越して案内文やFAQを先に用意した経験を話せる方です。当社では、先に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをご案内しています。
:::

## ヘルプデスクの役割はどう変わるか

| これまでの中心 | 加わりやすい仕事 |
|---|---|
| 1台ずつのキッティング | 自動設定の仕組みの運用と、うまくいかなかった端末の対応 |
| OSの更新の個別対応 | バージョンの把握、更新の段取り、更新後の問い合わせへの備え |
| 電話での受付 | チャットやセルフサービスの窓口、FAQの整備 |
| 問い合わせへの回答 | 問い合わせの分析と、減らすための手順の見直し |
| アカウントの個別処理 | 入退社の流れに沿った処理と、権限の見直しの補助 |

受付の手段が電話からチャットや案内ページに広がると、利用者が自分で解決できる範囲が増えます。その分、ヘルプデスクに届くのは、手順どおりに進めても解決しない、切り分けの難しい問い合わせの比率が高くなりがちです。一次対応だけを担う働き方より、二次対応や改善まで担える人が求められやすくなるのは、このためです。

共通しているのは、**一件ずつの作業より、作業が減る形を作り、作業が増える時期を前もって準備する**役割が求められることです。

## 選択肢を広げる3つの方向

### 1. 端末とOS更新の段取りを担う

端末の台帳とOSのバージョンを把握し、更新や入れ替えの順番、日程、利用者への案内を取りまとめる役割です。自動設定や端末管理の仕組みの運用まで担えると、入れ替えの時期に合わせた案件で選ばれやすくなります。

### 2. 窓口の運用設計とITSMを担う

ITILの考え方に沿って、受付の分類、エスカレーションの基準、ナレッジの流れを作る役割です。ITSMツールの導入や運用の設計まで進む道もあり、[ServiceNowエンジニアのスキルの記事](/media/servicenow-skills/)が参考になります。資格での裏付けや、ITILの新しい版への移行は[ITILの認定資格の記事](/media/cert-itil/)、より上位の運用管理は[ITサービスマネージャ試験の記事](/media/cert-ipa-sm/)で整理しています。

### 3. 情シス支援へ広げる

アカウントや端末の仕組みづくりから、SaaSの管理、IT計画、ベンダーの管理へと範囲を広げると、情シス支援の役割に近づきます。必要な経験は[社内SE・情シス支援がフリーランスになるには](/media/jousys-how-to/)で解説しています。

:::caution
OSの更新や端末の入れ替えの案件は、期限に合わせて期間が区切られていることが多く、作業が終わると契約も終わる場合があります。参画前に、担う範囲が段取りだけか、現地の作業まで含むか、更新後の問い合わせ対応まで続くかを確かめ、次の案件の探し始めの時期を考えておくことをおすすめします。
:::

## 経験の段階ごとの広げ方

### 一次対応が中心の方

受付の中で多い問い合わせを一つ選び、FAQや案内文を作って減らす経験から始めると、改善の段階に進みやすくなります。OSの更新の時期は問い合わせが増えるため、案内文づくりに関わる機会になります。

### 二次対応やキッティングを担ってきた方

切り分けや手順書づくりの経験を、端末管理や自動設定の仕組みの運用へつなげると、更新の段取りを任される役割に近づきます。

### まとめ役や改善を担ってきた方

窓口の運用設計やITSMの方向、または情シス支援の方向へ広げやすい段階です。どちらに進むかは、受付の仕組みを深めたいか、社内のIT全体を見たいかで考えるとよいでしょう。上流の役割への広げ方は[上流工程の案件に入るために必要な経験](/media/upper-process/)をご覧ください。

:::view
OSの更新や端末の入れ替えに合わせた案件は、期間が区切られていることが少なくありません。当社がご案内する案件では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。担う範囲が段取りまでか、現地の作業や更新後の問い合わせ対応まで含むかなど、気になる点はご質問いただければ確認します。
:::

- Windows 11はバージョンごとに期限があり、Home・Proは約2年、Enterprise・Educationは約3年で更新が必要になる
- 端末の準備は自動設定の仕組みへ移りつつあり、更新の段取り、窓口の運用設計、情シス支援の3方向で役割を広げられる

## よくある質問

### 自動化やセルフサービスが進むと、ヘルプデスクの仕事は減りますか？

1台ずつの設定や、よくある問い合わせへの回答は減りやすくなります。一方で、仕組みがうまく動かなかった端末の対応、更新の段取り、FAQや案内文の整備といった仕事は残ります。減らす側に回った経験を作っておくと、選べる案件が広がります。

### Windows 10の端末が残っている会社の案件は、今後も出ますか？

組織向けのESUはサポート終了から最大3年間とされているため、その間に移行を進める会社はあると考えられます。ただ、案件がどの程度出るかを言い切ることはできません。期限の情報はMicrosoftの公式ページでご確認ください。

### 40代・50代からでも、ヘルプデスクで役割を広げられますか？

広げる余地はあります。利用者への説明や、関係者を巻き込んで段取りを進める経験は、年代を重ねた方の強みになりやすい部分です。年代ごとの考え方は、ヘルプデスクの年代別の記事でも解説する予定です。
