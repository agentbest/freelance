予定納税は、前年分の所得税の申告納税額が15万円以上だった人が、今年の所得税の一部を前払いする制度です。前年の申告納税額をもとにした「予定納税基準額」の3分の1ずつを、7月（第1期）と11月（第2期）に納めます。

独立1年目の確定申告で納める所得税が15万円以上になると、2年目の6月に税務署から通知が届きます。払った分は翌年の確定申告で精算され、多すぎれば戻ってきます。この記事では、国税庁の説明をもとに、仕組みと減額申請の方法を整理します（2026年10月時点）。

## 予定納税の通知が届く条件

国税庁によると、予定納税の対象になるのは、5月15日の時点で確定している前年分の「予定納税基準額」が15万円以上の人です。

予定納税基準額は、原則として前年分の申告納税額です。申告納税額とは、確定申告書で計算した所得税と復興特別所得税から、源泉徴収された税額などを差し引いた後の、自分で納めた額のことです。報酬から源泉徴収されている分が多い人は、そのぶん基準額が小さくなります。源泉徴収の仕組みは[源泉徴収の記事](/media/gensen-choshu/)で解説しています。

前年分に次のような所得や控除があった場合は、それらを除いて基準額を計算します。

- 山林所得・退職所得などの分離課税の所得
- 譲渡所得・一時所得・雑所得
- 平均課税を選んだ臨時所得
- 外国税額控除や災害減免を受けた分

フリーランスのエンジニアやコンサルの場合、事業所得から計算した税額がほぼそのまま基準額になります。

## 通知から精算までのスケジュール

予定納税の流れは、毎年次のとおりです。

| 時期 | 内容 |
|---|---|
| 5月15日 | この日に確定している前年分の申告納税額で、対象かどうかが決まる |
| 6月15日まで | 税務署から、書面またはe-Taxで予定納税額が通知される |
| 7月1日〜31日 | 第1期分（基準額の3分の1）を納める |
| 7月15日まで | 第1期・第2期分の減額申請の期限 |
| 11月1日〜15日 | 第2期分だけの減額申請の期間 |
| 11月1日〜30日 | 第2期分（基準額の3分の1）を納める |
| 翌年2月〜3月 | 確定申告で、1年分の税額から予定納税額を差し引いて精算 |

納期限や申請期限が土日・祝日にあたる場合は、その翌日（翌開庁日）が期限です。2026年は11月15日が日曜日のため、第2期分の減額申請は11月16日（月）までとなります。

### 計算例（仮の数字）

仮に、独立1年目の確定申告で納めた所得税（復興特別所得税を含む）が60万円だったとします。

- 予定納税基準額：60万円
- 第1期（7月）：20万円
- 第2期（11月）：20万円

2年目の所得が増え、1年分の税額が90万円になった場合は、翌年の確定申告で90万円−40万円＝50万円を納めます。逆に所得が減って税額が30万円になった場合は、40万円−30万円＝10万円が還付されます。

## 独立1年目に通知が届かない理由

会社員を辞めて独立した年は、予定納税の通知は届かないのが普通です。前年は会社員で、所得税は給与から源泉徴収され、年末調整で精算されていたからです。確定申告をしていても、医療費控除などの還付申告であれば、申告納税額は0円です。

通知が届き始めるのは、独立した年の分を確定申告した後です。たとえば2026年の途中で独立した場合、2027年3月に2026年分の確定申告をします。そのとき納めた所得税が15万円以上なら、2027年6月に通知が届き、7月と11月に予定納税をします。

年の途中で独立した場合、1年目の事業所得は数か月分だけです。2年目は1年分の売上になるため、1年目の税額をもとにした予定納税額より、2年目の実際の税額のほうが多くなることがよくあります。その差額は3年目の3月の確定申告で納めることになります。予定納税を払ったからといって、2年目の税金が済んだわけではない点に注意してください。

## 独立2年目にお金が出ていく時期が重なる理由

予定納税が「2年目に負担が重い」と感じられるのは、支払いの時期が重なるからです。2年目には、おおむね次の支払いが続きます。

1. 3月：1年目の所得税の確定申告と納付
2. 6月以降：1年目の所得をもとにした住民税の納付が始まる
3. 7月：予定納税の第1期
4. 8月・11月：1年目の所得をもとにした個人事業税（対象になる場合。東京都の例）
5. 11月：予定納税の第2期

会社員のころは、所得税も住民税も給与から引かれていたため、まとまった額を自分で払う経験が少ない人も多いはずです。住民税の時期は[住民税の記事](/media/juminzei/)、個人事業税は[個人事業税の記事](/media/kojin-jigyozei/)で解説しています。

:::view
案件をご紹介していると、独立2年目の夏ごろに「思ったより手元にお金が残らない」というご相談をいただくことがあります。原因の多くは、住民税と予定納税の時期が重なることです。報酬の入金日は契約によって決まっているため、当社がご案内する案件では、報酬と支払期日を個別契約に書いてお渡ししています。入金日がわかっていれば、7月と11月の納付に向けて、毎月の報酬から一定額を取り分けておく計画を立てやすくなります。
:::

## 所得が減りそうなときは減額申請ができる

今年の所得が前年より大きく減りそうな場合は、予定納税額の減額を申請できます。国税庁によると、主な内容は次のとおりです。

- **申請できる場合**：休業・廃業・業況不振などで事業の所得が減る、災害や盗難の被害を受けた、医療費や社会保険料などの所得控除が増えたなど、今年の申告納税見積額が予定納税基準額より少なくなると見込まれるとき
- **第1期・第2期分をまとめて申請**：その年の7月1日から7月15日まで
- **第2期分だけを申請**：その年の11月1日から11月15日まで
- **提出方法**：書面またはe-Taxで、納税地の所轄税務署に提出する
- **結果**：税務署が審査し、承認するかどうかが通知される

フリーランスで多いのは、案件の終了や稼働日数の減少で、今年の売上が前年を下回る場合です。7月の時点で年間の所得と税額を見積もり、基準額より少なくなりそうなら申請を検討します。見積もりの根拠として、案件の契約期間や入金の記録を手元にそろえておくと説明しやすくなります。

:::caution
減額申請は、承認されるまでは通知どおりの金額が予定納税額です。申請したからといって、期限までの納付をやめてよいわけではありません。期限に遅れると延滞税がかかります。振替納税を使っている場合も、口座の残高が足りずに引き落とせないと延滞税の対象になります。
:::

## 令和8年度税制改正の基礎控除の見直しとの関係

国税庁の予定納税のページには、令和8年度税制改正による基礎控除の見直しは予定納税額の計算に反映されず、確定申告のときに考慮して精算すると書かれています。2026年に届いた通知の金額は、改正前の基礎控除を前提にした前年分の税額がもとになっている、ということです。差額は翌年の確定申告で調整されます。

## 消費税の中間申告とは別の制度

インボイスの登録などで消費税の課税事業者になった人は、消費税にも前払いの仕組みがあります。国税庁によると、個人事業者は前年の消費税の年税額（地方消費税を除く）が48万円を超えると、中間申告と納付が必要です。年税額が48万円超400万円以下なら年1回で、前年の税額の12分の6を納めます。

所得税の予定納税とは対象も計算も別のものです。消費税の納税については[消費税の納税の記事](/media/shohizei-nouzei/)をご覧ください。

:::view
売上が伸びてくると、所得税の予定納税・住民税・個人事業税・消費税と、自分で納める税金の種類と時期が増えていきます。案件のご案内の際に、稼働日数や希望金額とあわせて「年間でどのくらいの売上を見込むか」を伺うことがあります。年間の見通しが立つと、税金の準備だけでなく、法人化を考える時期の判断にもつながります。法人化の考え方は[法人化のタイミングの記事](/media/incorporation-timing/)で解説しています。
:::

:::point
- 前年分の申告納税額が15万円以上なら、7月と11月に3分の1ずつ前払いする
- 通知は6月15日までに届く。独立1年目の申告で15万円以上になると、2年目から始まる
- 払った分は翌年の確定申告で精算され、多すぎれば還付される
- 所得が減りそうなら、7月15日まで（第2期分だけなら11月15日まで）に減額申請ができる
- 2年目は住民税・個人事業税と時期が重なるため、報酬から計画的に取り分けておく
:::

## よくある質問

### 予定納税を払わないとどうなりますか？

納期限までに納めないと、延滞税がかかります。予定納税は「前払い」ですが、納付は義務です。一度に払うのが難しい場合は、早めに所轄の税務署に相談してください。所得が減る見込みなら、減額申請も検討しましょう。

### 会社員に戻った場合も予定納税は続きますか？

前年分の申告納税額が15万円以上なら、その年は通知が届きます。会社員に戻って事業の所得がなくなる場合は、廃業などを理由に減額申請ができます。翌年以降は、確定申告で納める税額が15万円未満になれば通知は届かなくなります。個別の事情は、税務署・税理士にご相談ください。

### 予定納税で払いすぎた分は、いつ戻ってきますか？

翌年の確定申告で、1年分の所得税額から予定納税額を差し引いて精算します。予定納税額のほうが多ければ、その差額が還付されます。国税庁によると、確定申告の義務がない人でも、予定納税額などが年間の税額より多ければ還付申告ができます。申告の方法は[e-Taxの記事](/media/etax/)をご覧ください。
