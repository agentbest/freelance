マーケティングコンサルタントのスキルシートは、プロジェクトごとに**どの領域を、どんな商売の形で、どの立場から担い、何を判断し、どの指標を見て、何を変えたか**を書くのが基本です。「デジタルマーケティングを支援」「売上向上に貢献」とまとめるだけでは、任せられる範囲が読み手に伝わりません。

マーケティングの実績は、広告費や売上など、発注側の機密に当たる数字と結び付いています。この記事では、数字を出さずに実績を伝える工夫を含めて、要約・プロジェクト欄・スキル一覧の書き方を解説します。スキルシート全体の構成は[スキルシートの書き方の基本](/media/skillsheet-basics/)で扱っています。

## 読み手は「領域」と「判断の範囲」を先に探す

マーケティングの案件は、「新商品の立ち上げの方針を決めたい」「広告と検索の施策をまとめて見直したい」「数字を見て施策を決める仕組みを作りたい」のように、領域と課題で募集されます。読み手はシートを開くと、まず案件の領域と商売の形に近い経験があるかを探します。

次に見られるのが、判断の範囲です。同じ広告の施策でも、決まった方針で運用を回したのか、予算の配分を決めたのか、部門全体の方針の中で広告の位置づけを決めたのかで、経験の中身は違います。

| 読み手が探すこと | スキルシートで答える場所 |
|---|---|
| 案件の領域に近い経験があるか | 要約の1行目、各プロジェクトの「領域・テーマ」 |
| 商売の形が近いか | 「商材・顧客」 |
| どこまで判断を任せられるか | 「立場」と「判断した範囲」 |
| 数字で考えられるか | 「見た指標」と「成果」 |
| 社内外の関係者を動かせるか | 「関わった相手」 |

## 要約は「領域・商売の形・得意な局面」で組み立てる

要約は3〜5行で、何を任せられる人かを示します。次の3点を入れると、読み手が案件と結び付けやすくなります。

1. **領域**：戦略、ブランド、デジタル施策、データ活用のどこが厚いか
2. **商売の形**：BtoBかBtoCか、店舗・通信販売・定期購入・会員制など
3. **得意な局面**：立ち上げ、見直し、改善の継続、仕組みづくりのどこか

例（架空）：

- BtoCの通信販売を中心に、デジタル施策の方針づくりと改善に8年従事
- 検索・広告・メールを横断した予算配分の見直しと、週ごとの振り返りの仕組みづくりが得意
- 事業会社のマーケティング部門で予算の配分案を作成し、事業部長の判断を支えた経験あり

応募する案件の領域に合わせて、要約の順番を入れ替えると伝わりやすくなります。「マーケティング全般に対応」のような書き方は、得意な領域が読み手に伝わらないため避けましょう。複数の領域の経験がある場合も、厚い領域を1行目に置き、他の領域は「あわせて〜も担当」と添える形が読みやすくなります。

## プロジェクト欄で厚く書く項目

エンジニアの「使用技術」の代わりに、マーケティングコンサルタントは次の項目を厚く書きます。

| 項目 | 書き方のポイント |
|---|---|
| 領域・テーマ | 「新商品の立ち上げの顧客設定と施策設計」のように、領域と課題を一続きで書く |
| 商材・顧客 | 業種、BtoBかBtoCか、売り方。社名が分からない程度にぼかす |
| 立場 | 事業会社の担当／責任者、支援会社の担当、外部の相談役など |
| 判断した範囲 | 方針を決めた、予算配分の案を作った、施策の取捨選択を提案した、など |
| 関わった相手 | 経営層、事業部長、営業部門、広告会社、制作会社、システムの担当 |
| 見た指標 | 何を目標の指標とし、何を途中の指標として見たか |
| 成果 | 何を変え、指標がどちらに動いたか |

### 「判断した範囲」は省かない

マーケティングの案件で最もよく聞かれるのは、「それはあなたが決めたのか」です。提案した、決めた、実行した、の区別を書き分けておくと、面談での説明と食い違いません。決裁権がなかった場合も、「配分の案を作成し、部長の判断を得た」と書けば、判断に関わった範囲が伝わります。

### 「見た指標」で考え方を示す

成果の数字を出せない場合でも、どの指標を目標にし、どの指標で途中経過を見たかを書くと、数字で考える人だと伝わります。たとえば「問い合わせ数を目標に置き、途中の指標として資料請求ページへの到達率を見た」のように書きます。

## 数字を書けないときの置き換え方

広告費、売上、顧客数などは、発注側や前職の機密に当たることが多い数字です。次のように置き換えます。

| 避けたい書き方 | 置き換えの例 |
|---|---|
| 広告費や予算の金額を書く | 「部門の広告予算のうち、検索と広告の配分を担当」のように範囲で示す |
| 売上や件数の実数を書く | 「問い合わせ数が前年同期を上回った」のように方向と比べ方で示す |
| 社名・商品名が分かる書き方 | 「中堅の化粧品の通信販売」のように業種と規模で示す |
| 効果を率で強く言い切る | 施策の効果と他の要因を分けられない場合は、「〜の期間に〜が改善」と事実だけ書く |

どこまで書いてよいかの考え方は[スキルシートと守秘義務の記事](/media/confidentiality-in-skillsheet/)で扱っています。迷う場合は、契約書の秘密保持の条項を確かめてください。

:::view
マーケティングの案件紹介の現場では、スキルシートに成果の率だけが大きく書かれていて、面談で「その数字は施策の効果か、他の要因か」を聞かれて答えに詰まるケースを見かけます。評価されやすいのは、成果の大きさより、何と比べてどう判断したかを説明できる方です。成果の欄は、比べ方まで添えて書くことをおすすめします。
:::

## 記入例（架空）

次は書き方の型を示すための例で、実在のプロジェクトではありません。

> **期間**：20XX年4月〜翌年3月（1年）
> **領域・テーマ**：デジタル施策の予算配分の見直しと、振り返りの仕組みづくり
> **商材・顧客**：BtoCの定期購入型の食品（中堅規模の通信販売）
> **立場**：外部の相談役（週2日）。マーケティング部長の直下
> **判断した範囲**：検索・広告・メールの役割分担と予算配分の案を作成し、部長の判断を得た。効果の薄い広告の種類を停止する提案を行い、採用された
> **関わった相手**：マーケティング部長、広告会社、制作会社、システム部門
> **見た指標**：新規の定期購入の申込数を目標とし、途中の指標として初回購入から2回目の購入に進む割合を見た
> **担当内容**：施策ごとの指標の定義をそろえ、週次の振り返りの会議の型を作成。広告会社への依頼の文書を見直し、提案を比べる基準を決めた
> **成果**：申込数を前年同期と比べられる形で毎週追えるようになった。停止した広告の予算を既存顧客向けのメール施策に移し、2回目の購入に進む割合が改善した

実際に書くときは、ご自身の経験に置き換えてください。

## 出身による書き分け

### 支援会社の出身の場合

広告会社や支援会社の出身者は、担当した顧客の数が多くなりがちです。直近の数年をくわしく書き、同じ領域の案件は「同種の施策の見直しを複数の業種で」とまとめると読みやすくなります。顧客側の判断と、自分が提案した範囲を書き分けておきましょう。

### 事業会社の出身の場合

社内の部署名や施策の呼び名は、読み手に通じないことがあります。一般的な言葉に置き換え、他の会社でも通じる手順として書きます。1社での経験が長い場合は、商品や時期ごとにプロジェクトを分けて書くと、経験の幅が伝わります。

### 業界の経験を強みにする場合

広告・メディアの業界での経験を前面に出す書き方は、[広告・メディア業界の経験をスキルシートで伝える記事](/media/ind-koukoku-skillsheet/)で解説しています。

## スキル一覧は「領域・手法・道具」を並べる

| 区分 | 記入例（架空） |
|---|---|
| 領域 | デジタル施策の方針（6年）、ブランドの言葉の整理（2年） |
| 手法 | 顧客の聞き取りの設計、指標の設計、比較の試験の設計、予算配分の見直し |
| 道具 | 解析ツール（指標の設計とレポート作成）、表計算ソフト（集計と試算）、BIツール（ダッシュボードの設計） |
| 協力会社との仕事 | 広告会社・制作会社への依頼の文書の作成、提案の比較 |
| 資格 | 業務に関係するもの |

道具は名前だけでなく、何に使ったかを括弧で添えると、使い方の深さが伝わります。MAやCRMのツールを自分で設定した経験がある場合は、設定の範囲を書き分けておくと、エンジニアの案件との違いが伝わります。

:::caution
作った資料や広告の表現をそのままスキルシートに添付するのは避けましょう。前職や発注側の権利と秘密に触れることがあります。見本を求められた場合は、構成を言葉で説明するか、架空の題材で作った見本を用意する方法があります。実績の見せ方は[ポートフォリオの記事](/media/portfolio-github/)も参考になります。
:::

:::view
当社では、ご経歴は、ご本人の了承を得た案件にだけ、氏名・連絡先を伏せてご提案しています。マーケティングの案件は領域と商売の形の組み合わせで探されることが多いため、要約の1行目と、各プロジェクトの「領域・テーマ」「商材・顧客」の書き方をそろえておくことをおすすめします。
:::

:::point
- 要約は「領域・商売の形・得意な局面」で組み立て、案件ごとに順番を入れ替える
- プロジェクト欄は「判断した範囲」と「見た指標」を厚く書く
- 広告費や売上は、範囲・方向・比べ方に置き換える
:::

## よくある質問

### 担当した施策の数が多く、すべて書くと長くなります。

直近の5年程度をくわしく書き、それより前は期間・領域・立場を1〜2行にまとめます。同じ領域の短い案件は一つにまとめると読みやすくなります。

### 成果が出なかったプロジェクトは書かないほうがよいですか？

書いて構いません。何を試し、何が分かり、次に何を変えたかが書いてあれば、判断の力が伝わります。面談で聞かれたときの説明も用意しておきましょう。

### 面談ではスキルシートのどこを聞かれますか？

「判断した範囲」と「成果の比べ方」がよく聞かれます。面談の準備は[自己紹介の記事](/media/self-introduction/)も参考になります。
