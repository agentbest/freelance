医療の案件で求められる業務知識は、**受付から会計までの診療の流れ**、**レセプトによる保険請求の仕組み**、**診療録（カルテ）の法的な扱い**、**標準規格とマスタ**の4つが土台です。医師や看護師と同じ医学の知識が要るわけではありません。システムがどの業務のどの場面を支えているかを、現場の言葉で説明できることが求められます。

この記事では、それぞれの押さえどころと身につけ方を整理します（2026年10月時点）。案件の種類は[医療のIT案件の記事](/media/ind-iryou-it/)、守るルールは[医療の規制とセキュリティの記事](/media/ind-iryou-kisei/)で扱います。業界知識全般を強みにする考え方は[業界知識の記事](/media/gyoukai-chishiki/)をご覧ください。

## 医療の案件で求められる業務知識は4つ

| 知識 | 何が分かるようになるか |
|---|---|
| 診療の流れ | どの職種が、どの場面で、どの画面を使うか |
| 保険請求の仕組み | 医事会計やレセコンが、なぜその形で記録を持つか |
| 診療録の扱い | 記録を消せない・書き換えにくい設計がなぜ必要か |
| 標準規格とマスタ | システムどうしが、どのコードと形式でつながるか |

## 診療の流れ：受付から会計まで

外来の一日の流れを、システムの動きと重ねて覚えると、案件の会話が分かりやすくなります。病院と診療所で細部は違いますが、骨格は次のとおりです。

1. **受付**：保険の資格を確かめる（オンライン資格確認）。初診なら患者の基本情報を登録する
2. **診察**：医師が電子カルテに所見や病名を記録する
3. **オーダー**：検査・画像・処方・注射などの指示を出す。各部門のシステムに指示が流れる
4. **部門での実施**：検査、撮影、調剤などを行い、結果をカルテに返す
5. **会計**：実施した内容から医療費を計算し、患者の負担分を受け取る
6. **請求**：月ごとにまとめて、残りを審査支払機関に請求する

入院では、これに病棟での看護記録、食事、手術、退院時のサマリーなどが加わります。医療法第1条の5は、20人以上の患者を入院させる施設を持つものを病院としており、病院の案件では入院の業務とそれを支える部門システムの比重が大きくなります。

### オーダーは部門をまたぐ「指示」

電子カルテの案件で大事なのが、オーダーの考え方です。医師の指示が、検査部門や薬剤部門のシステムに渡り、実施の記録と結果が戻ってきます。指示の取消しや変更、実施済みの扱いなど、例外の流れが多いのが特徴です。部門どうしの連携の不具合は、この例外の扱いから生まれることがよくあります。

## 保険請求の仕組み：レセプトの流れ

保険診療では、患者が窓口で払うのは医療費の一部で、残りは医療機関が審査支払機関に請求します。この請求のデータがレセプトです。

医療情報基盤・診療報酬審査支払機構（DX審査支払機構）の説明では、医療機関等はレセプトのデータを請求用の端末からオンライン請求のセンターに送り、審査の結果は「増減点連絡書」のデータなどとして医療機関等に返ってきます。保険者へは、審査支払機関からレセプトのデータが渡ります。

システムの側から見ると、押さえたいのは次の点です。

- **算定のルールは制度で決まっている**：何をどう点数にするかは診療報酬の決まりに沿っており、改定のたびに医事会計やレセコンの改修が発生する
- **病名と行為の対応が見られる**：請求では、行った検査や処方と病名の整合が問われるため、電子カルテの病名の登録が医事の業務にも影響する
- **返戻や査定への対応がある**：審査の結果を受けて、請求を直して出し直す業務がある

点数の細かい規則まで覚える必要は、多くの案件ではありません。ただ、医事課の担当者が何に困るかを理解していると、要件の聞き取りがかみ合いやすくなります。

## 診療録の扱い：記録を守るための要件

医師法第24条は、医師は診療をしたときは遅滞なく診療録に記載し、病院・診療所に勤務する医師の診療に関するものは、その管理者が5年間保存しなければならないと定めています。

厚生労働省の「医療情報システムの安全管理に関するガイドライン」第7.0版の概説編は、電磁的に保存できる文書の情報を電子媒体に保存する場合には、**真正性・見読性・保存性**が確保されている必要があるとしています。

- **真正性**：誰がいつ書いたか、書き換えられていないかが分かる
- **見読性**：必要なときに読める形で表示・出力できる
- **保存性**：決められた期間、読める状態で残せる

電子カルテで「削除」ではなく「取消しの記録を残す」設計になっていること、更新の履歴を持つこと、データ移行で過去の記録の扱いが重く議論されることは、この要件から来ています。ガイドライン自体の読み方は[医療の規制の記事](/media/ind-iryou-kisei/)で扱います。

:::view
医療の案件をご紹介していると、面談で評価されやすいのは、技術の説明に加えて「この機能は外来のどの場面で、どの職種が使うか」を言える方です。反対につまずきやすいのは、オーダーの取消しや実施済みの扱いなど、例外の流れを聞かれて答えに詰まるケースです。参画前に、外来と入院の流れを一度紙に書き出しておくことをおすすめします。
:::

## 標準規格とマスタ：システムをつなぐ共通語

医療のシステムは、部門どうし、施設どうしでデータをやり取りします。そのための共通の規格を、厚生労働省は「厚生労働省標準規格」として認めています。2025年1月29日の一部改正の通知に載っている規格の一部を、分類して紹介します。

| 分類 | 規格の例 |
|---|---|
| マスタ・コード | 医薬品HOTコードマスター、ICD10対応標準病名マスター、臨床検査マスター、個別医薬品コード（YJコード）リスト |
| 画像 | 医療におけるデジタル画像と通信（DICOM） |
| データ交換 | JAHIS臨床検査データ交換規約、JAHIS処方データ交換規約、SS-MIX2ストレージ仕様書および構築ガイドライン |
| 文書（HL7 FHIR） | 処方情報、健康診断結果報告書、診療情報提供書、退院時サマリーのHL7 FHIR記述仕様 |
| セキュリティ | 「製造業者/サービス事業者による医療情報セキュリティ開示書」ガイド |

同じ通知は、標準規格の実装は現在のところ医療機関等に強制するものではないとしつつ、厚生労働省の施策や補助事業は標準規格の実装を踏まえたものにするとしています。電子カルテ情報共有サービスなど国の仕組みでHL7 FHIRが使われていることもあり、新しい案件ほど標準規格の知識が問われやすくなっています。

マスタの知識は地味ですが重要です。病名や医薬品のコードの対応がずれると、請求、連携、データ分析のすべてに影響します。移行の案件では、旧システムの独自コードを標準のマスタにどう対応づけるかが大きな作業になります。

## 案件ごとに必要な知識の深さは違う

| 案件の種類 | 深く求められやすい知識 |
|---|---|
| 電子カルテ・部門システムの導入 | 診療の流れ、オーダーの例外、部門の運用 |
| 医事会計・レセコン | 保険請求の流れ、診療報酬の改定への対応 |
| 国の仕組みへの対応 | 技術解説書の読み方、標準規格（HL7 FHIRなど） |
| データ活用・連携 | マスタとコード、SS-MIX2などのデータ形式 |
| PMO・医療機関側の支援 | 院内の部門の役割、ガイドラインの体系 |

## 身につけ方：参画前と参画中で分ける

### 参画前：公開資料で骨格を押さえる

- **安全管理ガイドラインの概説編**：対象、用語、法令との関係がまとまっており、医療情報システムの全体像をつかむ入口になる
- **国の仕組みの技術解説書**：オンライン資格確認、電子処方箋、電子カルテ情報共有サービスなどは、厚生労働省のページで事業者向けの資料が公開されている
- **標準規格の一覧**：担当する領域に関わる規格だけを、医療情報標準化推進協議会の情報で確かめる

### 体系的に学ぶなら医療情報技師の範囲が目安

日本医療情報学会の医療情報技師育成部会は、医療情報技師を、医療情報を安全かつ適切に管理・活用・提供する保健医療福祉分野の専門職として認定しています。能力検定試験で評価する知識は「医学・医療」「医療情報システム」「情報処理技術」の3つの領域です。資格を取るかどうかは別として、この3領域の到達目標は、何を学べばよいかの地図として使えます。資格の考え方は[資格の記事](/media/shikaku/)で整理しています。

### 参画中：現場の言葉を自分のメモに残す

参画したら、職種ごとの呼び方の違い（同じものを医師と医事課で別の名前で呼ぶ、など）や、例外の流れを自分の言葉でメモしておくと、次の案件でも使える知識になります。ただし、患者の情報や取引先の資料そのものを持ち出したり、メモに写したりすることは避けてください。経験の棚卸しの方法は[キャリアの棚卸しの記事](/media/tanaoroshi/)で扱います。

:::caution
診療報酬や国の仕組みの仕様は、改定や更新が続いています。古い版の知識のまま要件を話すと、現場の運用と食い違うことがあります。参画前に、厚生労働省などの公式ページで最新の版と日付を確かめてください。医療行為そのものの判断や、算定の解釈が必要な場面では、自分で結論を出さず、医療機関の担当部門に確かめることが大切です。
:::

## よくある質問

### 医学の知識はどこまで必要ですか？

多くの案件では、病名や薬の中身を理解するより、どの業務でどの情報が使われるかを理解することが求められます。用語は参画してから覚えることも多いので、まずは診療の流れと保険請求の骨格を押さえることをおすすめします。

### レセプトの点数計算まで覚えないといけませんか？

医事会計やレセコンの開発で算定の処理そのものを担う場合を除けば、細かい点数の規則まで覚える必要は少ない傾向があります。改定のたびに改修が起きること、病名と行為の整合が請求で見られることなど、仕組みの骨格を理解しておけば、多くの会話についていけます。

### 医療情報技師の資格は案件で必須ですか？

必須とされる案件は多くありません。ただ、学習範囲が医療・システム・情報処理の3領域にまたがるため、体系的に学ぶ目安になります。資格より、担当した業務と工程を具体的に説明できることのほうが見られます。
