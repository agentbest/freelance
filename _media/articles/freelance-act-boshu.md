フリーランス新法第12条では、従業員を使う発注者（特定業務委託事業者）が、**広告などで広く**フリーランスを募集するときに、募集情報に虚偽の表示や誤解を生じさせる表示をしてはならず、情報を正確かつ最新の内容に保たなければならないとされています。

対象になるのは「広く勧誘する」募集です。公正取引委員会のQ&Aでは、特定の1人に業務委託を打診する場合は原則として対象外ですが、1つの業務委託について2人以上に打診する場合は対象に含まれるとしています。2026年10月時点の法律・指針・Q&Aをもとに、ルールの中身と、フリーランスが案件情報を見るときの確認点を整理します。

## 義務を負うのは誰か、どんな募集が対象か

### 義務を負うのは「特定業務委託事業者」

第12条の義務を負うのは、フリーランスに業務委託をする事業者のうち、**従業員を使う個人、または役員が2人以上いるか従業員を使う法人**です（第2条第6項）。従業員を使わない個人のフリーランスが、別のフリーランスを募集する場合は、この条文の義務の対象ではありません。発注者の区分は[フリーランス新法の要点の記事](/media/freelance-act-overview/)で整理しています。

### 「募集」は広告等による広い勧誘

厚生労働省の指針では、「業務委託に係る特定受託事業者の募集」を、業務委託をしようとする者が自ら、または他の事業者に委託して、フリーランスになろうとする者に対して**広告等により広く勧誘すること**としています。専ら労働者の募集や、従業員を使う事業者への業務委託を想定した募集は含まれないとされています。

対象になる提供の方法として、指針は次のようなものを挙げています。

- 新聞・雑誌などの刊行物への掲載
- 文書の掲出・配布、書面の交付、ファクシミリ
- 電子メールやSNSのメッセージ機能など、受信者を特定して送る方法
- テレビ・ラジオ・オンデマンド配信、自社のWebサイト、クラウドソーシングのプラットフォームなど

### 1対1の打診と、一斉送信の扱い

Q&Aでは、知り合いに1対1で仕事を頼む場合のように、特定の1人を相手に打診する場合は、通常すでに契約交渉の段階にあり、交渉の中で条件の確認や変更ができるため、的確表示義務の対象外としています。一方、1つの業務委託について2人以上に打診する場合は対象になります。

また、事前に集めたアドレスにBccで一斉送信する場合でも、実質的に広く募集しているといえれば対象になるとされています。募集をプラットフォームの運営事業者などに委託した場合も、発注者の義務の対象です。

## 対象になる募集情報の中身

指針は、的確表示の対象となる情報を、次の5つに整理しています。

| 区分 | 主な中身 |
|---|---|
| 業務の内容 | 成果物や役務の内容、必要な能力・資格、検収の基準、知的財産権の扱い、違約金の定め など |
| 業務に従事する場所・期間・時間 | 想定される作業場所、納期、期間、時間 |
| 報酬 | 報酬の額（算定方法を含む）、支払期日、支払方法、諸経費の扱い、知的財産権の対価 など |
| 契約の解除（不更新を含む） | 解除の事由、中途解除のときの費用や違約金 |
| 募集を行う者に関する事項 | 業務委託をする者の名称や業績 など |

## 禁止される「虚偽の表示」

指針は、意図的に実際の条件と異なる募集情報を出すことや、実在しない業務の募集を出すことを、虚偽の表示としています。例として次のようなものが挙げられています。

- 別の事業者の名称で募集する
- 契約期間を偽って表示する
- 実際より低い報酬を予定しているのに、高い金額を表示する
- 業務委託をする予定がないのに募集を出す

一方、募集の後に当事者の合意で条件を変えた場合は、虚偽の表示には当たらないとされています。Q&Aでは、誤って表示した場合も虚偽の表示には当たらないものの、客観的に誤解を生じさせる表示であれば対象になるとしています。

## 禁止される「誤解を生じさせる表示」

虚偽でなくても、一般的・客観的に誤解を生じさせる表示は禁止されます。指針は、次のような点に留意するよう求めています。

1. 関係会社がある場合、業務委託を行う予定の者を明確にし、関係会社と混同されないようにする
2. フリーランスの募集と、労働者の募集が混同されないようにする
3. 報酬額などを、実際より高額であるかのように表示しない
4. 職種や業種について、実際の業務の内容と著しく離れた名称を使わない

### 6つの事項が欠けた募集は「誤解を生じさせる表示」

Q&Aでは、募集情報のうち、①募集を行う者の氏名または名称、②住所（所在地）、③連絡先、④業務の内容、⑤業務に従事する場所、⑥報酬のいずれかを欠くものは、「誤解を生じさせる表示」に当たり、第12条違反になるとしています。公正取引委員会の2026年の特設サイトでも、この6つの事項が示されています。

ただし、業務の内容や報酬を細かく書く必要まではなく、「応相談」や「◯円〜」のような書き方も認められるとされています。仲介事業者を使う場合の扱いも、Q&Aで示されています。

特設サイトでは、想定される違反の例として、実際より高い報酬額を意図的に表示すること、一例にすぎない報酬額を確約されているかのように表示すること、募集が終わった後も情報を掲載し続けることが挙げられています。

:::view
当社は、案件をご案内するときに、稼働日数・リモートの可否・希望金額を先に伺い、合う案件だけをご紹介しています。案件情報に書かれた条件は、その時点の見込みを含むことがあり、最終的な条件は契約の段階で書面になります。案件情報と、個別契約に書かれた条件を見比べて、違う点があれば署名前にご質問ください。ご質問いただければ確認します。
:::

## 「正確かつ最新」に保つための措置

指針は、募集情報を正確かつ最新の内容に保つため、次のような措置を求めています。

- 募集を終えたり内容を変えたりしたら、速やかに情報の提供を終える、または内容を変更する
- 広告などを他の事業者に委託している場合は、終了や変更を依頼し、対応されたかを確かめる
- 募集情報を出すときは、**その情報の時点**を明らかにする

委託先の事業者が虚偽や誤解を生じさせる表示をしていると知った場合も、発注者は訂正を依頼し、訂正されたかを確かめる必要があるとされています。

また、指針は望ましい取組として、対象となる事項をできるだけ含めて募集情報を出すこと、応募者にもこれらの事項を示すこと、事項を変える場合はその内容も示すことを挙げています。

## フリーランスが案件情報を見るときのポイント

第12条は発注者の義務ですが、ルールを知っておくと、案件情報を読むときの物差しになります。

1. **募集主がわかるか**：名称・所在地・連絡先が示されているか。エージェント経由なら、照会したときに答えてもらえるか
2. **業務の内容と場所**：何をする仕事か、どこで作業するか（リモートの可否を含む）
3. **報酬の書き方**：確定額か、幅か、一例か。「最大」「〜」の金額がどんな条件で出るのか
4. **情報の時点**：いつ時点の情報か。古い情報が残っていないか
5. **労働者の募集と混同していないか**：業務委託なのに勤務時間や指揮命令の前提で書かれていないか

案件票の項目ごとの読み方は[案件票の読み方の記事](/media/project-info-read/)で解説しています。応募した後、契約の段階で示される条件は、第3条の取引条件の明示として書面やメールで受け取るものです。確認の仕方は[取引条件の明示の記事](/media/freelance-act-terms/)をご覧ください。

:::caution
募集の段階で示された金額が、契約の段階で下がっていた場合、合意して条件を変えたのであれば虚偽の表示には当たりません。だからこそ、署名の前に、募集情報と契約書の条件を見比べることが大切です。違いに気づかないまま署名すると、契約書の条件が基準になります。
:::

## 違反を見つけたときの申出と行政の措置

第12条の違反について、フリーランスは厚生労働大臣に申し出て、適当な措置をとるよう求めることができます（第17条）。厚生労働大臣は、必要な調査を行い、違反していると認めるときは是正のための勧告をすることができ（第18条）、正当な理由なく勧告に従わない場合は命令し、その旨を公表することができます（第19条）。命令に違反した場合は、50万円以下の罰金の対象です（第24条）。

申出をしたことを理由に、取引を減らしたり停止したりするなどの不利益な取扱いをすることは禁止されています（第17条第3項で第6条第3項を準用）。相談先は[相談先の記事](/media/freelance-trouble-consult/)にまとめています。個別の事案が違反に当たるかの判断は、窓口や弁護士などの専門家にご相談ください。

:::view
案件紹介の現場では、案件情報に書かれた「〜」付きの金額を、そのまま自分が受け取る確定額と受け取ってしまう方をよく見かけます。金額の幅は、スキルの合い方や稼働日数で変わることが多いものです。気になる案件があれば、金額がどの条件で決まるのかを、応募の段階で質問しておくことをおすすめします。
:::

:::point
- 第12条の義務を負うのは、従業員を使う発注者（特定業務委託事業者）
- 対象は広告等による広い勧誘。特定の1人への打診は原則対象外、2人以上への打診は対象
- 虚偽の表示と誤解を生じさせる表示が禁止。名称・所在地・連絡先・業務内容・場所・報酬のいずれかが欠けると誤解を生じさせる表示とされる
- 募集を終えたら速やかに取り下げ、情報の時点を明らかにする
:::

## よくある質問

### 知り合いから直接声をかけられた仕事も、このルールの対象ですか？

特定の1人を相手に打診する場合は、通常すでに契約交渉の段階にあるため、原則として対象外とされています。ただし、同じ業務委託について2人以上に声をかけている場合は対象になります。どちらの場合も、契約の段階では第3条の取引条件の明示を書面やメールで受け取りましょう。

### フリーランスエージェントの案件情報も対象になりますか？

発注者が募集を他の事業者に委託した場合も、発注者の義務の対象とされています。また、フリーランスと直接業務委託契約を結ぶエージェントが自ら広く募集する場合は、そのエージェント自身が義務を負う立場になり得ます。どちらに当たるかは契約の関係によって変わるため、具体的な判断は専門家にご相談ください。

### 応募した案件の情報が、契約の段階で変わっていました。違反になりますか？

当事者が合意して条件を変えた場合は、虚偽の表示には当たらないとされています。一方、最初から実際と違う条件を意図的に表示していた場合は、虚偽の表示に当たり得ます。まずは変わった理由を確かめ、納得できない条件のまま署名しないことが大切です。違反の疑いがある場合は、相談窓口を利用できます。
