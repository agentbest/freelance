ゲームエンジニアの週2〜3日・副業の案件は、**週5日の案件と比べると少なめ**です。ゲームの開発は、毎日のビルドと試遊、仕様の変更、品質保証の担当とのやり取りが細かく回るため、チームに毎日いる人のほうが任せやすいからです。

ただし、**ツールやビルドの仕組み、サーバーの保守、技術の検証、性能の調査**のように、チームの毎日の流れから切り出しやすい仕事では、週2〜3日の案件も見つかります。この記事では、見つかりやすい案件の型、探し方、短い稼働で信頼を得る進め方、受けるときの注意点を整理します。週3日の働き方全般は[週3日のフリーランス案件の記事](/media/week3/)で解説しています。

## 週2〜3日のゲームの案件が少ない理由

ゲームの開発で週2〜3日の稼働が難しくなりやすいのは、主に次の事情からです。

- **毎日の流れが速い**：毎日ビルドが出て、触った人から指摘が届く。不在の日が多いと、指摘への対応が遅れる
- **仕様がよく変わる**：遊んでみて仕様が変わるたびに、プランナーとすぐに話す必要がある
- **節目に作業が集中する**：試遊会、提出、更新の前は作業が増え、決まった曜日だけでは収まりにくい
- **機材と情報の決まり**：家庭用ゲーム機の開発機材や未発表の情報を扱う作業は、場所や時間が限られやすい

反対に言えば、**毎日のやり取りが少なく、成果物の区切りがはっきりした仕事**なら、短い稼働でも任せやすくなります。

## 週2〜3日・副業で見つかりやすいゲームの案件

| 案件の型 | 中身の例 | 短い稼働と合う理由 |
|---|---|---|
| ツール・ビルドの仕組み | エディタの拡張、データを確かめる道具、ビルドの自動化 | 作るものの区切りがはっきりしている |
| サーバーの保守・改善 | 運営中のタイトルのAPIの改善、管理画面の機能追加 | 急ぎでない改善を計画的に進められる |
| 技術の検証 | 新しいエンジンの版や機能、外部のサービスの試し | 調べた結果を報告書にまとめて渡せる |
| 性能の調査 | 重い場面の計測と原因の特定、改善案の提示 | 計測と報告の単位で区切れる |
| 小規模なタイトルの開発 | 小さなチームでのクライアントの実装 | チーム全体の稼働が少なく、合わせやすい |

どの型でも、**チームの中で自分の担当がほかの人の作業を止めにくい**ことが共通しています。新規タイトルのゲームプレイの実装のように、毎日ほかの職種と受け渡しをする担当は、短い稼働では合わせにくくなります。単発で区切れる仕事は[スポット案件の記事](/media/spot-anken/)もご覧ください。

:::view
ゲームの案件をご紹介していると、週2〜3日の希望でも、担当を「ツール」「サーバーの改善」「性能の調査」のように絞っている方のほうが、合う案件が見つかりやすい傾向があります。反対に、週2日で新規タイトルのクライアント全般を担いたいという希望は、取引先が求める稼働と合いにくいことが多くあります。担える範囲を先に決めておくことをおすすめします。
:::

## 週2〜3日のゲームの案件の探し方

### 1. 担える範囲を先に決める

「週3日で何でも」より、「週3日でサーバーの改善とバッチの保守」「週2日でエディタの拡張」のように、担当を一つに絞って伝えるほうが、取引先は任せる絵を描きやすくなります。

### 2. 稼働する曜日と、稼働外の連絡の扱いを決める

ゲームの現場は毎日動いているため、稼働しない日にも質問が届きます。どの曜日に稼働し、稼働しない日の連絡にいつ返すかを先に決めておくと、参画後のずれを防げます。

### 3. 週5日の案件の一部を切り出してもらう

週5日の募集でも、その中のツールやサーバーの一部だけなら週2〜3日で受けられることがあります。案件票の稼働日数だけで判断せず、どの部分なら切り出せるかを相談してみましょう。

### 4. 経験の近い領域から選ぶ

短い稼働では、参画してから覚える時間が限られます。これまで多く担ってきた領域とエンジンに近い案件から選ぶと、最初の数週間で成果を出しやすくなります。働く場所の条件は[ゲームエンジニアのリモート案件の記事](/media/game-engineer-remote/)で整理しています。

## 短い稼働で信頼を得る進め方

- **稼働日の始めと終わりに短く報告する**：その日にやることと、終わったこと、次に誰の確認が要るかを文章で残す
- **成果物を小さく区切って渡す**：大きな機能を一度に出すより、確かめてもらえる単位で出す
- **不在の日に止まる作業を作らない**：自分の担当がほかの人の作業を止めそうなときは、先に決まりや代わりの手順を渡しておく
- **記録を一か所にまとめる**：設計の判断や直した理由を残し、不在の間もチームが同じ情報を見られるようにする

週5日の人と同じ量は出せなくても、**いつ何が届くかが分かる**ことで、短い稼働でも任せてもらいやすくなります。

## 受けるときの注意点

### 稼働日数と、任される範囲をそろえる

週2日の契約なのに、週5日の人と同じ範囲や締め切りを任されると、稼働時間を超えて働くことになりがちです。任される範囲と締め切りが稼働日数に見合っているかを、契約前に確かめましょう。

### 節目の時期の稼働の増え方を確かめる

試遊会や提出、更新の前に、稼働を増やしてほしいと頼まれることがあります。増やす場合の上限と、精算の仕方を先に決めておくと安心です。精算の仕組みは[精算幅の記事](/media/seisan-haba/)で解説しています。

### 当番と、機材の扱いを確かめる

運営中のタイトルでは、障害の当番を求められることがあります。週2〜3日の契約で当番に入るかどうか、入る場合の扱いを確かめておきましょう。開発機材や未発表の情報を扱う作業がある場合は、稼働日にだけ出社するのか、手元で作業できるのかも確かめます。

### 稼働時間の記録と、契約の形を確かめる

週2〜3日の契約では、月の稼働時間の幅が小さく決められていることが多く、少しの超過でも精算の扱いが問題になります。稼働した日と時間、作業の中身を日々つけておき、月末の報告にそのまま使えるようにしておきましょう。また、ツールの開発や技術の検証のように成果物で区切りやすい仕事は、作業すること自体に報酬が払われる準委任ではなく、成果物の完成に報酬が払われる請負の形で提示されることもあります。完成の責任や直しの扱いが変わるため、契約の形も確かめておくと安心です。違いは[準委任と請負の違い](/media/junin-vs-ukeoi/)で解説しています。

:::caution
複数の案件をかけもちするときは、同じ時期に発表前のタイトルを複数扱うことになる場合があります。秘密保持の約束はそれぞれの契約で決まっており、作業の場所や機器、資料の置き場を分けておかないと、思わぬ形で情報が混ざるおそれがあります。かけもちの考え方は[かけもちの記事](/media/kakemochi/)をご覧ください。
:::

## 会社員の副業でゲームの案件を受けるとき

会社員の方が副業でゲームの案件を受けるときは、次の点を先に確かめておきましょう。

- **勤務先の就業規則**：副業が禁止か、許可制か、届出制か。業務委託が対象に含まれるか
- **本業との競合**：本業と同じゲーム会社の取引先や、競合するタイトルに関わる案件は、競業や秘密の扱いで問題になりやすい
- **時間帯**：仕様の確認や品質保証とのやり取りは平日の日中に入ることが多く、本業の時間と重ならないか

厚生労働省は、副業・兼業の促進に関するガイドラインを公表しており、最新の改定は2022年（令和4年）7月です（2026年10月時点、厚生労働省による）。勤務先の決まりの考え方の参考になります。副業が禁止されている場合の考え方は[副業禁止の会社で業務委託を受けるときの記事](/media/fukugyo-kinshi/)、本業の取引先に関わる案件は[本業の取引先の案件の記事](/media/hongyo-torihikisaki/)で解説しています。副業の所得と確定申告の関係は[副業の20万円の記事](/media/fukugyo-20man/)をご覧ください。個別の税務の判断は税理士にご相談ください。

:::view
当社では、案件をご案内する前に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをお出ししています。週2〜3日の希望の場合は、稼働できる曜日と時間帯、稼働しない日の連絡への返し方もあわせてお伝えいただくと、案件を照らし合わせやすくなります。取引先が節目の時期にどの程度の稼働を想定しているかは、ご質問いただければ確認します。
:::

:::point
- ゲームの週2〜3日案件は少なめだが、ツール、サーバーの保守、技術の検証、性能の調査では見つかる
- 担える範囲を一つに絞り、稼働する曜日と稼働外の連絡の扱いを先に決める
- 稼働日の報告と、成果物を小さく区切って渡すことで、短い稼働でも信頼を得やすい
- 節目の稼働の増え方、当番、機材の扱い、会社員なら就業規則と競合を確かめる
:::

## よくある質問

### 週2〜3日の案件でも、ゲームエンジニアとしての経験として評価されますか？

評価されます。稼働日数より、何を担当し、どんな成果を出したかが見られます。ツールを作って作業の時間を減らした、性能の原因を特定して改善案を出したなど、成果を具体的に残しておくと、次の案件の面談で話しやすくなります。

### 週3日で始めて、あとから週5日に増やすことはできますか？

取引先の事情によっては可能です。ただ、最初から増やす前提で受けると、増やせなかったときに困ります。増やす可能性がある場合は、契約の更新の時期に相談できるかを、最初に確かめておくとよいでしょう。

### 平日の夜や週末だけでもゲームの案件は受けられますか？

ゲームの現場とのやり取りは平日の日中が中心のため、夜や週末だけの稼働で受けられる案件は限られます。ツールの開発や技術の検証のように、やり取りが少なく成果物で区切れる仕事なら、見つかることもあります。考え方は[週末だけのフリーランスの記事](/media/weekend-freelance/)が参考になります。
