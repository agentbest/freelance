IT業務のフリーランスが賠償責任保険で備えたいのは、**作業のミスで取引先のシステムを止めた、預かったデータを漏えいさせた、成果物が他人の権利を侵害していた**といった場面で、取引先や第三者から損害賠償を求められるリスクです。会社員なら会社が対応するこうした責任も、フリーランスは自分で負います。

ただし、保険を選ぶ前に確かめたいのは**契約書で自分がどこまで責任を負う約束になっているか**です。責任の範囲と上限を把握したうえで、保険の補償の対象業務・免責・支払限度額を見ると、備えの過不足が分かります（2026年10月時点）。

## フリーランスが負う賠償責任の2つの根拠

### 契約にもとづく責任（債務不履行）

民法第415条では、債務者が約束どおりに履行しないときは、債権者はそれによって生じた損害の賠償を請求できるとしています。ただし、債務者の責めに帰することができない事由によるときは、この限りでないとされています。

準委任の案件では、受任者は善良な管理者の注意をもって業務を行う義務を負います（民法第644条）。成果が出なかっただけで責任を負うわけではありませんが、専門家として通常求められる注意を怠り、それで損害が出た場合は責任を問われることがあります。準委任と請負の責任の違いは[準委任と請負の記事](/media/junin-vs-ukeoi/)で解説しています。

### 契約の外の責任（不法行為）

民法第709条では、故意または過失によって他人の権利や法律上保護される利益を侵害した者は、それによって生じた損害を賠償する責任を負うとしています。契約関係のない第三者に損害を与えた場合は、こちらが問題になります。

たとえば、客先で機器を壊した、エンドユーザーの個人情報を漏えいさせた、といった場面です。会社員であれば、使用者責任（民法第715条）によって会社も責任を負う場面ですが、フリーランスは自分が事業者として責任を負う立場です。

## IT業務で起きやすい損害の場面

| 場面 | 例 | 主に関わる責任 |
|---|---|---|
| 作業ミスによる障害 | 本番環境の設定変更を誤り、サービスが止まった | 契約上の責任 |
| 情報漏えい | 預かったデータを私物の端末に保存し、紛失した | 契約上の責任・不法行為 |
| 権利侵害 | 成果物にライセンス条件を守らないコードや素材が含まれていた | 契約上の責任・不法行為 |
| 納期・品質の問題 | 請負で受けた開発の成果物に不具合があった | 契約不適合責任 |
| 客先での事故 | 常駐先の設備を壊した、来訪者にケガをさせた | 不法行為 |

### 情報漏えいは発注者側の負担も大きい

個人情報保護委員会は、要配慮個人情報を含む個人データの漏えい等や、本人の数が1,000人を超える漏えい等などについて、事業者に委員会への報告を求めています。速報は発覚した日から3〜5日以内、確報は30日以内（不正の目的によるおそれがある場合は60日以内）が目安とされています。

報告や本人への対応、原因の調査は発注者側の大きな負担になり、その費用が損害として請求されることもあります。個人データを扱う案件では、発注者の情報管理のルールを守ることが何よりの備えです。秘密保持の条項は[NDAの記事](/media/nda/)で整理しています。

:::view
案件をご紹介していると、損害賠償の条項は「よくある文言」として読み飛ばされがちです。けれども、上限があるかどうか、どこまでの損害を対象にしているかで、万が一のときの負担は大きく変わります。当社がご案内する案件では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。担当する業務の範囲がはっきりしているほど、責任の範囲も明確になります。条項についてご不明な点は、ご質問いただければ確認します。
:::

## 保険を選ぶ前に契約書で確かめること

保険は、契約で負う責任をそのまま肩代わりしてくれるとは限りません。まず契約書の損害賠償の条項を、次の点で読みます。

1. **責任を負う条件**：「責めに帰すべき事由がある場合」に限られているか
2. **賠償の範囲**：直接かつ通常の損害に限るか、逸失利益まで含むか
3. **上限額**：個別契約の委託料を上限とするなどの定めがあるか
4. **請求できる期間**：業務の終了からいつまで請求されうるか

情報処理推進機構（IPA）の「情報システム・モデル取引・契約書（第二版）」は、損害賠償の累計総額を個別契約に定める金額までとする考え方を示し、第二版の見直しのポイントの一つに「重大な過失」の明確化を挙げています。上限の考え方と交渉の仕方は[損害賠償の上限の記事](/media/damages-cap/)で詳しく解説しています。

:::caution
契約で上限のない責任や、法律上の責任より重い責任を引き受けた場合、その加重された部分は保険の補償の対象外とされることがあります。保険があるから大丈夫と考えて契約条件を確かめずに署名すると、保険でまかなえない負担が残るおそれがあります。契約の条項と保険の約款の両方を確かめましょう。
:::

## IT業務の備えになる保険の種類

賠償責任に備える保険は、補償する場面によっていくつかの種類があります。名前は保険によって違うため、一般的な分け方で整理します。

| 種類 | 主に備える場面 |
|---|---|
| 業務の過誤に備える賠償責任保険（IT業務向け・専門業務向け） | 作業ミスや納品物の不具合で、取引先に経済的な損害を与えた |
| 情報漏えい・サイバーリスクに備える保険 | データの漏えいや不正アクセスによる賠償、事故対応の費用 |
| 施設や業務遂行中の事故に備える賠償責任保険 | 客先の設備を壊した、人にケガをさせた |

ITエンジニアやコンサルの場合、物を壊すより「作業の結果で取引先に経済的な損害を与える」リスクの方が中心です。施設や対人・対物の事故だけを補償する保険では、システム障害による損害は対象外のことがあります。

## 約款で確かめたい項目

- **対象になる業務**：システム開発、運用保守、コンサルティング、PMOなど、自分の業務が含まれているか
- **補償される費用**：損害賠償金のほか、争いになったときの弁護士費用などが含まれるか
- **支払限度額と自己負担額**：1事故あたり・期間中の合計の限度額、自分で負担する額
- **免責になる場合**：故意、契約で加重した責任、罰金や違約金、一定の権利侵害など
- **補償の時期**：保険期間中に起きた事故が対象か、保険期間中に請求されたものが対象か。案件が終わってから請求された場合の扱い
- **再委託した場合**：自分が人に任せた作業で起きた損害が対象になるか（[再委託の記事](/media/subcontract/)）

取引先から保険への加入を条件にされることもあります。その場合は、求められている補償の種類と限度額を確かめてから選びます。

## 働き方によって備えたい場面は変わる

同じITの仕事でも、働き方によって起こりやすい損害は違います。自分の案件に当てはめて、どの保険を優先して検討するかを考えます。

| 働き方 | 起こりやすい場面 | 優先して確かめたい補償 |
|---|---|---|
| 運用保守・インフラ | 本番環境の操作ミスによる停止 | 業務の過誤による経済的な損害 |
| 個人データを扱う開発 | データの持ち出しや誤送信 | 情報漏えいの賠償と事故対応の費用 |
| 請負での受託開発 | 納品物の不具合、納期の遅れ | 成果物の不具合による損害、争訟の費用 |
| コンサル・PMO | 助言や資料の誤りによる判断の誤り | 専門業務の過誤による損害 |
| 客先常駐 | 設備の破損、人へのケガ | 施設や業務遂行中の対人・対物の事故 |

複数の案件を掛け持ちしている場合は、案件ごとに業務の内容が違うことがあります。保険の対象業務に、すべての案件の業務が含まれているかを確かめておきましょう。

## 保険の前にできるリスクの減らし方

保険は損害が出たあとの備えです。損害そのものを起こしにくくする工夫もあわせて行います。

- **作業の範囲を書面で残す**：何をして何をしないかを個別契約やメールで確かめる
- **本番作業の手順を決める**：承認の手順、作業前の確認、元に戻す手順を取引先とすり合わせる
- **データの扱いを守る**：持ち出し、私物端末の利用、クラウドへの保存は取引先のルールに従う
- **ライセンスを確かめる**：外部のライブラリや素材の利用条件を記録しておく。成果物の権利は[著作権の記事](/media/copyright/)で解説しています

:::view
当社は、取引先の会社の実態と支払条件を確かめたうえで案件を扱っています。案件紹介の現場でよく見るのは、指示や仕様の変更を口頭だけで受け、あとで経緯を説明できずに困るケースです。本番環境に触れる作業や、個人データを扱う作業がある案件では、作業の範囲と承認の流れをメールなど記録の残る形で受け取っておくことをおすすめします。
:::

:::point
- 賠償責任は、契約にもとづく責任（民法415条）と不法行為の責任（民法709条）の2つ
- IT業務では、作業ミスによる障害・情報漏えい・権利侵害が主なリスク
- まず契約書で責任の条件・範囲・上限・期間を確かめる
- 保険は対象業務・補償される費用・限度額・免責・補償の時期を約款で確かめる
:::

## よくある質問

### 準委任の案件でも賠償責任保険は必要ですか？

準委任では、成果が出なかったことだけで責任を負うわけではありません。ただし、専門家として通常求められる注意を怠って損害が出た場合や、情報漏えいなどで第三者に損害を与えた場合は、責任を問われることがあります。扱うデータや作業の内容、契約上の上限の有無を見て、加入するかを判断しましょう。

### 取引先に賠償を求められたら、すぐに支払うべきですか？

その場で了承する必要はありません。損害の内容と金額、契約上の根拠を書面で示してもらい、保険に加入している場合は保険の窓口にも早めに連絡します。保険によっては、事前の相談なく賠償を約束すると補償されないことがあります。責任の有無に争いがある場合は、弁護士などの専門家にご相談ください。

### 所得補償保険とは何が違いますか？

賠償責任保険は、取引先や第三者に与えた損害を賠償するための保険です。所得補償保険は、自分が病気やケガで働けなくなったときの収入の減少に備える保険です。備える対象が違うため、必要に応じてそれぞれ検討します。所得補償保険は[所得補償保険の記事](/media/shotoku-hosho/)で解説しています。
