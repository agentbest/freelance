希望単価と提示額が合わないときは、すぐに受けるか断るかを決めず、**まず金額の前提をそろえ、差がどこから来ているかを分けて考えます**。差の原因は、多くの場合「前提の違い」「役割の見立ての違い」「発注側の予算」のどれかです。

原因が分かったら、あらかじめ決めておいた最低ラインと比べ、**そのまま受ける、条件を変えて受ける、見直しの時期を決めて受ける、見送る**のいずれかを選びます。この記事では、その順番と判断の材料を整理します。交渉そのもののタイミングと伝え方は[単価交渉の記事](/media/rate-negotiation/)で扱っています。

## まず前提をそろえる

希望額と提示額の差が、実は同じ条件で比べていないだけ、ということがあります。次の項目をそろえてから、差を見ます。

| そろえる項目 | ずれやすい例 |
|---|---|
| 税込か税別か | 希望は税別で考えていたが、提示は税込だった |
| 月額か1時間あたりか | 希望は時給から逆算していたが、提示は月額だった |
| 精算の条件 | 同じ月額でも、精算幅の上限が高い、精算なしの固定 |
| 稼働日数 | 週5日の希望額を、週4日の案件の提示と比べていた |
| 交通費・経費 | 交通費込みの提示か、別途精算か |
| 何の金額か | 案件票の「予算」と、自分の契約で受け取る金額を混同していた |

税込・税別の確かめ方は[税込・税別の記事](/media/tax-included/)、精算の仕組みは[精算幅の記事](/media/seisan-haba/)、1時間あたりへの直し方は[月額単価の換算の記事](/media/hourly-convert/)で解説しています。

前提をそろえると、差が小さくなったり、逆に広がったりします。この段階で見えた差が、考えるべき本当の差です。

## 差の原因を3つに分ける

前提をそろえても差が残る場合は、その差がどこから来ているかを考えます。

| 原因 | どういう状態か | 手がかり |
|---|---|---|
| 役割の見立ての違い | 自分は「リーダーとして」の額を考え、発注側は「メンバーとして」任せるつもり | 面談で聞かれた内容、任される範囲の説明 |
| 発注側の予算 | 役割の評価は合っているが、案件全体の予算に上限がある | 「予算の都合で」という説明、他の条件の柔軟さ |
| 経験の評価 | 求める経験の一部が足りないと見られている | 面談での質問の重点、見送りに近い評価のコメント |

### 役割の見立てが違うとき

希望額の根拠が「前の案件で担っていた役割」で、今回の案件では別の役割を想定されている場合です。この差は、金額だけを交渉しても縮まりにくく、**任される範囲**の話にすると整理できます。範囲を広げてもらうか、提示された役割に合わせて自分の希望を見直すかを考えます。

### 予算に上限があるとき

役割の評価は合っていても、発注側の予算に上限がある場合は、金額そのものは動きにくくなります。このときは、金額以外の条件で差を埋められないかを考えます。

### 経験の評価が足りないとき

求める経験の一部が足りないと見られている場合は、提示額が希望を下回るのは、ある意味で評価の結果です。この案件で経験を積むことに価値があるかどうかで、受けるかを考えます。

:::view
案件をご紹介していると、希望額と提示額の差が、実は前提の違い（税込と税別、週5日と週4日など）から来ている例をよく見かけます。当社では、案件をご案内するときに、先に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをお出ししています。ご希望の金額は、税込か税別か、月額か1時間あたりかを添えて伝えていただくと、提示の段階で前提がずれにくくなります。
:::

### 差が出やすい場面

次のような場面では、希望額と提示額の差が出やすくなります。自分が当てはまるかを先に考えておくと、提示を受けたときに慌てずに済みます。

- **独立した直後**：会社員時代の年収を月額に直して希望額にしていると、業務委託の役割ごとの条件と前提が合わないことがある
- **職種や領域を変えた直後**：前の領域での実績が、新しい領域ではそのまま評価されにくい
- **稼働日数を減らしたいとき**：週5日の月額を基準に、日数の割合で下がることが多い
- **間に入る会社が多い案件**：同じ役割でも、受け取る金額が変わる

どれも、提示額が低いこと自体が不当というわけではなく、金額の決まり方の結果です。原因が分かれば、受けるか、別の案件を探すかを落ち着いて決められます。

## 最低ラインと目標を分けておく

差を見たあとに判断がぶれるのは、「どこまでなら受けるか」が決まっていないときです。希望額は、**最低ライン**と**目標**の2つに分けておきます。

- **最低ライン**：これを下回ると生活と事業が成り立たない、または続ける意味がない額
- **目標**：役割と経験に見合うと考える額

最低ラインは、次の順に見積もります。以下はすべて**仮の数字**で、計算の手順を示すための例です。実際の金額は人によって大きく変わります。

1. 1年に必要な生活費：仮に360万円
2. 税金・社会保険料の見込み：仮に120万円（所得や自治体で変わるため、自治体の案内や税理士に確認する）
3. 事業の経費：仮に40万円
4. 案件のない期間への備え：仮に60万円
5. 合計：580万円
6. 案件がある見込みの月数で割る：仮に11か月なら、580万円 ÷ 11 ≒ 約53万円

この例では、税別の月額で約53万円が最低ラインの目安になります。提示額がこれを下回るなら、条件を変えるか、見送るかを考える目安になります。税金と保険料の見込みの立て方は[フリーランスと正社員の手取りの違い](/media/tedori-hikaku/)を参考にしてください。

## 選べる4つの返し方

最低ラインと比べたら、次の4つから選びます。

| 返し方 | 向いている場面 | 気をつけること |
|---|---|---|
| そのまま受ける | 最低ラインは上回っている。経験や条件に他の価値がある | 次の更新で見直すための材料を、参画中にためておく |
| 条件を変えて受ける | 金額は動かないが、他の条件に余地がある | 変えた条件を個別契約に書いてもらう |
| 見直しの時期を決めて受ける | 最初は様子見で、評価が出れば上げられる見込みがある | 時期と、見直しの観点を先に聞いておく |
| 見送る | 最低ラインを下回る。役割と金額の見立てが大きく違う | 理由を短く伝え、関係は保つ |

### 金額以外で差を埋める条件

金額が動かないときは、次の条件で実質の差を縮められることがあります。

- **稼働日数**：週5日を週4日にする。空いた日を別の案件や学習に使える
- **精算幅**：上限を下げる、精算なしを精算ありにする
- **リモートの割合**：出社の日数を減らし、移動の時間と交通費を減らす
- **契約期間**：最初の契約期間を短くし、更新の時点で見直しを相談する
- **業務範囲**：任される範囲を絞り、金額と役割の釣り合いを取る

どの条件で調整するかは、自分が何を重く見るかで決まります。案件を選ぶときの観点は[案件の選び方の記事](/media/project-selection/)にまとめています。

### 見直しの時期を決めて受けるとき

「参画後の評価を見て、次の更新で見直す」と言われた場合は、その言葉だけで受けず、次の点を確かめておきます。

- いつの更新で見直すのか
- 何をもって評価するのか（任される範囲、成果など）
- 見直しの話を誰と、いつするのか

口約束のままでは、更新の時期に話が進まないことがあります。合意したことはメールなどで残しておきます。更新の時期の交渉の進め方は[単価交渉の記事](/media/rate-negotiation/)をご覧ください。

:::caution
提示額が低いと感じても、面談の場で発注側の担当者に直接金額の不満を伝えるのは避けた方が無難です。エージェント経由の案件では、条件の話は担当者を通して行うのが一般的です。また、一度受けた金額をすぐに上げてほしいと求めるのは難しいことが多いため、受けるかどうかは条件提示の段階で決めておきます。
:::

## 見送るときの考え方

最低ラインを下回る、役割の見立てが大きく違う、といった場合は、見送ることも選択肢です。見送るときは、理由を短く、事実で伝えます。

> ご提示いただいた条件を検討しましたが、今回は希望する条件との差が大きく、辞退させていただきます。機会をいただきありがとうございました。

条件が理由の辞退は、珍しいことではありません。伝え方とタイミングは[案件を辞退するときの記事](/media/decline-offer/)で整理しています。

### 同じ差が何度も続くとき

複数の案件で同じように提示額が希望を下回る場合は、希望額の根拠を見直す時期かもしれません。

- 希望額が、前の案件の役割や商流の条件を前提にしていないか
- 今応募している案件の役割と、希望額の根拠になっている役割が合っているか
- スキルシートで、その役割の経験を具体的に示せているか

案件ごとの金額は、商流によっても変わります。仕組みは[商流の記事](/media/shoryu/)と[エージェントのマージンの記事](/media/agent-margin/)で解説しています。長い目で単価を上げる考え方は[単価を上げるための考え方](/media/raise-rate/)にまとめています。

:::view
当社では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。金額以外の条件で折り合った場合も、変えた稼働日数や精算の条件が個別契約にそのまま書かれているかを、受け取った時点で見比べることをおすすめします。提示された条件の前提が分かりにくいときは、ご質問いただければ確認します。
:::

:::point
- 差を見る前に、税込・税別、精算幅、稼働日数、交通費などの前提をそろえる
- 差の原因を「役割の見立て」「予算」「経験の評価」に分ける
- 最低ラインと目標を分けておき、最低ラインと比べて判断する
- 金額が動かないときは、稼働日数・精算・リモート・期間・範囲で調整を考える
:::

## よくある質問

### 提示額が希望より少し低いだけなら、受けた方がよいですか？

最低ラインを上回っていて、案件の内容や働き方に価値があるなら、受ける判断もあり得ます。その場合は、参画中に役割の広がりや成果を記録しておき、更新の時期に見直しを相談できるように準備しておくと、次につながります。

### 希望額は高めに伝えておいた方がよいですか？

根拠のない高い額を伝えると、合う案件が少なくなり、紹介や提案の機会が減ることがあります。最低ラインと目標を分けて考え、目標の額を根拠とあわせて伝える方が、条件の話が進みやすくなります。

### 提示額の根拠を聞いてもよいですか？

聞いてかまいません。どの役割を想定した金額か、精算の条件はどうか、といった点を確かめることは、判断に欠かせない情報です。エージェント経由の案件では、担当者に尋ねる形にします。
