ORACLE MASTERは、フリーランスにとって**Oracle Databaseの管理やSQLの知識を体系的に持っていることの裏付けにはなりますが、資格だけでデータベースの案件に参画できるとは限りません**。業務委託の面談で先に見られるのは、どの規模のデータベースで、構築・運用・性能改善・移行のどこを担ったかという実務の経験です。

効きやすいのは、Oracle Databaseを使う環境が決まっている案件や、開発・運用の経験から管理の工程へ広げたい時期です。この記事では、資格の体系、効く場面と効かない場面、実務との組み合わせ方、スキルシートでの書き方を整理します（2026年10月時点の日本オラクルの公式サイトによる）。

## ORACLE MASTERの体系

ORACLE MASTERは、日本オラクルのOracle Universityが案内しているOracle Databaseの認定資格です。2026年10月時点では、Oracle Database 19cに対応する「ORACLE MASTER 2019」と、Oracle AI Database 26aiに対応する資格の2つの体系が案内されています。

### グレードと証明されるスキル

| グレード | 19c対応（2019） | 26ai対応 | 主に示すスキル |
|---|---|---|---|
| Bronze DBA | 1Z0-085-JPN | 1Z0-185-JPN | データベースの基礎知識、アーキテクチャと用語の理解 |
| Silver DBA | 1Z0-082-JPN | 1Z0-182-JPN | 日常的な運用管理、障害の一次対応 |
| Gold DBA | 1Z0-083-JPN | 1Z0-183-JPN | 環境設計・構築、バックアップとリカバリ、性能管理、障害対応 |
| Platinum DBA | 実技試験 | 提供予定 | ミッションクリティカルな環境での設計・構築・運用 |
| Silver SQL | 1Z0-071-JPN | 1Z0-171-JPN | SQLによる問い合わせ、データの操作、表の管理 |

Bronze DBAとSilver DBAは前提資格がなく、Gold DBAはSilverの資格、Platinum DBAはGoldの資格が前提です。19c対応のSilver DBAはSQLの基礎も範囲に含みますが、26ai対応のSilver DBAは管理の分野に絞られ、SQLは出題されなくなりました。そのぶん、SQLの知識はSilver SQLで示す形がはっきりしています。26ai対応のBronzeとSilverはマルチテナント環境を前提とした出題になり、Goldの主な出題分野には性能管理が加わっています。

### 有効期限の考え方

ORACLE MASTERは、対象のバージョンごとに資格が分かれています。公式サイトでは、12cの試験は配信を終えたものの、取得した資格が失効するわけではないと案内されています。一方で、資格名にバージョンが入るため、どのバージョンの知識を学んだかが名前から読み取られます。古いバージョンの資格から新しい体系へ移る移行の道筋も用意されています。

## 案件で効く場面と効かない場面

### 効きやすい場面

- **Oracle Databaseを使う環境が決まっている案件**：基幹システムの保守や更改など、製品が決まっている案件では、知識の範囲がそのまま重なります
- **開発から管理の工程へ広げるとき**：SQLを書く開発の経験から、バックアップや性能の管理へ広げたい時期に、管理の知識を体系的に持っていることを示せます
- **バージョンアップや移行の案件**：新しいバージョンの資格は、新しい機能や構成の考え方を学んでいることの裏付けになります

### 効きにくい場面

- **性能改善やトラブル対応を任される案件**：実際に遅いSQLを特定して直した経験や、障害から復旧した経験が先に問われます。案件で見られる力は[データベースエンジニアのスキルの記事](/media/db-engineer-skills/)で整理しています
- **Oracle以外のデータベースが中心の案件**：考え方は生きますが、資格の名前の効き目は小さくなります
- **Oracleの業務アプリ（ERP）の導入案件**：同じ「Oracle」でも、ERPの導入は業務とアプリの設定の知識が中心で、データベースの資格とは別の領域です。ERPの資格は[Oracle ERPコンサルの資格の記事](/media/oracle-erp-shikaku/)で扱っています

:::view
案件紹介の現場では、データベースの案件の面談で「バックアップから実際に戻したことがあるか」「遅いSQLをどう見つけたか」をよく確かめられる傾向があります。ORACLE MASTERの学習で身につけた用語や仕組みは、こうした質問に答えるときの説明の土台になります。資格の名前だけを並べるより、その知識を使った場面を一つ話せるようにしておくことをおすすめします。
:::

## 実務経験との組み合わせ方

グレードと実務の担当範囲をそろえると、資格と経験が一つの流れとして伝わります。

1. **Silver SQL・Silver DBA**：SQLの作成や日々の運用を担っている時期。定期的な作業の手順化や、障害の一次対応の経験と組み合わせます
2. **Gold DBA**：環境の構築やバックアップの設計を担う時期。復旧の手順を作って試した経験、性能の数値を見て対策した経験と組み合わせます
3. **Platinum DBA**：止められないシステムの設計や運用を担う時期。可用性の構成や、高度な障害対応の経験と組み合わせます

データベースの土台になるOSの知識を補いたい場合は[LinuC・LPICの記事](/media/cert-linuc/)が、製品に依存しない設計の知識を示したい場合は[データベーススペシャリスト試験の記事](/media/cert-ipa-db/)が参考になります。

## スキルシートでの書き方

資格欄には、正式な名称、対象のバージョン、取得年月を書きます。グレードとバージョンの両方が名前に入るため、省略せずに書くと正確に伝わります。

- 例：「ORACLE MASTER Gold DBA 2019 20XX年X月取得」
- 例：「ORACLE MASTER Silver SQL Oracle AI Database 26ai 20XX年X月取得」

経歴欄には、資格の範囲と重なる作業を具体的に書きます。

- 「Oracle Database 19cのバックアップ方式を見直し、復旧の手順書を作成して年1回の復旧訓練を実施」
- 「夜間バッチの遅延の原因となるSQLを実行計画から特定し、索引の追加で処理時間を短縮」

データベースの経歴全体の書き方は[データベースエンジニアのスキルシートの記事](/media/db-engineer-skillsheet/)と[スキルシートの書き方の記事](/media/skillsheet-basics/)で紹介しています。

:::caution
「ORACLE MASTER Gold」のようにバージョンを省いて書くと、どの時期の範囲で取ったのかが分かりません。古いバージョンの資格でも失効するわけではありませんが、案件で扱うバージョンと離れている場合は、新しいバージョンでの実務経験を経歴欄で補ってください。試験の内容や移行の道筋は変わることがあるため、受験の前に公式サイトを必ずご確認ください。
:::

## 受験の準備と案件との両立

### 19c対応と26ai対応のどちらを受けるか

狙う案件で扱うバージョンを、案件票で確かめます。既存のシステムの保守が中心なら現行のバージョンに近い体系が、新しい環境の構築や移行が中心なら新しい体系が、範囲として重なりやすくなります。Gold DBAの前提資格は、19c対応と26ai対応の間で相互に有効と案内されています。案件票の読み方は[案件票の読み方の記事](/media/project-info-read/)で解説しています。

### 実機で手順を確かめる

バックアップと復旧、ユーザーと権限の管理、性能の確認などは、検証環境で一度ずつ手を動かしておくと、試験の理解も面談での説明も深まります。Platinumの実技試験に向けては、公式が公開している試験内容のチェックリストを実機で試す準備が案内されています。

### 取引先の環境は学習に使わない

参画中の案件の環境を、資格の学習のために使うことは、契約や秘密保持の範囲を確かめずに行わないでください。学習は自分で用意した環境で行うのが基本です。

:::view
当社では、取引先の会社の実態と支払条件を確かめた案件を扱っています。データベースの案件は、夜間の作業や障害時の呼び出しの有無で働き方が大きく変わるため、案件票の稼働条件とあわせて確かめておくことをおすすめします。資格が必須か歓迎かが読み取りにくいときは、ご質問いただければ確認します。
:::

:::point
- ORACLE MASTERは19c対応（2019）と26ai対応の2つの体系があり、Bronze・Silver・Gold・Platinum・Silver SQLに分かれる
- 26ai対応のSilver DBAはSQLを出題せず、SQLはSilver SQLで示す形になった
- 資格は失効しないが、名前にバージョンが入るため、案件のバージョンとの距離が読まれる
- スキルシートにはグレードとバージョンを省略せずに書き、使った作業を経歴欄で示す
:::

## よくある質問

### ORACLE MASTERがあればデータベースの案件に参画できますか？

資格だけで参画が決まることは多くありません。データベースの案件では、構築・運用・性能改善などの実務の経験が先に見られます。資格は、その経験に添える知識の裏付けとして使うと効果があります。

### 古いバージョンのORACLE MASTERは書いても意味がありますか？

書いて問題ありません。取得した資格が失効するわけではないためです。ただ、案件で扱うバージョンと離れている場合は、新しいバージョンで担った作業を経歴欄で示すと、知識が今の環境につながっていることが伝わります。

### 開発者はSilver SQLとSilver DBAのどちらを受ければよいですか？

SQLを書く開発が中心なら、SQLの知識を示すSilver SQLが内容に合います。運用や管理の工程にも広げたい場合は、Silver DBAで管理の範囲を学ぶと、担える範囲を説明しやすくなります。
