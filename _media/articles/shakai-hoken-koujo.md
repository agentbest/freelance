国民健康保険料（国民健康保険税）や国民年金保険料は、その年に実際に払った金額の全額が社会保険料控除になります。上限はありません。経費ではなく、確定申告書の「所得から差し引かれる金額」の欄に書く所得控除です（2026年10月時点。国税庁のタックスアンサーは令和8年4月1日現在の法令）。

数えるのは「その年に払った額」で、どの年度の保険料かは問いません。過去の未納分をまとめて払えば払った年の控除になり、前納した保険料には扱いを選べるものがあります。国民年金保険料と国民年金基金の掛金は、証明書の添付か提示が必要です。この記事では、フリーランスが控除の金額を数えるときの決まりを順番に整理します。

## 社会保険料控除の対象になる保険料

国税庁が示す社会保険料控除の対象は14項目あります。フリーランスに関係しやすいものを抜き出すと次のとおりです。

| 保険料 | フリーランスとの関係 |
|---|---|
| 国民健康保険の保険料・国民健康保険税 | 独立後に加入する人が多い（[国民健康保険の記事](/media/kokuho/)） |
| 国民年金の保険料 | 第1号被保険者として自分で納める（[国民年金の記事](/media/kokumin-nenkin/)） |
| 健康保険・厚生年金保険の保険料（被保険者として負担するもの） | 独立した年の会社員期間に給与から差し引かれた分など |
| 介護保険料 | 40歳以上が対象。40〜64歳で国民健康保険に加入している人は国民健康保険料と一緒に納める（[介護保険料の記事](/media/kaigo-hoken/)） |
| 国民年金基金の掛金 | 加入している場合（[国民年金基金の記事](/media/nenkin-kikin/)） |
| 労働者災害補償保険の特別加入の保険料 | 特別加入している場合（[労災保険の特別加入の記事](/media/rousai-special/)） |
| 雇用保険の被保険者として負担する労働保険料 | 会社員期間の分 |
| 後期高齢者医療制度の保険料 | 75歳以上の家族の分を払う場合など |

控除できる金額は、その年に実際に払った金額、または給与や公的年金から差し引かれた金額の全額です。所得税の控除の中には上限が決まっているものも多いのですが、社会保険料控除には上限がありません。

### iDeCoと小規模企業共済は別の控除

iDeCo（個人型確定拠出年金）の掛金と小規模企業共済の掛金は、社会保険料控除ではなく「小規模企業共済等掛金控除」の対象です。どちらも、その年に払った掛金の全額が控除になります。申告書では欄が分かれているため、混ぜて書かないようにしてください。制度の中身は[iDeCoの記事](/media/ideco/)と[小規模企業共済の記事](/media/shokibo-kyosai/)で解説しています。

国民年金基金は社会保険料控除、iDeCoは小規模企業共済等掛金控除と、似た目的の制度でも控除の種類が違います。

## 経費ではなく所得控除として書く

国民健康保険料や国民年金保険料は、事業のための支出ではなく個人の保険料です。会計ソフトで事業用口座から払った場合も、経費の科目ではなく「事業主貸」などで処理し、確定申告書の社会保険料控除の欄に書きます。

経費に入れても所得控除に入れても、所得税の額は同じになると考えがちですが、そうとは限りません。経費は事業所得を下げ、所得控除は事業所得を出した後に差し引くものです。事業所得の額は、国民健康保険料の計算や、基礎控除などの区分を決める合計所得金額にも使われます。保険料を経費に入れると、これらの数字がずれてしまいます。

## 「その年に払った額」で数える

社会保険料控除は、保険料がどの年度の分かではなく、その年中に払ったかどうかで数えます。国税庁のQ&Aでは、次の場面の扱いが示されています。

| 場面 | 控除の扱い |
|---|---|
| 生計を一にする子の過去3年分の国民年金保険料をまとめて払った | 本年中に払ったものなら、過去の年分でも本年分の控除の対象 |
| 本年中に翌年3月までの1年分の保険料を前納した | 前納した期間が1年以内なら、本年分の控除にしてよい。各年分に相当する額を各年に控除する方法も選べる |
| 国民年金保険料の「2年前納」をした | 前納した2年分の全額を、払った年の控除にしてよい。各年分に相当する額を各年に控除する方法も選べる |
| 生計を一にしていた子が年の途中で別生計になった後も、子の保険料を払い続けた | 生計を一にしていた期間に払った分だけが控除の対象 |
| 扶養している配偶者の公的年金から介護保険料が差し引かれた | 払ったのは配偶者なので、納税者の控除の対象にならない |

未納だった保険料を後から納めた場合も、払った年の控除になります。国民年金の追納や後納の仕組みは[追納の記事](/media/kokunen-tsuino/)をご覧ください。

### 2年前納はどちらの方法を選ぶか

2年前納をした年は、払った年に全額を控除する方法と、各年に分けて控除する方法を選べます。所得税は所得が増えた部分に高い税率がかかるため、所得の多い年に控除をまとめた方が、税金の減り方は大きくなります。独立1年目で所得が少ない年に2年前納した場合は、各年に分けた方がよいこともあります。住民税への影響もあるため、迷う場合は税務署にご確認ください。

:::caution
控除の対象は「実際に払った額」です。12月に届いた納付書を年明けに払った場合、その保険料は翌年の控除になります。口座振替の引き落とし日が年をまたぐ場合も、引き落とされた年で数えます。
:::

## 家族の保険料を払った場合

国税庁によると、自分または自分と生計を一にする配偶者・その他の親族が負担すべき社会保険料を払った場合、払った金額は自分の社会保険料控除の対象になります。生計を一にする家族の国民健康保険料や国民年金保険料を払っていれば、その分も合算できます。

ただし、払ったのが誰かで判断します。家族の年金から差し引かれた保険料は、その家族が払ったことになるため、自分の控除にはできません。後期高齢者医療制度の保険料を口座振替で払う場合は、口座の名義人（被保険者本人か、生計を一にする家族）の控除になります。

:::view
案件をご案内するときは、先に稼働日数・リモートの可否・希望金額を伺い、条件に合う案件を出しています。取引先へ出社する日がある案件では、移動中や作業中のけがへの備えが話題になることがあります。業務委託のフリーランスは、会社員のように取引先の労災保険の対象にはならないためです。労災保険の特別加入の対象になるかを[特別加入の記事](/media/rousai-special/)で確かめておくことをおすすめします。特別加入の保険料も、払った年の社会保険料控除の対象です。
:::

## 確定申告での書き方と必要な書類

### 国民年金・国民年金基金は証明書が必要

国税庁によると、国民年金保険料と国民年金基金の掛金について控除を受けるには、払った金額を証明する書類（または電磁的記録印刷書面）を確定申告書に添付するか、提出の際に提示する必要があります。証明書は日本年金機構や国民年金基金から届きます。

令和8年分以後の確定申告書を令和9年（2027年）1月1日以後に出す場合は、証明書の添付・提示に代えて、一定の事項を書いた明細書を確定申告書に添付することもできます。

### 国民健康保険料は1年分の合計を書く

国民健康保険料は、1月から12月までに払った額を合計して書きます。市区町村から届く納付書の控えや、口座振替の記録で確かめられます。支払額のお知らせを出している市区町村もあるため、手元の記録と合わない場合は市区町村の窓口に問い合わせてください。

### 独立した年は会社員期間の分を合算する

年の途中で退職して独立した場合は、次の2つを合計します。

1. 会社員期間に給与から差し引かれた健康保険料・厚生年金保険料・雇用保険料など（退職時の源泉徴収票に記載がある）
2. 退職後に自分で払った国民健康保険料・国民年金保険料など

退職後に健康保険の任意継続を選んだ場合の保険料も、その年に払った分を数えます（[任意継続の記事](/media/nini-keizoku/)）。1を書き忘れると控除が小さくなり、税金を多く払うことになります。

## 控除でどのくらい税金が減るか（仮の数字）

数字は説明のための仮のものです。所得控除は、控除額にその人の税率を掛けた分だけ所得税が減ります。

| 1年間に払った社会保険料 | 所得税の税率 | 所得税が減る目安 |
|---|---|---|
| 80万円 | 10% | 約8万円 |
| 80万円 | 20% | 約16万円 |

実際には、これに復興特別所得税の分が加わり、住民税も社会保険料控除で下がります。税率の区分は[所得税の計算の記事](/media/shotokuzei-keisan/)で確認できます。ほかの所得控除との関係は[所得控除の一覧の記事](/media/shotoku-koujo-ichiran/)にまとめています。

:::view
当社が扱っているのは、取引先の会社の実態と支払条件を確かめた案件です。報酬の支払期日が個別契約で分かっていれば、国民健康保険料や国民年金保険料の納期と入金日を並べて、どの口座から払うかを先に決めておけます。保険料を事業用口座と個人の口座から混ぜて払うと、確定申告で1年分を集計するときに漏れが出やすくなります。払う口座を1つに決め、退職時の源泉徴収票も申告まで残しておくことをおすすめします。
:::

:::point
- 国民健康保険料・国民年金保険料などは、その年に払った全額が社会保険料控除。上限はない
- 経費ではなく所得控除。iDeCo・小規模企業共済は別の控除（小規模企業共済等掛金控除）
- 過去の分を払えば払った年の控除。1年以内の前納と2年前納は、払った年にまとめるか各年に分けるか選べる
- 国民年金・国民年金基金は証明書の添付か提示が必要。独立した年は会社員期間の分も合算する
:::

控除の年分の選び方や家族分の扱いで迷う場合は、税理士・税務署にご相談ください。

## よくある質問

### 国民健康保険料を経費として計上してしまいました。どうすればよいですか？

国民健康保険料は経費ではなく、社会保険料控除として申告します。申告前なら、経費から外して控除の欄に書き直してください。すでに申告した後なら、所得の額が変わるため、修正の手続きが必要になることがあります。手続きは[修正申告と更正の請求の記事](/media/shusei-shinkoku/)をご覧ください。

### 去年払えなかった国民年金保険料を今年まとめて払いました。どの年の控除になりますか？

今年の控除になります。国税庁のQ&Aでは、本年中に払ったものであれば、過去の年分の保険料でも本年分の社会保険料控除の対象になるとされています。

### 配偶者の国民年金保険料を自分の口座から払っています。自分の控除にできますか？

生計を一にする配偶者が負担すべき保険料を自分が払っている場合は、自分の社会保険料控除の対象にできます。国民年金保険料の控除を受けるときは、払った金額を証明する書類の添付か提示が必要です。
