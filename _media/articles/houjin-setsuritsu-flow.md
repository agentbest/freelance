フリーランスが会社を作るときは、**会社の基本事項を決める → 定款を作る（株式会社は公証人の認証を受ける） → 出資を払い込む → 法務局に設立登記を申請する**、の順に進みます。会社が成立するのは、登記所が設立登記の申請を受け付けた日です。

登記が終わってからも手続きは続きます。年金事務所への新規適用届は事実の発生から5日以内、税務署への法人設立届出書は設立の日から2か月以内と、期限の短いものが重なります。この記事では、設立の前後にやることを順番に並べ、期限を一覧にします（2026年10月時点）。法人化するかどうかの判断は[法人化を考えるタイミングの記事](/media/incorporation-timing/)、会社の形の選び方は[合同会社と株式会社の違いの記事](/media/godo-vs-kabushiki/)をご覧ください。

## 設立から届出までの全体の流れ

一人で会社を作る場合の大まかな流れは次のとおりです。

| 順番 | やること | 相手先 | 目安の時期 |
|---|---|---|---|
| 1 | 商号・本店・目的・資本金・役員・事業年度を決める | — | 設立の数週間前 |
| 2 | 定款を作る。株式会社は公証人の認証を受ける | 公証役場（株式会社のみ） | 登記の前 |
| 3 | 出資金を払い込む | 自分名義の口座など | 定款を作った後、登記の前 |
| 4 | 設立登記を申請する | 本店を管轄する法務局 | 設立日にしたい日 |
| 5 | 社会保険の新規適用届 | 年金事務所・事務センター | 事実の発生から5日以内 |
| 6 | 法人設立届出書など | 税務署 | 設立の日から2か月以内 |
| 7 | 法人設立届（地方税） | 都道府県・市区町村 | 自治体が定める期限 |
| 8 | 個人事業の廃業の届出など | 税務署ほか | 個人事業をやめるとき |

手順1〜4は「会社を作る」手続き、5〜8は「会社として動き出す」手続きです。後半は期限が短いため、登記の前から書類を用意しておくと慌てずに済みます。

## 手順1：登記の前に決めておくこと

定款と登記申請書に書く内容を先に決めます。主なものは次のとおりです。

- **商号（会社名）**：株式会社・合同会社の文字を入れる。取引先の請求書や契約書にそのまま載る名前になる
- **本店所在地**：自宅を本店にする場合は、賃貸借契約や管理規約で事業用の登記が認められているかを確かめる
- **事業目的**：実際に受ける業務（システム開発、ITコンサルティングなど）が入るように書く。取引先や金融機関が登記事項証明書で確かめることがある
- **資本金の額**：登録免許税や定款認証の手数料、消費税の納税義務の判定に関わる
- **役員**：一人会社なら自分が代表取締役（合同会社なら代表社員）になる
- **事業年度**：決算月を決める。設立日からの期間で1期目の長さが決まる

事業年度は、決算と申告の時期、役員報酬を決め直す時期に関わります。役員報酬は原則として事業年度の開始から3か月以内に決めるため、設立時に報酬の額も考えておく必要があります。決め方は[役員報酬の記事](/media/yakuin-hoshu/)で解説しています。

## 手順2：定款を作り、株式会社は公証人の認証を受ける

定款は、会社の名前・目的・本店・資本金などの基本ルールを書いた書類です。合同会社は公証人の認証が要りませんが、株式会社は認証を受けなければ定款の効力が生じません。

日本公証人連合会の案内による、株式会社の定款認証の主な点は次のとおりです。

| 項目 | 内容 |
|---|---|
| 実質的支配者の申告 | 認証の嘱託までに、実質的支配者となるべき者の氏名・住居・生年月日などと、暴力団員等に該当しないかを申告する |
| 認証の手数料 | 資本金100万円未満は3万円、100万円以上300万円未満は4万円、それ以外は5万円 |
| 手数料の特例 | 資本金100万円未満で、発起人が全員自然人で3人以下、発起人が設立時の株式をすべて引き受ける、取締役会を置かない、のすべてに当たれば1万5,000円 |
| 収入印紙 | 紙の定款は4万円。電子定款なら不要 |
| 謄本 | 1枚250円。登記に使う謄本も必要 |
| 必要書類 | 発起人の印鑑登録証明書（発行後3か月以内）など |
| 面談の方法 | 電子定款は、2024年3月から原則としてウェブ会議で面前審査を行う |

一人で株式会社を作る場合は、資本金100万円未満で上の特例に当たることも多く、手数料が1万5,000円になることがあります。ただし、定款の内容で当たるかどうかが決まるため、作成を依頼する司法書士などに確かめてください。

また、株式会社では、電子定款の認証と設立登記の申請をオンラインで同時に行う仕組みがあります。一定の要件を満たせば、申請から24時間以内に登記が完了する運用です。ウェブ会議での認証が前提で、認証予定日の当日に申請するなどの条件があります。

## 手順3：出資の払込みと設立登記の申請

定款ができたら、出資金を払い込み、本店所在地を管轄する法務局に設立登記を申請します。

### 申請の方法

法務局の案内では、申請はオンラインでも書面でもできます。一人会社の設立登記は、完全オンライン申請が推奨されています。書面で出す場合は、法務局のサイトに株式会社（取締役会の有無などの区分ごと）と合同会社の申請書の様式・記載例があります。

申請のときには、会社の印鑑を届け出る「印鑑届書」も出します。印鑑届書には、市区町村長が作成した3か月以内の印鑑証明書などを添付します。

### 登録免許税

設立登記には登録免許税がかかります。国税庁の税額表（令和8年4月1日現在法令等）では次のとおりです。

| 会社の種類 | 登録免許税 |
|---|---|
| 株式会社 | 資本金の額×1,000分の7（15万円に満たないときは15万円） |
| 合同会社 | 資本金の額×1,000分の7（6万円に満たないときは6万円） |

### 設立日は「申請を受け付けた日」

法務局の案内では、会社は設立の登記によって成立し、設立年月日は登記所が申請書を受け付けた日になります。登記が完了した日ではありません。設立日は事業年度の始まりや、社会保険・税務の届出の期限の起点になるため、申請する日を決めてから動くと計画が立てやすくなります。

:::caution
出資金の払込みは、定款を作った後、登記を申請する前に行います（株式会社の同時申請では、定款作成日以降かつ登記申請までと案内されています）。順番を誤ると書類を作り直すことがあります。登記事項証明書が取れるのは登記の完了後なので、銀行口座の開設や取引先への届出は、完了の見込みを確かめてから進めてください。
:::

:::view
法人化を決めた方には、参画中の案件の契約期間と照らして設立日を決めることをおすすめします。当社では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししているため、次の更新日がいつかは契約書で分かります。更新日の少し前に登記を終えておくと、更新のタイミングで契約の名義を法人に移しやすくなります。設立日が決まったら、早めにご相談ください。
:::

## 手順4：登記のあとに出す届出

会社が成立したら、税務署・地方自治体・年金事務所へ届け出ます。主なものと期限をまとめます。

| 届出 | 提出先 | 期限 |
|---|---|---|
| 健康保険・厚生年金保険 新規適用届 | 事務センターまたは年金事務所 | 事実の発生から5日以内 |
| 法人設立届出書（定款等の写しを添付） | 税務署 | 設立の日（設立登記の日）以後2か月以内 |
| 青色申告の承認申請書 | 税務署 | 設立の日以後3か月を経過した日と、1期目の事業年度終了の日のうち早い日の前日まで |
| 給与支払事務所等の開設届出書 | 税務署 | 開設の事実があった日から1か月以内 |
| 源泉所得税の納期の特例の承認に関する申請書 | 税務署 | 特例を受けたいとき（期限の定めではなく、承認後に適用） |
| 事前確定届出給与に関する届出書 | 税務署 | 賞与を払う場合、設立の日以後2か月を経過する日まで |
| 法人設立届（地方税） | 都道府県・市区町村 | 自治体ごとに定める期限 |

### 税務署への届出

国税庁の案内では、法人設立届出書は設立の日から2か月以内に、定款などの写しを添えて納税地の税務署に出します。1期目から青色申告にしたい場合は、承認申請書の期限が別にあります。会社から役員報酬を払うと源泉徴収をするため、給与支払事務所等の開設届出書も出します。

給与の支給人員が常時10人未満なら、源泉所得税を半年分まとめて納める「納期の特例」があります。承認を受けると、1〜6月分は7月10日、7〜12月分は翌年1月20日が納付期限になります。一人会社では毎月の納付の手間を減らせるため、検討する人が多い制度です。

### 地方税の届出

都道府県と市区町村にも法人設立の届出をします。期限と様式は自治体ごとに決まっています。たとえば東京都主税局の案内では、都内で法人を設立した場合、事業を開始した日から15日以内に、定款等の写しを添えて都税事務所に「法人設立・設置届出書」を出します。本店を置く自治体の案内を確かめてください。

### 年金事務所への届出

日本年金機構の案内では、法人の事業所は事業主のみでも健康保険・厚生年金保険の適用事業所になり、新規適用届を事実の発生から5日以内に出します。法人の登記簿謄本（提出日から90日以内に発行されたもの）を添付します。役員としての加入手続きや保険料の考え方は、[法人化したときの社会保険の記事](/media/houjin-shakai-hoken/)で解説しています。

### 届出をまとめて出す方法

国税庁の案内では、マイナポータルの「法人設立ワンストップサービス」を使うと、国税・地方税の設立届や、年金事務所・ハローワークへの届出などをまとめて行えます。法人代表者のマイナンバーカードが必要です。

## 個人事業をたたむ手続きも並行して進める

フリーランスから法人化する場合、個人事業をやめる手続きも必要です。

- **個人事業の開業・廃業等届出書**：廃業も同じ届出書で届け出る。国税庁の手続案内では、提出時期は「事業の開始等の事実があった日の属する年分の確定申告期限まで」（2026年10月時点）
- **青色申告の取りやめ届出書**：青色申告の承認を受けていた人
- **消費税の事業廃止届出書**：消費税の課税事業者で、ほかに課税売上になる所得がない人
- **個人事業税の廃止の申告**：東京都の場合、事業の廃止の日から10日以内

個人として結んでいた業務委託契約や、インボイスの登録の扱いは[法人化後に契約を切り替える手順の記事](/media/houjin-keiyaku-kirikae/)で整理しています。法人化した年は、個人事業の分の確定申告も必要です。

:::view
法人化した後も、案件探しの進め方は個人のときと大きく変わりません。当社では、先に稼働日数・リモート・希望金額を伺い、合う案件だけをご案内しています。違いが出るのは契約の名義です。新しく案件を探すときは、個人と法人のどちらで契約するかを最初にお知らせいただくと、契約書の準備が進めやすくなります。設立の途中で案件が決まりそうな場合は、早めにご相談ください。
:::

:::point
- 流れは、基本事項を決める → 定款（株式会社は認証） → 出資の払込み → 設立登記の申請
- 会社の設立日は、登記所が申請を受け付けた日
- 新規適用届は5日以内、法人設立届出書は2か月以内、給与支払事務所等の開設届出書は1か月以内
- 地方税の届出の期限は自治体ごとに違う。東京都は事業開始から15日以内
- 個人事業の廃業の届出と、個人分の確定申告も忘れない
:::

## よくある質問

### 会社の設立は自分でできますか？

できます。法務局のサイトに申請書の様式と記載例があり、一人会社はオンライン申請も推奨されています。ただし、定款の内容や資本金の決め方は、後の税務や手続きに影響します。書類作成に不安がある場合は、司法書士にご相談ください。税務の届出は税理士に依頼する人も多くいます。

### 設立日を好きな日にできますか？

設立日は、登記所が申請を受け付けた日になります。希望する日に申請すれば、その日が設立日です。登記所の開庁日やオンライン申請の受付時間によっては希望の日に受け付けられないことがあるため、日付を決めたら事前に法務局の案内を確かめておくと安心です。

### 法人設立届出書を出し忘れるとどうなりますか？

法人設立届出書は、設立の日から2か月以内に出すこととされています。遅れたことに気づいたら、すぐに提出してください。青色申告の承認申請書は期限を過ぎると1期目から青色申告にできなくなるなど、届出ごとに影響が違います。具体的な対応は税理士にご相談ください。
