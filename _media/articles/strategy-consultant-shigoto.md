フリーランスの戦略コンサルタントの仕事は、**経営の判断に必要な問いを立て、材料を集めて分析し、経営層が決められる形にまとめて合意まで運ぶこと**です。案件は、中期経営計画の策定、新規事業の検討、事業ポートフォリオの見直し、M&Aの検討、経営企画の補佐などに分かれ、種類によって報告の相手、期間、成果物が変わります。

同じ「戦略案件」でも、ファームのチームの一員として一つの論点を持つ仕事と、事業会社の経営企画に一人で入る仕事では、一日の過ごし方がかなり違います。この記事では、案件の種類ごとの仕事内容と、1か月・1日の流れ、関わる相手と成果物を整理します。求められるスキルは[戦略コンサルタントのスキルの記事](/media/strategy-consultant-skills/)、報酬の決まり方は[報酬の記事](/media/strategy-consultant-rate/)で扱っているため、ここでは「何をする仕事か」に絞ります。

## 案件の種類ごとの仕事内容

### 中期経営計画の策定支援

3年前後の計画を作る、または見直す仕事です。経営企画部門の中に入り、各事業部から出てくる計画の数字を集め、全社の目標とのずれを確かめ、どの事業に資源を寄せるかの議論の材料を作ります。仕事の中心は、事業部との打ち合わせ、数字の突き合わせ、経営会議に出す資料の取りまとめです。

この種類の案件では、新しい分析を作るより、**各部門の数字と言い分を一つの筋書きにまとめる**作業の比重が大きくなります。取締役会や投資家向けの説明資料の土台を作るところまで含まれることもあります。

### 新規事業の検討

参入する市場を選ぶ、またはすでに選んだ市場で事業の形を詰める仕事です。市場の大きさの推計、想定する顧客への聞き取り、競合の調べ、収益の試算を組み合わせ、「進めるか、やめるか、条件つきで進めるか」の判断材料を作ります。

聞き取りの設計と実施が多く、社外の人と話す時間が長いのが特徴です。検討の結果、参入しないという結論になることもあり、その場合も撤退の判断材料をまとめるのが成果になります。

### 事業ポートフォリオの見直し・事業再編

複数の事業を持つ会社で、事業ごとの収益と将来性を比べ、伸ばす事業・維持する事業・縮小や売却を考える事業を分ける仕事です。事業ごとの損益を同じ基準で並べ直す作業から始まることが多く、管理会計の数字と向き合う時間が長くなります。

対象の事業の担当役員にとっては自分の事業の評価にあたるため、**議論の進め方そのものに配慮が要る**仕事です。限られたメンバーだけで検討が進むことも多くあります。

### M&A・提携に関わる検討

買収や提携の候補を探す、候補の事業を評価する、統合後の計画を作るといった仕事です。財務や法務の専門家が別に入る体制が多く、戦略コンサルは事業の見立て（市場、競合、統合の効果）を担うことが中心になります。取引の日程に合わせて作業が急に詰まることがあるのも特徴です。統合後の運営に軸足を置いた仕事は[M&A・PMIコンサルタントの仕事内容](/media/pmi-shigoto/)で扱います。

### ファームのプロジェクトのメンバー

コンサルティング会社が受けたプロジェクトに、外部の人材としてチームに加わる形です。全体の論点はファームのマネージャーやパートナーが決め、フリーランスは分けられた論点の一つ、または特定の分析を受け持ちます。社内の定例会議、ファームの資料の型、レビューの順番に合わせて動きます。

### 経営企画の補佐・経営者の相談役

週の一部や月数回の頻度で、経営者や経営企画の責任者の検討を手伝う仕事です。会議の前に論点を整理する、出てきた資料に意見を出す、外部の情報を集めて短くまとめるといった、細かい依頼が積み重なる形になりやすい仕事です。週2〜3日での関わり方は[戦略コンサルタントの週2〜3日・副業案件](/media/strategy-consultant-shuu3/)で解説しています。

## プロジェクト型の案件の1か月

数か月で区切られるプロジェクト型の案件は、おおむね次の順で進みます。期間や区切り方は案件によって違うので、目安として見てください。

| 時期 | 主な仕事 | この時期の成果物 |
|---|---|---|
| 立ち上げ（最初の1〜2週） | 依頼の背景の聞き取り、論点の洗い出し、作業の計画づくり | 論点の全体像、作業計画、聞き取りの候補一覧 |
| 仮説と材料集め | 初期の仮説を立て、公開情報・社内データ・聞き取りで確かめる | 分析の途中経過、聞き取りの記録 |
| 中間報告 | 分かったことと残った論点を示し、検討の方向をそろえる | 中間報告の資料 |
| 深掘り | 方向が決まった論点について、数字の試算や選択肢の比較を詰める | 試算のモデル、選択肢の比較表 |
| 最終報告と次の段取り | 提言をまとめ、経営層と議論する。実行の担当と最初の進め方を決める | 最終報告の資料、実行計画の骨子 |

1か月の中で負荷が一番高くなるのは、中間報告と最終報告の直前です。資料の構成を何度も組み替え、数字の前提を確かめ直す作業が集中します。反対に、立ち上げ直後は聞き取りの日程を押さえる連絡が多く、手を動かす作業はまだ少ない時期です。

:::view
戦略の案件をご紹介していると、面談で「報告の山の前後で、どのように時間を配分していたか」を尋ねられる場面をよく見ます。評価されやすいのは、報告日から逆算して、いつ仮説を固め、いつ数字を締めるかを具体的に話せる方です。プロジェクトの流れを担当工程だけでなく時間の使い方で説明できると、一人で任せられるかが伝わりやすくなります。
:::

## 1日の流れの例

事業会社の経営企画に週5日で入り、中期経営計画の見直しを手伝っている場合の一日を、**架空の例**で示します。

- **午前**：前日に事業部から届いた数字を確かめ、計画との差を表にまとめる。気になる点を担当者への質問として書き出す
- **昼前**：経営企画の担当者と短い打ち合わせ。今週の経営会議に出す論点の順番を決める
- **午後の前半**：事業部長への聞き取り。数字の背景にある見込みと、本人が気にしている点を聞く
- **午後の後半**：聞き取りの要点を記録し、資料の構成を直す。経営企画の責任者に途中版を送り、方向を確かめる
- **夕方**：翌日の聞き取りの質問を準備し、その日の進み具合と残った論点を短く報告する

ファームのチームに入る場合は、これに加えて、チーム内の朝会や、マネージャーによる資料のレビューが入ります。ファームの型に合わせて資料を直す時間が増え、クライアントと直接話す時間は役割によって大きく変わります。

## 関わる相手

戦略の案件では、立場の違う相手と話す場面が一日の中に混ざります。

| 相手 | 主なやり取り |
|---|---|
| 経営者・役員 | 中間・最終の報告、論点の確認、判断を仰ぐ議論 |
| 経営企画の担当者 | 日々の進め方の相談、社内の資料や会議の段取り |
| 事業部長・現場の責任者 | 聞き取り、数字の確かめ、提言への意見の受け止め |
| 財務・経理 | 管理会計の数字の出し方、試算の前提のすり合わせ |
| 社外の専門家・顧客 | 市場や競合についての聞き取り |
| ファームのマネージャー | 担当論点の進み具合の報告、資料のレビュー（ファーム経由の場合） |

事業会社に直接入る場合は、経営企画の担当者が日々の窓口になり、役員と話すのは報告の場が中心になることが多くあります。誰が窓口で、誰が最終的に判断するのかは、参画の最初に確かめておくと動きやすくなります。

## 主な成果物

戦略の案件で手元に残るのは、ほとんどが資料と数字のファイルです。

1. **論点の全体像と作業計画**：何を明らかにするか、どの順番で、誰に聞くかをまとめたもの
2. **分析資料**：市場の推計、競合の比較、事業ごとの収益の並べ直しなど
3. **聞き取りの記録**：誰に何を聞き、何が分かったかの要点
4. **試算のモデル**：表計算ソフトで作る収益や投資の試算。前提の一覧を含む
5. **中間・最終の報告資料**：結論を先に置き、根拠となる分析を後ろに並べた経営層向けの資料
6. **実行計画の骨子**：提言を部門の取り組みと指標に分け、最初の数か月の進め方を示したもの

会議の議事録や論点の一覧のように、地味でも継続の依頼につながりやすい成果物もあります。議事録の書き方は[議事録の記事](/media/gijiroku/)が参考になります。

:::caution
報告資料や試算のモデルは、作ったのが自分でも、契約で権利がクライアントに移ることが多い成果物です。案件が終わった後に資料を手元に残してよいか、次の案件の参考にしてよいかは、契約の定めによって変わります。案件を選ぶ段階での確かめ方は[戦略コンサルタントの案件の選び方](/media/strategy-consultant-anken-erabi/)で扱っています。
:::

## 働き方の特徴

戦略の案件の働き方には、ほかのコンサル職種と比べて次のような特徴があります。

- **期間が短く、区切りがはっきりしている**：報告日が先に決まり、そこに向けて作業が組まれる
- **作業の山と谷が大きい**：報告の前に作業が集中し、報告の直後は次の論点の整理に移る
- **出社や出張が報告の場に集まる**：日々の分析は手元で進め、経営層との議論の日に出向く形が多い。くわしくは[リモートの記事](/media/strategy-consultant-remote/)で解説している
- **扱う情報の機密性が高い**：未公表の計画や再編の検討に触れるため、資料の置き場所や持ち出しの決まりに従う

業務の流れを作り直す段階まで関わる案件は、業務コンサルタントの仕事に近づきます。違いは[業務コンサルタントの仕事内容](/media/business-consultant-shigoto/)と比べると分かりやすくなります。

:::view
当社では、先に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをご案内しています。戦略の案件は、同じテーマ名でも、ファームのチームの一員として分析を持つのか、経営企画に一人で入るのかで仕事の中身が大きく違います。案件の説明を受けるときは、報告の相手と、自分が受け持つ成果物の範囲を確かめておくことをおすすめします。
:::

:::point
- 戦略の案件は、中期経営計画、新規事業、事業の見直し、M&Aの検討、ファームのチームへの参加、経営企画の補佐などに分かれる
- プロジェクト型の案件は、立ち上げ・仮説と材料集め・中間報告・深掘り・最終報告の順に進み、報告の前に作業が集中する
- 関わる相手は経営層から現場、社外の専門家まで幅広く、成果物は論点の全体像、分析、試算、報告資料、実行計画の骨子が中心になる
:::

## よくある質問

### 戦略の案件では、資料づくりがほとんどの時間を占めますか？

資料に向かう時間は長いものの、その前の聞き取りや数字の確かめ、論点を決める打ち合わせにも同じくらい時間を使います。特に事業会社に直接入る案件では、社内の人と話して材料と合意を集める時間の比重が大きくなります。

### 提言を出した後の実行まで関わることはありますか？

あります。提言を部門ごとの取り組みに分け、最初の数か月の進み具合を見る段階まで続けて依頼されることがあります。実行の段階では、会議の運営や指標の確認など、仕事の中身が業務改革に近づきます。

### ファーム経由の案件と事業会社に直接入る案件では、仕事の中身はどう違いますか？

ファーム経由では、全体の論点はファームが持ち、フリーランスは分けられた論点や分析を受け持つことが多くなります。事業会社に直接入る場合は、論点を決めるところから社内の合意づくりまでを自分で担う範囲が広がります。どちらが合うかは、これまで担ってきた工程によって変わります。
