経営セーフティ共済（中小企業倒産防止共済）は、**取引先が倒産して売掛金を回収できなくなったときに、無担保・無保証人・無利子で事業資金を借りられる**、国の機関（独立行政法人中小企業基盤整備機構）が運営する共済です。掛金は月5,000円から200,000円で、個人事業主は**事業所得の必要経費**にできます。

一方で、解約して受け取る解約手当金は事業所得の収入になり、掛金を納めた期間が40か月未満だと元本割れ、12か月未満なら掛け捨てです。「節税」のイメージだけで始めず、取引先の倒産への備えという本来の目的と、解約する時期の税金まで考えて使うことが大切です（2026年10月時点）。

## 制度の要点を一覧で見る

| 項目 | 内容 |
|---|---|
| 運営 | 独立行政法人中小企業基盤整備機構（中小機構） |
| 目的 | 取引先の倒産による連鎖倒産を防ぐ |
| 掛金 | 月5,000円〜200,000円（5,000円単位）。増額できる。減額は事業の縮小などの場合に限る |
| 積立の上限 | 掛金総額800万円。達すると引き落としが止まる |
| 掛金の税金 | 個人事業主は事業所得の必要経費、法人は損金 |
| 借入れ | 取引先の倒産時に、掛金総額の10倍（上限8,000万円）まで。無担保・無保証人・無利子 |
| 解約手当金 | 12か月未満は掛け捨て。40か月以上で掛金の全額 |
| 解約手当金の税金 | 個人事業主は事業所得の収入金額になる |

## フリーランスは加入できるか

中小機構の加入資格では、個人事業主は次の条件を満たす必要があります。

- **継続して1年以上事業を営んでいる**こと
- 事業所得（または不動産所得）として確定申告をしていること
- 常時使用する従業員の数が業種ごとの上限以下であること（ソフトウェア業・情報処理サービス業は300人以下、サービス業は100人以下など）

業務委託で案件を受けているフリーランスは、事業所得で確定申告をして1年以上たっていれば、加入を検討できる場合があります。独立したばかりの年は、1年の要件を満たすまで加入できません。

### 加入できない主な場合

- 納めるべき所得税を滞納している
- 事業の経理の内容がはっきりしない
- 掛金を12か月以上滞納して契約を解除され、12か月たっていない
- すでに共済契約者である（重複して入れない）

中小機構は、一般の消費者を取引先とする事業者など、売掛金債権が生じない業種は貸付けの対象にならない場合があるとしています。業務委託で企業から報酬を受け取るフリーランスは、報酬の未払いが売掛金にあたりますが、自分の取引で貸付けの対象になるかは、加入前に中小機構の窓口でご確認ください。

## 取引先が倒産したときの借入れ

経営セーフティ共済の本来の役割は、取引先の倒産で入金が止まったときの資金繰りです。

### 借りられる条件

中小機構の案内では、主に次の条件があります。

1. 加入してから6か月以上たってから取引先が倒産した
2. 倒産までに6か月分以上の掛金を納めている
3. 倒産が起きてから6か月以内に借入れの手続きをする

ここでいう「倒産」は、破産・民事再生などの法的整理の申立て、手形やでんさいネットの取引停止処分、弁護士などからの支払停止の通知（私的整理）などです。中小機構は、いわゆる夜逃げは倒産にあたらないとしています。請求額が少額の場合（50万円と月間の総取引額の20%相当額のいずれにも届かない場合など）や、倒産を予知していた場合なども借りられません。

### 借りられる額と返し方

| 項目 | 内容 |
|---|---|
| 借入限度額 | 回収できなくなった売掛金等の額と、掛金総額の10倍のいずれか少ない額（上限8,000万円） |
| 利率 | 無利子 |
| 担保・保証人 | 不要 |
| 返済（5,000万円未満の場合） | 5年（うち据置6か月）、54回の均等返済 |
| 掛金への影響 | 借りた額の10分の1にあたる掛金の権利がなくなる |

無利子ですが、借りた額の10分の1の掛金がなくなるため、実質的な負担がないわけではありません。返済が遅れると年14.6%の違約金がかかります。

:::view
当社は、取引先の会社の実態と支払条件を確かめた案件を扱っています。それでも、フリーランスにとって主な取引先が1社か2社に集中していると、その会社の支払いが止まったときの影響は大きくなります。業務範囲・報酬・支払期日は個別契約に書いてお渡ししていますので、支払期日を過ぎた入金がないときは、早めにご連絡いただくことをおすすめします。経営セーフティ共済は、こうした事態への備えの一つとして位置づけると考えやすくなります。
:::

## 掛金は必要経費になる

中小機構の制度のしおりでは、個人事業主が納めた掛金は**事業所得の必要経費**に入れられるとされています（租税特別措置法第28条）。小規模企業共済やiDeCoの掛金が「所得控除」なのに対し、経営セーフティ共済は「経費」として事業所得を減らす点が違います。

| 制度 | 掛金の扱い | 受け取るときの扱い |
|---|---|---|
| 経営セーフティ共済 | 事業所得の必要経費 | 解約手当金は事業所得の収入金額 |
| 小規模企業共済 | 小規模企業共済等掛金控除（所得控除） | 共済金は退職所得または公的年金等の雑所得など |
| iDeCo | 小規模企業共済等掛金控除（所得控除） | 老齢給付金として課税 |

### 経費にするときの注意

- **事業所得の分だけ**：個人事業の場合、不動産所得など事業所得以外の必要経費にはできない
- **前納の扱い**：前納した期間が1年以内なら、払った年の必要経費にできる。1年を超える分は、期間の経過に応じて経費にする
- **再加入の制限**：令和6年10月1日以後に解約して再び加入した場合、解約の日から2年を経過する日までに払う掛金は、必要経費にできない

申告のときの書き方や、必要な明細の添付などは、税理士・税務署にご相談ください。

## 解約手当金と元本割れの条件

解約手当金は「掛金総額×支給率」で計算されます。中小機構の案内による支給率は次のとおりです。

| 掛金を納めた月数 | 任意解約 | 機構解約（滞納など） |
|---|---|---|
| 1〜11か月 | 0% | 0% |
| 12〜23か月 | 80% | 75% |
| 24〜29か月 | 85% | 80% |
| 30〜35か月 | 90% | 85% |
| 36〜39か月 | 95% | 90% |
| 40か月以上 | 100% | 95% |

自分の都合で解約する任意解約では、40か月以上納めて初めて掛金の全額が戻ります。また、掛金総額は、借入れで差し引かれた10分の1の額などを除いた金額です。

### 解約した年の所得が増える

解約手当金は、個人事業主の場合、**事業所得の収入金額**になります。掛金を払った年に経費として所得を下げた分が、解約した年にまとめて所得として戻ってくる仕組みです。

たとえば、所得が高い年に掛金を払い、案件が減って所得が下がった年や、事業をやめる年に解約すると、税負担を平準化しやすくなる、という考え方があります。反対に、所得が高い年に解約すると、税金と国民健康保険料が大きく増えることがあります。解約の時期は、税理士と相談して決めることをおすすめします。

:::caution
解約手当金は、受け取った年の事業所得として、所得税・住民税だけでなく、所得をもとに計算する国民健康保険料にも影響します。数百万円の解約手当金が一度に入ると、翌年度の国民健康保険料が上がることがあります。国民健康保険料の決まり方は[国民健康保険の記事](/media/kokuho/)で解説しています。
:::

## 倒産以外でも借りられる一時貸付金

取引先の倒産がなくても、解約手当金の範囲内で事業資金を借りられる「一時貸付金」の制度があります。

- 借入限度額：解約手当金（機構解約の場合）の95%の範囲内
- 借入額：30万円以上、5万円単位
- 期間：1年（期限に一括返済。借り換えもできる）
- 利率：金融情勢などで変わる（令和6年4月1日時点で年0.9%）

案件の切れ目で一時的に資金が足りないときに、解約せずに資金を用意する方法として知っておくとよいでしょう。最新の利率は中小機構の案内でご確認ください。

## 掛金を決めるときの考え方

1. **主な取引先への依存度を見る**：売上の多くが1〜2社に集中しているほど、倒産への備えとしての意味は大きい
2. **40か月以上続けられる額にする**：途中で解約すると元本割れし、減額できる場面も限られるため、案件が途切れても払える額にする
3. **解約の時期を想定する**：事業をやめる年、所得が下がる年など、解約手当金を受け取る年の見込みを立てる
4. **小規模企業共済・iDeCoとの配分を決める**：経費になる経営セーフティ共済と、所得控除になる制度は性格が違う

小規模企業共済の仕組みは[小規模企業共済の記事](/media/shokibo-kyosai/)、iDeCoは[iDeCoの記事](/media/ideco/)で解説しています。

:::view
独立して数年たち、報酬が安定してきた方から「経営セーフティ共済で経費を増やしたほうがよいか」というご相談を受けることがあります。掛金は経費になりますが、解約すれば収入として戻ってきます。また、参画先のプロジェクトの終了で次の案件まで間が空くこともあります。手元に数か月分の生活費と税金・保険料を残したうえで、続けられる額にしておくことをおすすめします。個別の判断は税理士にご相談ください。
:::

:::point
- 取引先が倒産したとき、掛金総額の10倍（上限8,000万円）まで無担保・無保証人・無利子で借りられる
- 掛金は月5,000〜200,000円、総額800万円まで。個人事業主は事業所得の必要経費になる
- 解約手当金は事業所得の収入。任意解約は40か月未満で元本割れ、12か月未満は掛け捨て
- 令和6年10月1日以後に解約して再加入すると、2年間は掛金を経費にできない
- 加入には、継続して1年以上事業を営んでいることが必要
:::

## よくある質問

### 独立したばかりでも加入できますか？

中小機構の加入資格では、個人事業主は継続して1年以上事業を営んでいることが条件です。独立した直後は加入できないため、事業所得で確定申告をして1年以上たってから検討することになります。開業日などの確認は中小機構の窓口でご確認ください。

### 掛金を払えなくなったらどうなりますか？

制度のしおりでは、事業規模が縮小したときや、経営の著しい悪化・病気・けがなどで掛金を払い続けるのが著しく難しいときなどに限り、掛金を減額できるとされています。掛金を12か月分以上滞納すると、中小機構による解約（機構解約）となり、支給率は任意解約より低くなります。払うのが難しくなったら、滞納する前に中小機構へ減額の手続きを相談してください。

### 法人化したら契約はどうなりますか？

個人事業主としての契約と、法人としての契約は別のものです。法人化したときに個人の契約を解約するのか、どのように扱えるのかは、法人化の手続きの前に中小機構に確認してください。解約手当金は個人の事業所得の収入になるため、解約の年の税金も含めて税理士にご相談ください。
