退職前の有給休暇は、**残日数を確かめ、引き継ぎの計画と合わせて、退職日から逆算して申し出る**のが基本です。消化している間も会社に在籍しているため、フリーランスの案件に参画するのは、原則として退職日の翌日以降にします。

有給休暇の期間は、独立の準備に使える貴重な時間でもあります。ただし、健康保険や年金の切り替えのように、退職日の翌日にならないと進められない手続きもあります。この記事では、残日数の確かめ方、消化の組み立て方、消化中にできること・できないことを整理します（法令は2026年10月時点でe-Gov法令検索で確認）。退職の伝え方そのものは[退職と独立の伝え方の記事](/media/taishoku-tsutaekata/)をご覧ください。

## 残っている有給休暇の日数を確かめる

### 法律で決まっている付与日数

労働基準法39条では、雇い入れの日から6か月間継続して勤務し、全労働日の8割以上出勤した労働者に、10労働日の年次有給休暇を与えることとされています。その後は勤続年数に応じて日数が増えます。週の所定労働日数が通常の労働者と同じ場合の日数は次のとおりです。

| 継続勤務の期間 | 付与日数 |
|---|---|
| 6か月 | 10日 |
| 1年6か月 | 11日 |
| 2年6か月 | 12日 |
| 3年6か月 | 14日 |
| 4年6か月 | 16日 |
| 5年6か月 | 18日 |
| 6年6か月以上 | 20日 |

所定労働日数が少ない働き方の場合は、日数を比例して決める別の定めがあります。また、会社が法律を上回る日数を就業規則で定めていることもあります。

### 前年の分も残っていることがある

労働基準法115条では、賃金以外の請求権の時効は2年とされています。年次有給休暇もこれにあたるため、前年に使い切れなかった日数が残っていることがあります。正確な残日数は、給与明細や勤怠のシステム、人事への問い合わせで確かめます。

### 時間単位で取れる場合もある

労使協定がある会社では、1年に5日分までを上限に、時間単位で有給休暇を取れる仕組みがあります（労働基準法39条4項）。引き継ぎの合間に半日や数時間だけ休みたいときに使えるかどうか、就業規則を確かめておきます。

## 消化の組み立て方は2通り

有給休暇の消化の仕方は、大きく分けて次の2通りです。

| 組み立て方 | 流れ | 向いている場面 |
|---|---|---|
| 最後にまとめて取る | 引き継ぎを終える → 最終出社日 → 有給消化 → 退職日 | 引き継ぎの量がはっきりしていて、後任が決まっている |
| 引き継ぎと並行して取る | 出社日と休みを混ぜながら引き継ぎ → 退職日 | 後任が決まらない、退職日を早めにしたい |

どちらの場合も、**退職日・最終出社日・有給休暇の日数**の3つを、上司や人事と同じ表で共有しておくと行き違いが起きにくくなります。

### 日程の組み方の例（仮の日付）

考え方を示すために、**仮の日付と日数**で例を置きます。有給休暇の残りが15日、引き継ぎに3週間かかる見込みで、月末に退職したい場合です。

1. 退職日を「◯月末日」と決める
2. 退職日から営業日を15日さかのぼり、その前日を最終出社日の候補にする
3. 最終出社日から3週間さかのぼった日を、引き継ぎの開始日にする
4. 引き継ぎの開始日より前に、上司へ退職を伝える（就業規則の申し出の期限も満たしているかを見る）

このように逆算すると、「いつまでに上司へ話せばよいか」がはっきりします。土日や祝日、会社の休業日の数え方で日付は変わるため、実際の日程は人事と確かめてください。逆算した結果、申し出の時期がすでに過ぎている場合は、退職日を後ろにずらすか、引き継ぎと並行して消化する方法に切り替えます。

### 消化期間の長さと、最初の案件の開始日

有給休暇が多く残っている人は、最終出社日から退職日までが1か月近くあくこともあります。消化中は給与が支払われるため、この期間の生活費に困ることは少ないはずです。注意したいのは退職日のあとです。案件の開始日は退職日の翌日以降になり、業務委託の報酬は稼働した月の締めのあとに支払われるのが一般的なため、**退職日から最初の入金まで、給与も報酬も入らない期間ができる**ことがあります。資金は「最終出社日」ではなく「退職日」を起点に見積もっておきます。資金の見積もり方は[独立前に用意しておく生活費の記事](/media/seikatsu-hi-junbi/)で解説しています。

### 時季の変更を求められたとき

労働基準法39条5項では、有給休暇は労働者が請求する時季に与えるものとされ、請求された時季に与えると事業の正常な運営を妨げる場合に限り、会社は他の時季に与えることができるとされています。退職日が決まっていると、別の時季に移せる期間はかぎられます。消化の日程で折り合わない場合は、退職日そのものを含めて話し合うことになります。扱いに迷うときは、労働基準監督署などの相談窓口にご確認ください。

:::caution
「有給休暇を使い切ってから退職したい」と、退職を伝える時期が遅くなると、引き継ぎの期間が足りなくなりがちです。残日数が多い人ほど、早めに申し出て、引き継ぎと消化の両方の日程を確保しておきましょう。
:::

## 有給消化中も「在籍中」であることに注意

最終出社日を過ぎても、退職日までは会社の従業員です。この期間に気をつけたいことをまとめます。

- **案件への参画**：在籍中に業務委託の仕事を始めてよいかは、就業規則の兼業・副業の定めによります。定めを確かめないまま始めるのは避けます
- **健康保険・厚生年金**：退職日までは会社の健康保険と厚生年金に加入しています。国民健康保険や国民年金への切り替えは、退職日の翌日以降の手続きです
- **会社の端末やアカウント**：返却の時期が最終出社日か退職日かを確かめます

開始日の決め方は[参画開始日の調整の記事](/media/start-date-adjust/)、退職日による年金・保険の違いは[独立のタイミングの記事](/media/independence-timing/)で解説しています。

:::view
有給休暇の消化に入る前のタイミングで、案件の情報集めを始める方は多いです。当社では、案件をご案内するときに先に稼働日数・リモート・希望金額を伺い、合う案件だけをお出ししています。消化期間に面談を入れたい場合は、最終出社日と退職日の両方が分かった段階で、早めにご相談ください。参画の開始日は退職日の翌日以降で考えておくことをおすすめします。
:::

## 有給消化中に進めたい独立の準備

在籍中でもできる準備は多くあります。時間のある消化期間に、次のものを進めておくと独立後が楽になります。

### 案件探しの準備

- スキルシートを最新の内容にする（書き方は[スキルシートの基本の記事](/media/skillsheet-basics/)）
- 独立後の稼働日数・リモート・希望する報酬の下限を決める
- 面談の日程を入れやすい時期なので、案件の面談を進める

### お金と事務の準備

- 生活費と、税金・保険料のための資金を口座ごとに分ける
- 会計ソフトや帳簿の付け方を決める
- 事業用の口座やクレジットカードを検討する（在職中に済ませたいことは[独立前の準備の記事](/media/before-independence-prepare/)）

### 退職日の翌日以降の手続きを下調べする

- 国民健康保険と任意継続の保険料を比べる
- 国民年金の手続きに必要なものを確かめる
- 開業届と青色申告承認申請書の書き方を確かめる

手続きの期限と流れは[退職後の手続きの記事](/media/retirement-procedures/)にまとめています。開業届は、事業を始めた年分の確定申告期限までに出すものです（2026年10月時点の国税庁の案内）。開業日を退職日の翌日などにする場合は、消化中に書類を作っておき、開業日以降に提出します。

### 体の準備

会社の健康診断を受けられる時期であれば、在籍中に受けておくと、自分の健康状態を把握したうえで独立できます。独立後の健康管理は[健康診断の記事](/media/health-check/)で扱っています。

## 消化中にやらない方がよいこと

- **在籍中の会社の顧客と、独立後の仕事の約束をする**：就業規則や誓約書に触れるおそれがあります
- **会社の資料を持ち出す**：引き継ぎ資料を含め、会社の情報は会社に残します
- **退職日を確かめないまま参画日を決める**：退職日が後ろにずれると、開始日を守れなくなります

:::view
案件紹介の現場では、有給消化中に参画を始めたいという希望が出ることがあります。発注側も開始日は大事にしているため、在籍中に始められるかどうかがはっきりしないまま話を進めると、双方にとって負担になります。当社がご案内する案件では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。契約開始日と退職日の関係は、契約を結ぶ前に見比べておくことをおすすめします。
:::

:::point
- 残日数は、前年の繰り越し分も含めて人事や勤怠のシステムで確かめる
- 消化は「最後にまとめて」か「引き継ぎと並行」かを決め、3つの日付を共有する
- 消化中も在籍中。参画は退職日の翌日以降が基本で、保険・年金の切り替えも退職後
- 消化期間は、スキルシート・資金の分け方・手続きの下調べに使う
:::

## よくある質問

### 有給休暇が残ったまま退職したら、買い取ってもらえますか？

退職時に残った有給休暇を買い取るかどうかは、会社の規程や話し合いによります。買い取りの定めがあるかは就業規則で確かめてください。残すつもりがないなら、退職を早めに伝えて消化の日程を確保する方が確かです。

### 有給消化中に開業届を出してもよいですか？

開業届は、事業を始めた日を開業日として出す書類です。在籍中に事業を始めてよいかは就業規則の兼業の定めによるため、退職日の翌日などを開業日にすると分かりやすくなります。提出期限は、事業を始めた年分の確定申告期限までとされています（2026年10月時点の国税庁の案内）。

### 有給消化中に案件の面談を受けてもよいですか？

面談を受けること自体は、在籍中でも可能な場合が多いです。ただし、参画の開始日は退職日の翌日以降で調整し、在籍中に業務を始めることにならないよう注意してください。就業規則の兼業の定めも、あわせてご確認ください。
