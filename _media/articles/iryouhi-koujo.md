医療費控除は、本人と生計を一にする家族のために1年間（1月1日〜12月31日）に払った医療費から、保険金などで補てんされる分を引き、さらに10万円を引いた額を所得から差し引ける制度です。総所得金額等が200万円未満の人は、10万円の代わりに総所得金額等の5%を引きます。控除額の上限は200万円です。

セルフメディケーション税制は、その特例です。健康診断などの「一定の取組」をしている人が、対象の市販薬（スイッチOTC医薬品など）を買った場合に、購入費のうち1万2,000円を超えた分（上限8万8,000円）を控除できます。2つは**どちらか一方しか選べません**。この記事では、国税庁のタックスアンサー（令和8年4月1日現在の法令）をもとに、フリーランスが選ぶときの考え方を整理します（2026年10月時点）。

## 医療費控除の計算のしかた

国税庁が示す計算式は次のとおりです。

**医療費控除の額 ＝（1年間に実際に払った医療費 − 保険金などで補てんされる金額）− 10万円**

- 「10万円」は、その年の総所得金額等が200万円未満の人は、総所得金額等の5%になります
- 控除額の上限は200万円です
- 補てんされる金額には、生命保険の入院給付金や、健康保険の高額療養費・出産育児一時金などが含まれます

補てんされる金額は、その給付の目的になった医療費から差し引きます。たとえば入院給付金が入院費を上回っても、余った分をほかの通院費から引く必要はありません。

### フリーランスは「5%」の基準に当たることがある

会社員なら給与所得、フリーランスなら事業所得が総所得金額等のもとになります。事業所得は、売上から経費と青色申告特別控除を引いた後の金額です。独立1年目で売上が少ない年や、案件の切り替えで稼働が少なかった年は、総所得金額等が200万円未満になることがあります。その年は、医療費が10万円に届かなくても控除を受けられる場合があります。

| 総所得金額等 | 医療費から引く金額 |
|---|---|
| 200万円以上 | 10万円 |
| 200万円未満 | 総所得金額等×5% |

所得控除の差し引き方や、控除によって税額がどれくらい減るかは、[所得税の計算の流れ](/media/shotokuzei-keisan/)で解説しています。

## 医療費控除の対象になるもの・ならないもの

国税庁が対象として挙げる主なものは次のとおりです。いずれも、病状などに応じて一般的に支出される水準を大きく超えない部分に限られます。

| 対象になる主なもの | 対象にならない例 |
|---|---|
| 医師・歯科医師の診療や治療の費用 | 健康診断の費用、医師への謝礼 |
| 治療や療養に必要な医薬品の購入費（風邪薬など） | ビタミン剤など、予防や健康増進のための医薬品 |
| 通院のための電車・バス代 | 自家用車で通院したときのガソリン代・駐車場代 |
| 公共交通機関が使えない場合のタクシー代 | 公共交通機関を使えるのに乗ったタクシー代 |
| 入院時の部屋代・食事代で通常必要なもの | 疲れを癒すなど治療と直接関係のないマッサージ |
| あん摩マッサージ指圧師・はり師などの治療としての施術 | 家族に付添いを頼んで払った付添料 |
| 治療に直接必要な義歯・補聴器・眼鏡などの購入費 | |

健康診断や人間ドックの費用は、原則として対象外です。フリーランスの健診の受け方と費用は[健康診断の記事](/media/health-check/)で整理しています。

:::caution
医療費控除の対象は、その年に**実際に払った**医療費です。12月に治療を受けて翌年1月に払った分は、払った年の控除になります。また、家族の医療費を合算できるのは、生計を一にする配偶者や親族の分を自分が払った場合です。
:::

:::view
案件をご案内するときは、先に稼働日数やリモートの可否を伺い、条件に合う案件だけをお出ししています。定期的な通院や治療の予定がある方は、通院する曜日を空けた稼働日数や、移動の少ないリモート中心の案件を希望条件に含めて考えることができます。参画が決まってから曜日を動かすのは難しいこともあるため、通院の予定は稼働の希望として早めにご相談ください。
:::

## セルフメディケーション税制の要件

### 対象になる人

その年に「健康の保持増進及び疾病の予防への取組」として、次のいずれかを**申告する本人が**受けていることが条件です。家族が受けている必要はありません。

1. 健康保険組合・市区町村の国民健康保険などが行う健康診査（人間ドック、各種健診など）
2. 市区町村が健康増進事業として行う健康診査
3. 予防接種（定期予防接種、インフルエンザの予防接種）
4. 勤務先で行う定期健康診断（事業主健診）
5. 特定健康診査（いわゆるメタボ健診）、特定保健指導
6. 市区町村が健康増進事業として行うがん検診

会社員なら4の事業主健診で条件を満たすことが多いのですが、業務委託のフリーランスは勤務先の健診がありません。国民健康保険の特定健診（40〜74歳）や市区町村のがん検診、インフルエンザの予防接種などを受けた年に使える制度だと考えておきましょう。取組を受けたことを示す書類（氏名・受けた年・実施した保険者や医療機関の名称の記載があるもの）は、申告書への添付は不要ですが、申告期限から5年間は提示を求められることがあります。

### 対象になる医薬品と控除額

対象は、医療用から市販薬に転用された医薬品（スイッチOTC医薬品）などです。対象商品は、購入時のレシートなどにセルフメディケーション税制の対象である旨が表示されます。

**控除額 ＝ 対象医薬品の購入費（保険金などで補てんされる分を除く）− 1万2,000円**（上限8万8,000円）

健康診断や予防接種そのものの費用は、この控除の対象になりません。

## どちらを選ぶかの考え方

国税庁によると、2つは選択適用です。セルフメディケーション税制を選んだ年は、ほかの医療費が10万円を超えていても通常の医療費控除は受けられません。申告した後に、更正の請求や修正申告で選び直すこともできません。

| 比べる点 | 医療費控除 | セルフメディケーション税制 |
|---|---|---|
| 対象 | 診療・治療・薬・通院費など幅広い | 対象の市販薬の購入費だけ |
| 引く金額 | 10万円（総所得金額等200万円未満は5%） | 1万2,000円 |
| 上限 | 200万円 | 8万8,000円 |
| 条件 | なし | 本人が健診・予防接種などを受けている |

判断の手順は次のとおりです。

1. 1年分の医療費（補てん分を引いた後）を合計し、10万円（または所得の5%）を引いて、医療費控除の額を出す
2. 対象の市販薬の購入費を合計し、1万2,000円を引いて、セルフメディケーション税制の額を出す
3. 控除額の大きいほうを選ぶ（健診などの条件を満たしていなければ1しか選べない）

入院や歯の治療などで医療費が大きい年は医療費控除、病院にはほとんど行かず市販薬を使った年はセルフメディケーション税制が有利になりやすい、という目安になります。

## 申告の手順と書類

医療費控除は確定申告で受けます。フリーランスはもともと確定申告をするため、申告書に控除の内容を加えるだけです。

- **明細書を作って添付する**：領収書をもとに「医療費控除の明細書」または「セルフメディケーション税制の明細書」を作り、申告書に付けます。領収書そのものの添付は不要です
- **医療費通知を使う**：健康保険から届く医療費通知（医療費のお知らせ）を添付すると、その分は明細書の記載を簡略にできます
- **領収書は5年間残す**：税務署が申告期限から5年を経過する日まで、領収書の提示や提出を求めることがあります

国税庁の確定申告書等作成コーナーでは、明細書も入力に沿って作成されます。領収書が多い人は、国税庁の「医療費集計フォーム」で集計したデータを読み込むこともできます（セルフメディケーション税制では使えません）。e-Taxでの申告は[e-Taxの記事](/media/etax/)をご覧ください。

:::view
業務委託の契約には期間があり、案件と案件の間に数週間の空きができることもあります。当社は個別契約に契約期間を書いてお渡ししているため、契約の終わりが見えた段階で、次の参画までの間に健診や歯の治療、予防接種の予定を入れる方法もあります。セルフメディケーション税制の条件になる健診や予防接種は、その年のうちに受けておく必要があるため、受けた記録を確定申告の書類とまとめて保管しておくことをおすすめします。
:::

## 医療費控除で税金はどれくらい減るか

医療費控除は所得控除なので、控除額がそのまま税金になるわけではありません。所得税は「控除額×その人の所得税率」の分だけ減ります。住民税も、所得控除が反映されて所得割が下がります（住民税の仕組みは[住民税の記事](/media/juminzei/)）。

所得税率は課税所得によって5%から45%まで分かれています。たとえば税率10%の人が10万円の医療費控除を受けると、所得税は1万円ほど減る計算です（復興特別所得税は別）。

:::point
- 医療費控除は「払った医療費−補てん分−10万円（所得200万円未満は5%）」。上限200万円
- フリーランスは所得が少ない年に「5%」の基準に当たり、10万円未満でも控除できることがある
- セルフメディケーション税制は「対象市販薬−1万2,000円」。上限8万8,000円。本人の健診などが条件
- 2つはどちらか一方。申告後に選び直せない
:::

対象になるかどうか迷う支出や、家族の医療費の扱いは、税理士・税務署にご相談ください。

## よくある質問

### 申告を忘れた医療費控除は、後から受けられますか？

確定申告を出した後に医療費控除を追加する場合は、更正の請求で直す方法があります。更正の請求ができる期間や手順は[修正申告と更正の請求の記事](/media/shusei-shinkoku/)で解説しています。ただし、通常の医療費控除とセルフメディケーション税制のどちらかを選んで申告した後に、もう一方へ切り替えることはできません。

### 家族の医療費もまとめて控除できますか？

自分と生計を一にする配偶者やその他の親族のために自分が払った医療費は、合算できます。同居していない親の医療費も、生計を一にしていれば対象になる場合があります。誰が払ったかで控除を受ける人が決まるため、個別の判断は税務署にご相談ください。

### 人間ドックの費用は医療費控除の対象になりますか？

健康診断や人間ドックの費用は、原則として対象になりません。また、セルフメディケーション税制でも、健診や予防接種そのものの費用は対象外です。人間ドックは、セルフメディケーション税制を使うための「一定の取組」として役に立ちます。
