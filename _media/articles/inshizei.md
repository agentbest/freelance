業務委託契約書に印紙が要るかどうかは、契約書の名前ではなく**書かれている中身**で決まります。仕事の完成を約束する請負の内容なら「請負に関する契約書（第2号文書）」として記載金額に応じた印紙税が、継続する取引の基本的な条件を定めるものなら「継続的取引の基本となる契約書（第7号文書）」として1通4,000円の印紙税がかかることがあります。

一方、業務を行うことを約束する準委任だけの契約書は、課税文書にあたらないことが多く、電子契約で作ったデータには印紙税がかかりません。2026年10月時点の国税庁の資料（令和8年4月1日現在の法令等に基づくもの）をもとに、判断の手順を整理します。

## 課税文書かどうかを決める3つの条件

国税庁は、印紙税がかかる「課税文書」を、次の3つすべてにあたる文書としています。

1. 印紙税法別表第一（課税物件表）に掲げる20種類の文書によって証明されるべき事項（課税事項）が記載されている
2. 当事者の間で、その課税事項を証明する目的で作られた文書である
3. 印紙税法第5条の非課税文書ではない

判断は、文書の名称や形式的な文言ではなく、**記載されている内容の実質的な意味**で行うとされています。「業務委託契約書」という名前でも、中身が請負なら請負に関する契約書として扱われます。また、取引金額が書かれていなくても、単価や数量などから当事者の間で金額を計算できる場合は、その金額が記載金額になるとされています。

## 請負の内容なら第2号文書

### 「請負」の範囲

国税庁は、請負を、一方が仕事の完成を約束し、相手方がその結果に対して報酬を払うことを約束する契約と説明しています。建設工事のような形のあるものだけでなく、警備や清掃のような**形のない結果**を目的とするものも含まれます。システムの機能を完成させて納める契約や、Webサイトの制作を一括で受ける契約は、内容によってここにあたります。

### 税額

第2号文書の印紙税は、記載された契約金額で決まります。

| 記載された契約金額 | 印紙税額 |
|---|---|
| 1万円未満 | 非課税 |
| 1万円以上100万円以下 | 200円 |
| 100万円超200万円以下 | 400円 |
| 200万円超300万円以下 | 1,000円 |
| 300万円超500万円以下 | 2,000円 |
| 500万円超1,000万円以下 | 1万円 |
| 1,000万円超5,000万円以下 | 2万円 |
| 5,000万円超1億円以下 | 6万円 |
| 1億円超5億円以下 | 10万円 |
| 契約金額の記載がないもの | 200円 |

5億円を超える区分もありますが、フリーランスの契約では使う場面が限られるため省略しています。建設工事の請負契約書には、令和9年3月31日までに作成されるものについて軽減措置がありますが、ITの業務委託は通常これにあたりません。

なお、1万円未満の非課税には例外があります。第2号のほかに第3号から第17号の文書にもあたり、所属が第2号に決まる文書は、1万円未満でも非課税にならないとされています。

## 継続取引の基本条件を定めるなら第7号文書

第7号文書は、特定の相手と継続して生じる取引の基本となる契約書のうち、一定の要件を満たすものです。業務委託に関係するのは、主に次の形です。

- 営業者の間で、売買・売買の委託・運送・運送取扱い・**請負**に関する複数の取引を継続して行うため、取引に共通する基本的な条件を定める契約書
- 基本的な条件とは、目的物の種類、取扱数量、単価、支払方法、損害賠償の方法、再販売価格のうち1つ以上

税額は1通4,000円です。ただし、**契約期間が3か月以内で、更新の定めがないもの**は除かれます。国税庁は、下請基本契約書を例の一つに挙げています。

請負の基本契約を結び、案件ごとに個別契約を交わす形では、基本契約が第7号文書に、個別契約が第2号文書にあたることがあります。基本契約と個別契約の関係は[基本契約と個別契約の記事](/media/basic-and-individual-contract/)で解説しています。1つの文書が複数の号にあたる場合は、どの号に属するかを決めるルールがあり、それによって税額が変わります。判断に迷うときは税務署にご確認ください。

## 準委任の契約書は通常かからない

課税物件表の20種類には、委任（準委任）の契約そのものを対象とする号はありません。そのため、業務を行うことを約束する準委任の内容だけが書かれた契約書は、第2号にも第7号にもあたらなければ、通常は課税文書になりません。月額で稼働する開発支援、PMO、コンサルティングの契約は、多くがこの形です。

ただし、次のような場合は確認が必要です。

- 準委任の契約書に、成果物の完成と引き渡しを約束する条項が入っている
- 1つの契約書の中に、準委任の業務と請負の業務が両方書かれている
- 準委任と書かれていても、内容が仕事の完成を約束するものになっている

準委任と請負の違いは[準委任と請負の記事](/media/junin-vs-ukeoi/)で整理しています。

:::view
当社は、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。印紙税がかかるかどうかは、この「業務範囲」に何を約束すると書かれているかで変わります。契約形態の表示だけでなく、業務範囲の書き方を読んでおくことをおすすめします。お渡しした契約書について印紙の扱いが気になるときは、ご質問いただければ確認します。
:::

## 電子契約のデータには印紙税がかからない

国税庁の質疑応答事例では、印紙税の課税対象は課税物件表に掲げる「文書」であり、電磁的記録はこれに含まれないため、電子メールで送った注文請書などの電磁的記録には印紙税が課されないとしています。電子契約サービスで結んだ契約書も、紙の原本を作らない限り、同じ考え方になります。

一方、電子契約で結んだあとに、別途、紙の契約書に署名・押印して取り交わすと、その紙の文書が課税文書にあたることがあります。署名前の確認や締結後の保存は[電子契約の記事](/media/denshi-keiyaku/)で解説しています。

:::view
案件紹介の現場では、準委任の案件に長く参画してきた方が、初めて請負の仕事を直接受けたときに、印紙の要否や負担を決めないまま紙の契約書を交わしてしまう例を見かけます。準委任では意識しなかった論点が、請負では出てきます。紙で契約書を作ると決まった段階で、印紙をどちらが負担するかを先に話しておくことをおすすめします。
:::

## 誰が納めるか、貼らなかったらどうなるか

### 納めるのは文書の作成者

印紙税法第3条は、課税文書の作成者が印紙税を納める義務を負うとしています。1つの文書を2人以上で共同して作った場合は、**連帯して**納める義務を負います。契約書を2通作って双方が1通ずつ保管する場合は、それぞれの文書が課税文書になるため、実務では自分が保管する1通の印紙を自分で負担する形が多く見られます。どちらが負担するかは契約で決めておくと安心です。

### 貼り方と過怠税

印紙は文書を作る時までに貼り、文書と印紙の彩紋にかけて判明に消さなければなりません（第8条）。

貼らなかった場合は、納めなかった印紙税の額とその2倍の額を合わせた額、つまり**本来の3倍**の過怠税がかかります（第20条第1項）。調査を受ける前に自分から申し出た場合は、納めなかった額とその10%を合わせた額に軽くなります（同条第2項）。印紙を消さなかった場合は、消していない印紙の額面と同じ額の過怠税がかかります（同条第3項）。過怠税の合計額が1,000円に満たないときは1,000円とされています（同条第4項。自分から申し出た場合の過怠税だけのときを除く）。

:::caution
印紙税は文書の作成者に納める義務があり、共同で作った文書なら連帯して負います。「相手が貼るだろう」と思い込まず、請負の契約書を紙で作るときは、契約金額の区分を確かめて、署名・押印の時点でどちらが貼るかを決めておきましょう。経費の扱いは[経費の記事](/media/keihi-list/)も参考にしてください。
:::

## 判断の手順のまとめ

1. **電子か紙か**：電子契約だけで結ぶなら、印紙税はかからない
2. **中身は請負か準委任か**：仕事の完成を約束していれば第2号の候補
3. **継続取引の基本条件か**：請負などの継続取引について単価や支払方法などを定め、期間が3か月を超えるか更新の定めがあれば第7号の候補
4. **記載金額はいくらか**：単価と数量から計算できる場合も記載金額になる
5. **迷ったら税務署へ**：複数の号にあたる場合の所属の決め方など、個別の判断は税務署や税理士に確認する

:::point
- 印紙税は契約書の名前ではなく中身で決まる
- 請負の内容なら第2号文書。記載金額1万円以上100万円以下なら200円など、金額に応じて税額が決まる
- 請負などの継続取引の基本条件を定める契約書は第7号文書（1通4,000円）。3か月以内で更新の定めがないものは除く
- 準委任だけの契約書や、電子契約のデータには通常かからない
- 貼り忘れは本来の3倍の過怠税。自分から申し出れば軽くなる
:::

## よくある質問

### 業務委託契約書に「準委任」と書いてあれば印紙は不要ですか？

名称や表示ではなく中身で判断されるため、「準委任」と書かれていても、成果物の完成を約束する内容であれば請負に関する契約書にあたることがあります。業務を行うこと自体を約束する内容だけなら、通常は課税文書にあたりません。判断に迷う場合は、税務署にご確認ください。

### 契約金額を書かずに単価だけを書けば、200円で済みますか？

国税庁は、取引金額の記載がなくても、単価や数量などから当事者の間で金額を計算できる場合は、それを記載金額とするとしています。単価と期間・数量が書かれていれば、計算した金額で区分が決まることがあります。また、請負の継続取引で単価を定める基本契約は、第7号文書にあたる場合もあります。

### 注文書と注文請書のどちらに印紙が要りますか？

国税庁は、請負に関する契約書の例として工事注文請書や物品加工注文請書を挙げています。請負の注文を受けたことを証明するために受注者が作る注文請書は、内容によって第2号文書になります。一方、発注者が出す注文書は、通常は申込みの文書です。ただし、書き方によって扱いが変わることがあるため、個別の判断は税務署にご確認ください。
