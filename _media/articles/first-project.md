独立後の最初の案件は、**すでに経験のある職種・工程で、契約期間と支払条件がはっきりした案件**を選ぶと失敗しにくくなります。最初の案件は、収入の土台であると同時に、フリーランスとしての最初の実績にもなります。報酬の額だけで決めず、続けられる内容か、いつ入金されるか、契約が書面で示されるかをあわせて確かめることが大切です。

この記事では、最初の案件で重視したいこと、決める時期、避けたい案件の特徴、契約で確かめる点を整理します。

## 最初の案件で重視したい3つのこと

### 1. 経験のある職種・工程であること

独立直後は、新しい分野に挑戦したくなるかもしれません。ただ、最初の案件で成果を出せないと、契約が早く終わったり、次の案件の面談で説明に困ったりすることがあります。会社員として実務で担ってきた職種・工程の案件を選ぶと、立ち上がりが早く、評価も得やすくなります。

新しい技術や役割は、経験のある領域を軸にした案件の中で、周辺から少しずつ広げていくほうが現実的です。

### 2. 一定の期間、続く見込みがあること

最初の案件が数週間で終わると、すぐに次の案件を探すことになり、収入も不安定になります。契約期間がある程度あり、更新の見込みがあるかを面談で確かめておくと、独立直後の生活を組み立てやすくなります。

### 3. 支払条件がはっきりしていること

独立直後は、会社員時代の貯えで生活をつなぐ時期です。報酬がいつ入金されるかによって、必要な手元資金が変わります。支払期日、請求書の締め日と送り方を、参画前に確かめておきましょう。

:::view
独立直後の方の案件をご紹介していると、最初の1件目は「報酬が少し下がっても、慣れた工程で、長く続きそうな案件」を選ばれた方のほうが、その後の案件選びが楽になる傾向があります。最初の案件での評価が、次の案件の面談で話せる材料になるからです。当社では、案件をご案内するときに先に稼働日数・リモートの希望・希望金額を伺い、合う案件だけをお出ししています。また、取引先の会社の実態と支払条件を確かめた案件を扱っています。
:::

## 最初の案件を決める時期

最初の案件は、退職日が見えてきた段階で探し始めるのが一般的です。参画の開始日は退職日の後になるため、次の順番で進めると、空白期間を短くしやすくなります。

1. **退職の時期を決める**：会社の規則に沿って、退職の申し出の時期を決める
2. **スキルシートを用意する**：会社員時代の経験を、案件の募集に合わせて書けるようにする
3. **参画できる日を決めて相談する**：退職日と有給休暇の消化を踏まえ、参画できる最も早い日を伝える
4. **面談・契約**：条件を確かめ、取引条件が示された書面を受け取る

募集中の案件は、参画の開始日が近いものが多いため、あまり早く探し始めても、条件が合わないことがあります。退職までの手順は[会社員からフリーランスになる手順の記事](/media/quit-company-steps/)、スキルシートの書き方は[スキルシートの基本の記事](/media/skillsheet-basics/)をご覧ください。

## 条件に優先順位を付ける

最初の案件では、すべての希望がそろうとは限りません。次のような条件について、何を優先し、どこまでなら譲れるかを先に決めておくと、提案を受けたときに判断しやすくなります。

| 条件 | 考えたいこと |
|---|---|
| 報酬 | 生活費、国民健康保険料・国民年金保険料、税金を払っても回る額か |
| 稼働日数 | 週5日か、週3〜4日か。最初から日数を減らして収入が足りるか |
| リモート | 出社の頻度はどこまで受けられるか |
| 契約期間 | 短期でもよいか、一定期間続く見込みがほしいか |
| 技術・役割 | 経験のある範囲か、少し広げる範囲か |

独立直後は、国民健康保険や国民年金への切り替えで、会社員時代より手元から出ていくお金が増えることがあります。報酬は、こうした支出を差し引いても生活が回るかで考えます。

## 避けたい案件の特徴

次のような特徴がある案件は、最初の1件目としては慎重に判断したほうが安全です。

- **取引条件を書面で示してもらえない**：口頭の約束だけで参画が始まる
- **支払期日があいまい**：「納品後に支払い」とだけ言われ、具体的な日付が決まっていない
- **業務の範囲が決まっていない請負**：完成の基準や追加作業の扱いがはっきりしない
- **経験のない分野で報酬だけが高い**：成果を求められる水準と、自分の経験が合っていない
- **前職の取引先からの依頼で、退職時の約束に触れるおそれがある**：競業避止や引き抜きの禁止の誓約に反しないか確かめていない

特に、前職の会社や取引先から直接声がかかった場合は、退職時に交わした誓約書や就業規則で、同業での業務や取引先との直接の取引が制限されていないかを確かめてください。考え方は[競業避止の条項の記事](/media/non-compete/)で解説しています。

:::caution
「早く決めたいので、契約書はあとで」と言われて参画を始めると、報酬の額や支払期日、業務の範囲で認識がずれたときに、確かめる手段がありません。独立直後ほど、条件を書面で受け取ってから参画を始めることが大切です。
:::

## 契約で確かめること：フリーランス法の取引条件の明示

2024年11月1日に施行されたフリーランス法（特定受託事業者に係る取引の適正化等に関する法律）では、発注側がフリーランスに業務を委託したときに、直ちに取引条件を書面または電子メールなどで示すことが求められています。示される条件には、業務の内容、報酬の額、支払期日、役務の提供を受ける場所や期日などが含まれます（公正取引委員会「フリーランス法特設サイト」、2026年10月時点で確認）。

支払期日についても決まりがあります。発注側は、給付を受領した日から60日以内のできる限り短い期間内で、支払期日を具体的な日付として定める必要があるとされています。最初の案件では、稼働を始めた月の報酬がいつ入金されるかを、この支払期日から逆算しておくと、手元資金の計画が立てやすくなります。くわしくは[60日以内の支払いの記事](/media/freelance-act-60days/)をご覧ください。

また、6か月以上の業務委託を発注側が中途解除したり、更新しなかったりする場合は、原則として少なくとも30日前までの予告が求められています。公正取引委員会のQ&Aでは、同じ当事者で内容に一定の同一性があり、空白期間が1か月未満で更新された契約は、最初の始期から通して期間を数えるという考え方も示されています。最初の案件が短い期間の契約から始まる場合でも、更新を重ねるうちにこの対象になることがあります。

明示される項目の詳しい内容は[取引条件の明示の記事](/media/freelance-act-terms/)で解説しています。なお、フリーランス法の「フリーランス」は、従業員を使用しない事業者を指します。

## 入金までの資金を見積もる

最初の案件では、稼働を始めてから最初の報酬が入金されるまでに、ある程度の期間があきます。たとえば月末締めで請求する案件なら、1か月目の稼働分は、締め日の後に請求し、その後の支払期日に入金されます。この間の生活費と、独立直後に払う保険料・税金は、手元の資金でまかなうことになります。

- 最初の入金日はいつか（締め日と支払期日から確かめる）
- その日までの生活費と、保険料・税金の支払い
- 入金が遅れた場合に、何か月分の余裕があるか

独立前の貯えの目安や準備は、[独立のタイミングの記事](/media/independence-timing/)もあわせてご覧ください。

## 困ったときの相談先

最初の案件で、報酬の未払いや、契約にない作業を求められるといったトラブルが起きた場合は、ひとりで抱え込まずに相談できる窓口があります。厚生労働省の委託事業として第二東京弁護士会が運営する「フリーランス・トラブル110番」では、発注者との取引のトラブルについて、弁護士に無料で相談できます（2026年10月時点で確認）。案件紹介サービスを通して参画している場合は、担当者にも早めに相談してください。個別の契約の判断は、弁護士などの専門家にご相談ください。

:::view
最初の案件で戸惑う方が多いのは、技術よりも、請求や稼働の報告といった事務の面です。月末の稼働報告の締め切り、請求書の送り先、入金の確認の仕方を、参画の初週に確かめておくと安心です。当社では、契約で業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。条件の読み方で分からない点があれば、ご質問いただければ確認します。
:::

:::point
- 最初の案件は、経験のある職種・工程で、続く見込みと支払条件がはっきりしたものを選ぶ
- 報酬・稼働・リモート・期間・役割に優先順位を付けておく
- 取引条件は書面で受け取り、支払期日から最初の入金日を逆算する
- 前職の関係からの依頼は、退職時の誓約や競業避止の範囲を確かめる
:::

## よくある質問

### 最初の案件は短期と長期のどちらがよいですか？

独立直後の生活を安定させたいなら、一定の期間続く見込みがある案件のほうが計画を立てやすくなります。短期の案件は、終わった後すぐに次を探す必要があります。短期の案件を受ける場合は、終わる時期を見越して、早めに次の案件の相談を始めておくと安心です。

### 前の会社から業務委託で仕事を受けてもよいですか？

受けることはできますが、会社員時代と同じように指示を受けて働く形になっていないかに注意が必要です。業務委託である以上、業務の範囲や進め方を契約で決め、自分の判断で進めるのが前提です。退職時の誓約書の内容も確かめておきましょう。

### 最初の案件の報酬は、会社員時代の給与をもとに決めてよいですか？

給与の額だけを基準にすると、国民健康保険料や国民年金保険料、経費、案件のない期間の分が足りなくなることがあります。報酬は、こうした支出を差し引いても生活が回るかで考えます。報酬の水準は案件によって大きく変わるため、複数の案件の条件を比べてから決めると判断しやすくなります。
