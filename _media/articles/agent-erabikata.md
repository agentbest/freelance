フリーランスエージェント（案件紹介サービス）は、**扱う案件と自分の希望の重なり、契約と取引条件の示し方、取引先の確かめ方、報酬の説明の仕方、経歴の扱い、担当者の対応**の6つの観点で比べるのが基本です。案件の数や、広告に出ている高い金額だけで決めると、参画してから「思っていた条件と違う」となりやすくなります。

確かめ方として一番手堅いのは、登録先の候補それぞれに**同じ質問をして、答えを並べて比べる**ことです。この記事では、観点ごとに何を聞けばよいかと、比べるときの手順を整理します。登録から参画までの流れは[エージェントの使い方の記事](/media/agent-how-to-use/)で解説しています。

## 比べる観点の全体像

最初に、6つの観点と、それぞれで確かめることを一覧にします。

| 観点 | 確かめること | 見えにくい理由 |
|---|---|---|
| 1. 扱う案件と希望の重なり | 自分の職種・働き方・稼働日数の案件がどのくらいあるか | 公開されている案件は一部のことが多い |
| 2. 契約と取引条件の示し方 | 誰と契約し、条件がどの書面で示されるか | 登録の段階では契約書を見ないことが多い |
| 3. 取引先の確かめ方 | 発注元の会社や支払条件をどう確かめているか | 外からは分からない |
| 4. 報酬の説明の仕方 | 受け取る金額の内訳や精算をどこまで説明するか | 率だけが話題になりやすい |
| 5. 経歴の扱い | 経歴を誰に、どの範囲で提案するか | 規約やプライバシーポリシーに書かれている |
| 6. 担当者の対応 | 希望を踏まえて紹介するか、都合の悪い情報も伝えるか | 担当者によって差がある |

どれか一つが優れているかどうかより、**自分が重視する観点で不安が残らないか**を見るほうが、選んだあとに困りにくくなります。

## 観点1：扱う案件と自分の希望が重なっているか

登録先によって、得意な職種・業界・働き方は違います。開発の案件が中心のところもあれば、コンサルやPMOの案件が多いところもあります。

確かめるときは、公開されている案件の一覧を眺めるだけでなく、最初の面談で希望を伝えたあとに**実際に紹介される案件**を見るのが確かです。公開されていない案件を持っていることもあるためです。

- 自分の職種・工程の案件が、継続して出ているか
- 週3〜4日、フルリモートなど、希望する働き方の案件があるか
- 紹介された案件の必須スキルが、自分の経験と重なっているか

案件の数が多くても、自分に合う案件が少なければ使いにくくなります。案件票の読み方は[案件票の読み方の記事](/media/project-info-read/)で紹介しています。

## 観点2：契約の相手と取引条件の示し方

参画が決まったとき、**自分が誰と業務委託契約を結ぶのか**を確かめます。案件紹介サービスが自ら契約の相手になる形と、発注元と直接契約し、サービスは紹介や事務の代行だけをする形があります。契約の相手によって、報酬を払う会社、困ったときの窓口、契約書の書式が変わります。

フリーランス法では、業務を委託した事業者は、委託したら直ちに、業務の内容・報酬の額・支払期日などの取引条件を、書面またはメールなどの電磁的方法で示すこととされています。口頭だけでは足りません（公正取引委員会の特設サイト、2026年10月時点）。

比べるときは、次の点を聞いてみます。

1. 契約の相手はどこか
2. 基本契約と個別契約（または発注書）のどちらに何が書かれるか
3. 契約書のひな形を、参画の前に見せてもらえるか
4. 契約期間と更新の手続き、途中で終わるときの扱い

ひな形を事前に見られると、損害賠償や再委託、秘密保持の条項を落ち着いて読めます。示されるべき取引条件の中身は[取引条件の明示の記事](/media/freelance-act-terms/)にまとめています。

:::view
案件をご紹介する立場から見ると、契約の書面について質問される方は、参画後の行き違いも少ない傾向があります。当社では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。登録先を比べるときは、どこに対しても「参画前に契約書の書式を見られますか」と同じ形で聞き、答えを並べてみることをおすすめします。
:::

## 観点3：取引先と支払条件をどう確かめているか

紹介される案件の発注元が、どのような会社かは外からは見えません。支払が遅れる、発注元の都合で急に案件が止まるといった事態は、フリーランスの生活に直接響きます。

聞いてみたいのは、次のような点です。

- 発注元の会社について、何を確かめてから案件を扱っているか
- 自分への支払期日は、発注元からの入金に左右されるか
- 支払が遅れたとき、誰がどう対応するか
- 商流の中で、自分の契約の相手から上に何社が入っているか

答えが具体的かどうかが比べる手がかりになります。商流の仕組みは[商流の記事](/media/shoryu/)、支払期日の考え方は[支払サイトの記事](/media/payment-terms/)で解説しています。

## 観点4：報酬の内訳をどう説明するか

エージェント経由の案件では、発注元が払う金額と自分が受け取る報酬の間に差があります。差の大きさそのものより、**質問したときにどう説明されるか**が比べる材料になります。

- 提示される金額が「自分が受け取る額」なのか、はっきりしているか
- 税込か税別か、精算幅と超過・控除の計算方法を説明できるか
- 交通費や経費が報酬に含まれるか
- 内訳を聞いたとき、答えられる範囲と答えられない理由を示してくれるか

率を公開しているかどうかだけで比べると、商流や精算の条件の違いが見えません。受け取る額と条件をそろえて並べるのが確かです。考え方は[マージンの記事](/media/agent-margin/)で整理しています。

## 観点5：経歴と個人情報の扱い

スキルシートや連絡先は、登録先に渡す大事な情報です。比べるときは、次の点を確かめます。

- 経歴を発注元に提案する前に、自分の了承を求めるか
- 提案するとき、氏名や連絡先をどう扱うか
- 登録した情報の利用目的と、退会したときの削除の方法

了承なしに経歴が出る仕組みだと、別の登録先と同じ案件に重ねて応募してしまうおそれがあります。複数の登録先を使うときの注意は[複数登録の記事](/media/multi-agent/)をご覧ください。

## 観点6：担当者の対応

同じ登録先でも、担当者によって進め方は違います。最初の面談とその後のやり取りで、次の点を見ます。

| 見るところ | 気にしたいサイン |
|---|---|
| 希望の聞き方 | 稼働日数やリモート、金額を聞かずに案件を並べる |
| 断ったときの反応 | 理由を伝えても、同じ条件の案件が続く |
| 都合の悪い情報 | 出社の頻度や商流を聞いても、はっきり答えない |
| 決断の急がせ方 | 比べる時間を取らせず、その場での返事を求める |
| 連絡の確かさ | 約束した連絡の時期が守られない |

担当者との相性は、何度かやり取りをしないと分かりません。気になる点があれば、担当者の変更を頼めるかを聞いてみる方法もあります。

## 案件情報が正確かどうかも見る

フリーランス法では、従業員を使う発注事業者が広告などでフリーランスの募集情報を出すときは、虚偽の表示や誤解を生じさせる表示をしてはならず、情報を正確かつ最新の内容に保つこととされています（公正取引委員会の特設サイト、2026年10月時点。所管は厚生労働省）。

利用者の立場では、**案件情報と面談で聞く話が食い違わないか**を見ておくと、登録先の情報の扱い方が分かります。募集が終わった案件が載り続けていないか、金額や働き方が説明の段階で大きく変わらないかも手がかりです。ルールの詳しい内容は[募集情報の的確表示の記事](/media/freelance-act-boshu/)で解説しています。

:::caution
「高単価」「案件数」をうたう広告は、比べる材料の一つにすぎません。広告の金額が自分に当てはまるとは限らず、案件数が多くても自分の職種の案件が少ないこともあります。登録の前後で、自分の条件に合う案件が実際に紹介されるか、契約の書面がどうなっているかで判断してください。
:::

## 比べるときの手順

観点が分かっても、頭の中だけで比べると印象に引っ張られます。次の順で進めると、答えを並べて比べやすくなります。

1. **候補をいくつかに絞る**：自分の職種や働き方の案件を扱っているところを選ぶ
2. **聞くことを一枚にまとめる**：上の6つの観点から、自分にとって大事な質問を選ぶ
3. **同じ質問を各社にする**：最初の面談やメールで、言い回しを変えずに聞く
4. **答えを表に並べる**：具体的な答えか、あいまいな答えかを書き分ける
5. **紹介された案件で確かめる**：答えと、実際に紹介された案件の条件が合っているかを見る

一つに絞る必要はありません。いくつか使いながら、合うところに寄せていく人もいます。直接契約との違いも含めて考えたい場合は、[直接契約とエージェント経由の違いの記事](/media/direct-vs-agent/)が参考になります。

:::view
取引先の会社がどのような会社か、支払の条件がどうなっているかは、ご紹介を受ける側からは見えにくいところです。当社では、取引先の会社の実態と支払条件を確かめた案件を扱っています。ご紹介した案件の発注元や支払について気になる点があれば、ご質問いただければ確認します。どの登録先を使う場合も、参画を決める前にこの点を聞いておくことをおすすめします。
:::

:::point
- 案件の数や広告の金額ではなく、6つの観点で比べる
- 契約の相手と、取引条件がどの書面で示されるかを確かめる
- 報酬は率より、受け取る額と精算・支払期日の説明で比べる
- 同じ質問を各社にして、答えを並べるのが確かな比べ方
:::

## よくある質問

### 大手と小規模の登録先では、どちらがよいですか？

規模だけでは決まりません。扱う案件の数が多いところでも、自分の職種の案件が少なければ使いにくくなります。小規模でも、特定の領域の案件を多く持っていることがあります。6つの観点で同じ質問をし、自分の希望に合う案件が実際に紹介されるかで判断することをおすすめします。

### 担当者の対応が合わないと感じたら、どうすればよいですか？

希望条件や断った理由が伝わっていない場合は、まず具体的に伝え直します。それでも合わないときは、担当者の変更を頼めるかを聞くか、ほかの登録先を中心に使う方法があります。合わないまま案件を決めると、参画後の相談もしにくくなります。

### 登録前に、契約書の中身を見せてもらうことはできますか？

登録先によって対応は違いますが、聞いてみる価値はあります。少なくとも参画を決める前には、業務の内容・報酬の額・支払期日などの取引条件を書面やメールで受け取り、面談で聞いた内容と合っているかを確かめてください。
