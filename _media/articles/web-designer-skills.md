Webデザイナーのフリーランス案件では、**目的に沿ったビジュアルの設計、画面幅ごとのレイアウト、実装を前提にしたデータの作り方、アクセシビリティと表示の速さへの配慮、公開後の改善、確認と修正を進める力**が見られます。デザインツールを使えることは前提で、その上で「何を判断して作れるか」が問われます。

どこまで求められるかは経験の段階によって違います。この記事では、案件で問われるスキルを分野ごとに整理し、段階ごとに何ができると任される範囲が広がるかをまとめます。

## 案件で見られるスキルの全体像

| 分野 | 主な中身 | 案件で問われること |
|---|---|---|
| ビジュアル設計 | レイアウト、文字、配色、写真やイラストの扱い | 媒体の目的と相手に合っているか |
| 情報の並べ方 | 構成案の読み取り、見出しの強弱、導線 | 伝えたい順に目が動くか |
| 画面幅への対応 | スマートフォンとパソコンでの見え方 | 幅が変わっても崩れず、読みやすいか |
| 実装への受け渡し | 部品の使い回し、余白と文字のルール、書き出し | 実装の担当者が迷わず組めるか |
| 品質への配慮 | アクセシビリティ、表示の速さ | 多くの人が使え、重くならないか |
| 改善 | 数値の見方、比較の進め方 | 公開後に何を直せばよいか判断できるか |
| 進め方 | 聞き取り、確認と修正、素材の手配 | 確認する人が多くても作業を前に進められるか |

画面の操作の流れやユーザー調査が中心になる案件は、UI/UXデザイナーの領域です。求められるスキルは[UI/UXデザイナーのスキルの記事](/media/uiux-skills/)で別に整理しています。

## 分野ごとに問われる中身

### ビジュアル設計

案件で見られるのは、きれいに作れるかより、**媒体の目的と相手に合った見た目を選べるか**です。企業サイトなら会社の印象と信頼感、LPなら申し込みまでの流れ、バナーなら一瞬で内容が伝わることが求められます。既存のロゴや色の決まりがある案件では、その範囲の中で表現を工夫する力も問われます。

### 情報の並べ方

構成案やワイヤーフレームを受け取ったとき、そのまま形にするだけでなく、見出しの強弱や要素の順序が目的に合っているかを判断できると、任される範囲が広がります。文章が長すぎる、比べたい情報が離れているといった問題に気づき、代わりの案を出せることも評価されます。

### 画面幅への対応と実装への受け渡し

スマートフォンで見られることを前提に、画面幅が変わったときの並び方を設計できることは、ほとんどの案件で求められます。チームの案件では、次の点ができているかで実装の手戻りが大きく変わります。

- 同じ部品は同じ形で作り、使い回せるようにしている
- 余白、文字の大きさ、色を決まった値の組み合わせで作っている
- ボタンを押したとき、入力に誤りがあったときなど、状態ごとの見た目を用意している
- 画像の書き出し方や、動きの指示を残している

自分で組まない案件でも、HTML・CSSでどう組まれるかを知っていると、組めないデザインを渡すことが減ります。WordPressに組み込む前提の案件では、更新する人が使いやすい作りも問われます。CMSの構築は[WordPressの案件で求められるスキル](/media/wordpress-skills/)をご覧ください。

### アクセシビリティ

障害のある人や高齢の人を含め、多くの人が使えるページにするための配慮です。デザインの段階で決まることも多く、Webデザイナーに求められる場面が増えています。

- 文字と背景の明るさの差（コントラスト）が十分か
- 色だけで意味を伝えていないか（必須の項目を赤い文字だけで示すなど）
- 画像に代わりの説明を付けられる作りになっているか
- 押せる部分の大きさと、キーボードで操作しているときの見た目を用意しているか

国際的な指針としては、W3C（ウェブの標準を定める団体）のWCAG（ウェブコンテンツのアクセシビリティの指針）があり、2026年10月時点の最新版はWCAG 2.2です。達成の水準はA・AA・AAAの3段階で示されます。国内の規格や法律の動きは[Webデザイナーの将来性の記事](/media/web-designer-future/)で整理しています。

### 表示の速さ

重い画像や過剰な動きは、ページの表示を遅くします。Googleは、読み込みの速さ（LCP）、操作への反応（INP）、表示のずれ（CLS）の3つを「Core Web Vitals」として示し、それぞれに良好とする目安を公開しています（2026年10月時点の公式ページによる）。デザイナーが直接計測しない案件でも、大きな画像の使い方や、読み込み中に要素がずれない作りを意識できると、実装の担当者からの信頼が上がります。

### 公開後の改善

LPやバナーの運用案件では、アクセス解析の数値や、2つの案を比べるテストの結果を見て、次に何を直すかを判断する力が問われます。数値の取り方を自分で設定しなくても、「どこで離れているか」「どの案が反応されたか」を読み取り、デザインの直し方に落とし込めることが大切です。

### 確認と修正を進める力

確認する人が複数いる案件では、修正の指示が食い違うことがあります。指示を一か所に集める、方向性の確認と細部の確認を分ける、判断する人を最初に決めてもらうなど、作業を前に進める工夫が求められます。進行の管理そのものはディレクターの役割ですが、デザイナーの側でできる工夫があると、案件が滞りにくくなります。

:::view
Webデザイナーの案件をご紹介していると、面談で評価されやすいのは、デザインの方針を「なぜそうしたか」とあわせて説明できる方です。たとえば「申し込みの前に不安を解消する情報を置くため、料金の説明を先に出した」のように、目的と判断がつながっていると、発注側は任せられる範囲を想像しやすくなります。ツールの名前を並べるだけでは、この部分が伝わりにくい傾向があります。
:::

## 経験の段階ごとに求められること

| 段階 | 任されやすい仕事 | 次の段階に進むために |
|---|---|---|
| 指示に沿って作る段階 | 既存のデザインに沿ったページ追加、バナーの量産、画像の加工 | 目的を確かめてから作る習慣をつけ、代わりの案を出してみる |
| 一つの媒体を任される段階 | LPや下層ページのデザイン、画面幅ごとの設計、実装への受け渡し | 公開後の数値を見る機会をつくり、改善まで関わる |
| 方針を決める段階 | サイト全体の見た目のルール、部品の整理、ほかのデザイナーの確認 | ルールを文書にまとめ、チームで使われる形にする |
| 成果に責任を持つ段階 | 改善の計画づくり、複数の媒体をまたいだ見た目の統一 | 事業の目的と数値の話を、依頼者と直接できるようにする |

段階を上がるほど、作業の速さより判断の質が重く見られます。報酬との関係は[Webデザイナーの報酬の記事](/media/web-designer-rate/)で解説しています。

## 生成AIと素材の扱い

画像の生成や文章の下書きにAIを使う案件も出てきています。使ってよいか、どのサービスなら使えるか、生成したものを納品物に含めてよいかは、取引先の方針によって違います。写真やイラスト、フォントの素材も、商用で使えるか、納品物に含めてよいかの条件がそれぞれ決まっています。案件で使う前に、取引先の方針と素材の利用条件を確かめることが大切です。AIの使い方と契約の関係は[AIを使った業務と契約の記事](/media/ai-riyou-keiyaku/)、成果物の権利は[成果物の著作権の記事](/media/copyright/)で解説しています。

:::caution
「デザインだけ」と聞いて参画したのに、実際には文章の作成、写真素材の選定、実装の確認まで求められることがあります。どれも関連する作業なので断りにくい一方、作業量は大きく増えます。面談で、素材と文章を誰が用意するか、実装の確認をどこまで担うかを確かめておきましょう。
:::

:::view
当社では、取引先の会社の実態と支払条件を確かめた案件を扱っています。Webデザインの案件は、制作会社のチームに入るものと事業会社の運用を支えるものとで、重く見られるスキルが違います。応募の前に、作る媒体、実装の担当者の有無、改善まで関わるかを確かめておくことをおすすめします。気になる点はご質問いただければ確認します。
:::

:::point
- 見られるのは、目的に合ったビジュアル設計、画面幅への対応、実装への受け渡し、品質への配慮、改善、進め方
- アクセシビリティと表示の速さは、デザインの段階で決まる部分が多い
- 段階を上がるほど、作業の速さより判断の質と、方針を文書にまとめる力が重く見られる
:::

## よくある質問

### 使えるデザインツールは多いほど有利ですか？

ツールの数より、案件で使われているツールで、チームの決まりに沿ってデータを作れるかが見られます。部品の使い回しや共有の仕方まで含めて使いこなしているツールを、具体的な使い方とあわせて伝えるほうが評価につながります。

### アクセシビリティの知識はどの程度必要ですか？

すべての案件で専門的な知識が求められるわけではありませんが、コントラスト、色だけに頼らない表示、代わりの説明、押せる部分の大きさといった基本は、デザインの段階で配慮できることが望まれます。基本を押さえた上で、案件で求められる水準を確かめるとよいでしょう。

### バナー制作の経験しかありません。応募できる案件はありますか？

バナーの量産や運用の案件は多く、その経験を生かして応募できる案件はあります。反応を比べて作り直した経験があれば、改善の経験として伝えられます。LPやサイトの案件に広げたい場合は、構成を考える工程に関わる機会をつくると、任される範囲が広がります。
