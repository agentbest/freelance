適格請求書（インボイス）には、①発行する人の氏名と登録番号、②取引の年月日、③取引の内容、④税率ごとに分けた合計金額と適用税率、⑤税率ごとの消費税額、⑥受け取る事業者の名前、の6つを書きます。様式は決まっておらず、名称が「請求書」でなくても、手書きでも、PDFなどのデータでも、6つがそろっていれば適格請求書になります。PDFで送る請求書と、Peppolでやり取りするデジタルインボイスの違いは[電子インボイスの記事](/media/denshi-invoice/)で解説しています。

消費税額の1円未満の端数は、1枚の請求書につき税率ごとに1回だけ処理します。この記事では、国税庁の資料をもとに、フリーランスの月額報酬の請求書を例に書き方を整理します（2026年10月時点）。

## 適格請求書に書く6つの事項

国税庁が示している記載事項は次のとおりです。

| No. | 記載事項 | フリーランスの請求書での書き方 |
|---|---|---|
| ① | 適格請求書発行事業者の氏名または名称と登録番号 | 自分の氏名（屋号を併記してもよい）と「T＋13桁」の登録番号 |
| ② | 取引年月日 | 業務を行った期間（例：2026年10月1日〜31日） |
| ③ | 取引内容（軽減税率の対象品目である旨） | 「システム開発支援業務（10月分）」など。IT業務は通常10%のみ |
| ④ | 税率ごとに区分して合計した対価の額（税抜または税込）と適用税率 | 「10%対象 550,000円（税抜）」など |
| ⑤ | 税率ごとに区分した消費税額等 | 「消費税 55,000円」 |
| ⑥ | 書類の交付を受ける事業者の氏名または名称 | 取引先の会社名 |

個人事業者の登録番号は「T」に13桁の数字を付けたものです。法人番号を持つ法人は「T＋法人番号」になります。

なお、小売業・飲食店業・タクシー業など不特定多数を相手にする事業では、⑥を省いた「適格簡易請求書」を使えます。企業から業務を受けるフリーランスの請求書は、通常の適格請求書で作ります。

## 月額報酬の請求書の記載例

仮に、準委任契約で月額報酬55万円（税抜）の業務を受けているとします（仮の数字）。請求書には、次のように書けば記載事項がそろいます。

| 項目 | 記載例 |
|---|---|
| 書類名 | 請求書 |
| 発行日 | 2026年10月31日 |
| 宛先（⑥） | 株式会社〇〇 御中 |
| 発行者（①） | 氏名（屋号）、登録番号 T1234567890123 |
| 取引年月日（②） | 2026年10月1日〜10月31日 |
| 内容（③） | システム開発支援業務 10月分（稼働160時間） |
| 10%対象の金額（④） | 550,000円（税抜）、税率10% |
| 消費税額（⑤） | 55,000円 |
| 請求金額 | 605,000円 |
| 支払期日・振込先 | 契約で決めた期日、口座 |

取引年月日は、1日ごとに書く必要はありません。国税庁は、一定期間の取引をまとめて記載する方法も認めています。月単位の業務なら「〇月分」と期間で書けば足ります。

### 精算幅で金額が変わる月

稼働時間に応じて報酬が増減する契約（精算幅）では、超過分や控除分を明細に書いたうえで、税抜の合計額と消費税額を書きます。消費税額は、合計した後の金額に10%を掛けて計算します。精算の考え方は[精算幅の記事](/media/seisan-haba/)で解説しています。

### 源泉徴収がある報酬

講演料や原稿料など、源泉徴収の対象になる報酬を請求するときは、報酬の額・消費税額・源泉徴収税額・差引の請求額を分けて書きます。国税庁によると、請求書で報酬の額と消費税の額がはっきり分かれていれば、消費税を除いた額を源泉徴収の対象にできます。対象になる報酬は[源泉徴収の記事](/media/gensen-choshu/)をご覧ください。

:::view
当社は、参画前に業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。請求書の「取引内容」や金額は、この個別契約と一致させるのが基本です。案件をご紹介していると、契約上の業務名と請求書の品目がずれていて、取引先の経理で確認に時間がかかる例を見かけます。契約書の業務名・期間・単価をそのまま写すようにすると、支払いの手続きが滞りにくくなります。
:::

## 消費税額の端数処理は1枚につき税率ごとに1回

国税庁によると、適格請求書に書く消費税額は、税率ごとに区分して合計した金額（税抜または税込）に10%（税込なら10/110）を掛け、その結果について端数処理をします。1円未満の端数は、1枚の適格請求書につき、税率ごとに1回だけ処理します。切上げ・切捨て・四捨五入のどれを選んでもかまいません。

明細の行ごとに消費税額を計算して端数処理し、それを合計して記載する方法は認められていません。行ごとの消費税額を参考として書くことは差し支えないとされています。

たとえば、作業ごとに明細を分けて請求する場合（仮の数字）は、次のように計算します。

- 明細：要件定義支援 123,456円、設計支援 234,567円（いずれも税抜）
- 10%対象の合計：358,023円
- 消費税額：358,023円×10%＝35,802.3円 → 端数処理して35,802円（切捨ての場合）

## 取引先が支払明細書を作る場合

取引先によっては、フリーランスが請求書を出す代わりに、取引先側が「支払明細書」「支払通知書」などを作って送ってくることがあります。国税庁によると、買手が作成する仕入明細書等でも、記載事項を満たし、売手（フリーランス）の確認を受けたものであれば、買手は仕入税額控除に使えます。

この場合、明細書には売手であるフリーランスの登録番号が書かれます。確認を受ける方法として、書類への確認済みの署名、オンラインのシステムでの確認、メールで確認した旨を返信する方法などが例に挙げられています。届いた明細書の金額や登録番号に誤りがないかを確かめ、確認の記録を残しておきましょう。

:::caution
登録していない免税事業者が、適格請求書と誤認されるおそれのある書類を出すことは法律で禁止されており、罰則もあります。登録番号を持っていないのに、それらしい番号を書くことはできません。登録するかどうかの考え方は[インボイス登録の判断の記事](/media/invoice-register-or-not/)で解説しています。
:::

## 登録したフリーランスに生じる義務

国税庁によると、適格請求書発行事業者には、原則として次の義務があります。

1. **交付**：取引先（課税事業者）から求められたら、適格請求書を交付する
2. **返還インボイスの交付**：値引きや返金をしたときは、適格返還請求書を交付する（税込1万円未満なら不要）
3. **修正した適格請求書の交付**：交付した請求書に誤りがあったら、修正したものを交付する
4. **写しの保存**：交付した請求書の写しを保存する

### 誤りがあったときの直し方

金額や登録番号などに誤りがあった場合は、修正した適格請求書を交付します。国税庁は、修正点を含めてすべての事項を書き直した書類を改めて出す方法と、当初の請求書との関係を明らかにしたうえで修正箇所だけを示す書類を出す方法を例に挙げています。

### 振込手数料を差し引かれたとき

取引先が振込手数料相当額を差し引いて支払い、それを値引き（対価の返還）として処理する場合、その額が1万円未満なら返還インボイスの交付は不要とされています。手数料の扱いを契約でどう決めているかも確かめておきましょう。

### 写しの保存

交付した請求書の写しは、交付した日の属する課税期間の末日の翌日から2か月を経過した日から7年間保存します。PDFで送った請求書は、送ったデータのまま保存できます。データで送った請求書は電子取引データにもあたるため、[電子帳簿保存法の記事](/media/denshi-chobo/)もあわせてご覧ください。

:::view
案件のご紹介の段階で、報酬が税込か税別かを確認しておくことは、請求書の書き方にも直結します。当社がご案内する案件では、この点を個別契約に書いてお渡ししています。税別の契約なら、請求書には税抜の報酬に消費税を加えて書けばよく、迷いが生じにくくなります。報酬の表示については[報酬は税込か税別かの記事](/media/tax-included/)で解説しています。
:::

:::point
- 記載事項は、氏名と登録番号・取引年月日・取引内容・税率ごとの合計額と税率・税率ごとの消費税額・相手の名前の6つ
- 様式は自由。手書きやPDFでもよく、請求書と納品書など複数の書類を合わせて満たすこともできる
- 月単位の業務は「〇月分」と期間でまとめて書ける
- 消費税額の端数処理は1枚につき税率ごとに1回。行ごとに処理して合計するのは不可
- 誤りは修正した請求書で直し、交付した請求書の写しは7年間保存する
:::

## よくある質問

### 屋号だけで請求書を出してもよいですか？

適格請求書には「氏名または名称」と登録番号を書きます。屋号を書く場合も、登録番号とあわせて取引先が発行者を確認できるようにしておきましょう。国税庁の公表サイトでは、申し出をすれば主たる屋号も公表できます。

### 税込の金額だけを書いた請求書でもインボイスになりますか？

税率ごとの合計額は税込・税抜のどちらで書いてもかまいません。ただし、適用税率と税率ごとの消費税額も書く必要があります。税込の合計額だけで消費税額がない請求書は、適格請求書の記載事項を満たしません。

### 請求書と納品書を分けて出している場合はどうなりますか？

国税庁によると、相互の関連がはっきりしている複数の書類全体で記載事項を満たしていれば、合わせて1つの適格請求書として扱えます。たとえば、納品書の番号を請求書に書いて関連を示す方法があります。個別のケースで迷う場合は、税理士・税務署にご相談ください。
