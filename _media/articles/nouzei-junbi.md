税金と保険料の納付に困らないためには、**1年分の納付予定を表にして必要な額を出し、報酬が入るたびに決まった額を納付用の口座へ移しておく**のが基本です。積み立てる額は「売上の◯%」と人から聞いた数字で決めず、前年に実際に払った額か、今年の見込みの計算から自分で決めます。

フリーランスは、所得税・住民税・国民健康保険料などを自分で納めます。しかも納付の時期は年の中でばらつき、独立2年目には前年の所得をもとにした支払いが重なります。この記事では、納付の予定表の作り方と積立額の決め方、足りなくなりそうなときの動き方を整理します（2026年10月時点）。収入が途切れたときの生活費の備えは[貯蓄の記事](/media/emergency-fund/)で、口座の分け方は[事業用口座の記事](/media/business-account/)で扱っています。

## 自分で納める税金と保険料の一覧

まず、自分が何を納めるのかを洗い出します。人によって対象にならないものもあります。

| 種類 | 対象になる人 | 納める時期の目安 |
|---|---|---|
| 所得税（確定申告分） | 所得があり確定申告をする人 | 3月15日まで |
| 所得税の予定納税 | 予定納税基準額が15万円以上の人 | 7月と11月 |
| 消費税 | 課税事業者 | 3月31日まで。前年の税額によって中間申告もある |
| 住民税 | 前年に所得があった人 | 市区町村の通知に書かれた納期 |
| 個人事業税 | 法定業種で一定の所得がある人 | 都道府県の通知に書かれた納期 |
| 国民健康保険料 | 国保に加入している人 | 市区町村の通知に書かれた納期 |
| 国民年金保険料 | 第1号被保険者 | 納付対象月の翌月末日 |

国税庁の案内では、予定納税は前年の申告納税額などから計算した予定納税基準額が15万円以上の人が対象で、6月15日までに通知が届き、第1期は7月1日〜31日、第2期は11月1日〜30日に、原則として基準額の3分の1ずつを納めます。仕組みは[予定納税の記事](/media/yotei-nouzei/)で解説しています。

消費税の課税事業者は、直前の課税期間の確定消費税額が48万円を超えると中間申告が必要になり、額に応じて年1回・3回・11回と回数が増えます。計算の手順は[消費税の納税の記事](/media/shohizei-nouzei/)を、個人事業税の対象と計算は[個人事業税の記事](/media/kojin-jigyozei/)をご覧ください。

国民年金保険料は令和8年度が月17,920円で、日本年金機構の案内では、納付期限は納付対象月の翌月末日です。

## 1年分の納付予定表を作る

一覧ができたら、12か月のカレンダーに並べます。ポイントは、**金額が分かっているものと、まだ分からないものを分けて書く**ことです。

1. **通知が届いているものを書く**：住民税・国民健康保険料・個人事業税は、通知書に納期ごとの額が書かれている
2. **定額のものを書く**：国民年金保険料
3. **前年の申告から決まるものを書く**：予定納税（通知の額）、消費税の中間申告
4. **まだ決まっていないものを見込みで書く**：来年3月の所得税と消費税の確定分

住民税や国民健康保険料は、1年のうち通知が届く時期まで額が決まりません。通知が届いたら予定表を書き換えます。住民税の納期と計算は[住民税の記事](/media/juminzei/)で、国民健康保険料の決まり方は[国民健康保険の記事](/media/kokuho/)で整理しています。

### 独立した年と翌年で額が変わる

住民税や国民健康保険料は前年の所得をもとに計算されるため、独立した年は会社員のときの給与をもとにした額が届きます。翌年からは、フリーランスとしての所得をもとにした額に切り替わり、確定申告の納税や予定納税も加わります。**独立1年目に払った額を、2年目の積立額の基準にしない**ことが大切です。

## 積み立てる額を決める2つの方法

### 方法1：前年に実際に払った額から決める

独立して2年以上たち、所得が大きく変わっていない人に向く方法です。前年の1年間に納めた税金と保険料の合計を出し、それを12か月で割った額を毎月積み立てます。ただし、報酬が上がった年や、課税事業者になった年は、翌年の負担が増えるため上乗せが要ります。

### 方法2：今年の所得の見込みから計算する

独立したばかりの人や、所得が大きく変わる年に向く方法です。

1. 今年の売上の見込みから、経費を引いて所得を出す
2. 所得控除を引いて、所得税と住民税の見込みを出す
3. 国民健康保険料は、市区町村の料率や試算の仕組みで見込む
4. 課税事業者は、消費税の見込みも出す
5. 合計を、報酬が入る回数で割る

所得税の計算の流れは[所得税の計算の記事](/media/shotokuzei-keisan/)で解説しています。

### 計算例（仮の数字）

流れを示すための**仮の数字**です。実際の税額や保険料は、所得・控除・住んでいる市区町村で大きく変わります。

- 今後12か月の納付予定の合計 … 仮に180万円
- 報酬の入金 … 毎月1回
- 毎月の積立額 … 180万円÷12＝15万円

毎月の入金額が仮に80万円なら、入金のうち15万円を納付用の口座に移すことになります。割合にすると約19%ですが、この割合はこの仮の条件での結果にすぎません。自分の予定表から出した額を使ってください。

### 消費税は「預かったお金」として分けて考える

課税事業者の場合、報酬と一緒に受け取る消費税は、いずれ納める分を含んでいます。入金額をすべて自分の収入と考えると、申告の時期に資金が足りなくなります。消費税の分は、所得税などとは別に見込んでおくと把握しやすくなります。

:::view
当社がご案内する案件では、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。支払期日が分かれば、入金日に合わせて積み立ての振替日を決められます。毎月の入金日から納付用の口座へ自動で移す設定にしておくと、使ってしまう前に取り分けられます。契約の支払期日を確かめたうえで、振替の日を決めることをおすすめします。
:::

## 積み立てを続ける仕組み

### 口座を分け、入金日に移す

納付用のお金は、生活費や事業の支払いに使う口座とは別にしておくと、残高を見ただけで足りているかが分かります。入金日に自動で振り替える設定にすると、毎月の判断が要りません。

### 納付の方法を決めておく

口座振替やクレジットカードなど、税金と保険料には複数の納め方があります。引き落としにしておけば、納付を忘れる心配は減ります。その分、引き落としの日に残高が足りているかを確かめる必要があります。納め方の違いは[税金の納め方の記事](/media/nouzei-houhou/)で整理しています。国民年金保険料には前納の割引もあり、まとめて払うと一時的に出ていく額が大きくなるため、予定表に入れて判断します。仕組みは[国民年金の記事](/media/kokumin-nenkin/)をご覧ください。

### 年に一度、精算して見直す

確定申告が終わったら、1年分の積立額と実際に払った額を比べます。余った分は翌年の積立の一部に回し、足りなかった場合は翌年の積立額を上げます。所得が増えた年の翌年は、住民税・国民健康保険料・予定納税が一度に増えるため、申告の直後に予定表を作り直しておくと慌てずに済みます。

:::caution
積み立てたお金を、生活費の不足や投資に一時的に回すと、納付の時期に戻せなくなることがあります。納付用のお金は「すでに使い道が決まっているお金」として扱い、収入が途切れたときの備えとは別に持っておきましょう。
:::

## 足りなくなりそうなとき

国税を納期限までに納めないと延滞税がかかります。国税庁の案内では、令和8年の延滞税の割合は、納期限の翌日から2か月を経過する日までは年2.8%、2か月を経過した日以後は年9.1%です。期間が長くなるほど負担が大きくなります。

足りないと分かった時点で、次の順に確かめます。

1. **減額や免除の手続きを使えるか**：その年の所得が大きく減る見込みなら予定納税の減額申請、国民年金保険料なら免除・納付猶予の申請がある（[貯蓄の記事](/media/emergency-fund/)でまとめています）
2. **納付の相談をする**：国税は税務署、住民税や国民健康保険料は市区町村の窓口に、納期限の前に問い合わせる
3. **黙って遅らせない**：連絡しないまま滞納すると、延滞税などの負担が増え、住宅ローンの審査などでも説明を求められることがある

:::view
案件紹介の現場では、報酬が上がった翌年に、住民税や国民健康保険料、予定納税が重なって驚いたという話をよく耳にします。単価が上がるときは、翌年の納付額も増えると考えて、積立額をその月から見直すことをおすすめします。案件の切り替えで報酬や支払期日が変わる場合は、契約前に条件を確かめておくと、予定表も作り直しやすくなります。
:::

:::point
- 自分が納める税金と保険料を一覧にし、12か月の予定表に並べる
- 独立1年目に払った額を、2年目の積立の基準にしない
- 積立額は、前年の実績か今年の見込みから自分で計算する。割合に共通の正解はない
- 入金日に納付用の口座へ自動で移し、年に一度精算して見直す
- 足りないときは、納期限の前に減額・免除の手続きと窓口への相談を確かめる
:::

## よくある質問

### 売上の何%を積み立てればよいですか？

共通の割合はありません。所得税は所得が増えるほど税率が上がり、国民健康保険料は市区町村で料率が違い、課税事業者かどうかで消費税も変わります。前年の実績か今年の見込みから必要額を出し、入金の回数で割って決めることをおすすめします。具体的な税額の見込みは税理士などの専門家にご相談ください。

### 積み立ては事業用口座の中で分けて管理してもよいですか？

管理できるならその方法でもかまいません。ただし、残高のうちどれだけが納付用かが見えにくくなり、知らないうちに使ってしまうことがあります。続けにくいと感じたら、納付用の口座を別に作る方法を試してください。

### 積み立てが余った場合はどうすればよいですか？

翌年の積立の一部として残しておくのが一般的です。所得が増えると、翌年の住民税・国民健康保険料・予定納税も増えます。余った分をすぐに生活費や投資に回すより、翌年の予定表を作ってから使い道を決めることをおすすめします。
