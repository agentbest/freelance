取引先から「うちの社員にならないか」と誘われたら、その場で返事をせず、**自分の契約に直接の雇用や契約を制限する条項がないか**、**提示される労働条件が書面で示されるか**、**業務委託を続ける場合と比べてどうか**の3点を確かめてから答えます。

誘われること自体は、現場での働きが評価された結果です。ただ、業務委託の契約には、取引先との直接の雇用や契約について定めた条項が入っていることがあり、知らずに話を進めるとトラブルになりかねません。この記事では、確かめる順番と、答え方の考え方を整理します（2026年10月時点）。

## 取引先が正社員に誘う理由を知っておく

取引先が業務委託の人を社員に誘う理由は、一つではありません。理由によって、提示される役割や条件の見方が変わります。

| 誘う理由 | 考えておきたいこと |
|---|---|
| 今の仕事を長く任せたい | 正社員になっても、今と同じ仕事を続けられるか。異動の可能性はあるか |
| 社内に知見を残したい | 自分が作ったものを社員として引き継ぐ役割が期待されているか |
| 業務委託では任せにくい仕事を頼みたい | 部下の管理や社内の意思決定など、業務委託の範囲を超える仕事が増えるか |
| 人件費の見通しを立てたい | 業務委託の報酬より年収の総額が下がる提示になっていないか |

3つ目に関連して、業務委託のまま、社員と同じように細かい指示を受け、時間や場所を管理される働き方になっている場合は、契約の形と働き方の実態が合っていない状態です。取引先が雇用に切り替えたいと考える背景に、こうした事情があることもあります。働き方の線引きは[偽装請負の記事](/media/gisou-ukeoi/)で解説しています。

## 最初に確かめるのは自分の契約の条項

### 直接の雇用や契約を制限する条項

案件紹介サービスや元請けを通じて参画している場合、契約書に次のような条項が入っていることがあります。

- 契約期間中や終了後の一定期間、取引先と**直接、業務委託契約を結ばない**こと
- 契約期間中や終了後の一定期間、取引先に**雇用されない**こと
- 違反した場合の違約金や損害賠償

読むときは、**対象（取引先だけか、グループ会社も含むか）**、**期間（契約中だけか、終了後◯か月か）**、**違反したときの扱い**の3点を確かめます。直接契約の禁止や競業避止の条項の読み方は[直接契約の禁止・競業避止の記事](/media/non-compete/)で詳しく扱っています。

また、自分の契約に条項がなくても、紹介した会社と取引先の間の契約で、取引先側が紹介された人を直接雇用するときの取り決めをしていることがあります。この契約は自分からは見えないため、話を進める前に、間に入っている会社に相談しておくのが安全です。

### 派遣の場合とは決まりが違う

労働者派遣法第33条は、派遣元が、正当な理由なく、派遣労働者が雇用関係の終了後に派遣先に雇用されることを禁じる契約を結んではならないと定めています。派遣先との間でも、同じ趣旨の契約を結ぶことを禁じています。

業務委託（準委任・請負）は派遣ではないため、この条文がそのまま当てはまるわけではありません。業務委託の場合は、契約の条項の内容と、その条項が合理的な範囲かどうかで考えることになります。契約社員・派遣・業務委託の違いは[雇用の相手・指示・期間で比べた記事](/media/keiyaku-haken-hikaku/)で整理しています。

公正取引委員会などの「フリーランスとして安心して働ける環境を整備するためのガイドライン」（令和8年1月1日改定）は、競業避止義務や専属義務などを合理的に必要な範囲で設けることは直ちに独占禁止法上問題となるものではないとしつつ、取引上の地位が優越している発注事業者が、一方的に合理的に必要な範囲を超えて課す場合は、優越的地位の濫用として問題となるとしています。条項が気になる場合も、自分だけで「無効だ」と判断せず、弁護士などの専門家にご相談ください。

:::caution
誘いを受けた勢いで、契約の条項を確かめずに入社日まで決めてしまうと、後から違約金の定めに気づくことがあります。まず「前向きに考えたいので、契約の確認をしてからお返事します」と伝え、時間をもらいましょう。返事を保留すること自体は、失礼にはあたりません。
:::

:::view
当社は、取引先の会社の実態と支払条件を確かめたうえで案件をご紹介し、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。参画中の取引先から正社員に誘われた場合は、返事をする前に、早めにご相談ください。契約の条項のうち、どこが関係するか分からない場合も、ご質問いただければ確認します。
:::

## 提示される条件を書面で確かめる

### 雇用では労働条件の明示が求められる

正社員になると、業務委託と違い、労働基準法が適用される雇用の関係になります。労働基準法第15条は、使用者は労働契約の締結に際し、賃金、労働時間その他の労働条件を明示しなければならないと定めています。厚生労働省は、2024年4月から労働条件明示のルールが変わったことを案内しています。

現場で口頭で誘われた段階では、条件は具体的になっていないことがほとんどです。応じるかどうかを考えるのは、条件が書面で示されてからにしましょう。

### 確かめたい項目

| 項目 | 確かめたいこと |
|---|---|
| 雇用の形 | 正社員か、契約社員か。試用期間の有無と長さ |
| 年収の内訳 | 基本給、賞与の扱い、残業代が含まれているか |
| 仕事の内容 | 今の仕事を続けるのか、役割が変わるのか。将来の変更の範囲 |
| 働く場所と時間 | 出社の頻度、リモートの可否、勤務時間 |
| 評価と昇給 | 何を基準に評価されるか |
| 副業の扱い | 入社後に業務委託の副業を続けられるか |
| 入社の時期 | 今の契約の終了時期と合うか |

特に、今の仕事を続けたいと考えている場合は、仕事の内容と変更の範囲をよく見てください。正社員は会社の方針で担当が変わることがあり、業務委託のように契約で仕事の範囲が決まる働き方とは違います。

## 業務委託を続ける場合と比べる

誘いを受けるかどうかは、今の働き方を続けた場合と並べて考えます。

### お金の比べ方

業務委託の月額の報酬と、正社員の年収を12で割った額をそのまま比べると、判断を誤りやすくなります。正社員の年収には、会社が負担する社会保険料や有給休暇などが表れず、業務委託の報酬には、経費や案件が途切れる期間が含まれていないためです。同じ前提にそろえる手順は[年収と単価の比べ方の記事](/media/nenshu-tanka-convert/)、手取りの違いは[手取りの違いの記事](/media/tedori-hikaku/)で解説しています。

### お金以外の比べ方

| 観点 | 業務委託を続ける | 取引先の正社員になる |
|---|---|---|
| 仕事の範囲 | 契約で決めた範囲 | 会社の方針で広がったり変わったりする |
| 収入の見通し | 契約の更新しだいで変わる | 雇用が続く前提で見通しを立てやすい |
| 取引先との関係 | 外部の専門家として関わる | 社内の一員として評価制度の中で働く |
| ほかの仕事 | 契約で制限がなければ掛け持ちできる | 就業規則の副業の定めに従う |
| 病気や休み | 自分で備える | 有給休暇や会社の制度がある |

どちらが向いているかは、暮らしの状況や目指すキャリアによって変わります。判断の軸の立て方は[フリーランスと正社員の判断の軸の記事](/media/freelance-vs-seishain/)で整理しています。

同じ現場で働いているぶん、職場の雰囲気や人間関係を知ったうえで判断できるのは、通常の転職にはない利点です。一方で、外部の専門家として見えていた職場と、社員として評価され、社内の調整を担う立場で見る職場は、違って見えることがあります。社員として働く人の仕事の範囲や評価のされ方を、具体的に聞いておきましょう。

## 答え方の選択肢

検討したうえでの答え方には、次のような選択肢があります。

1. **受ける**：条件が書面で示され、契約の条項にも問題がないと確認できたら、今の契約の終了時期と入社日を調整する
2. **断る**：誘ってくれたことへのお礼を伝え、業務委託として今の仕事を続けたい理由を簡潔に話す
3. **別の形を提案する**：契約期間を長くする、業務範囲を広げるなど、業務委託のまま関わり方を変える

断る場合は、評価への感謝と、今の仕事への意欲を伝えれば、取引先との関係が悪くなることは多くありません。別の形を提案する場合は、契約の変更にあたるため、間に入っている会社を通じて条件を決め直します。

### 受ける場合の進め方

受けると決めたら、次の順で進めます。

- 間に入っている会社に、取引先から誘いを受けたことと、受けたい意向を伝える
- 今の契約の終了時期と予告期間を確かめる（[中途解約の記事](/media/termination/)）
- 入社日から逆算して、引き継ぎの期間を決める
- 個人事業をやめる場合は税務署への廃業の届出を、あわせて健康保険・年金の切り替えを準備する（[正社員に戻る記事](/media/back-to-seishain/)）

:::view
案件紹介の現場で見ると、取引先から声がかかりやすいのは、契約で決めた範囲をきちんと守りながら、周りの社員と協力して仕事を進めてきた方です。一方でつまずきやすいのは、誘われたその場で前向きな返事をしてしまい、後から契約の条項や条件の食い違いに気づくケースです。うれしい話ほど、条件が文字で示されるまで決めないことをおすすめします。
:::

:::point
- 誘われたら即答せず、確認してから答えると伝えて時間をもらう
- 自分の契約の、直接の雇用や契約を制限する条項（対象・期間・違反時の扱い）を確かめる
- 雇用では労働条件の明示が求められる。条件が書面で示されてから判断する
- 年収と報酬は同じ前提にそろえて比べ、仕事の範囲や評価のされ方も比べる
:::

## よくある質問

### 誘いを断ったら、今の契約に影響しますか？

断ったことを理由に契約が打ち切られるとは限りません。誘ってくれたことへの感謝と、業務委託として今の仕事を続けたい意向を伝えれば、関係を保てることが多いです。気になる場合は、間に入っている会社に相談してから返事をすると安心です。

### 契約が終わった後なら、自由に取引先に入社できますか？

契約書に、終了後の一定期間、取引先に雇用されないことなどを定めた条項がある場合は、その期間の扱いを確かめる必要があります。期間を過ぎていれば、その条項による制限はなくなるのが通常です。期間の起算日や対象の範囲も含め、契約書を読んだうえで進めてください。

### 正社員ではなく、業務委託のまま長く続けたいと伝えてもよいですか？

伝えてかまいません。契約期間を長くする、業務範囲を広げるといった形で、取引先の「長く任せたい」という考えに応えられることもあります。条件を変える場合は、変更後の内容を契約書や書面で受け取りましょう。
