PMOのフリーランス案件には、**リモートで働けるものがあります**。進捗や課題の集計、会議の運営、報告資料の作成は、オンラインの会議と共有の管理表があれば離れた場所からでも進められます。

ただし、PMOは「関係者が集まる場にいること」自体が仕事の一部になりやすい職種です。プロジェクトの立ち上げ期や、システム移行の山場では出社を求められることが多く、同じ案件でも時期によって働き方が変わります。この記事では、PMOの仕事のどこがリモートに向き、どこで現地が求められやすいかを分けたうえで、探し方と契約で確かめる点を整理します。

## PMOの仕事のうちリモートで進めやすいもの

PMOの仕事は、情報を集めて整え、判断する人に届けることが中心です。その多くは、道具がそろっていればオンラインで完結します。

| 仕事 | リモートで進めやすい理由 |
|---|---|
| 進捗・課題・リスクの集計 | 各チームの報告がチケット管理ツールや共有の管理表に集まっていれば、場所を問わず更新できる |
| 定例会議の運営 | 議題の配布、進行、議事録の共有までオンラインで回せる |
| 報告資料の作成 | 経営層やステアリングコミッティ向けの資料は、作る作業そのものに場所の制約がない |
| 変更管理・課題の起票ルールの整備 | 手順書やテンプレートを作り、チャットで周知できる |
| 工数・費用の集計 | 稼働報告や見積もりのデータを集めて差異を確かめる作業は、手元の環境でできる |

特に、開発チームがすでにリモートで動いている自社サービスの会社や、クラウドの管理ツールを使っているプロジェクトでは、PMOもリモートで参加しやすくなります。PMOに求められるスキルそのものは[PMOのスキルの記事](/media/pmo-skills/)で詳しく解説しています。

## 現地が求められやすい場面

一方で、PMOには対面のほうが早く、行き違いも少なく進む場面があります。案件の説明に「リモート可」と書かれていても、次のような場面では出社を求められることがあります。

### 立ち上げ期の体制づくり

プロジェクトの最初の数週間は、誰が何を決めるのか、どの会議で何を報告するのかを固める時期です。発注側の担当者、複数のベンダー、利用部門の代表と顔を合わせ、会議体と報告のルールを合意する作業は、対面で行われることが多くあります。この時期だけ出社し、体制が回り始めたらリモートに移る形の案件もあります。

### 経営層への報告と判断の場

ステアリングコミッティなど、経営層が判断する会議は、役員会議室で対面で開かれることがあります。PMOが資料を作るだけでなく、その場で質問を受けて補足する役割を任される場合、会議の日は出社が前提になります。

### 移行・切り替えの当日

システムの本番切り替えや移行リハーサルの日は、関係者が一か所に集まり、手順の進み具合を時刻単位で確かめることがあります。夜間や休日にかかることも多く、PMOが全体の進行表を管理する役を担う場合は、現地での待機を求められやすくなります。

### 複数のベンダーが集まる調整

ベンダー間で責任の境界があいまいな課題は、会議の場だけでなく、その前後の立ち話で解けることがあります。こうした調整が多いプロジェクトでは、週に何日かの出社を条件にしている案件も見られます。

## リモートのPMOが信頼を得る進め方

リモートのPMOは、会議室での雑談から情報を拾うことができません。その分、情報が自分のところに集まる仕組みを先に作っておくことが大切です。

1. **「現在地」を一枚にまとめて毎週出す**：進捗、未解決の課題、判断待ちの事項を1枚に整理し、決まった曜日に共有する。見る人が増えるほど、情報も集まりやすくなる
2. **会議の前に論点を配る**：オンライン会議は、その場での発言が少なくなりがちです。議題ごとに「決めたいこと」を前日までに配り、会議を判断の場にする
3. **議事録は当日中に出す**：決定事項と宿題、期限、担当を先頭に書く。時間がたつほど認識のずれを直しにくくなる
4. **チームのリーダーと短い個別の定例を持つ**：全体会議では出てこない懸念は、少人数の場で聞くほうが早く分かる
5. **チャットの未回答を棚卸しする**：誰の返事待ちで止まっているかを週に一度見える形にし、放置される質問をなくす

これらは、発注側から細かく指示を受けて動くこととは別の話です。業務委託では、受けた側が自分の判断で業務を進めるのが前提で、報告の方法や頻度は合意にもとづいて決めます。

:::view
PMOの案件をご紹介していると、面談で「リモートでどう情報を集め、どう判断の場をつくったか」を具体的に話せる方は評価されやすい傾向があります。使った管理表やツールの名前より、会議の前に何を配り、未解決の課題をどう追いかけたかを話せるかが見られます。当社では、先に稼働日数・リモートの希望・ご希望の金額を伺い、合う案件だけをご案内しています。出社できる頻度や、移行の当日に対応できるかも、あわせてお伝えいただくことをおすすめします。
:::

## PMOのリモート案件の探し方

### プロジェクトの段階を見る

PMOの働き方は、プロジェクトの段階で大きく変わります。立ち上げ期は出社が多く、開発や試験の期間はリモートが中心になり、移行の前後で再び現地の対応が増える、という流れはよく見られます。案件を見るときは、いまどの段階にあり、参画期間中にどの段階を通るのかを確かめると、働き方の見通しが立ちます。

### 担う範囲で選ぶ

同じPMOでも、事務局の運営や資料作成が中心の案件と、ベンダー間の調整や品質の判断まで担う案件があります。前者はリモートとの相性がよく、後者は対面の調整が増える傾向があります。どちらの経験を軸にするかで、探す案件の範囲も変わります。

### 管理の道具がそろっているかを見る

リモートのPMOが成果を出せるかは、プロジェクトで使っている道具にも左右されます。課題やリスクがチケット管理ツールや共有の表に集まっているプロジェクトでは、離れていても状況をつかめます。反対に、各チームの報告がメールの添付や紙の資料で回っている場合は、まず情報の集め方を変えるところから始めることになり、立ち上げの時期に出社が増えやすくなります。面談では、進捗や課題をどこで管理しているかを聞いておくと、参画後の働き方を想像しやすくなります。

### スキルシートにリモートでの運営経験を書く

スキルシートには、プロジェクトの規模やチームの数に加えて、拠点が分かれていたか、リモートでどの会議体を運営したか、報告の頻度をどう決めたかを書いておくと、案件側が判断しやすくなります。書き方は[PMOのスキルシートの書き方](/media/pmo-skillsheet/)で解説しています。PM寄りの案件も視野に入れる場合は[PMのリモート案件の記事](/media/pm-remote/)もご覧ください。

:::caution
「リモート可」と書かれたPMO案件でも、移行の時期になって出社や夜間・休日の待機が増えることがあります。参画期間に移行が含まれるかと、そのときの働き方を面談で確かめておかないと、生活の予定が立たなくなることがあります。
:::

## 契約の前に確かめたいこと

2024年11月に施行されたフリーランス法では、発注側がフリーランスに業務を委託したとき、業務の内容、報酬の額、支払期日に加えて、役務の提供を受ける場所などを、書面やメールなどで直ちに明示することが求められています（公正取引委員会「フリーランス法特設サイト」、2026年10月時点で確認）。PMOの場合は、次の点をあわせて確かめておくと、参画後のずれを防げます。

1. **出社の頻度と場所**：通常の週と、立ち上げ期・移行期で違うか
2. **夜間・休日の対応**：移行の当日やリハーサルに対応するか、そのときの稼働の扱いと報酬
3. **業務の範囲**：事務局の運営までか、ベンダー管理や品質の判断まで含むか
4. **稼働の上限と精算**：会議が増えて稼働が上限を超えそうなときの扱い
5. **作業の環境**：貸与のパソコンを使うか、社外から管理表やチャットに入れるか
6. **交通費**：出社や拠点への出張が発生したときに、誰が負担するか

取引条件の明示の中身は[フリーランス新法の取引条件の明示の記事](/media/freelance-act-terms/)で解説しています。常駐とリモートの選び方そのものは[常駐案件とリモート案件の違い](/media/jochu/)をご覧ください。

:::view
PMOの案件は、参画後に会議や担当範囲が少しずつ増えやすい仕事です。当社では、取引先の会社の実態と支払条件を確かめた案件を扱い、業務範囲・報酬・支払期日・契約期間を個別契約に書いてお渡ししています。出社の頻度や移行期の対応について気になる点があれば、契約の前にご質問いただければ確認します。
:::

:::point
- PMOの集計・会議運営・資料作成はリモートで進めやすい
- 立ち上げ期、経営層への報告、移行の当日、ベンダー間の調整は現地が求められやすい
- リモートでは情報が集まる仕組みを先に作る。契約では時期ごとの出社と夜間・休日の扱いを確かめる
:::

## よくある質問

### PMOの経験が浅くてもリモート案件に参画できますか？

難しいことが多いのが実情です。リモートのPMOは、発注側から作業ぶりが見えないぶん、会議体の運営や課題管理をひとりで回せることが前提になります。経験が浅い場合は、出社を含む案件でプロジェクトの全体を見る経験を積み、そのうえでリモートの案件を目指すほうが現実的です。独立までの進め方は[PMOがフリーランスになるには](/media/pmo-how-to/)をご覧ください。

### 週の一部だけ出社する案件と、フルリモートの案件はどちらがよいですか？

担いたい役割によります。事務局の運営や資料作成が中心ならフルリモートでも成果を出しやすく、ベンダー間の調整や品質の判断まで担うなら、週の一部の出社がある案件のほうが動きやすいことがあります。出社の頻度は、住む場所と移動の負担もあわせて考えましょう。

### 住んでいる地域から遠いプロジェクトでもPMOとして参画できますか？

フルリモートの案件なら参画できることがあります。ただし、立ち上げ期や移行期だけ現地に行く形の案件では、移動の負担と交通費の扱いが問題になります。応募の前に、出社が発生する時期と頻度を確かめておくと安心です。地方から案件を受ける考え方は[地方在住でフリーランス案件を受ける方法](/media/chiho/)で解説しています。
