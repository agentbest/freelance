稼働報告書（作業報告書）は、その月に何時間働き、何をしたかを発注側に伝える書類で、月額の準委任案件では**精算額を決める根拠**になります。日ごとの稼働時間と作業内容を、契約で決めた時間の数え方に沿って書き、期限までに現場の確認を受けて提出するのが基本です。

書き方に決まった様式はなく、発注側やエージェントが用意した書式を使うことがほとんどです。この記事では、書く項目、時間の数え方で確かめておくこと、提出の流れと、つまずきやすい点を整理します。

## 稼働報告書が果たす3つの役割

稼働報告書は、単なる勤務記録ではありません。業務委託では、主に次の3つの役割があります。

| 役割 | 内容 |
|---|---|
| 精算の根拠 | 精算幅のある契約では、報告した合計時間で超過・控除の有無と金額が決まる |
| 請求の前提 | 報告の確定を受けて、請求書や支払通知書が作られることが多い |
| 業務の記録 | どの作業にどれだけ時間を使ったかが残り、更新時の説明材料や、トラブル時の証拠になる |

精算幅の考え方そのものは[精算幅の記事](/media/seisan-haba/)で、計算方式の違いは[上下割と中間割の記事](/media/jouge-chukan-wari/)で解説しています。この記事では、その計算のもとになる「時間の記録と報告」に絞って説明します。

## 稼働報告書に書く主な項目

書式は案件ごとに違いますが、次の項目が入っていることが一般的です。

| 項目 | 書き方のポイント |
|---|---|
| 対象月・氏名・案件名 | 個別契約と同じ表記にする |
| 日付と曜日 | 稼働しなかった日も行を残すと、合計の確認がしやすい |
| 開始・終了時刻 | 契約で決めた単位（15分、30分など）にそろえる |
| 休憩時間 | 実際に休んだ時間を書く。決まった時間を一律に引く書式もある |
| 稼働時間 | 終了−開始−休憩。日ごとの合計と月の合計を出す |
| 作業内容 | その日の主な作業を短く。社外に出ない書式でも、秘密情報は書きすぎない |
| 備考 | 祝日、休んだ日、夜間・休日の対応、出張など、通常と違うことを書く |
| 確認欄 | 現場の担当者の確認・承認を受ける欄 |

### 作業内容は「何を進めたか」が分かる程度に

作業内容は、詳しすぎても簡単すぎても困ります。「開発」「会議」だけでは、時間が多かった月に理由を説明しにくくなります。一方、システムの内部の情報や、顧客名などをそのまま書くのは、秘密保持の点から避けた方が無難です。

例えば、次のくらいの粒度が目安になります。

- 「受注画面の改修（設計レビュー指摘の対応）」
- 「本番リリースの準備・手順書の更新」
- 「障害対応（夜間、22時〜23時半）」

普段と違う作業や、予定より時間がかかった作業は、理由を一言添えておくと、確認する側も承認しやすくなります。

## 時間の数え方は、参画前に確かめておく

精算で行き違いが起きやすいのは、計算式よりも「何を稼働時間に数えるか」の認識のずれです。次の点は、契約書や発注側の案内で確かめ、分からなければ参画前に質問しておきます。

1. **時間の単位と端数**：15分単位か、30分単位か。端数は切り捨てか、日ごとか月ごとにまとめるか
2. **休憩の扱い**：1日の休憩を一律で何時間とするのか、実際の休憩時間で数えるのか
3. **会議や移動**：客先への移動や、拠点間の移動を稼働に含めるか
4. **時間外・休日の対応**：夜間のリリースや障害対応をどう記録し、精算するか。事前の承認が必要か
5. **待機・オンコール**：呼び出しに備えて待機している時間を数えるか
6. **学習や準備**：参画前の環境構築や、業務に必要な調べものを数えるか

特に、月の稼働の合計が精算幅の上限や下限に近い月は、こうした数え方の違いがそのまま金額の差になります。

:::caution
「端数は切り捨て」と書かれた書式を毎日使うと、月の合計で思ったより時間が減っていることがあります。日ごとに切り捨てるのか、月の合計で切り捨てるのかで差が出るため、ルールが分からないときは書式の作成者に確かめましょう。端数の扱いは、精算額の計算に関わる条件です。
:::

## 提出までの流れ

月額の準委任案件では、次のような流れが一般的です。

1. **日々の記録**：自分の手元で、毎日の開始・終了・休憩・作業内容を記録する
2. **月末の集計**：締め日に合計を出し、書式に転記する
3. **現場の確認**：発注側の担当者に内容を確認してもらい、承認を受ける
4. **提出**：エージェント経由の案件ではエージェントへ、直接契約では発注側の窓口へ出す
5. **精算額の確定**：報告にもとづいて超過・控除が計算され、請求額が決まる

その後の請求書の出し方と入金までの流れは、[請求書の出し方の記事](/media/seikyusho-flow/)で整理しています。

### 毎日記録して、月末にまとめて書かない

月末に1か月分を思い出して書くと、時間も作業内容も不正確になりがちです。手元のメモ、表計算ソフト、勤怠や工数を記録する道具など、方法は何でもかまいません。毎日、終わったときに記録しておくと、確認を求められたときにも答えやすくなります。

発注側のシステムに入力する案件でも、自分の手元に控えを残しておくと、報告の数字と請求額を突き合わせるときに役立ちます。

:::view
案件紹介の現場では、精算をめぐる行き違いの多くが、計算の誤りよりも「何を稼働に数えるか」の認識の違いや、報告の遅れから生じている傾向があります。参画が決まったら、時間の単位・休憩・時間外の扱いと、報告の期限を最初の月のうちに確かめておくことをおすすめします。不明な点はご質問いただければ確認します。
:::

## 提出期限と、遅れたときの影響

報告の期限は、締め日から数営業日以内とされていることが多く、案件ごとに違います。報告が遅れると、精算額の確定と請求の作成が後ろにずれ、社内の手続に影響することがあります。

一方で、法律上の支払期日は、報告の提出日とは別に決まります。フリーランス法の「考え方」では、準委任のような役務の提供では、原則として役務の提供を受けた日から60日以内に支払期日を定めるとしています。月単位で締める契約では、取引条件に明記するなどの条件を満たせば、締めの期間の末日から60日（2か月）以内でよいとされています。また、公正取引委員会のQ&Aでは、請求書が出ていないことは、支払期日を過ぎてよい理由にあたらないとしています。

ただし、こうしたルールがあっても、期限を守って報告することは取引を円滑に進める基本です。支払期日の決まりは[60日ルールの記事](/media/freelance-act-60days/)で解説しています。

## 差し戻されたとき・修正するとき

現場の担当者から、時間や作業内容について質問されたり、修正を求められたりすることがあります。

- **単純な誤り**：転記ミスや計算の誤りは、すぐ直して再提出する
- **認識の違い**：数え方のずれによる場合は、手元の記録を示しながら、どのルールで数えたかを説明する
- **削ってほしいと言われた**：実際に働いた時間を、理由なく報告から外すよう求められた場合は、そのまま応じず、根拠を確認する

働いた時間を少なく書くように求められると、精算額が下がり、結果として報酬が減ることになります。精算の条件に沿って正しく数えた時間であれば、合意した算定方法に従って精算されるのが基本です。納得できないときは、エージェント経由なら担当者に、直接契約なら契約書の条件を示して相談しましょう。

## 稼働報告と「指揮命令」の関係

業務委託では、発注側がフリーランスに直接、細かく仕事の進め方や時間を指示することは、契約の形によっては問題になることがあります。稼働報告は、精算のために実績を報告するものなので、報告を出すこと自体が直ちに問題になるわけではありません。

一方で、始業・終業の時刻を細かく管理される、遅刻や早退をとがめられるといった状態が続く場合は、契約の実態が雇用に近いと判断される可能性もあります。どこからが問題になるかは個別の事情で変わるため、気になるときは[偽装請負の記事](/media/gisou-ukeoi/)を参考にし、専門家や相談窓口にご相談ください。

:::view
当社がお渡しする個別契約には、業務範囲・報酬・支払期日・契約期間を書いています。稼働報告を書いていて、その業務範囲にない作業が増えている、時間外の対応が続いているといった変化に気づいたら、その内容を報告書の備考や手元の記録に残しておくことをおすすめします。記録があると、条件の見直しを相談するときの材料になります。気になる変化があれば、早めにご相談ください。
:::

## 報告書の控えは残しておく

提出した稼働報告書は、請求書や入金の記録と一緒に保存しておきます。精算額に疑問が出たときや、報酬の入金額が違ったときに、どの時間を報告したかを確かめる材料になります。

メールやクラウドで受け渡しした報告書や請求書のデータは、税務上の保存の対象になる場合があります。保存の方法は[電子帳簿保存法の記事](/media/denshi-chobo/)で整理しています。

:::point
- 稼働報告書は、精算額と請求額を決める根拠になる
- 単位・端数・休憩・時間外など「何を稼働に数えるか」を参画前に確かめる
- 毎日記録し、月末に集計して、期限までに現場の確認を受けて出す
- 実際に働いた時間を理由なく削るよう求められたら、根拠を確認する
:::

## よくある質問

### 稼働報告書の書式は自分で作ってもよいですか？

発注側やエージェントから書式が指定されていればそれを使います。指定がない直接契約では、自分で作ってもかまいません。その場合も、日付・開始と終了・休憩・稼働時間・作業内容・合計の欄を設け、時間の単位や休憩の扱いを相手と合わせておきます。

### 精算幅の下限に届かない月は、少し多めに書いてもよいですか？

実際と違う時間を書くことは避けてください。報告は精算の根拠であり、事実と違う報告は信頼を損ない、トラブルの原因にもなります。下限に届かない月が続きそうなときは、休みの予定や稼働の見通しを早めに共有し、精算の扱いを相談するのが筋です。

### 作業内容はどこまで詳しく書くべきですか？

その日に何を進めたかが、確認する人に伝わる程度で十分です。機能名や工程名で書き、顧客の情報や社内の機密にあたる内容は避けます。時間が多かった日や、予定外の対応をした日は、理由を一言添えると承認を受けやすくなります。
